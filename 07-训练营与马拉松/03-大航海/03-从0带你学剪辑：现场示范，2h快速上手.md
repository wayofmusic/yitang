# **第4关：追求无限进步**

**在这里，给大家分享3个未来可能用到的小技巧。**

1. 将要压字的视频，复制一份，轨道对齐。
2. 点击上方的视频，右键，分离音频，删掉音频。
3. 点击上方的视频，抠像-智能抠像。
4. 新建文本，输入「关键词」，比如“必修课”。字体选择「优设标题」，白色，勾选阴影。根据画面缩放至合适大小。
5. 把文本移到两个视频轨道之间，就完成啦！

> 使用场景：一个人分饰两角/让对话更加简明有趣

1. 复制视频，两个轨道。
2. 两个视频缩放至50%，对齐。
3. A视频说话，B视频定格帧+滤镜搜索“布兰卡”，拖拽到视频上
4. 反之同理

> 适用场景：中长视频，增加观众耐心

1. **黑条：**新建文本，空格代替文字。勾选背景，比如黑色。就成了一个黑条。移动到合适位置。
2. **黄条：**相同的办法创建一个黄条。
3. **进度：**新建字幕，写上不同进度的关键词。中间用竖线隔开。放到最上方。
4. **开头关键帧：**在视频开头，把黄条拉到最左侧（刚好在画面外），打上位置的关键帧。
5. **过程关键帧：**当时间线走到相应位置，不断给黄条打位置关键帧 。使之和进度重叠。
6. **结尾关键帧：**一直到最后视频结束，黄条彻底覆盖黑条，打上最后的关键帧。
