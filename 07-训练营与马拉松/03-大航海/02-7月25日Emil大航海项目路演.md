# 背景与目标

## 起点：阶段性0起点

大家好，我是 Emil。

在座各位，AI 这一波你们从什么时候开始跟的？去年就上车，还是今年才觉得"我得补课"？——我属于后者。

去年龙虾推出来后，Q4特别忙，没有跟进。春节前后看一堂那场直播，加大航海推出，才发现自己落了很多功课，所以赶紧就报名大航海了。今天和大家汇报下阶段性进展

## 一句话介绍业务：培训行业的“精品店”

- **基础业务：**我们的核心业务，是给企业客户做**培训和测评**，主打积极心理学方向。其中领导力是我们其中一个非常重要的方向
- **业务中的高级货**：和普通培训公司不同，我们还提供这些培训的**认证课**，算细分市场里中高端的"精品专卖店"，有一定知名度
- **客户群：**我们直接培训的客户，基本都是很优秀的企业领导团队，项目里大量定制化访谈要做
- **今日分享聚焦：2B咨询与定制化领导力培训**

## 大航海收获的两个思路：毛选 + 双三角

### **第一条 · 毛选的"抓主要矛盾"。**

用 AI 之前，先逼自己回答一个问题：我业务里最痛的点到底是什么？想清楚，再选工具。绝不能反过来——先拿个工具到处找场景。那是马克吐温说的，有了锤子看什么都是钉子，本末倒置。这条让我每个项目开干前先锁定主要矛盾，以及矛盾里的主要方面。

### **第二条 · 一堂的"双三角"。**

一堂把 AI 时代竞争力拆成两个三角，中间是乘号不是加号。人强，能调教出强的 AI；有了强 AI，又反过来把人托高。任一边为零，整体归零。

- **人的三角**（AI 替代不了）：创造力 / 审美 / 体系
- **AI 的三角**（工具杠杆）：场景 / 基本功 / 数据

## 两条思路叠起来，就是我要用AI处理的两个具体场景：

- **老产品（5B）太消耗心力。** 针对领导团队的一个项目，5B是值得健康团队的五种行为，思路就是先搞定人，再搞定事情。看着框架简单，但是每一个项目里面有大量的信息要消化处理，和找到团队症结。

下面这张图，把老产品（5B）为什么这么消耗心力画了出来——框架看着就五种行为，实际落地每一步都是心力的消耗：**如何消化对方的倾诉，找到项目重点，提供解决方案——————————和医院医生的诊疗过程一样：情绪安抚和理性分析治疗同等重要（“常常安慰，总是帮助，有时治愈” ）**

所以这次大航海，我给自己定了两个目标：

1. **老产品提效（今天讲这个）**

   1. **：**让 5B 交付提效；减少顾问的心力消耗，提升效率；提升对症下药的疗效
   2. 同时把这种方法封装skill给我们的认证顾问，让他们也能用
2. **新产品从 0 到 1**——把积极心理学推成能拿去谈合作的 MVP。**新产品（积极心理学）从 0 长不出来。** 理论非常非常丰富，潜在的重要合作专业也谈了3年了，但怎么从理论变成一门客户愿意买的产品是今年最重要的事情（今天没时间讲）

# **老产品5B提效——**从真实业务到可复用 AI 专家：一个 5B 咨询助理的诞生

## 一、怎么定位这个问题

我没一上来就"做个 AI"。我先问自己三件事：

- **值不值得做成系统？** —— **值得。**同样是"信任 / 冲突 / 承诺 / 负责 / 结果"五件事，每来一个团队都要诊断一遍，望闻问切过程信息过载，非常疲惫。
- **能不能被结构化？** —— **能。**因为我们提供认证课，已经5B 有成熟模型、有测评、有访谈套路、有如何做顾问的现成讲课资料（逐字稿）。
- **最大风险是什么？** —— **AI 瞎编。**顾问还要进行侦探式挑错就太麻烦了。诊断的结论是项目设计的基石，对自己负责，也要对客户负责。

### 结论：需要一个守规矩的5B专业咨询助理
