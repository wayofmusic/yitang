从「难以维系的公益项目」到「可持续助人的社会企业」——为帮助休学孩子所做的商业探索

社会拓展活动：7位伙伴举臂望向城市天际线

**一句话项目介绍**

为厌学休学青少年家庭提供「社会化功能复健」服务。**孩子卡住时（休学 / 厌学 / 情绪崩溃），来「晴空假期」补给一下，再重新出发**。

> 我们不是医院，不是培训机构，是成长路上的**补给站**——用温养的方法论，把「卡住」的当下先接住，把重新出发的可能性慢慢养回来。

> **大航海三个月目标：**参加大航海之前，专业有底气，商业没章法。这三个月聚焦三个目标——① 跑通获客转化模型；②把依赖个人经验的服务变成可复制的标准化体系 ③ 验证单店能否赚钱，固盈利化模型。三个月走下来，三个问题都有了答案。

三条航线与三大卡点

## 一、市场机会：一个正在爆发却被忽略的千亿缺口

- 根据《2025中国精神心理健康蓝皮书》，全国18岁以下青少年存在抑郁问题的约**2800万**
- 清华大学彭凯平教授在第四届青少年心理安全论坛公布：12-18岁青少年中**37.2%**存在不同程度心理问题
- 全国中小学生休学率五年暴增**240%**，中学生厌学率高达**30%**——每3个中学生就有1人对学习失去兴趣
- 中国心理健康市场2026年预计接近**2000亿元**，而休学厌学这个细分赛道几乎**没有成熟的标准化服务供给**

**家长感受到的是：**孩子不出门、不社交、日夜颠倒，整个家被拖入深渊。他们要的不是一张心理咨询处方，是孩子能变好的可能性。

**供给端的空白：**全国仅约**25个**面向休学厌学青少年的社区基地，几乎都高度依赖创始人个人经验，没有一家形成了可脱离个人独立运作的系统化方案。

# 二、我们的发现：社会功能的修复是重点

从2024年到现在，两年来我们持续跟家长深度互动，结合实际服务的案例反复做了深度访谈验证。反复出现一个发现——**80%的家长最焦虑的不是「孩子有心理疾病」，而是「孩子回不到正常生活了」。**

孩子真正缺的不是治疗，是**社会化能力的修复**。为此，我们构建了**「社会化能力金字塔模型」**：

金字塔把孩子的社会化能力分成四个层次，层层递进，不可跳跃：

社会化能力金字塔模型

三个核心逻辑：**底层是根基**；**层层递进不可跳跃**；**上下互动动态平衡**。

同一个「厌学」症状，卡住的位置可能完全不同——底层自我价值崩塌，还是顶层意义缺失？这正是家长和学校最需要的：不是笼统说「这孩子有问题」，我们可以分析出孩子问题卡在哪一层、怎么帮，我们的服务体系也基于这个基础模型进行设计和构建。

**一句话定位：**晴空假期——青少年成长补给站。孩子卡住时，来补给一下，再重新出发。

**投资人关心的是：这东西能不能脱离创始人独立运作？能不能规模化复制？**

**家长关心的是：把孩子交给你们，到底会发生什么？安全吗？**

我们不是医院，不是培训机构，是介于家庭、学校、虚拟网络社交空间之外的**「第四空间」**。打个比方——传统心理咨询就像老中医看诊，医生没个十年的经验很难有效解决问题。而现在阶段资深的心理医生和咨询师都不足。我们晴空做的是把打造一套结构化的场景，把服务变成相对标准化的模块，让这个项目通过一些有爱心的社工、和普通心理咨询师通过我们的模式，参与就能有很好的效果。

**于是我们开始建构这三样东西：**

|  | 产品 | 解决什么问题 |
|-|-|-|
| **1** | **评估工具**
社会化能力金字塔 | 精准定位孩子卡在哪一层。**对家长：**不再笼统说「孩子有问题」，而是明确告诉你卡在哪、为什么卡、从哪开始帮。**对投资人：**这是标准化入口，确保每个孩子进来都有科学评估，而非凭感觉。 |
| **2** | **操作手册**
七卷三十章 | 从孩子进项目到最终回归，有哪些环节、怎么做，全部标准化。**对家长：**任何一位受过基础训练的老师，按照手册就能帮你孩子从「出不了门」一步步走回正常生活。**对投资人：**这意味着不依赖顶尖专家也能保证服务品质——复制的基础。 |
| **3** | **安全机制**
三级预警系统 | 确保过程中孩子安全。**对家长：**底线保障，零极端事件。**对投资人：**风险可控，运营以来零上访、零纠纷。 |

**核心差异化：系统驱动，而非专家驱动。**我们的使命，不是通过这个项目去挖掘更多的专业心理咨询师来做这个工作，而是构建一套系统——让基础的心理咨询师和社会工作师协同，共同解决问题。中国心理健康人才缺口太大，不能指望每个机构都找到顶尖专家。真正的解法，是用系统把普通人的能力放大。

# 四、验证过程：假设驱动的科学方法论

大航海评判的核心标准是：**假设-实验-数据的严谨逻辑链**。这三个月我们应用一堂课程的方法论，从凭直觉做事的公益人，转变为先提假设、再做实验、最后看数据。12周时间，跑了三阶段验证——一共验证五个假设，推翻三个假设，每一个判断都有证据支撑。

80%家长首选回归正常生活 |

## 4.2 三个被推翻的假设——真金白银的教训

公益讲座获客漏斗

获客渠道效率对比

> **假设X1：免费公益活动转化率高** → 100个公益讲座家长只转化1个（约1%）。免费吸引的是好奇型非刚需型，配合度极低。**认知更新：**获客效率的核心不是流量大小，是信任结构的本质不同。倒逼我们转向B端学校获客，效率提升15倍。

> **假设X2：资深心理咨询师愿意输出经验实现标准化** → 资深心理咨询师不愿意被AI萃取、不愿被复制。**认知更新：**不能依赖萃取专家经验，要自建标准化体系，让普通社工也能按体系运作。

> **假设X3：先做标准化再复制** → **认知更新：**先低成本验证再标准化，小步快跑、跑通即固化。

## 5.2 服务成效

- 迄今累计服务**41组家庭**，约28名青少年完成回归衔接，复学率**70%**

# 六、单店模型与规模化路径

**投资人最关心的三个问题：能不能赚钱？能不能复制？什么时候能看到回报？**

## 6.1 单店盈利模型

| 指标 | 数据 | 说明 |
|-|-|-|
| 单客月综合收入 | **7,000-10,000元** | 基础托管6,600元+咨询追加+餐费 |
| 8人标准班月利润（合理档） | **约+10,070元** | 含政府场地补贴3,000元 |
| 盈亏平衡线 | **5-6人** | 现阶段基本维持在4-6人之间 |
| 多招1人边际贡献 | **约+6,900元/月** | 最高效的利润杠杆 |
| 单学员全周期净利润 | **约12,525元** | 平均停留5个月 |

**关键发现：定价不是问题，获客才是。**三阶梯定价策略：体验（1,150元/周）→ 适应（约9,900元/首月）→ 稳定（7,200-7,500元/月续费）。

# 七、晴空的认知分享

> **有些孩子停下来了。**
> 就像我们成年人工作不开心后的辞职，就像旅途中的暂停，他们不是叛逆，是歇脚。
> 他们不需要被修理，需要被温养。
> —— 这句话重构了整个团队对服务对象的定义，也让我们敢对家长说：我们先接住，再谈改变。

一个妈妈说：我以为我在救他，后来才发现，是他救了我。他让我停下来，看见自己。

孩子原话：妈妈，你能不能别再盯着我了，我真的喘不过气。

## 方法复用：哪些经验可供其他项目参考

以下三条方法不仅适用于晴空，也可供其他社会企业或早期项目参考：

- **假设驱动比经验驱动更可靠。**以前凭直觉做判断，现在先提假设、再做实验、最后看数据。这套方法任何项目都能用——把模糊的「我觉得」变成可验证的假设，用最小成本试错。
- **信任结构比流量大小更重要。**与其广撒网100人转化1个，不如找信任节点精准转介26人转化4个。这个逻辑对任何B端合作获客的项目都适用——找到你的「老师」角色。
- **先验证再标准化，小步快跑。**不要等完美了再出手，先低成本跑通，跑通即固化。这套「验证-固化-复制」的节奏，适合所有需要规模化的服务型项目。
