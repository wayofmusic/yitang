# 3.学习新闻体后

**2025年2月**先不管内容如何，先**验证新闻体这个表达方式，观众接不接受？**

这个时候我的**3.0短视频内容公式**：

**标题：新闻体表达方式：主题+内容+评论（变化）**

封面：最有特色，有食欲的一张封面（不变）

内容：食材的从原材料展示到成品的过程（不变）

**背景音乐：新闻的背景音乐（新增）**

**标题：新闻体表达方式：主题+内容+评论（不变）**

**封面：最有特色，有食欲的一张封面（不变）**

# **4.复盘，看对标账号，看最佳实践后**

a、容易爆的视频共同点是什么，可以复制吗？

b、我需要输出什么样的内容，可以像美团点评一样引流到店？

1、确定爆款的框架，先拆已经有的素材，先把平台推荐机制弄明白：

同一款内容视频号爆了2次，抖音也爆了

共同点：

糖粉肉串内容非常奇特，所以换了个封面一样爆，背后的逻辑是**引发观众的好奇心的内容，容易获得用户停留，得到平台推荐。**

2、拆前5播放量的特点

共同点：

1、**点赞，转发，推荐，评论的数值比较高**，内容需要引导观众产生这些动作

2、播放第一的视频有话题，话题容易引发评论。（不同地方这个瓜的叫法不一样，所以引发了评论的话题）

这是一条美食类短视频的内容截图，视频主题为红河烤瓜，文字信息显示该烤瓜为围火烧豆腐店现切现烤，口感脆甜像水果，每天都要卖断货，网友评价“一口入魂！这瓜甜得不像地球产物”，话题标签包含#昆明#云南美食#小吃#围火烧豆腐#丰收瓜#一堂大航海精选等。视频播放量达10.7万次，数据面板中红框标注的互动数据清晰可见：对应点赞数为238，转发数为469，爱心数为139，评论数为170，这些高互动数值也契合前文提到的高播放量视频的特点。

3、看平台推荐的对标账号，平台给我的账号标签打是美食类的推荐，所以对标的是美食博主。缺乏审美继续去刷视频，拉个群收集好的短视频，用自己的号刷一堂的，大航海同学的，亦菲老师的**（去找新的表达形式）**，新开一个号刷美食类的**（看美食账号的审美）**。

**但是我不是美食博主啊，新闻体怎么转化，这个场景没有找到转化的切入点。**

找对标账号，看看最佳实践。

一个本地的边境民族菜系中餐馆，每天拍摄店里发生的各种内容，真实的故事。

关键点：幽默的介绍，非常有**特色**菜品**（突出卖点）**，**输出个人观点**，展示菜品的制作过程

一家本地中餐馆，十几家连锁餐饮，主打滇系菜系，内容为大厨介绍各个菜品怎么做的，**让人馋哭（转化率：动力）。**

关键点：**方言（体现地道），做菜，吃东西的画面和声音（引起观众食欲）**

# 5.不断提假设，验证假设，复盘

提高生产效率

用飞书AI生产文案，但是自己要有审美，直接照搬肯定会翻车。

这是一组围绕昆明特色烧豆腐小吃的内容列表，每条内容均标注了发布时间，最早为2025年4月8日，最新为2025年4月13日，且全部标注为已声明原创。每条内容都带有“#昆明 #云南美食 #小吃 #围火烧豆腐”的话题标签，并以“围火豆腐+对应食材名称”的形式作为内容标题，如“围火烧豆腐·糖分串”“围火烧豆腐·洋丝瓜”“围火烧豆腐·豆腐小酥”等，部分内容还附带了与标题对应的食材实拍图，各条内容下方分别显示了点赞、评论、转发等互动数据，其中“围火烧豆腐·洋丝瓜”的互动数据相对较高，分别为点赞8、评论12、转发7。

近期流量又起不来了，**重复的内容无法长期保持稳定的流量（又验证一个假设）。**

插曲：从剪一个视频1-2个小时，不断优化剪辑，用重复内容反复剪，达到2个小时剪辑一周的内容，2个小时整理出文案标题内容，一周5个小时准备7条内容。
