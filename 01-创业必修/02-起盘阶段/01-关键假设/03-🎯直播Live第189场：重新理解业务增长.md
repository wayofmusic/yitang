## 第三阶段：加速增长

时间到了2022年年中，这个时候新的问题出现了：**增速放缓，而且是明显下滑。**

我们复盘，发现有两个很严重的问题：

• 随着投放，一次次复投，**获客质量**会出现明显下滑。

• 随着规模，人数越来越多，导致"综合用户质量"比例在持续降低。

具体的表现是，会员数持续增加，但是ROI出现了缓慢的下滑，已经到了临界的线了（综合ROI<1.5甚至1.0），这个长此以往，就很难了。

我们明显感觉到了四个字：**不进则退。**

同样的模型，跑了一年以后，整个的ROI，就出现了非常显著的下滑，怎么办呢？

于是我给团队定了一个大的增长里程碑目标：**1w1w150万。**

 *单月1w人学习，交1w份作业，可规模化收入150万。*

我们开始进行了建模和精细化运营，给每一个核心模块，建立一个业务公式，然后持续提假设打磨和优化：

比如，新人体验营（259复盘营），我们拆成了5个模块，然后一层层分解：

第一层拆解：**复盘营 =  流量 +  运营 + 上课 +  推荐 +  销售**

比如其中的【运营】模块，进行**第二层**拆解：

**运营 = 加微率 x 到课率 x 选课率 x 作业率 x 3次作业率 x 周二到场率**

比如其中的【到课率】，可以进行**第三层**理解：

**到课率 = 预约率 x 到场率 x 讲课90分钟在场率**

比如其中的【预约率】，我们又会展开到**第四层**，理解成三个本质要素：

**预约率 = f（预约动力，预约阻力，预约触点）**

甚至还有**第五层**，某一个动力，某一个阻力的具体假设：

• 比如动力：如何引导用户承诺一致？

• 比如阻力：如何降低没时间的阻力？

这样，我们就把业务分成了5个部分，3-5层，大概100+参数，每个参数都可以提出一堆的假设。比如光围绕如何增加【预约率】，我们提出了一大堆假设：

1. *群里接龙，Truman提（动力+触点）*

2. *预约到课领资料，班班提（动力/无效)*

3. *班主任1v1追预约，参考同行（触点）*

4. *预约文案迭代，常规想法（增加动力）*

5. *伍月班班电话（从人工打到AI打），智钊提（动力+触点）*

6. *Truman视频号视频，雨安提（阻力/触点）*

如果只在第1-2层提假设，往往数量和质量都很一般；

但如果在3-5层提假设的话，就会非常准确、源源不断了....

就这么每周迭代，一路提假设，我们的复盘营一路从2019年底的第一期MVP，一直到2024年的200多期，我们从最早的100人，到300人、500人、1000人，到现在的每周3000-4000人，我们还做过几次万人复盘营。

在大量前辈/头部同行都试错/折戟的渠道，我们陆续跑通了公众号投放，抖音投放和视频号投放。而且在一步步扩张中，保持了ROI的稳定和健康。

 一堂的首单综合ROI在**1.5-2.5**，能支撑一家公司长期健康发展（不依赖红利和融资烧钱）。

我在《转化率认知篇》简单复盘过，“我请客”这个假设的诞生过程。

最开始，我想测试"老客推荐"，各种送课各种送礼物，提了十几轮假设，发现转化率都很差，综合**K<=5%**

 *一堂K的统计口径：推荐来总人数/正常招生总数。*

第二阶段：于是我们开始在复盘里大量验证假设，各种测试，一不小心，遇到了“用内部身份我请客”这个假设，跑了一个MVP，一下子把转化率提到了15%，真香。

第三阶段：我们开始建立了一个公式：

*获客人数 =  推荐成功人数 x  平均推荐人数*

• *成功推荐人数* = 直播UV x  听宣讲留存率 x  报名率 x  转发率

• *平均推荐人数* = 阅读海报扫码率  x  领取课程率 x  加微信率

然后围绕每一个环节的动力/阻力/触点提了大量的假设，把综合K系数，从15%一路提到了40%多，又翻了将近三倍的空间，基本上这个数字就是同行的5-10倍了。

第四阶段，我们又更高一层，把推荐拆成几部分：

*全部推荐获客 = 复盘营推荐 +  会员日常推荐 + 会员周五推荐 + 年度出圈推荐*

然后围绕每一个参数，继续展开二级、三级公式，然后提几十个、上百个优化假设进去，推荐人数从最早的每周300/500/800，到后面的1000\~1500，最近每周有超过2000个体验课新人来自于朋友推荐。

除了复盘营，我请客，很多模块，我们都展开成了公式，进行精细化的运营：*会员粘性运营，马拉松续费运营，1v1销售运营等等。*

这两年，我们围绕着业务公式的各个环节，提了几百个各种各样的假设，随着一个个要素提升，一个个转化率增长，业务也持续获得了增长。

所以，经历了一年多的迭代，我们不止没有ROI显著崩溃，而且还持续提升流量，复购流量，保持了一个持续健康的ROI。

我们从2022年到2023年初，一年多的时间，我们完成了每年从1500万到3000万的增长，也完成了会员破万，团队也到了30人+；

# 背后的方法：一堂增长模型

站在起点，我以为，一堂的增长，就是简单的"不断获客"就行了。但实际情况要远远复杂得多：

• *增长****开始****：找到一个可持续的获客渠道，养活团队。*

• *增长****早期****：建立业务公式，通过多角度+多参数全面拉动增长。*

• *增长****中期****：持续调整、简化、对抗规模不经济，拉升增长。*

而且，不单单要关注内部的牌，还要关注外部的竞争机会、行业窗口期、流量红利等等，综合完成增长决策。

在内部开会或者做推演时候，我特别喜欢做一个头脑实验"死亡原因推演"，曾经罗列过**《一堂的10种死法（商业侧）》。**

如果平行世界里，增长阶段的Truman，因为一些主观或客观的因素，在商业上会有哪些失败呢？

 1. *失败1：规模误判，做不起来，市场空间Max最大2-5kw。*

2. *失败2：无法获客，无法持续、大规模获客。*

3. *失败3：不懂销售，无法构建一个高质量的销售模型。*

4. *失败4：无法复制，过度依赖某一个人/一个资源，无法复制。*

5. *失败5：增长跑偏，目标定歪，指标做大，但没进步，能力缺失。*

6. *失败6：持续下滑，随着人群泛化+课程复制，导致越来越差。*

7. *失败7：财务失败，现金流管理失败，崩掉，无法持续。*

8. *失败8：越大越亏，商业越上规模越亏损，越做模型越差。*

9. *失败9：缺少优势，做了很多客户，但没有形成稀缺优势，一竞争就散架。*

10. *失败10：窗口错失，太慢，失去成为"必修课第一品牌"的机会。*

## 大量增长背后的规律

我们这次磨课过程中，调研了一组一堂的增长中/后期的案例，基本上都是类似的规律，我们找了一个营收过亿的奶茶店，一个爆款消费品，一个冷藏柜的规模增长。

你把这些放一起观察，就会发现一些特别有趣的规律：

**【规律1】**增长阶段，**核心任务的实质是不变的。**

从本质上看，增长的**核心动作**是什么呢？

• 一个词：复制

• 加名词：复制单元模型

这个阶段，人多事杂，各种任务、项目、可能性、外部机会，全部都出现了，一定不能被某一个偶遇的机会带着跑偏。纵然千变万化，我有一定之规。

# 第一周期：获客驱动增长

当你初步验证了商业的单元，初步获得了信心，就可以开始展开你的增长环节了。

 ***底线情况****：初步测试了单元模型，获客成本和渠道，用经验值benchmark来分析。*

***理想情况****：完整测试了单元模型+一条长期可持续的获客渠道。*

第一阶段的核心任务是什么呢？

这个阶段能做的事情非常多，拆业务公式，做品牌，做投放，提转化率，做招聘，找加盟商，优化组织结构，练习基本功，定增长指标.....我该抓什么主要矛盾呢？

## 理解主要矛盾

【划重点💡】一句话主要任务：**找到一个可持续的渠道。**

第一阶段，这时候你刚从单元模型过来，资源很少，收入很少，团队很少，你还没法确定是不是真的跑通了长期一个可持续的商业模式。

直接一点，你还没有度过最艰难的生存期，没办法证明可以持续养活自己。你需要找到一个持续的、相对稳定的获客渠道和模型，可以创造稳定的收入和现金流，完成**商业和渠道的充分匹配**。

• *如果你是知识付费，需要有能力从少量客户，再探索出持续内容-持续卖课的方式；*

• *如果你是线下连锁，需要有能力从一两家店，再成功开出七八家店；*

• *如果你是咨询公司，你需要从朋友推荐的两三个客户，找到一个持续稳定的获客路径；*

• *如果你是ToB SaaS，你需要从历史私域池，找到一个面向公域的持续获线索的方式；*

• *如果你是ToB大客户，你需要有办法复制销售，有能力脱离朋友关系持续拿下新客户；*

• *......*

这个阶段资源少，风险高，模型不成熟，所以要把优势兵力放在渠道、获客和销售上，这是当前最重要、ROI最高的任务。

【思考🙋🏻‍♀️】大家思考一个问题：在业务增长最早的阶段，指标、公式和模型重要吗？必要吗？为什么？

————

我的建议是，你**可以提前做，但是不必要**，因为当你样本量很少，并且获客渠道和销售模型还没确定的时候，你的指标和公式往往也很不靠谱，很难做准确的预测和管理。

在第一周期，我们调研了大量同学，包括我们内部、MBA线下场，还有GONGJIAN小组的案例，我们找到了很多非常典型的试错和失误。

## 见识大量踩坑

**案例1：**有一个一堂同学做**小吃线下培训**，早期的客户一直靠熟人推荐，或者二度人脉的引荐，收入和利润还不错，于是很开心，着手组建团队，开始扩张和增加履约服务。

半年后，发现新客户数量明显下滑，才意识到**熟人的存量被消耗光了**，却并没有找到一个面向公开市场的、可持续的获客方式，而履约和交付团队成本已经很高了，就陷入了一种**非常焦虑的现金流亏损状态。**

**案例2**：有一个一堂同学，**销售大型医疗器械**，单价特别高，售价上千万一台。

第一个订单，依靠的是他与和某三甲医院的强关系，刷脸拿下这家医院约3000万的订单。

俗话说“三年不开张，开张吃三年”。之后想找类似的医院就再也复制不了了，每个单子背后都有错综复杂的关系。

**依赖某一个人的渠道关系**，无法复制，他们的增长就很受限制了。

**案例3**：有个一堂同学曾在国内**某大厂做工业品**。他们在增长早期也出现过严重误判。他们想依托大厂已有的优势资源，主攻电商平台这个新渠道，于是快速组建团队，不到3个月就上架了80个SKU。

结果发现，一是电商平台的销售**GMV贡献低得离谱**，二是主要的采购渠道，居然来自于集团工业品的**大KA客户，比重超过95%。**后来，业务策略不得不重新调整，团队重组，重点推进KA销售。

**案例4**：**一堂早期做的会员服务**，销售会员产品。作为一堂学员也知道，一堂会员产品单价比较低，价格都不超过￥5000。会员服务刚推出，合伙人张磊进行销售。

他每天勤勤恳恳的给学员打电话促转化，一个电话一打就是一个小时，帮助做业务辅导咨询。转化率的确不错，有30%。

光靠张磊一个人做销售，肯定不行啊，那也太费张磊了。

我们成立了销售团队、想复制张磊（业务专家）的时候，**发现复制不了**。首先别说市面上基本找不到能够辅导学员业务的销售专家，即便找到了，**一堂低客单价的模型也支撑不了专家的电销**，单元模型跑不通。

背后原因就是，低客单价产品**不适合**用电话进行非标的专家销售，这是渠道错配。

**案例5**：有同学做**智能扫码枪**，打算采用渠道推广。

结果发现，渠道拓展特别困难。复盘之后发现，没有考虑到**业务的毛利较低**的情况，给渠道的利润过低，所以**渠道拓展严重受挫**。

**案例6**：有同学做的是**给私立医院送餐**的业务，他们想拓展到公立医院。

结果发现，很难进入公立医院。原因是，已有的销售团队**无法打通公立医院的关键KP**（Key Person），销售能力不匹配。**最终业务增长严重受损**。

**案例7**：有位一堂同学，原先是西装裁缝，**转型做了西装上门定制公司**。他会亲自上门免费帮忙客户量体获客，非常擅长量体和专业沟通，但并不擅长做销售，导致转化率和复购很差。

即便想他复制销售团队，找了专家型的裁缝，发现他们也都不擅长做销售，没法根据用户的**职业、场景、体型、脸型、性格、肤色做整体形象和穿搭建议，更没法提供情绪价值**。

**因为销售能力不行**，导致上门转化能力很差，增长明显低于同行。

ok，我们阶段性总结一下：

这个阶段，不管是非标渠道、渠道错配还是销售太弱，结果就是，在增长早期你会发现：**很难复制。**

你本身有持续扩大规模的预期，但因为渠道打不开，或者无法构建起能力，导致很难持续复制，只能服务几个客户，做一两家店，做一个很小的规模。

*说明：这个跟生意类型和增长意图相关，如果本身就是做个一人公司，或者阶段性生意，或者单店，没有增长复制的预期，好好经营，收好现金流，也挺好的。*

# 第二周期：系统驱动增长

## 理解主要矛盾

【划重点💡】一句话主要任务：**构建一个稳定的增长模型。**

第一个阶段，你可以靠获客和销售粗暴硬拉，粗放销售，粗糙投放，粗线条转化，问题不大。但是到了这个阶段，等你真正开始规模拉大，仍旧粗放增长，大概率会遭遇意外的困苦:(

明明我和之前一样，人还更多更专业了，为什么模型**一直在下滑**呢？

这个时候，你有了几家店，有了十几个人，有了稳定的客户，你发现光靠"**复制获客**"这个增长引擎已经ROI不是最高了，轻则单元模型变差，利润下滑，重则立刻进入亏损，遭遇现金流崩溃的现实危机。

【思考🙋🏻‍♀️】大家思考一个问题：在业务增长的目标下（规模/收入/利润/市占率），除了获新客来带动增长，还有什么方式能获得增长？

————

本质上，围绕**业务目标**，展开的**业务公式**，每一个业务**参数的进步**，都可以贡献业绩、提升业务增长。

但是现实中，大量业务意识不够，没有及时启动第二增长周期的“增长引擎”，导致交了不少的学费。

## 见识大量踩坑

**案例1**：这个案例来自徐剑大哥的复盘，他的业务是**ToB的SaaS业务**。某个阶段，他们把经销商数量的快速增加作为“臻票云”增长的重要目标（占坑思维）。

结果是，以低门槛签回来不少能力弱、意愿差的经销商，但这些经销商**对于终端用户的广泛覆盖根本起不到决定性的作用**。

事后复盘，这个举措浪费了他们大量的渠道开发资源、客户成功部门的资源，从时间窗口角度来看，也对公司的长期战略产生了一定的负面影响。

这次踩坑，让他们更加清晰地确定了业务的阶段性目标本质，是单位时间里获取的终端用户数量，而不仅仅是经销商数量。

**案例2：**这个案例是在一堂创办之前，我在以太曾经试水的一个项目，**创业者社群**。项目当时的负责人**一直坚信：活跃度 = 商业变现价值，**把互动人数作为增长重要目标。

这么做的结果是，**社群活跃度确实很高**，周活跃占比30%（群发言/报名听分享），同时线索到进群的拉新转化率很高，能达到15-20%，**社群人数也快速增长**，拉到了8000人，后面很快又到了1w，2w。

但是，随着团队扩张，整个运营姿势快速变形，比如用发红包、优化海报，鼓励"有闲时间"的人在群里灌水等方式来提升活跃度。

**运营数据看似持续在增长，但产品价值在快速被削弱**，本来就不够强的社群价值，一步步变得单薄，甚至开始了劣币驱逐良币，灌水横行，优秀闭嘴。

后来我在《我用一堂做一堂》里复盘也提到，**把新业务当做一个确定性的『运营KPI』来做了，导致背道而驰，朝着反方向越跑越远。**

**案例3：**这个案例来自于某个知名**线下连锁大卖场**，收入减少，出现亏损。

管理层非常焦虑，给每个运营负责人都定下以**"增加收入"为KPI的指标来推动增长**。可以打折，设置好折扣点红线。

导致团队做了**很多平进平出、不盈利的非核心业务**，还请了一堆临时工做促销，但没有成果。这次踩坑，让他们清晰意识到，**增长KPI设置偏差**，会导致业务团队动作变形。

**案例4**：这个案例来自于一堂学员，他做**大型医疗设备的租赁**，通过老板刷脸的关系，让设备进入了好几家医院，以收取租金的方式维持生意，利润不错。

后来他们开始招销售团队，努力拓展新的医院，过了一年后以外的发现：新签约的医院，几个月后，开始出现不付租金的情况，造成了大范围的违约。

 最早一批客户明明好好的，后面扩张以后，就出问题了。

本质上，问题出在哪儿了呢？

这位同学在一开始做销售的时候，就没有预判好可能出现的违约情况，**没有对可能出现的违约进行建模**。导致违约造成了公司的现金流问题，出现左右为难的情况。

**案例5**：这个案例来自陈先敏，他创办了一个**新国潮汉堡**品牌。他们采取的是连锁加盟的形式，要说只开几十家店还好，一家一家去考察点位就好了，人力物力投入，勉强能铺得开。但是**如果想开上百家店，上千家店呢？**

陈先敏在增长早期，就踩了一个坑。最早的加盟选址，是他和他的2个合伙人，亲自去实地看。

结果三个人根本跑不过来，且不说差旅成本很高，他们三个是创业团队最重要的三个人，**时间成本、机会成本都很高**。

而且随着咨询量的增加，异地加盟商的增加，带来很多问题：**加盟商流失、好点位流失，根本无法持续**。

一直到后来，他们学习最佳实践，**建立了自己的一个工业化选址模型，最后才实现加盟商的加速增长。**

**案例6：**这个案例来自吉春宇，做的**代理记账业务**，简单说就是给一些中小企业提供工商注册，记账的业务。他们很关键的获客方式，是在天猫淘宝这样的电商平台上，用户的常见路径是：**用户看详情页 - 咨询客服 - 下单。**

这里面非常前置的转化率就是**咨询转化率**，他一开始只是抄同行常规的做法，拿到的结果也基本和同行一样不够好，**咨询转化率只有5%**。

虽然知道这个转化率很关键，**具体要怎么提升却没什么想法，提不出假设**。最后他应用**动力阻力触点**提出了大量的假设并进行验证。

目前咨询转化率已经提升到了22%，是同行的4倍多，首单ROI已经达到了3，已经是行业的比较头部水平。

**案例7**：这个案例来自于一堂转化率训战营的同学汇报案例。她是**知名AI学习机的区域负责人**，管着大湾区好几十家直营门店。

她说，跟客户接触，就只有让客户来到门店试用这一条路径，如下：

 *引流客户——来到门店——产品试用——销售介绍——客户离开*

她说，客户什么也没带走，什么也没留下。她之前一直发愁于转化率那么低，经过学习，感觉又后悔又“羞耻”。

他们整个团队，包括她自己做了几十年的老销售，没有假设意识，一个新假设都没有提。没有假设就没有实验，就不可能提升转化率。

ok，我们阶段总结一下：

这个阶段，需要启动**第二增长引擎**进行**建模迭代优化**了，如果忽略这个工作，还在粗放的、强行的、猛烈的获客、复制、销售，可能会导致一个非常悲惨的结果：**现金流崩。**

这种故事，我真的在一堂听过很多很多次（尤其是MBA案例大爆炸）：原本一个不错的商业模型，早期从0到10的探索很谨慎，利润各方面都不错，然后开始疯狂复制，执行力拉满。

然后过了N个月后发现，账上快速亏损，现金流几近崩溃，一个本来不错的业务，明明利润率很好，为什么突然就制造了巨大的危机了呢？

*说明：复制早期单元模型会变差这是个经验观察，不是绝对值啊，有些业务or有些情况（尤其是红利）可能会变好，这个得具体问题具体分析。*

**通常来讲，你需要围绕三个环节来解题：**

• **目标：**最顶层的增长目标和指标（北极星）

• **假设：**不断提出优化想法，打磨和升级（假设驱动）

找到一个指标，用来衡量业务增长进展，难么？

————

我们发现大家习惯性很容易就定一个指标：

1. *收入指标：用收入or利润规模，作为核心指标。*

2. *会计指标：用传统会计指标，早期往往不好用。*

3. *最大数字：用最漂亮的数字，作为核心指标。*

定一个高价值的指标非常难，我在各个课程上，都会强调这件事。《增长黑客》里叫做北极星指标，有些模型里叫"顶层指标"，"核心指标"，我习惯性叫"第一指标"，都是类似的。

这个指标一旦确立，就像北极星一样，高高闪耀在天空中，指引着全公司上上下下，向着同一个方向迈进。

警惕虚荣指标，什么意思呢？

有一些指标，很漂亮，很开心，但并不能体现产品竞争力，增长进展，不能体现真实的产品进展的指标。

 *虚荣指标是一些表面指标。无法为你的下一步行动提供任何指导。*

说人话就是：听着非常好听、振奋人心，但是没法指导内部做增长决策的指标。

>

>
> a. **理解：是支持性、不会出错的要素。**    #跟上节奏，不能掉链子

## 理解主要矛盾

【划重点💡】一句话主要任务：**持续对抗规模不经济，来拉动增长。**

不只是获客，也不只是系统优化，而是要靠调整优化模型，来实现对抗了。

【思考🙋🏻‍♀️】大家思考一个问题：在业务增长的目标下（规模/收入/利润/市占率），除了获新客来带动增长，除了系统优化，还有什么方式能获得增长？

## 见识大量踩坑

**案例1**：这个案例来自赵耀军，搞砸之夜案主。他是**给幼儿园提供监控系统**的。

他最早2014年开始入局，复制业务很容易，在辽宁省全省迅速打进了14个地市的幼儿园市场，逐渐覆盖了**1000多所幼儿园**，业务进入一个稳扎稳打的状态，可以加速扩张了。

业务到了增长期，就得考虑跑马圈地，和未来壁垒问题了，结果当时他完全没有预判，认为赚多少钱，就做多少扩张，不盲目，不激进，不着急。

结果2018年，互联网公司开始入场。**正规军，来了**。

竞争对手下场、融资很快，2018年就融到D轮1亿美元，进入东北市场。他们扩张速度很快，而且还在不断蚕食赵耀军的市场份额，当年赵耀军一下子就**损失了300家幼儿园**。

后来赵耀军来到一堂学习，才发现当时问题的根源是：**完全忽略了壁垒的构建。**

这个业务的壁垒主要就是**B端的迁移成本**，应该在商业模式跑通以后，尽快增长，尽快签约，尽快用合同锁定幼儿园，这才是他当时最应该做的事情。

**案例2**：这是某位一堂学员的案例，他的产品是**工业测距仪，**属于精密仪器**，**因为质量过硬，产品利润特别高，活得也比较滋润。

跑通单元模型，到了增长阶段，他沉迷于营收和利润不错，**完全没有预判未来的壁垒问题。**因为一号位的预判疏漏，招聘销售团队的速度都很慢，没有集中火力去开拓客户。

后来他来一堂学习，跟教练们和组员们一讨论，发现自己差点错过“窗口期”。**他们产品其实有一个壁垒，是“客户的迁移成本”，**当务之急应该是尽可能去开拓更多客户，去抢占市场，跑马圈地。

他回去赶紧搭建团队，集中一切力量开拓市场。

后来果真越来越多的**竞争对手下场**，竞争非常激烈。因为他已经这个细分品类上抢占了自己的"**一席之地"**，即便出现很多强劲对手，他的市场份额没有被蚕食。

访谈的时候，他说自己有些后怕，要是没来一堂，没有构建壁垒抢占市场等一系列动作，但凡动作慢一些，可能他的业务已经不存在了。

**案例3：**这个案例来自程思祺Justin，他做的业务是**做新型涂料业务**，这种涂料可以反复书写和清洗。

业务早期，销售团队粗放管理，责任心强、能力够的好销售，一年能做到300w的业绩，但意识和能力都差点的销售，连自己都养不活，一年能做到十几万都不错了。**GMV一直卡在一两千万上不去**。

后来在学了一堂的科学销售课后**，发现自己的打法太草莽，没模型。**于是开始带着团队，一点一点把公司的线索模型、线索库、销售工具、销售流程、管理系统，全都搭建了起来。

最后因为流程和系统的搭建，让签单能够走工业化流程，也解决了销售复制难的问题，从小白到专家的培养周期大大缩短，年营收从2000w提升到8000w左右。

**案例4：**这个案例来自杜金科，他做的业务是**自助棋牌室加盟业务**。

业务早期，为了和同行一样，想要快速抢市场，不收加盟费，营收主要靠销售固定设备和收取技术服务费（营收的5%）。

同时，他通过探索，找到了几个稳定可复制的获客渠道，又通过各种假设迭代，提升了渠道的转化率，很快就完成了第一波增长，突破了300+门店，市场占有率重庆第一。

但是当他们希望挑战更高的目标，希望突破1000家店的时候，问题来了。

虽然原来的单店模型都不错，回本周期只有12个月，而且持续有技术服务费进账，但是因为**规模增长太快，总部账上依然没有多余现金流，融资又很难，靠原有模型的复制，根本支撑不了下一阶段的扩张。**

最后他们通过一系列ROI的测算和测试，从不收加盟费调整到**收加盟费**，从优先做加盟拓展调整到**优先做地区代理拓展**，缓解了现金流压力，实现了大规模复制，很快达到了1000家店的里程碑。

**案例5**：这个案例来自国内曾经头部的**咖啡连锁品牌**，他们是国内第一批主打现磨咖啡的连锁咖啡馆，为了能够快速占领市场，采用了低门槛加盟的方式进行扩张。

当时，国内的咖啡行业还处于早期阶段，存在大量红利。起初，大多数门店开业后，都很容易就能赚到钱，加上宽松的加盟政策和品牌效应，几年时间内就在全国连锁开了上千家门店。

随着门店数量的不断增加，行业竞争也越来越大，而他们依然持续采用之前相对松散的加盟方式，没有对门店进行精细化管理，出现了一系列的问题。比如，很多加盟商为了降低成本偷工减料，有的还擅自改变了店铺经营内容，**连锁咖啡的品牌形象不断受损，口碑一落千丈。**

在快速增长的过程中，总部**没有及时改变原有的松散模式，忽视了管理机制和标准的建立**，导致门店服务质量参差不齐，消费者体验也越来越差，最终失去了市场竞争力，门店数量也不断减少。

**案例6**：这是来自Amanda的案例，他们是国内最早一批，**做O2O电影票线上选座业务**的公司。公司前后进行了**5轮融资**，总共**融资7.98亿元。**这个案例每个人听完之后都觉得无比惋惜。

到2017年，又融了一大笔钱，又做了：**电影发行、电影投资和影院代运营。**
