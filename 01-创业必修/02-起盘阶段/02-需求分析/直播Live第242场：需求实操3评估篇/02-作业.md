# 内容核心

###  核心心法：一句话定义“需求评估”

**“通过多选项评估，不断对比需求维度，最终形成信心。”**

- **本质：** 需求评估不是“算账”（那太贵太慢），而是**低成本的“生死判”**。
- **作用：** 它是“法官”。在投入开发和设计商业模式前，用定性分析掐死“伪需求”，筛选出“高潜力选手”。
- **原则：**

  1. **多选项：** 必须有3-10个备选项（不同人群/场景/任务的组合）。
  2. **对比：** 没有绝对的好坏，只有相对的优劣。
  3. **维度：** 普遍性 x 频次 x 刚性。
  4. **信心：** 类似于贝叶斯定理，通过信息修正，将直觉转化为科学的信心。

---

###  核心模型：需求评估三角（RFP）

判断一个需求是否成立，必须且只需考察这三个核心维度：

1. **刚性 (Rigidity)：** 多痛？用户愿意付出多少成本（钱/时间/麻烦）？
2. **频次 (Frequency)：** 多久发生一次？是自然发生的节奏。
3. **普遍性 (Prevalence)：** 多少人有这个痛点？决定了天花板。

> **⚠️ 不可能三角：** 现实中极少有“高刚性x高频次x高普遍性”的需求（那是微信/基础设施）。创业者通常要在三者间做平衡和取舍。

---

###   实操进阶：需求评估的三次飞跃

要掌握这套方法，需要经历从“入门”到“高阶”的三个阶段，对应**8个自我修养**。

#### 第一阶段：秩序——从“单点”到“全局”

*拒绝“拍脑袋”和单一维度的直觉判断（如“这太低频了不做”），建立系统分析框架。*

- **自我修养1：坚持全局分析**

  - 单一维度的强弱不能定生死，要看三维综合得分。
  - *案例：* 非洲中餐厅。

    - 大众快餐：普高、频高、刚弱（利润薄）。
    - 高端宴请：刚极强、普低、频低（圈子小）。
    - **最终解：1+1组合。** 大厅做川菜（保流量/普频），包厢做高端（赚利润/刚性）。
- **自我修养2：尽量合理对比**

  - **控制变量法：** 只有用户、场景、行业接近的选项对比才有意义。
  - \*误区：\*拿“喝奶茶”和“上管理课”比刚需，毫无意义。
- **自我修养3：追求平衡和匹配**

  - 承认“错配”是灾难。
  - **高频打低频：** 找死（如上门开锁做补贴大战）。
  - **低频打高频：** 瞎干（如手握高频流量却只做黄页赚小钱）。
  - *策略：* 初创期寻找 **“极高刚性、中高频次、窄普遍性”** 的切口（小众且疼）。

#### 第二阶段：尺子——从“主观”到“客观”

*拒绝“我觉得/我推测”，建立客观的度量衡。*

- **准备动作：**

  - **定性客观化：** 虽不测算具体数字，但必须能证伪（如：大食堂比外卖便宜，是客观事实）。
  - **锁定分析层级：** 聚焦在 **L3/L4 任务层 (JTBD)**。不要停留在“我想做个APP”，也不要泛化到“人都要吃饭”。
- **自我修养4：追求客观的“刚性”**

  - **定义：** 刚性不是痛，是**支付意愿**（金钱、时间、认知成本）。
  - **刚性尺子（从弱到强）：**

    1. 白给也不用 -> 免费才用 -> 收钱也用 -> **加钱抢着用**。
    2. 痒点（虚拟自我）-> 爽点（及时满足）-> 痛点（恐惧）-> **救命稻草**。
  - **调研话术（行为面试法）：**

    - ❌ 别问：“你想要吗？有这个你会用吗？”（这是愿望，会失真）。
    - ✅ 要问：“上次遇到这事你咋办的？花了多少钱/时间？最不满意啥？”（这是事实）。
  - *案例：* 跨境手电筒。户外发烧友（极挑剔/红海）vs 商务送礼（刚需是“体面不出错且能印Logo”/蓝海）。
- **自我修养5：追求客观的“频次”**

  - **定义：** 是**接触节奏**，不是使用时长。
  - **误区：** 把“人工干预（补贴/提醒）”当成了“自然频次”。
  - **频次尺子：**

    1. 一生一次 -> 每年 -> 每月 -> 每周 -> 每天。
    2. 被动高频（付账单） -> 主动高频（刷抖音）。
    3. 可催化（打车） -> **难催化（上门洗车）**。
  - **策略：** 高频做“习惯/流量入口”，低频做“信任/高客单变现”。
- **自我修养6：追求客观的“普遍性”**

  - **定义：** 是真正有痛点的用户**总量**。
  - **误区：** 幸存者偏差（身边朋友都说好 ≠ 市场大）。
  - **普遍性尺子：**

    1. 特定行业 -> 跨行业 -> 全民。
    2. 路边大爷懂 -> 发烧友懂 -> 只有专家懂。
  - **调研策略：**

    - 找**陌生人**随机测试（听懂率、共鸣率）。
    - **走出五环**，去下沉市场，去查百度/微信指数。
  - *警句：* **小众不可怕，可怕的是把小众需求当成大众生意做。**

#### 第三阶段：雷达——从“单次”到“系统”

*面对创新难题，像雷达一样多轮扫描，深挖到最Sharp的点。*

- **自我修养7：多轮JTBD循环探索**

  - 不要满足于第一轮拆解出的选项。如果是创新/难题，需要一轮轮深挖。
  - *流程：* 拆解 -> 评估 -> 不够Sharp -> 再拆解 -> 再评估。
  - *案例：* **挂脖空调（Cici的逆袭）**

    - Round 1: 泛人群（年轻男性） -> 太粗，卖不动。
    - Round 2: 户外场景（徒步/钓鱼/露营） -> 发现徒步登山嫌重、钓鱼有替代方案。
    - Round 3: 锁定“露营” -> 细分为“精致露营”。
    - Round 4: 锁定“都市白领的精致露营” -> 场景细化为：生火（装逼）、搬运（不狼狈）、搭帐篷（从容）、拍照（社交货币）。
    - *结果：* 价格贵3倍却卖爆，因为**刚性**在“社交货币”和“体面”上变得极强。
- **自我修养8：培养最佳实践 Benchmark**

  - 建立“判断基准线”。不仅要内部比，还要跟外部的替代品比。
  - *方法：* 找外部对标（如做露营空调，对标露营KTV、露营投影仪）。
  - *逻辑：* 如果对标物能卖好，且你的需求评估（普/频/刚）得分不低于它，那信心就足了。

---

###   避坑指南

1. **Don't：** 不要把“使用时长”当“频次”（看长视频是低频高时长，看日历是高频低时长）。
2. **Don't：** 不要把“用户愿望”当“刚需”（问过去发生了什么，别问未来想不想）。
3. **Don't：** 不要依赖熟人“夸夸群”（去做陌生人访谈，去算共鸣率）。
4. **Do：** 如果没有信心，请果断**熔断（Kill）**，止损也是成功。
5. **Do：** 控制变量对比，在相似层级（L3/L4任务层）进行比较。

###   总结

需求评估就是为了找到那个**唯一正确的切口。**
**通过** 拆（场景）- 推（JTBD）- 评（RFP三角） 的循环，把模糊的直觉，打磨成客观的、高信心的商业判断。
