# 一堂直播 Live 第 238 场：需求分析实操（拆解篇）核心要点

## 1. 认知基础：为什么要学需求拆解

### 1.1 需求分析的商业价值

- **1.1.1 决策的基础**

  - 需求是商业的起点，支撑一切逻辑基础。
  - 需求错了，后续产品、品牌、营销皆为徒劳。
- **1.1.2 需求探索的三个价值**

  - **价值 1：选择题（低成本试错）**

    - 尽早验证或证伪，不花钱就能拿到答案。
  - **价值 2：设计题（提升决策质量）**

    - 对人群、画像、场景理解越清晰，产品定价、选址等决策质量越高。
  - **价值 3：数学题（形成笃定）**

    - 明确业务天花板空间，管理心态更从容。
- **1.1.3 核心方法论：一堂五步法**

  - 需求 -> 解决方案 -> 商业模式 -> 增长 -> 壁垒。
  - 需求分析的两大关键动作：**拆**（像手术刀一样精准分析）和 **拔**（站在全局视角思考）。

## 2. 基础篇（60分）：剥离出五步法

### 2.1 核心概念：硬剥离（Hard Peeling）

- **2.1.1 常见的误区**

  - 将“需求”与“产品/解决方案”混淆。
  - 错误思维：“我要做一个XX产品”。
- **2.1.2 正确的思维**

  - **JTBD思维 (Jobs to be Done)**

    - 定义：用户不是购买产品，而是“雇用”产品来完成某项任务（进步）。
    - 核心：需求隐藏在挫败感和未完成的任务中，而非口头想要的功能。
    - 案例：用户不想要钻头，只想要墙上的洞。
  - **剥离原则**

    - 提醒自己：你想提供什么不重要，重要的是用户想解决什么具体问题。
    - 认知：用户从来不是铁板一块，可以切开看。

### 2.2 剥离的实操步骤与价值

- **2.2.1 剥离商业最小单元可行性**

  - **单元模型（前三步）**

    - 验证：需求、解决方案、商业模式（单订单/单客户模型）。
    - 目标：验证是否健康、有利润。
  - **增长与复制（后两步）**

    - 验证：复制、扩张、竞争。
- **2.2.2 剥离产品内核**

  - **关键转化测试**

    - 不测试完整商业模式，先测试产品内核（Sharp度）。
    - 指标：复购率、留存率、使用率。
    - 案例：移动充电桩、AI智能工牌（从销售助手转为AI教练）。
- **2.2.3 极致剥离：只验证需求**

  - **极低成本验证**

    - 仅用1%-10%的成本验证客观存在的问题。
    - 案例对比：

      - **版本A（带方案）**：盲人是否买机器狗（验证周期长，成本高）。
      - **版本B（剥离后）**：盲人是否有“在家缺少陪伴/不安全”的问题（验证快，访谈即可）。
  - **案例应用**

    - 宠物寄养柜子 -> 验证“离家无法照顾宠物的痛点”。
    - 醒酒产品 -> 验证“商务喝酒痛苦及付费意愿”。

## 3. 进阶篇（75分）：关键假设与三原则

### 3.1 需求三要素 (USP模型)

- **3.1.1 公式**

  - **Demand = User (用户) × Situation (场景) × Problem (问题)**
- **3.1.2 要素解析**

  - **User (用户)**：需求的载体，具备支付能力/决策权。
  - **Situation (场景)**：需求的触发器，特定时空环境。
  - **Problem (问题)**：需求的原动力，现实与预期的差距（GAP）。
- **3.1.3 动态变化**

  - 任何一个要素改变，都是一个全新的需求定义。
  - 案例：AI陪伴（情感伴侣 vs 情绪疏导 vs 健康冥想）。

### 3.2 需求拆解的三原则 (关键假设)

- **3.2.1 原则 1：向上支撑原则**

  - **核心逻辑**：拆分后的细分市场，能否支撑长期的商业预期/天花板。
  - **反面案例**：

    - 酒店建材业务：拆分到最后发现当地市场无法支撑第二曲线。
    - AI算力项目：砍掉大企业（自建）、砍掉中小企业（无能力），剩下市场极小。
  - **判断标准**：根据预期（1-4/5-6/6-7）决定需求的规模要求。
- **3.2.2 原则 2：内部证伪原则**

  - **核心逻辑**：拆分出的需求是否一致、矛盾，或者必须取舍。
  - **操作方法**：

    - 拆到证伪：发现需求不存在或伪需求。
    - 拆到高效：发现1/2层不够痛，继续细分直到Sharp。
  - **案例**：

    - 育儿课程多平台分发（需求矛盾）。
    - 可视化空气炸锅（从全人群拆到独居/合租青年，转化率提升）。
- **3.2.3 原则 3：横向自检原则**

  - **核心逻辑**：需求与其他四步（产品、商模、增长、壁垒）是否匹配 (Fit)。
  - **常见硬伤**：

    - **用户-商模不匹配**：新人直播AI助手（新人期短，不适合续费制）。
    - **用户-产品不匹配**：高端防脱洗发水（价格高对标医疗，但信任度低）。
    - **需求-壁垒匹配**：物联网芯片（选中小客户构建转换成本壁垒）。

### 3.3 警惕虚假拆解

- **3.3.1 伪取舍**

  - 现象：画布填满，但没砍掉任何人（如“中国大陆不是我的客户”）。
- **3.3.2 真正的战略取舍**

  - 定义：在“正面”和“反面”都很正确的情况下，做艰难选择。
  - 标准：看上去“我应该服务”甚至“很赚钱”，但为了战略聚焦依然舍弃。

## 4. 高阶篇（85分）：三维拆解实操 (USP拆解)

### 4.1 维度 1：专业拆解“用户” (User)

- **4.1.1 核心目标**

  - 找到最重要的 3-5 刀，切分出核心客群。
- **4.1.2 角色分离处理**

  - 场景：使用者、决策者、购买者分离（如2B、送礼、家庭）。
  - 策略：抓主要矛盾，分析关键假设和风险最大的一方。
- **4.1.3 2C 用户拆解维度 (盲区清单)**

  - **L1 人口统计**：年龄、地域、类型（租房/自有）。
  - **L2 角色阶段**：家庭结构、社会角色（宝妈/铲屎官）。
  - **L3 能力状态**：健康程度、能力水平（小白/专家）。
  - **L4 行为习惯**：生活、工作、消费习惯。
  - **L5 价值观念**：颜值、效率、性价比、极简。
  - *案例*：咖啡含片（司机/网吧/少上厕所）；无人网球馆（小白接不住球 vs 专业难进步）。
- **4.1.4 2B 用户拆解维度**

  - **L1 业务类型**：2B/2C/2G、线上/线下。
  - **L2 规模性质**：市场份额、营收、员工数、央企/私企。
  - **L3 标准程度**：数字化水平、供应链标准。
  - **L4 决策文化**：流程复杂度、决策角色、切换难度。
  - *案例*：发票SaaS（切入生活服务类线下商户）；通信模组（切入中小客户）。

### 4.2 维度 2：专业拆解“场景” (Situation)

- **4.2.1 定义**

  - 相对稳定的用户发生具体问题的一个场合和触发器。
- **4.2.2 2C 场景拆解维度**

  - **L1 时间周期**：早晚、工作日/周末、碎片时间。
  - **L2 空间环境**：固定地点、路上、社交状态（独处/聚会）。
  - **L3 身心状态**：负向情绪（孤独/焦虑）、正向情绪、身体状态。
  - **L4 特别时刻**：求职、团建、送礼、升学。
  - **L5 稀缺窗口**：重大决策、意外偶发（摔倒）、关键前后（刚回国）。
  - *案例*：高端挂脖空调（精致露营-烧烤/搭帐篷）；宠物殡葬（家中惊慌时刻）。
- **4.2.3 2B 场景拆解维度**

  - **L1 流程环节**：生产、采购、销售、售后。
  - **L2 操作地点**：车间、办公室、户外、远程。
  - **L3 人物协作**：跨部门、上下级、外部合作。
  - **L4 时间节点**：经营节点（起步/扩张）、事件节点（新品上线）。
  - **L5 重大事件**：融资、并购、合规检查、危机公关。
  - *案例*：锐捷网络（医院移动查房-无缝漫游）；Pad班（教室高密度并发）。

### 4.3 维度 3：专业拆解“问题” (Problem)

- **4.3.1 定义**

  - 预期和现实的差距（GAP）。
  - 必须基于“现有解决方案”来评估问题（非真空讨论）。
- **4.3.2 2C 问题拆解维度**

  - **L1 上层功能**：缺少信息、工具、能力。
  - **L2 深度体验**：更便宜、更快、更简单、更舒适、更有趣。
  - **L3 上层社交**：维持体面、情感陪伴、社交货币。
  - **L4 深度情感**：人设塑造、自我内心（自律/奖励）、自我实现。
  - **L5 转化成钱**：赚钱、省钱。
  - *案例*：滴滴小巴（比快车便宜一半，接受拼车）；女生性教育礼盒（送礼者的难以启齿）。
- **4.3.3 2B 问题拆解维度**

  - **L1 业务问题**：增长瓶颈、成本过高、效率低下、客户流失。
  - **L2 技术问题**：系统落后、数据不准、技术债务。
  - **L3 管理问题**：协作困难、人才短缺、流程冗长。
  - **L4 战略问题**：方向模糊、竞争压力、创新乏力。
  - **L5 风险管控**：合规风险、税务法务、数据泄露。
  - *案例*：公园自动驾驶游艇（大型景区-降低管理成本 vs 小型景区-直接创收）。

## 5. 总结与应用

- **USP拆解小抄**：包含ToC和ToB的用户、场景、问题详细维度表。
- **目的**：作为“武器库”，帮助快速排除80%的坏需求，尽早失败在纸面上。
