# **【一堂 Live 236：重新理解机会】课程结构拆解**

- **课程导入与核心问题**

  - **为什么要学“商业预判”？**

    - **普遍创业者的现状（问题）**

      - **预判工作做得太弱**

        - **表现一：人云亦云，看到赚钱模式就 all in。**
        - **表现二：不做调研，主流模式都没看过就开干。**
        - **表现三：思考简单，靠热情在一个错的项目上押注。**
      - **代价惨重**

        - **赌上10年时间和毕生积蓄，只为学一个明眼人早就看穿的道理。**
        - **段位差导致看不懂问题，只能靠烧钱换教训。**
    - **两种典型的创业者画像对比（建立审美）**

      - **P 型创业者 (Passion/激情型)**

        - **工作方式：先干再说。想法来自个人愿景或头脑一热，直接组团队开干，问题留到后面解决。**
        - **结果：大概率失败。过程中遇到各种意外，信心受挫，项目在跌跌撞撞中死掉。**
      - **L 型创业者 (Logical/逻辑型)**

        - **工作方式：先想再说。把创业当研究课题，系统性搜集信息、做推导，在动手前就规避了七八成的大坑。**
        - **结果：成功率高得多。因为商业故事推演充分，资本市场认可度高，项目发展快，困难也在意料之中。**
  - **课程整体框架介绍**

    - **第一部分：建立审美**

      - **通过案例，让大家建立体感和见识。**

        - **知道什么是糟糕的预判，什么是优秀的预判。**
    - **第二部分：背后规律**

      - **系统性地讲解如何开展预判工作。**

        - **会从心态、原则、方法论三个层面，给出一个完整框架。**
    - **第三部分：核心方法**

      - **展开讲解预判的每个步骤该如何思考。**

        - **给出关键的策略、原则和方法。**
    - **第四部分：重新理解**

      - **探讨“预判”工作的本质。**

        - **解释为什么“预判比一堂五步法重要数倍”的底层逻辑。**
- **核心预判框架：一个通用策略（15字心法）**

  - **第一步：主动想终局**

    - **核心是形成一个“模糊的预期”**

      - **为什么要先想终局？**

        - **因为终局预期不同，项目就完全不同。看似同一个项目，小作坊和大公司的打法天差地别。**
        - **避免“MBA私董会”式的混乱。先对齐目标，才能有效讨论商业模式，大幅提升决策效率。**
      - **如何定义终局？一堂商业机会预判 · 终局光谱图**

        - **光谱图的7个质变点：副业 -> 个体 -> 单体 -> 小规模 -> 体系增长 -> 细分头部 -> 做大上市。**
        - **光谱图的使用方法：不是选一个点，而是选一个“保 A 争 B”的区间。**
        - **这是一个关于未来5-10年的追求，而不是评价现在。**
    - **实战演练：3个案例的终局定位**

      - **案例1 - 陪诊业务**

        - **终局定位：“保2争4”。希望能多赚钱，保障家庭生活稳定，最后做成10-20人的公司。**
      - **案例2 - 回老家开咖啡馆**

        - **终局定位：“保3争5”。希望能养活自己，多赚点钱，长期能复制3-5家店，追求规模化。**
      - **案例3 - AI时间管理APP**

        - **终局定位：“保4争6”。期待做出行业内知名的产品和公司，开启融资快速扩张。**
  - **第二步：充分做加法**

    - **核心是把一个宽泛的 idea，拆解成一个“创业选项池”**

      - **为什么要做加法？（破除误区）**

        - **一个创业 idea ≠ 一个创业项目。一个模糊的想法背后，其实包含了几十上百个细分的商业模式。**
        - **你真正能赚钱、能做成的，可能只是其中两三个选项。**
      - **如何系统性地拆解，形成“选项池”？**

        - **方法1：按细分定位拆解（横向）。维度包括：价格带、线上线下、城市区域、2B/2C、品类等。**
        - **方法2：按行业链条拆解（纵向）。环节包括：原材料、生产制造、渠道、媒体、消费者交付等。**
        - **方法3：按一堂五步法拆解。维度包括：需求、解决方案、商业模式、增长、壁垒。**
      - **信息不够，不会拆怎么办？**

        - **简单方法：案头工作。读行业报告，看科技媒体（如36kr）。**
        - **进阶方法：让 AI 帮忙。把项目背景和预期给 AI，让它给你启发。**
        - **复杂方法：一线调研。混圈子、访谈专家、线下探店。**
    - **实战演练：用“五步法加法画布”来做加法**

      - **案例1 - 陪诊业务的画布**

        - **罗列了用户、场景、服务价格、服务模式、获客渠道等所有可能性。**
      - **案例2 - 咖啡馆的画布**

        - **按照关键逻辑（城市、产品、选址、价格等）组合出上百个选项。**
      - **案例3 - AI时间管理APP的画布**

        - **将目标商业区间内的所有可能性，画在五步法画布上。**
  - **第三步：专业做减法**

    - **核心是排除各种“硬伤”，找到成功率最高的选项**

      - **做减法的本质：芒格的名言**

        - **“如果知道我会死在哪里，那我将永远不去那个地方。”**
      - **减法的评估框架：预判模型的演进**

        - **初版（2019）：P(成功概率) = f(行业, 商业, 初心, 团队, 资源)。**
        - **第二版（2022）：【商业模式】+【团队能力】的匹配模型，总结了15个经典硬伤。**
        - **最新版（本次课程）：一个打通“预期-质变点-背后要求-修炼路径”的完整模型。**
    - **实战演练：在画布上排除明显不靠谱的选项**

      - **案例1 - 陪诊业务的减法**

        - **商业角度排除：跨城复制（管理成本高）、高客单（服务成本高）、恐医人群（难触达）。**
        - **能力角度排除：跨国用户（缺语言能力）、医保服务（缺相关能力）。**
        - **最终筛选出2个高可行性选项：A. 陪伴老人/宝妈做基础陪诊；B. 为外地人/职场人做增值陪诊。**
      - **案例2 - 咖啡馆的减法**

        - **商业角度排除：学校店（天花板低）、社交空间（盈利难）。**
        - **能力角度排除：网红店（缺营销能力）、Mall店（资金要求高）、便利店（缺关键资源）、专业咖啡师（缺能力）、放加盟（缺2B经验）。**
        - **最终筛选出3个高可行性选项：A. 便利/办公属性小店；B. 带餐的社区/办公店；C. 高客单价的街边精品店。**
      - **案例3 - AI时间管理APP的减法**

        - **商业角度排除：咨询（要做标准化软件）、学生群体（付费能力弱）。**
        - **能力角度排除：做课（缺核心做课能力）、企业用户（缺2B谈判能力）。**
        - **最终筛选出2个高可行性选项：A. 国内职场人APP；B. 海外职场人APP。**
- **三个L型创业者的真实案例复盘**

  - **案例一：董晓峰（古董）的奶茶店**

    - **背景与挑战**

      - **目标：做一个长期稳定、规模上亿的项目。**

        - **资源：资金几百万（只够一次尝试），能力是新兵蛋子（不懂精益创业）。**
    - **预判决策过程（四步筛选）**

      - **第一步：选大方向**

        - **放弃技术/互联网类（没能力、钱不够烧），选择【民生方向】（稳定可控）。**
      - **第二步：选择品类**

        - **放弃便利店/服装（竞争激烈）、大餐饮（兴趣不大），选择了【奶茶】（生命周期长，有“时光机”机会，成本低）。**
      - **第三步：选切入方式**

        - **放弃自建品牌（经验有限），选择加盟。在“全直营”和“单店加盟”中，发现并选择了【合资经营】模式（拿到100%经营决策权）。**
      - **第四步：选择城市战场**

        - **砍掉市场不够大的城市（看GDP、人口数据）、砍掉中西部（太远，文化差异）、砍掉竞争激烈的华东/华南，锁定【华北地区】。**
    - **最后的实地验证**

      - **肉身去青岛调研，验证判断。**

        - **看竞品（都是本地杂牌）、看消费（年轻人多，消费力旺盛）、看相似业态（连锁化趋势已现）、看细节（年轻人有消费习惯但奶茶弱）。**
      - **反向数据验证，最终立项。**

        - **结果：10年开了100多家店，成为青岛市场头部。**
  - **案例二：彭雪起（Peter）的垂类电商**

    - **背景与团队**

      - **方向：天猫电商 + 男士裤子。**

        - **团队能力：懂技术和数据分析、懂阿里平台规则、有淘宝卖衣服经验。线下业务不懂。**
    - **两个重要的早期预判**

      - **预判1：选赛道**

        - **核心认知：做电商大品牌，必须有强供应链。分析后，能碰的供应链只有服装相关，所以定在【服装品类】。**
      - **预判2：选具体品类**

        - **放弃女装（品牌太多，烧不起）、放弃童装（没好供应链），聚焦【男装】。再细分到只做【男士裤子】，单点突破。**
    - **一个关键插曲：搞定供应链**

      - **挑战：目标供应商老板思维传统，瞧不上电商，谈不下来。**

        - **破局点：讲道理没用，直接用同行做电商发达的案例刺激他。带一个潮汕小伙子，给他看后台营收数据，老板受到巨大冲击，主动合作。**
  - **案例三：Truman自己做“一堂”的从-1到0**

    - **背景与策略**

      - **目标：在4-6个季度，摸索一个能做到亿级营收的长期高价值业务。**

        - **策略一（全面预判）：认真做调研和预判，把成功率从低于10%提升到30%。**
        - **策略二（试错要快）：争取一个季度试错一个模式，一年内找到模式的成功率 P = 1 - (0.7^4) ≈ 76%。**
    - **预判过程（系统性扫描+排除）**

      - **第一步：快速扫描+收集信息。**

        - **通过产品扫描、专家访谈、用户访谈，全面了解创业服务市场。**
      - **第二步：按需求Mapping，寻找潜力赛道。**

        - **锁定四大类需求：找钱、找人、找信息、找学习。筛选出6个有一定机会的方向。**
      - **第三步：做减法，努力排掉错误选项。**

        - **V1.0->V2.0：排除“个性研报”（用户无付费意愿）和“服务黄页”（2B信任门槛高）。**
        - **V2.0->V4.0：进一步调研后，排除“找合伙人”（需求极度非标，模型不经济）。**
    - **最终的决策与结果**

      - **锁定3个可行性较高的方向：模块咨询、创业社群、规模化教育培训。**

        - **制定策略：先验证模块咨询，准备PlanB（社群、培训）。结果第一个证伪，第二个天花板低，最后跑通了PlanC（规模化教育培训）。**
- **对“机会预判”的重新理解与升华**

  - **第一层理解“心态”：创业是个概率游戏**

    - **要承认，做成一个生意是小概率事件。**

      - **副业赚钱概率 < 50%；小生意 < 30%；规模化业务 < 15%；创新头部项目 < 3%。**

        - **我们所有预判工作的核心目标，就是把这个基础概率，提升数倍乃至数十倍。**
  - **第二层理解“策略”：一套通用执行框架**

    - **就是那15个字。**

      - **主动想终局：思考模糊的长期目标。**

        - **充分做加法：把 idea 转化成“战略选项池”。**
        - **专业做减法：层层评估，找到你最有机会做成的题目。**
  - **第三层理解“修炼”：预判是刻意练习的**

    - **预判能力不是天赋，而是可以被“刻意练习”的。**

      - **这是CEO的核心基本功，包含构建选项池、找商业/团队硬伤、系统分析行业等。**

        - **预判交付物的4个质量层级：一个模糊idea -> 一个具体题目 -> 展开五步法假设 -> 五步法预判+PlanBCD。**
  - **最终的核心：能赢**

    - **创业预判，最核心的就是两个字：能赢。**

      - **用《孙子兵法》说，就是“先胜而后求战”。**

        - **很多项目在明眼人看来，从一开始就没有胜算。创业者只是用时间和金钱，证明了一个必输的预判。**
    - **王兴的话：不要用战术上的勤奋，来掩盖战略的懒惰。**

      - **CEO要能从业务中跳出来，用上帝视角不断思考和预判。**

        - **最糟的情况，就是在一条注定走不通的路上越走越远。**
    - **最后送给大家的九个字**

      - **别拧巴，别天真，别害怕。**

        - **天时（行业机会）-> 顺势而为，别拧巴。**
        - **地利（商业模式）-> 快速验证，别天真。**
        - **人和（初心/团队/资源）-> 积极改变，别害怕。**
