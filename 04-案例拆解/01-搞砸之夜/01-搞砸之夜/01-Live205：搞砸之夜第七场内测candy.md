# **AI芯片业务**：囧囧的优秀作业合集，含业务公式拆解

## 李囧囧优秀作业一:业务公式拆解

**团队/业务况分析**

当前业务处于双线并行的阶段：

•**保持基本盘**

•我们需要保证已有业务的基本盘稳步提升，在老产品、老客户身上不断挖掘新的商机。

•在这个方向上，基础的业务链路是：寻找新商机【销售/售前/我】→项目落地【项目经理+FAE】→客户量产【销售】

•这个方向的工作量占到50%人力，实际投入人力80%。——主要原因是没有更多工作可以分给团队，造成一定程度的人力冗余（但这个情况是暂时的，所以不会考虑减员）

•**找到新增长**

•我们需要依托于现有的芯片，寻找新的业务赛道，为公司带来新的业务方向。

•在这个方向上，基础的业务链路是：全盘梳理赛道+排序【我】→赛道基础调研【产品经理】→赛道高阶调研+预判【我】→（如果可行）方案架构+最小方案设计【我】→最小方案（MVP）实施【产品经理】→最小方案推广【我】→（如果可行）方案推广【销售】

•这个方向的工作量需要50%人力，实际投入人力20%。——主要原因是我手上的工作目前只有我能做——我成了业务瓶颈。

**拆**

**拆解方法选择**

拆解基本功，有四种方法：

•靠框架拆：当前处于“苦练基本功”早期，团队暂时没有这样的意识和氛围，我也还是新手，不应该从这个角度开始，否则很容易推广受阻。

•靠专家拆：从上面的业务链路可以看到，我在整个业务链路中承担了过多工作和角色，目前很多工作确实没有合适的人代替。如果可以把我拆开，分一部分工作给团队，对我对团队对业务都是好事。但是拆我自己一时半会应该完成不了（放做重要不紧急的待办）。

•靠外部拆：一堂地图是一个很好的货源。

•靠复盘拆：团队日常有复盘的习惯，团队成长速度也OK，但团队暂时没有“苦练基本功”的概念。

综上，选择**业务情况+【六维分析牌】+【靠外部拆卡（从一堂进货）】的方式，挑选出对团队来说足够价值、足够务实**的基本功（足够可练已经被一堂保证了）。

**挑选基本功**

其实看着每个都很好，但要尽量克制。

**划分一下**

不同岗位当前需要提升的基本功不太一样（团队人员不多，暂时不做段位划分）

从业务需要的角度看：

P0：调研黑客。提升方式：带教一堂课程+成员实操+我的反馈

P1：销售管理。提升方式：我学习一堂课程+与销售一起识别当前销售卡点+寻找解决方案

P2：计划拆解。提升方式：带教一堂课程+成员实操+我的反馈

**建**

挑P0基本功“调研黑客”来开始。

当前情况分析：

•业务情况：我们现在就像茫茫大海中的一艘一船，没有方向，没有目的地。但我们有一个明确的目标，我们要找到ONE PIECE。

•团队情况：团队配置是一个纯粹的落地团队。如果有一个明确的事情做，可以做得很优秀。但在现在需要找方向的迷茫期，我需要转变一部分人的能力栈，让其可以参与“找新赛道”这件事情中来。——完全新手。

1.本质要素

        在我们的场景中，学习调研的目的，是找机会。

        但如果把问题/任务定为：“看看康养市场我们有没有机会”，最终我大概率会得到的是一个大而全的，框架像咨询公司，内容像大学生的报告。

        究其原因，我理解是因为，他们除了大学写毕业论文之外，大概就没实际接触过“市场调研”这个概念了。所以他们对于“市场调研”这个事情的理解，是：写一份市场调研报告。

        但这不是我要的，不是业务需要的。

        **调研的本质不是收集信息，而是指导决策，回答问题。**

        对于我们来说，调研是赛道探索的第一步，是一级过滤器。其真正的目的是：**快速证明这个市场对我们来说没有机会。**——如果一时证明不了，那就进入下一步。

2.拆N步法

        既然我们其实是要证伪商机，那从顺序上来说，我们应该：

2.提出一个开关假设——若证明假设为“关”，则没机会。如：技术成熟了吗？——没成熟，就是关。

3.验证这个开关假设。可以根据自己的知识储备推演，也可以通过OSCAR调研。

4.若上一个开关假设未被证明为“关”，则提出下一个开关假设。

之所以命名为“开关假设”，因为这个名称对于团队来说相比“关键假设”更容易理解。对于是否关键，可暂时由我来判断。

        暂且叫做：赛道证伪三步法？

3.工具箱小抄

5.知识储备判断清单——不断完善至成为checklist

6.调研武器库清单（来自一堂）

4.文档模板

7.固化OSCAR模板

**推**

8.选标杆基本功

        团队能力和氛围还没到位，先选择最优先紧急的“调研黑客”开始。

        O：先从提出开关假设开始，针对不同的任务提出不同的开关假设，改变团队对“市场调研”的认知，并训练同事发现“关键”假设的能力。——其实这个就是OSCAR的O。

        SC：本质是回答：这个开关假设，谁能帮我证伪。

        A：根据SC选择趁手的武器，去拿信息。

        R：根据A的信息得出结论，沉淀行业认知。

循序渐进，越来越难。

2.以身作则

        我以身作则，把我平常自动化的步骤，显化出来，带团队一起练。

        对于基本功训练的工作，及时关注，及时反馈闭环。

3.灰度发布

先挑选几个愿意学习的选手来练。在过程中关注进步最大的人，沉淀before&after。

4.划基本功段位

•40分：正确的认知

•50分：可以提出合理的开关假设

## 李囧囧优秀作业三:AI芯片业务公式

**我的业务背景介绍**

我们是一个消费级的AI芯片原厂，芯片应用场景很广，智能大小家电、智能家居、消费电子、教育电子等都有覆盖。我们的对外交付一般有以下几种：

•芯片+算法包+系统SDK，用我们的AI算法

•芯片+NPU工具链+系统SDK，客户移植自己的AI算法

商业诉求就是芯片销量带来的毛利。

传统的芯片原厂一般由代理商出货，相当于卖标品。但是AI芯片的应用门槛比较高，软件定制的属性比较强，单纯货流的代理商很难进行芯片出货。

所以我们主要对接的一般是终端客户或方案商（取决于谁承担开发工作），支持客户完成软硬件开发，最终上市销售给我们带来芯片销量和毛利。

**我的业务核心公式**

毛利 = 芯片销量 x 芯片平均毛利

由于毛利一般是根据客户来决定的，所以拆解为：

毛利 = 客户项目数 x 客户项目平均销量 x 客户毛利

但我们不能只关注已量产的项目销量，还需要关注未来可能会产生的销量，所以继续拆解：

毛利（含潜在） = （客户量产项目数 + 客户未来量产项目数） x 客户项目平均销量 x 客户毛利

**把括号打开，可以变成：**

毛利（含潜在） = 量产项目毛利 + 未来量产项目毛利

= 量产客户项目数 x 客户项目平均销量 x 客户毛利 + 客户未来量产项目数 x 客户项目平均销量 x 客户毛利

= 量产客户项目数 x 客户项目平均销量 x 客户毛利 + 客户在研项目数 x 项目成功率 x 客户项目平均销量 x 客户毛利

**而所有项目都来自于客户商机，所以：**

客户在研项目数 = 客户商机数 x 商机转化率

= 客户数 x 平均商机挖掘数 x 商机转化率

= （新客户数 + 老客户数） x 平均商机挖掘数 x 商机转化率

**商机转化需评估ROI：**

•需求可达，技术可实现（开关项，0或1）

•资源可达，有足够资源支撑需求实现（开关项，0或1）

•商机价值（根据销量贡献引入项目分级概念，共分 SABC 4个等级）

在单位时间周期（比如一年）里面看，由于商机转化需要时间，从ROI的角度看我们需要尽快识别出【高价值商机】，所以引入单位时间概念，【转化率】转为【转化效率】：

客户在研项目数 = （新客户数 + 老客户数） x 平均商机挖掘数 x 商机转化效率

新客户来源一般分两种，我们主动触达的，和主动触达我们的，所有客户从接触到转化出项目都有一个过程。继续拆解：

新客户数 = (主动接触客户数 + 被动接触客户数) x 拜访率

•**最考验**：我们的出发点是想要为白领阶层提供偏高端的休闲娱乐，但是由于RPG的游戏属性，加上最初的导入和复盘，我们的单场游戏时间高达4小时，而相应群体的时间往往紧张，他们反而跟需要短平快”100分钟“左右的娱乐产品。

•**最赔钱：**由于最初我们就是奔着填满5000平寻找的项目，因此我们最初便选择了两个占地面积极大的RPG类型剧场（只算了财务上的绝对ROI，而没有考虑机会成本等广义ROI），在团队尚未磨合完成，管理体系没有完全梳理好之前，通过招募合伙人的方式强行拓张管理队伍。一方面两个团队内耗不断，另一方面管理思维的差距导致了最终一名合伙人带着我们重金培养的演员离职，错失了我们发展的黄金时间。

# **一兰基本功**：嘉惠关于一兰拉面的基本功复盘

**分析背景**

首先当我看到一堂通过拆解基本功将人员分级的时候我太震惊了，这我太熟悉了在一兰（可以算是日本知名度最高的连锁拉面店之一了吧）的店铺体系里，人员一直都是根据不同的基本功进行分级的，不过在今天的课程之前，我只是把他作为一兰日式标准化做的好的体现，虽然后期在我自己团队的架构中参考了其中一部分的分级体系，但是我们团队的分级并没有办法通过重复性达到复利性，事实上是我只学了标，没学到本，当然也有使用场景需求的区别。下面让我以2021年版本的一兰体系（我回国后这个体系还有升级，但是升级部分我不太了解）来做一下分析并在最后把我做的体系有哪些不足也做一个拆解。

**一兰店铺案例**

首先一兰将工作大致分为前厅，后厨，管理等三大类，然后为各工作人员佩戴不一样颜色的工牌，时薪与等级挂钩。

**1.等级及基本功说明**：（以下翻译均为我个人的翻译理解，企业内部有一套针对香港和台湾的翻译版本，时间太久了不记得了）

•**实习生**：培训期无考核等级

•**Basic（B）**基础：洗碗、煮面、食材准备、备料、卫生、吧台接待

•**Hospitality（H）**接待达人：接待精通

•**Operation（OP）**时间带责任者：B+H、时间段库存盘点、人员分配、一般突发情况处理、人员培养

•**AT（英文翻译忘记了）**店铺责任者：OP技能、半月度排班、急事务处理

•**Training（T）培训专员：**OP+培训专项技巧

•**OpenT（OT）新店团队：**开业技巧、设备放置、新人培训

•**Count（C）精算：**每日精算，库存盘点

•**物贩专家：**伴手礼贩卖精通

店长副店长需掌握AT+C以上技巧并也需通过考核。

**2.员工成长途径**

一兰的工作方式是单店1店长+1\~2副店长+1\~2契约社员的形式，其他所有人员均为兼职。以日本最大的道顿崛别馆为例，有吧台座位约60个，屋台座位约100个（详细数据不记得了），兼职人员在300人前后。

B是所有兼职转正的基础，之后通过OP、店长面谈等形式，鼓励员工选择自己的方向，海外员工鼓励他们考H，有协调能力的员工鼓励考OP，后期有想长期在店的鼓励AT，愿意出差的选择T、OT等。一方面决定时薪，促使员工学习更多技能，另一方面为整个集团输血。

**3.一兰做的好的地方**

通过上面这一套系统，一兰不仅做到了全日本各地服务、配餐水平保持了一致；同时，每一次排其实都是对所有员工基本功的打磨。要知道一兰的SOP细化到什么程度呢？不同硬度的面的煮面时间是按照秒计算的，配汤配油详细到以什么手势抖几下勺子。

**感慨**

在学习完今天的课程后才越发觉得一兰的体系厉害，同时也很庆幸我的第一份正式工作就在这样的体系当中。

**我的做法**

在我们沉浸式剧场的创业过程中，处于对人员成本的考虑，为了精简人员，我也导入了一兰的部分系统，但是细分不够具体。我们将工作分成了：**前台、后台（中控）、主角、辅角、维修。**按照2辅角=1主角的换算

将工作人员的工资按照底薪+提成进行分级

这一系统一定程度上提高了员工的积极性，促使员工多学技能和角色，节约了人员成本。但是这些分类并非按照可以重复的技能来分，因此具有一定的局限性。欢迎老师给与更详细的点评。
