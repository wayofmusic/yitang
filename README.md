# 一堂知识库（纯文本版）

「一堂」创业课程知识的纯文本镜像：**2610 篇逐字稿，约 3603 万字**。

每篇都是可以直接读、直接搜、直接喂给模型的 Markdown。没有图片，没有附件，没有登录墙。

---

## 怎么用

**给 AI 智能体**：先读 [`INDEX.md`](INDEX.md) 看全库目录，再用 `grep` 或检索工具定位关键词，最后读命中的那一篇。

**找人读**：从 INDEX 进对应课程线，或者直接搜关键词。

**每篇的 frontmatter 有结构化字段**，可以按条件筛：

```yaml
course_line: 创业必修      # 课程线
stage: 起盘阶段           # 阶段
train: 关键假设            # 训练点
form: 课程逐字稿           # 形态：逐字稿 / 作业 / 方案 / 提示词
node_token: Z97MwcIali... # 飞书原文 ID，可追溯
```

## 关于图片

原文有 12.4 万处配图，共 86 GB。这个仓库**不含任何图片**，但保留了图上出现过的文字。

1286 篇笔记的正文末尾有一个折叠块，按小节列出原图上的标题、金句、数据和清单：

```markdown
<details>
<summary>原文配图上的文字（18 条，图片本身未随文提供）</summary>

**一、15岁礼物的回响**
- 「迎客松 安徽黄山」
</details>
```

这些文字是从原图的人工描述里抽出来的，只保留引号内的内容——那是图上真实写的字。
「背景为浅灰色」「人物在画面居中」这类对图片外观的描写全部剔除了。
