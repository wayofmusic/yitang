2023年AI落地应用场景回顾

2023年是百模大战年，目前AI大模型的能力边界还不明晰，应用层创业是无人区也是重坑区，应用层的创业项目大多处于拿着锤子找钉子的阶段。反而是AI能力在已有业务场景中的落地应用，为企业带来了直接的降本增效。

**AI应用场景的三环模型**

|   |   |
|-|-|
| **AI能力达标，**
**满足交付要求**
  | 1.
一项AI技术能否落地应用，主要取决于AI技术的应用效果，能否满足交付要求。
2.
应用效果的要求有一个阈值，也就是及格线，达到或者超过这个阈值，AI技术才能落地，低于阈值则不可用，关键在于应用场景的选择。
3.
随着基座模型的能力越来越强，AI应用效果会跳过越来越多行业的及格线，使得原先不可应用AI的行业变得可以应用AI了。   |
| **对AI 的容错率高**
  | 不同行业的AI容错率，完全不同。我们来看两个极端的例子：
1.
艺术创作行业比如写小说、画图、做电影，AI容错率非常之高，有时甚至是“反向容错”，就是说错得越离谱，看着越独特越有创造性。这种场景中， “大模型的幻觉是种Feature，而不是Bug”。
2.
处于“AI容错率”另外一个极端的是“自动驾驶”。自动驾驶容错率是极低的，万分之一的错误率行吗？如果每天使用AI自动驾驶的交通工具有1亿辆，万分之一的错误率会造成多少交通事故？10000起，这个谁能接受？关键是伦理风险，人类司机出问题，是个体事件，AI自动驾驶出现幻觉，那意味着整个技术不安全。这种场景中，“大模型的幻觉是缺陷，需要修正”。
3.
其它行业，对“AI容错率”要求基本处于艺术行业和自动驾驶这两个极端之间，ToC的产品容错率就高一些，ToB的产品容错率就低一些，大致如此。   |
| **AI的ROI＞＞人工ROI**
  | 产品价值 = 新体验 - 旧体验 - 迁移成本；
AI化降本 = 旧成本 - AI成本 - 迁移成本；
AI化增效 = AI效率 - 旧效率 - 学习难度；
1.
目前AI的使用成本太高，算力贵；
2.
学习使用AI是有迁移成本和学习成本的，个人和企业要在工作中广泛运用AI，需要付出学习成本，需要改变原有的工作模式、工作流，要付出时间、精力、金钱、改变习惯等迁移成本。
3.
当AI使用成本大幅度明显低于人力成本，AI技术才会被应用，而“AI人力成本差”越大，则企业拥有者越有动力去应用AI，两者基本成正比关系，甚至可能是指数关系。注意：要大幅度明显低，因为有学习成本和迁移成本。
4.
完成作品所需要投入的时间和人力，时间越长，人力越多，人力成本就越高。从模态角度来说，人力成本由高到低应该是：游戏＞长视频＞短视频＞长文＞图片＞短文。
5.
而随着技术的快速发展，AI使用成本会极速下降，对大多数中等脑力劳动的行业来说，人力AI成本差会越来越大，这会带来劳动力从这些行业外溢。   |

总体而言：在AI技术能力达标的已有行业里，AI效果越好的、AI容错率越高的、人力AI成本差越大的行业，符合这三个条件的应用场景就是非常利于AI应用的落地推广，也会越早越快地进行AI普及与人力替代。

这也解释了目前的现象：“AI在吟诗作画，而人类在打扫房间”，**大模型首先替代的反而是中等程度的脑力劳动**。这是因为，高等脑力劳动，目前AI效果还没达标；日常体力劳动，人做起来成本低；而中等脑力劳动，正好完美符合以上三个条件。例如：

2024年，越来越多的企业会将AI引入到自己的工作流中，改造目前的工作流，以达到降低人工成本，提高生产效率的目的。
