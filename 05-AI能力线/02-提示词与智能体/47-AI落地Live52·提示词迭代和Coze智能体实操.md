对于不太赞同AI批改作业的同学，我们再消一轮阻力。

首先明确，大家写作业的价值/目标是什么？

对同学们，随便可以写几条条：

1.**自我提升**：要求大家听课写作业，目的是通过深度复盘和思考，提升自己的能力

2.**Truman会看**：作业的**分数取决于作业质量**，写得好的，大家会重点艾特Truman来看

3.**深度学习**：已经花时间听了直播、看了文档，最高价值的收益，就是自己思考、完善观点的过程，可以加深对方法论和课程的理解；

4.**独特见解**：一次认真作业是和教研团队沟通、联系的宝贵机会，如果能体现出你个人独特的思想，教研团队会非常乐意和你进一步交流，而AI完全没有你的灵性；

5.**刻意练习**：把每次作业当做一次刻意练习的机会，可以联系包括商业视角、文字表达、逐字稿等等，分数是一个最好的反馈，每周进行，长期训练自己的多种能力；

6.**作品展示**：作业不是任务，不是负担，是你在一堂学习的成果的沉淀，翻开后台，看到自己的若干作业，成就感是不可替代的；

7.**面向未来**：这些作业，是你现在对某个课题的理解，未来遇到真问题，才有更好的场景带入。

对一堂、对教研：

1.**挖掘**：好的业务、好的专家、好的讲师、好的案例等等等等，全是通过作业这个渠道；

2.**对话**：推动教学相长对话的机会，尤其是早期的时候，Truman、张磊都会直接看到作业就打电话开聊；

3.**沉淀**：同学们的作业既是自己的复盘，也是对别人非常有借鉴意义的内容，是未来创业学科的储备。

每次内测课，我们会专门拉一个群来看大家的作业，包括Truman在内的教研同学们都会看，不一定能全量看完，但是都会尽量看，然后给好的作业点赞，收到过点赞的同学可以评论区说一下哈。

>
> 我需要给这些作业打分，用一个提示词，指挥AI帮我完成作业分数的批改。

AI非常慷慨，直接帮我设计了一套评分系统，乍一看挺像回事。当时还乐此不疲的调了二十来个版本。deepseek甚至还尝试教会我，在自己电脑上部署一个本地大模型。

## Round2 结构化评分标准

第二轮的探索，我把评分标准发给了kimi，并且找了3个同学愿意公开的作业，尝试打分。（别问我为什么不用DS，满屏全都是请求超时的泪）

我给出的标准如下（注意我是在调提示词哈，这不是一堂真实的作业打分详细标准）

> 6分｜深度关联+业务分析
>
> 紧扣课程主题，结合自身业务案例深度分析，逻辑清晰连贯，提出自己的观点或思考
>
>
>
> 5分｜有效关联+浅层分析
>
> 围绕课程主题展开，有明确案例或心得，表达流畅，分析较浅层（如仅复述课程案例，缺乏业务延伸）
>
>
>
> 4分｜基础关联+简单描述
>
> 提及课程关键词，有零散学习感受，缺乏逻辑串联
>
>
>
> 3分｜弱关联+模糊表达
>
> 仅出现课程关键词，60%以上内容与课程无关或表述空洞
>
>
>
> 2分｜极弱关联+情绪化。碎片化表达
>
> 20%-40%内容与课程相关，有情绪化或碎片化表达
>
>
>
> 1分｜无效关联
>
> 80%以上内容与课程无关，通篇模糊表述（如"今天收获很大"）
>
>
>

>

>
> 总的来说，我认为MVP模型在证券投资领域有着广泛的应用前景。通过精简流程、借助工具和保持客观，我们可以更高效地进行投资分析。

## Round7 重新理解任务和拆解

最近内测的几节课，业务公式系列和精益实操系列，都在反复提及一个动作，“拆”。这个动作在一堂很常见啊，

•用户需求方法，拆推评算

•带团队练习基本功，拆建推练

•做项目管理，要拆计划拆里程碑

•……

这些做事的方法，其实迁移到写提示词上，原理是一样的。

在我决定用AI来尝试批改作业的时候，最先做的事情应该是，先把需要AI执行的工作流拆解出来。

我先是把助教的工作流，让AI尝试了一回，完全不行。人的思考是更快、更模糊的，但如果这类标准投喂给了人工智能，你将会收获一个放飞自我的人工智障。

这时候就要求我们，把原本模糊的混成一团的过程，拆解成更清晰、有维度、最好能量化的过程和标准。

第一步，分类，看看一份作业里的内容，是什么样的去向

第二步，打分，给相应类别的作业内容进行打分评级

第三步，算分，加权等算法，给出这份作业里最终分数

 暂时只能透露这么多，更精准的内容，以后有机会再给大家分享吧

这一轮的认知：一堂方法论YYDS！我们永远拥有可迁移的底层能力！

普通的LLM没有高级的技术方式，只能通过一种类似于遍历方法的唠叨着数。目前的多模态有可能解决这个问题。

**但是！这个需求通过代码可以实现，难度低，且精确。以python为例，几行搞定**\~

> import re
>
>
>
> def count_valid_characters(text):
>
>     \# 定义要统计的字符模式（汉字、字母、数字、全角和半角标点符号）
>
>     pattern = re.compile(r'[\u4e00-\u9fa5]|[a-zA-Z0-9]|[\u3000-\u303f\uff00-\uffef\u2000-\u206f\u0020-\u002f\u003a-\u0040\u005b-\u0060\u007b-\u007e]')
>
>
>
>     \# 找到所有匹配的字符
>
>     valid_chars = pattern.findall(text)
>
>
>
>     \# 计算有效字符数
>
>     count = len(valid_chars)
>
>
>
>     return count
>
>
>
