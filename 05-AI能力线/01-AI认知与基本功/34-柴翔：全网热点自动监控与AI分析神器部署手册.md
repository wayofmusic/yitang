# 柴翔：全网热点自动监控与AI分析神器部署手册

**目标：** 自动抓取微博、抖音、B站等30+平台热点，推送到你的飞书，并使用AI进行深度分析。

**适用人群：** 自媒体人、运营、热点追踪者（无需代码基础）。

**准备工作：**

1. 一个 GitHub 账号（免费注册）。
2. 一个 飞书 账号（推荐，配置最简单）。
3. 一台电脑（Windows 或 Mac）。

---

## 第一阶段：搭建热点推送系统 (云端运行，不用开电脑也能跑)

### 第一步：复制项目代码

1. 登录你的 GitHub 账号。
2. 打开 Trend Radar 项目主页（搜索 `TrendRadar`）。

1. 点击页面右上角的 **Use this template** 按钮。**（注意不要点Fork  ！会出错）**
2. 点击绿色的 Create a new repository 按钮。

   - *解释：这相当于把别人的代码复印一份放到你的仓库里，后续修改都是在你自己的仓库进行。*

### 第二步：配置消息接收渠道 (以飞书为例)

1. **创建机器人：**

   - 电脑浏览器打开 [飞书机器人助手](https://botbuilder.feishu.cn/home/my-app)。
   - 点击 **`新建机器人应用`**。
   - 名字随便取（例如：热点监控），点击确定。

2. **创建流程：**

   - 在左侧菜单点击 **`流程管理`** -> **`创建流程`**。

   - **触发器选择：** 往下翻，找到 **`Webhook 触发`** 并选中。

   - **设置参数：** 复制以下代码，粘贴到“参数”框中：

     ```JSON
     {
     "message_type": "text",
     "content": {
     "total_titles": "{内容}",
     "timestamp": "{内容}",
     "report_type": "{内容}",
     "text": "{内容}"
     }
     }
     ```
   - 保存wehook地址 点击右侧复制，找地方保存，后面有用

   - 点击 **`下一步`** -> **`完成`**。
3. **设置推送操作：**

   - 点击流程图中的 **`选择操作`**。

   - 选择 **`发送飞书消息`**。

      这是柴翔搭建热点推送系统时配置飞书消息接收渠道相关的页面截图，该页面属于设置推送操作的环节，核心是“飞书集成”相关内容，页面中明确提供了“发送飞书消息”的选项，其下方标注有“飞书消息与群组”的说明，结合上下文可知，该选项对应设置推送操作里选择发送飞书消息的步骤，是完成热点推送配置的重要操作选项。

   - **选择对象：** 建议选择“群消息”（你需要先在飞书里建一个只有你或者你团队的群），然后选中那个群。
   - **消息标题：** 填写“全网热点监控”。
   - **消息内容：** 以下格式填写（点击输入框上方的 **`+`** 号选择变量）：

     - 输入文字 `总新闻数：` -> 点击+号选 `Webhook触发 content.total_titles`
     - 输入文字 `时间：` -> 点击+号选 `Webhook触发 content.timestamp`
     - 输入文字 `类型：` -> 点击+号选 `Webhook触发 content.report_type`
     - 换行 -> 点击+号选 `Webhook触发 content.text`
   - 点击 **`完成`**。
4. **发布流程：**

   - 点击右上角的 启用 按钮。

   - 点击右上角的  发布 按钮

   - 等待审核通过（几秒钟），状态变为“已发布”。
5. **获取密钥：**

   - 回到 **`Webhook 触发`** 这个节点，点击它。
   - 复制 **`Webhook 地址`**（长得像一个网址）。**保存好，后面要用！**

### 第三步：配置 GitHub 仓库 (连接代码与飞书)

回到你在 GitHub 上 Fork 好的仓库页面：

1. 点击上方菜单栏的 **`Settings`** (设置)。

1. 在左侧栏找到 **`Secrets and variables`** -> 点击 **`Actions`**。

1. 点击绿色的 **`New repository secret`**。

1. **Name (名字)：** 填 `FEISHU_WEBHOOK_URL` (必须一模一样，全大写)。
2. **Secret (内容)：** 粘贴刚才在飞书里复制的那个 Webhook 网址。
3. 点击 **`Add secret`**。

### 第四步：个性化设置 (选填，建议做)

在 GitHub 仓库页面，点击 **`Code`** 回到代码列表：

1. 进入 **`config`** 文件夹。

1. **修改推送频率 (`config.yaml`)：**

   - 点击 `config.yaml` -> 点击右上角小铅笔图标编辑。

   - 找到 `mode:`。

     - 想每小时推一次当前热榜：改成 `mode: "current"`。
     - 想每天推一次汇总：改成 `mode: "daily"`。
   - **设置免打扰：** 将 `time_range` 下面的 `enabled: false` 改为 `enabled: true`，并设置开始和结束时间（如 09:00 到 22:00）。

   - *注意：输入必须用英文输入法。*
   - 改完点击右上角 **`Commit changes`** 提交。
2. **修改关注关键词 (`frequency_words.txt`)：**

   - 点击该文件 -> 点击小铅笔编辑。
   - 清空原有内容，每行写一个关键词。
   - **监控特定词：** 直接写，如 `华为`。
   - **组合词：** 用加号，如 `+手机 +华为` (同时包含才推)。
   - **排除词：** 用感叹号，如 `!水果` (包含水果的不推)。
   - **分组：** 不同类型中间空一行（如上面写数码，空一行下面写AI）。
   - 改完点击右上角 **`Commit changes`** 提交。

### 第五步：启动运行

1. 在 GitHub 仓库页面，点击上方菜单 **`Actions`**。
2. 点击绿色的按钮 **`I understand my workflows, go ahead and enable them`**。
3. 点击左侧的 **`Hot News Crawler`**。
4. 点击右侧的 **`Run workflow`** -> 绿色的 **`Run workflow`**。
5. 稍等片刻，你的飞书群就会收到第一条热点推送！以后它会自动运行。

## 第二阶段：进阶 AI 分析 (本地运行，像和人聊天一样分析热点)

此功能让你不仅能“看”热点，还能让AI帮你“分析”趋势。

### 第一步：下载并安装 Cherry Studio

1. 去 Cherry Studio 官网下载对应版本（Windows下载 `.exe`，Mac下载 `.dmg`）。
2. Mac用户注意：M1/M2/M3芯片下载 `arm64` 版本，老款Intel芯片下载 `x64` 版本。
3. 安装并打开软件。

### 第二步：获取项目文件到本地

1. 回到你的 GitHub 仓库主页。
2. 点击绿色的 **`Code`** 按钮 -> **`Download ZIP`**。
3. 下载后解压这个压缩包，记住解压后的文件夹位置。

### 第三步：部署服务环境

打开解压后的文件夹：

- **Windows用户：** 双击运行 `setup-windows.bat`，等待安装完成。
- **Mac用户：**

  1. 打开“终端”应用（按 Command+空格，搜索“终端”）。
  2. 输入 `cd` 并打一个空格，然后把解压的文件夹拖进终端，按回车。
  3. 输入 `chmod +x setup-mac.sh` 按回车（开通权限）。
  4. 输入 `./setup-mac.sh` 按回车，等待安装完成。
  5. *如果提示输入密码，输入你电脑的开机密码（输入时看不见），按回车。*

安装完成后，终端/窗口会显示一段绿色的命令和参数，**不要关，留着备用。**

### 第四步：连接 Cherry Studio

1. 打开 Cherry Studio 软件。
2. 点击左下角的 **设置（齿轮图标）**。
3. 点击 **`MCP`** 菜单 -> **`添加`** -> **`快速创建`**。
4. **填写信息：**

   - **名称：** TrendRadar
   - **类型：** 选 `标准输入/输出 (stdio)`
   - **命令 & 参数：** **关键步骤！**

     - 回到刚才运行脚本的黑窗口（终端）。
     - 它会告诉你“Command 是 xxx”，“Args 是 xxx”。
     - 把 Command 的路径复制到“命令”栏。
     - 把 Args 后面的内容（通常是 `mcp_server.server` 等），复制到“参数”栏。**注意：如果有多个参数，要在参数栏点“添加”，分行填写。**
5. 点击 **`保存`**。
6. 点击开关，**启用** 这个 MCP 服务（变绿）。

### 第五步：开始使用

1. 回到 Cherry Studio 的对话界面。
2. 在输入框上方，点击一个小插头图标（MCP图标），勾选 `TrendRadar`。
3. 像跟人聊天一样提问：

   - “帮我分析一下最近 iPhone 的热度趋势。”
   - “帮我抓取今天的 AI 行业新闻。”
   - “最近有什么关于华为的负面新闻吗？”
4. AI 会自动调用你本地的脚本去抓取数据，并生成专业的分析报告。

---

## 💡 避坑指南

1. **代码修改：** 在 GitHub 网页修改 `config.yaml` 等文件时，一定不要用中文输入法输入标点符号（冒号、引号必须是英文的）。
2. **飞书机器人：** Webhook 地址千万不要泄露给别人。
3. **Mac权限：** 运行脚本如果报错 `Permission denied`，记得用 `chmod +x` 命令赋权。
4. **AI分析：** 本地分析需要你的电脑保持联网，且 Cherry Studio 里配置了大模型（如 DeepSeek, GPT 等）的 API Key。

🎉 **恭喜！你现在已经拥有一套自动化的情报系统了！**
