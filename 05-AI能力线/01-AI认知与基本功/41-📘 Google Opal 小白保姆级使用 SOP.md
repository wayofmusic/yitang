# 📘 Google Opal 小白保姆级使用 SOP

## 一、 核心概念（先看这个，不然看不懂）

把 Opal 想象成一个**全自动工厂流水线**，这个流水线由三种“积木”组成：

1. **🟡 User Input (原材料入口)：** 用户输入的地方。比如你上传一张图片、输入一个网址、或者写一段文字。
2. **✨ Generate (加工车间)：** AI干活的地方。这里可以选择不同的AI模型（处理文字、生成图片、生成视频等）和工具（联网搜索、查天气等）。
3. **🟢 Output (成品展示)：** 最终结果呈现的地方。可以是网页界面、文档、PPT或Excel表格。

**核心操作：** 把这三个积木放到桌面上，用线连起来，就是一个App了。

---

## 二、 快速上手：创建你的第一个应用

### 方式一：懒人模式（通过对话自动生成）

*适合完全不想动脑，只想说人话的用户。*

1. **点击新建：** 在主页点击右上角的 `+ Create Now`。
2. **输入需求：** 在屏幕下方的对话框里，用大白话描述你想做什么。

   - *例子：* “做一个旅游助手，我输入地点，你帮我查天气、找景点，最后生成一个网页攻略。”
3. **等待生成：** AI 会自动帮你把“输入”、“处理”、“输出”这几个节点创建好并连好线。
4. **微调：** 如果觉得不完美，继续在对话框里说：“再增加一个推荐当地美食的功能”，AI会自动修改流程。

### 方式二：极客模式（手动拖拽搭建）

*适合想精准控制每一个步骤的用户，视频主要演示了这种方式。*

#### 第一步：设置入口 (User Input)

1. 点击顶部菜单栏的 **User Input** 按钮。
2. 在画布上会出现一个黄色卡片。
3. **重命名：** 在右侧属性栏，给它取个名字（例如：“输入的网址”或“上传美食图片”）。
4. **作用：** 这里是将来你（使用者）填内容的地方。

#### 第二步：设置AI处理 (Generate)

1. 点击顶部菜单栏的 **Generate** 按钮。
2. **连接节点：** 把鼠标放在【User Input】卡片右侧的小圆点上，拉出一根线，连接到【Generate】卡片左侧。

   - *这意味着：把用户输入的东西，传给AI去处理。*
3. **选择模型 (Model)：** 点击卡片上的下拉菜单，选择AI大脑：

   - **Gemini 1.5/2.0 Flash/Pro：** 适合处理文字、逻辑分析、翻译。
   - **Imagen 3：** 适合生成图片。
   - **Veo：** 适合生成视频。
   - **Deep Research：** 深度搜索（适合写长报告）。
4. **配置工具 (Tools)：** 如果任务需要联网（比如总结最新新闻），点击右侧属性栏右上角的“工具箱”图标，勾选：

   - `Search Web` (联网搜索)
   - `Get Webpage` (读取网页内容)
   - `Get Weather` (查天气) 等。
5. **编写提示词 (Prompt)：** 在右侧输入框告诉AI怎么做。

   - *技巧：* 可以输入“{”符号，引用上一步的内容。
   - *例如：* “请阅读 {输入的网址} 的内容，帮我总结成一篇摘要。”

#### 第三步：设置出口 (Output)

1. 点击顶部菜单栏的 **Output** 按钮。
2. **连接节点：** 把【Generate】卡片右侧的线，连到【Output】左侧。
3. **选择展示形式：** 点击 Output 卡片下拉菜单：

   - `Webpage with auto layout`：生成精美的网页（最推荐，视频中常用）。
   - `Save to Google Docs`：存为文档。
   - `Save to Google Slides`：存为PPT。

## 三、 实战案例演练：网页新闻总结器

*(对应视频中 02:35 - 06:30 的演示)*

1. **放置 Input 节点：** 命名为“新闻链接”，用于让用户粘贴网址。
2. **放置 Generate 节点：**

   - **连线：** Input -> Generate。
   - **提示词：** 写上“使用以下工具读取网页并总结”。
   - **工具：** 在右侧工具栏勾选 `Search Web` 和 `Get Webpage`。
   - **模型：** 选择 Gemini 2.0 Flash 或 Pro。
3. **放置 Output 节点：**

   - **连线：** Generate -> Output。
   - **类型：** 选择 `Render HTML` (渲染网页)。
4. **运行测试：**

   - 点击右上角的 **Preview (预览)** 模式。
   - 点击 **Start**。
   - 粘贴一个新闻网址，回车。
   - **查看结果：** 右侧屏幕会自动生成一个排版精美的新闻总结页面（包含数据图表等）。
   - **调试：** 如果想看AI在想什么，点击顶部的 **Console**，可以看到每一步的运行日志。

## 四、 高阶玩法：多节点串联（广告生成器）

*(对应视频中 08:00 后的复杂案例)*

你可以像思维导图一样，把一个任务拆分成很多步：

1. **节点A (Input)：** 输入“小米手机”。
2. **节点B (Generate)：** 深度搜索 (Deep Research) 它可以做什么，适合什么人群。
3. **节点C (Generate)：** 将搜索结果写成一段视频脚本（英文）。
4. **节点D (Generate)：** 将英文脚本翻译成中文。
5. **节点E (Generate)：** 使用 **Veo** 模型，根据脚本生成视频+配音。
6. **节点F (Output)：** 最终生成一个包含视频和文案的网页。

**修改技巧：**

如果你对结果不满意（比如视频里的广告词不好），不需要改代码。

- 直接在下方的对话框输入：“再增加一个步骤，根据指定的广告语来播放”。
- AI 会自动在你的流程图里**插入一个新的节点**，并重新调整连线。

## 五、 常用功能清单 (Checklist)

- [ ] **模型选择：** 一般任务用 Gemini Flash（快）；复杂任务用 Gemini Pro（强）；画图用 Imagen；做视频用 Veo。
- [ ] **引用变量：** 在提示词里输入 `{` 就能调用上一步产生的内容。
- [ ] **工具调用：** 需要实时信息（天气、新闻、地图）一定要去右侧开通 `Tools`。
- [ ] **预览调试：** 善用 Preview 窗口，如果不动了，去 Console 看看是不是卡在某一步了。
- [ ] **应用分享：** 做好的应用可以保存到 Gallery，或者直接分享给别人使用。

---

## 六、 避坑指南

1. **视频生成慢：** 使用 Veo 模型生成视频通常比较慢（如视频演示中的进度条），这是正常的，请耐心等待。
2. **工具调用失败：** 如果AI胡说八道，检查一下 Generate 节点里是不是忘记勾选 `Search Web` 了。
3. **节点过多：** 如果流程太复杂，建议用“自然语言对话”让AI帮你整理一下布局，或者手动点击 `Edit` 优化。

通过这套 SOP，即便是完全不懂代码的小白，也能用 Google Opal 搭建出属于自己的 AI 应用（如卡路里计算器、旅游攻略生成器等）。
