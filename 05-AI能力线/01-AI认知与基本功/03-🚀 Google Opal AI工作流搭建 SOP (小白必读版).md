# 🚀 Google Opal AI工作流搭建 SOP (小白必读版)

## 📖 核心概念：Opal 是什么？

Opal 是一个让不懂代码的人也能搭建AI工作流的工具。

- **核心逻辑**：输入信息 -> AI处理（生成/搜索/分析） -> 输出结果。
- **四大核心节点**（记住这4个就能玩转）：

  1. **User Input (用户输入)**：你给AI什么信息（文字、图片、文件）。
  2. **Generate (内容生成)**：调用AI模型干活（写文、画图、做视频、配音）。
  3. **Output (结果输出)**：展示结果（网页形式、保存到Google文档等）。
  4. **Add Assets (添加资产)**：导入外部数据（本地文件、云盘、YouTube链接）。

---

## 🛠 模式一：AI 对话自动生成（最简单，推荐新手）

**适用场景**：你有一个想法，但不想自己一个个拖拽节点。

### 步骤 1：新建项目

1. 登录 Opal 官网。
2. 点击 **"Create New"** (新建)。
3. 选择左侧边栏的 **"Gems"** -> **"New Gem"** (或者直接在主页对话框输入)。

### 步骤 2：描述需求

在对话框中用自然语言描述你想做的工具。

- **话术示例**：

\> “帮我做一个UGC广告生成器。用户输入产品名、上传产品图和模特图，还有广告创意。然后工作流自动生成一张广告图，并且生成一段适合社交媒体投放的广告视频。”

### 步骤 3：AI 自动搭建与测试

1. AI 会自动生成节点连接图。
2. 点击右侧的 **Start** 按钮进行测试。
3. 如果有不满意的地方（比如生成的图片脸部崩坏），直接在对话框告诉AI：

\> “生成的模特脸部有些失真，请优化一下，生成图片时严格参考模特原图。”

1. AI 会自动调整工作流逻辑。

## 🔧 模式二：手动搭建工作流（更精准，进阶必学）

**适用场景**：AI生成的流程不完美，或者你需要精细控制每一个步骤（如切换更高级的模型）。

以下以**“全自动博客文章生成器”** 为例进行拆解：

### 第一阶段：设置输入与调研

1. **添加 Input 节点**：

   - 点击顶部 `User Input`。
   - 设置提示语：“请输入文章主题”。
2. **添加 Generate 节点（联网调研）**：

   - 点击顶部 `Generate`。
   - **关键设置**：模型选择 **"Plan and Execute"** (这是处理复杂任务的神器)。
   - **开启工具**：勾选右侧的 `Search Web` (联网搜索) 和 `Get Webpage` (获取网页内容)。
   - **Prompt**：连接上一步的输入，要求AI：“针对该主题进行研究，生成一份研究报告，包含历史背景、主流观点等。”

### 第二阶段：生成大纲与正文

1. **添加 Generate 节点（写大纲）**：

   - 模型选择：`Gemini 2.5 Flash` (速度快)。
   - Prompt：引用上一步的“研究报告”，要求生成文章大纲，风格偏学术。
2. **添加 Generate 节点（写正文）**：

   - 模型选择：`Gemini 2.5 Flash`。
   - Prompt：结合“研究报告”和“文章大纲”，生成详细正文。

### 第三阶段：生成配图（⭐关键点）

1. **添加 Generate 节点（画图）**：

   - **⚠️ 避坑指南**：系统默认使用 Flash 模型画图，效果一般。
   - **必须操作**：点击模型列表，手动切换为 **`Gemini 3 Pro Image (Nano Banana Pro)`**。
   - Prompt：根据文章大纲生成一张Banner配图。

### 第四阶段：输出结果

1. **添加 Output 节点**：

   - 点击顶部 `Output`。
   - 连接“文章正文”和“Banner配图”。
2. **选择输出格式**：

   - 方式A：`Webpage with auto-layout` (生成漂亮的网页布局)。
   - 方式B：`Save to Google Docs` (直接保存到你的谷歌文档，方便编辑)。

## 🎬 高级案例：UGC 广告全套素材生成流

这个案例展示了 Opal 的多模态能力（图、文、声、影）。

### 1. 准备四个输入源 (User Input)

- 产品名称 (文本)
- 产品图片 (上传图片)
- 模特图片 (上传图片)
- 广告创意描述 (文本)

### 2. 生成高质量广告图 (Image Generation)

- **节点**：Generate。
- **模型**：**必须手动切为 `Gemini 3 Pro Image`**。
- **技巧**：Prompt中强调“使用上传的模特图和产品图，保持面部特征不变”。

### 3. 生成广告视频 (Video Generation)

- **节点**：Generate。
- **模型**：选择 **`Veo`** (谷歌的视频生成模型)。
- **输入源**：连接上一步生成的“广告图” + “创意描述”。
- **Prompt**：描述运镜、动作（如“模特正在涂抹面霜，近景特写”）。

### 4. 生成配音与音乐 (Audio Generation)

- **新增输入**：广告语 (Slogan) + 音乐风格 (Vibe)。
- **生成配音**：

  - 模型：`AudioLM`。
  - **⚠️ 避坑技巧**：如果生成的配音和文本不一致，**在广告语的前后各加一个空格**。
- **生成背景乐**：

  - 模型：`Lyria`。
  - Prompt：根据输入的风格（如“安静、优美”）生成音乐。

### 5. 最终组合 (Output)

- 将生成的图片、视频、配音、背景乐全部连线到 Output 节点。
- 你可以一键预览所有素材，也可以下载到剪辑软件进行组装。

## 💡 特殊功能节点详解

### 📂 Add Assets (导入外部数据)

**作用**：让AI处理现成的内容。

- **案例1：视频总结**

  - 选择 `Add Assets` -> `YouTube`。
  - 粘贴视频链接。
  - 连接 Generate 节点，Prompt：“总结视频核心内容”。
- **案例2：冰箱剩菜变食谱**

  - 选择 `Add Assets` -> `Upload file`。
  - 上传冰箱里食材的照片。
  - 连接 Generate 节点，Prompt：“识别食材，推荐3道菜谱及做法”。

## ⚠️ 避坑与提效心得 (SOP 附录)

1. **模型选择是关键**：

   - 处理复杂逻辑/联网搜索：用 `Plan and Execute`。
   - 画图：**一定要手动改选 `Gemini 3 Pro Image`**，否则脸部容易崩坏。
   - 日常文本：用默认的 `Gemini 2.5 Flash` 即可，省额度。
2. **善用 Remix (复刻)**：

   - 在 Opal 首页有很多别人做好的优质工具（Gallery）。
   - 点击进入 -> 点击右上角 **Remix**。
   - 这会把整个工作流复制到你的空间，你只需要微调（比如把英文Prompt改成中文）就能用，无需从头搭建。
3. **调试技巧 (Console)**：

   - 如果报错或效果不好，点击右上角的 **Console** 标签。
   - 这里能看到AI思考的每一步过程，方便排查是哪一步Prompt出了问题。
4. **保存结果**：

   - 生成的网页虽然好看，但为了实用，建议在 Output 节点增加 **`Save to Google Docs`** 选项，直接转化为生产力。
