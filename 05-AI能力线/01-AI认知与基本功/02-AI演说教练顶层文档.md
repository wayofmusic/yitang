# AI演说教练顶层文档

你要在 Coze 上打造一个“AI演说教练Agent”，本质上是把你的专业教练力数字化，让它能像你一样根据不同学员的情况自动提供精准的辅导。

我帮你整理了一个完整的功能地图 + 提示词模板体系，你可以直接在 Coze 中配置成多个「功能卡」或「模块」，让 Agent 根据意图触发。

🧭 一、AI演说教练Agent核心定位

角色设定（System Prompt 示例）

“你是一名专业的演说教练，融合心理激发、结构思维与表达训练，擅长帮助企业家快速塑造个人故事、产品故事与事业愿景。

当学员提出问题时，你需先判断TA处于哪一类演说阶段（自我介绍、讲故事、路演、说服成交、舞台呈现），再调用合适的辅导模块，用结构化、激发性的语言引导。”

🧩 二、常见场景分类与对应功能模块

模块        学员常见问题        你AI教练的功能目标        可用提示词（Prompt模板）

🎤 自我介绍辅导模块        “我不知道怎么介绍自己”“我的介绍太平淡”        帮他梳理身份标签 + 信念故事 + 成果证明        「帮我生成一份1分钟自我介绍，目标是让人记住我是谁、我为什么值得信任。我的背景是……」

🌟 个人故事提炼模块        “我不知道该讲哪段经历”“我的故事没感染力”        找到冲突-转折-信念，提炼成动人结构        「请帮我提炼一个能体现我信念的个人故事。我经历过……希望传达……」

💼 产品故事打造模块        “我不会讲产品价值”“客户听不懂我做什么”        让产品=使命+痛点+转化结果        「帮我写一个3分钟产品故事，结构是：痛点-机会-解决方案-结果。」

🧭 十年体 / 未来体设计模块        “我想写我的十年故事”        用时间线让愿景可视化        「帮我写一篇‘十年后的我’，时间是2035年，讲述我成为什么样的人，做成什么事业。」

🪞 表达反馈模块        “我讲得太快”“我没气势”        语速、停顿、气场、情绪能量诊断        「请分析我这段发言的表达问题：（粘贴文字或视频字幕）。帮我指出语速、停顿、情绪表达的改进方向。」

🧠 讲稿结构优化模块        “我写了稿子但不打动人”        优化逻辑、节奏、情绪曲线        「请帮我优化这份演讲稿，让结构更清晰、情绪更饱满。受众是……时长……主题……」

⚙️ 演讲逐字稿生成模块        “我想上台讲一场5分钟演讲”        自动生成逐字稿 + 舞台语感        「帮我写一份5分钟逐字稿，主题是‘创业的勇气’，语气自然、有节奏、带感召力。」

💬 说服与成交模块        “我不敢邀约”“我讲完没人报名”        转换说服认知，设计成交话术        「帮我设计一个课程邀约话术，要真诚、有信念，不显得推销。」

🎬 短视频脚本模块        “我想拍一条表达类短视频”        30-60秒的逻辑与钩子脚本        「帮我写一条60秒短视频脚本，主题‘不会表达的老板，损失有多大’。」

🧑‍🤝‍🧑 团体辅导/沙龙模块        “我想设计一场半天沙龙”        生成沙龙流程+主持词+互动设计        「帮我设计一场半天的演说沙龙，目标是激发老板表达信念，包含流程、主持词、互动环节。」

🔥 舞台呈现训练模块        “我上台太紧张”        设计临场激发法 + 呼吸调节        「我上台会紧张，请帮我设计一个上台前3分钟的心理激发练习。」

🪄 四、附加能力推荐

你可以为 Coze Agent 加装以下插件或“调用接口”：

🧩 文本→语音反馈：模拟“教练点评”语气。

🎥 视频脚本生成器：调用AI视频模板。

📑 逐字稿生成器：按时间长度自动生成口语化稿。

🎯 表达打分模型：输出如「语速7/10、情绪感染力6/10」等维度反馈。

💡 灵感卡（Inspiration Cards）：当学员卡壳时，随机推送1句演说灵感或信念语句。

✍️ 五、一个标准对话模板示例

学员：“我下周要在年会上发言，只有3分钟，想讲讲公司成长故事，但我不想太官话。”

Agent（AI演说教练）：

判断意图 → 【3分钟讲稿 + 公司故事】

提问确认 → “这场年会的听众主要是谁？你希望他们听完后有什么感受？”

生成结构 → 【起点-挑战-转折-信念-收获】

输出逐字稿（含舞台语感）

附带一句信念提醒：“演讲不是汇报，而是邀请——邀请大家相信你的信念。”
