为了保证质量，我为你设计了一套 **“结构化两步走”** 的提示词策略。

**使用方法：**

1. **第一步（定骨架）：** 发送第一个提示词，让AI阅读书籍内容（或你提供的摘要/目录），生成拆书大纲。
2. **第二步（填血肉）：** 确认大纲无误后，发送第二个提示词，让AI根据大纲逐个部分撰写逐字稿。

# VV1

### 第一步：角色设定与大纲构建 (The Architect)

请复制以下内容发送给AI（并在附件上传PDF，或粘贴书籍核心内容）：

```Markdown
# Role
你是一位拥有百万粉丝的资深“拆书达人”和金牌讲书人。你擅长将晦涩难懂的书籍内容转化为通俗易懂、引人入胜的口语化演讲稿。你的风格幽默风趣、逻辑严密，并且总是能结合生活案例给听众带来“啊哈时刻”（Aha Moment）。

# Task
请阅读我提供的书籍文件（或以下内容），帮我为这本书设计一个“拆书分享会”的**核心大纲**。
**注意：此时不需要写出逐字稿，只需要输出结构框架。**

# Design Principles
1.  **受众画像**：没读过这本书，但对该领域感兴趣，渴望通过听书获得谈资或实际改变的成年人。
2.  **坡道原则**：开头必须有吸引力的钩子（痛点、故事或反直觉的观点）。
3.  **做减法**：不要试图面面俱到，只提炼书中3-4个最核心、最能颠覆认知或最实用的观点（Key Concepts）。
4.  **RIA便签法思维**：
    *   **R (Reading)**: 原书片段/核心概念。
    *   **I (Interpretation)**: 用大白话解释，通过比喻或案例深化理解。
    *   **A (Appropriation)**: 联系实际，给听众具体的行动建议。

# Output Format (请严格按照此格式输出大纲)
## 书名：《[书名]》拆书大纲

### 1. 开场坡道 (The Hook)
*   **开场痛点/悬念**：[一句话描述如何通过提问或故事抓住听众注意力]
*   **书籍定位**：[一句话介绍这本书解决了什么核心问题]

### 2. 核心拆解 (The Body) - 请提炼 3 个关键模块
*   **模块一：[核心概念1的标题 - 甚至可以是金句]**
    *   原书观点：
    *   讲解逻辑（案例/比喻）：
    *   听众行动点：
*   **模块二：[核心概念2的标题]**
    *   原书观点：
    *   讲解逻辑（案例/比喻）：
    *   听众行动点：
*   **模块三：[核心概念3的标题]**
    *   原书观点：
    *   讲解逻辑（案例/比喻）：
    *   听众行动点：

### 3. 结尾升华 (The Closing)
*   **全书总结**：[一句话总结]
*   **高光时刻**：[设计一句必须要让听众记住的金句]
*   **行动呼吁 (Call to Action)**：[给听众布置一个小作业或思考题]

---
请先阅读书籍内容，并输出上述大纲。待我确认大纲满意后，我们再进行逐字稿的撰写。
```

### 第二步：逐字稿生成 (The Speaker)

当AI输出了大纲，且你觉得逻辑通顺后，请发送这个提示词。

*建议：为了防止AI字数超限，建议分模块让它写，效果最好。*

#### 选项 A：一次性尝试生成（适合短内容或长文本模型）

```Markdown
大纲已确认。现在请根据上述大纲，撰写一份完整的**拆书会逐字稿**。

# Requirements
1.  **口语化表达**：完全模拟真人演讲，多用“大家有没有这种经历”、“其实啊”、“举个例子”等连接词，拒绝书面语和翻译腔。
2.  **互动感**：在转换话题时，适当加入设问句，模拟与观众的眼神交流。
3.  **故事性**：在解释理论时，必须搭配一个具体的生活场景或案例（可以是虚构的职场/生活故事），让听众有代入感。
4.  **情绪起伏**：不要平铺直叙，要有情绪的递进，关键观点要用强调的语气（通过标点或短句体现）。
5.  **篇幅**：总字数控制在 [例如：2500-3000] 字左右，适合 10-15 分钟的分享。

请开始撰写，直接输出正文，第一人称“我”。
```

#### 选项 B：分段生成（强烈推荐，质量最高）

**先发这条：**

```Markdown
大纲已确认。现在我们需要分模块撰写逐字稿，以确保内容的深度和口语化质量。

请先撰写 **【1. 开场坡道】** 和 **【2. 核心拆解 - 模块一】** 的逐字稿。
要求：
- 语气亲切、幽默，像在和朋友聊天。
- 开场要迅速抓住痛点，模块一的案例要生动。
- 保持第一人称“我”。
```

**AI写完后，再发这条：**

```Markdown
写得很棒！请继续撰写 **【2. 核心拆解 - 模块二】** 和 **【2. 核心拆解 - 模块三】** 的逐字稿。
要求：
- 注意模块之间的衔接过渡，要自然顺滑。
- 确保案例贴近生活。
```

**最后发这条：**

```Markdown
请完成最后部分：撰写 **【3. 结尾升华】** 的逐字稿。
要求：
- 情绪要饱满，给出有力的金句。
- 最后的行动呼吁要具体可行。
```

### 给你的额外建议 (Pro Tips)

1. **如果AI理解有误**：在第一步生成大纲时，如果发现AI提取的观点不是你想要的，可以直接回复：“模块二的观点太浅显了，请替换为书中关于‘XXX’的那个理论。”
2. **关于PDF读取**：目前的AI（如ChatGPT Plus, Claude 3, Kimi等）读取长PDF能力不同。如果书太厚（超过300页），建议先让AI“总结全书的10个核心观点”，然后你挑出3个，让它基于这3个点去生成大纲，这样准确率更高。
3. **风格微调**：你可以在提示词中加入特定的风格指令，例如：“请模仿罗振宇的风格”、“请模仿樊登的风格”或“请用脱口秀的风格”。

### 第一步：生成“一页纸拆书大纲” (The Blueprint)

请复制以下内容发送给AI（记得在附件上传PDF）：

```Markdown
# Role
你是一位专业的金牌领读人，擅长从复杂的书籍中提炼精华，并能结合网络信息完善书籍背景。你的核心能力是将厚书读薄，产出高质量的“一页纸拆书指南”。

# Task
请阅读我上传的书籍PDF（或提供的文本），并结合**联网搜索**功能，按照我指定的模板生成一份《一页纸拆书大纲》。

# Steps
1.  **联网搜索**：请搜索这本书在“豆瓣（Douban）”的评分。如果找不到具体评分，请查找相关的书评热度或评价概况。
2.  **深度阅读**：分析PDF内容，提取核心观点和精彩案例。
3.  **大纲生成**：严格按照下方的“Output Format”填充内容。

# Output Format (请严格遵守此模板)
## 🧾 《[书名]》一页纸拆书指南

### 1. 书籍名片 📇
*   **书名**：[全名]
*   **作者**：[作者名]
*   **豆瓣评分**：[请填写搜索到的评分，如：8.5分]
*   **一句话推荐**：[基于评分和内容，用一句吸引人的话推荐这本书]

### 2. 核心问题 🎯
*   **本书解决的痛点**：[这本书到底是写给谁看的？解决了什么具体焦虑或难题？请用“用户视角”描述]
*   **核心论点**：[用一句话概括作者的终极答案]

### 3. 亮点案例 (关键素材) 💡
*   **案例一（颠覆认知）**：[提取书中一个反直觉或印象深刻的案例，简述背景+冲突+结果]
*   **案例二（实操落地）**：[提取书中一个具体的应用场景或实验]
*   *注意：这一部分是未来演讲的素材库，请尽量保留故事细节。*

### 4. 三大收获 (核心干货) 💎
*   **收获一**：[概念/理论] + [解释]
*   **收获二**：[概念/理论] + [解释]
*   **收获三**：[概念/理论] + [解释]

### 5. 行动改变 🚀
*   **立刻能做的一件事**：[读完这本书，听众明天早上起床就能执行的一个微小动作是什么？]

### 6. 金句共鸣 💬
*   **全书金句**：[引用书中原文最有力、最扎心的一句话]

---
请先执行搜索并阅读，生成上述“一页纸指南”。待我确认后，我们再基于此生成逐字稿。
```

### 第二步：基于一页纸生成“逐字稿” (The Script)

当AI输出了上面的一页纸表格，且你确认内容准确后，发送这条指令：

```Markdown
非常棒，大纲已确认。
现在，请你化身为一位幽默、亲切的读书会主持人，基于上面的《一页纸拆书指南》，为我生成一份**3000字左右的分享逐字稿**。

# Script Structure (逐字稿逻辑流)
1.  **开场（暖场+名片）**
    *   用“大家最近有没有遇到[核心问题]”提问开场。
    *   自然引出书名、作者，并提到“这本书在豆瓣有[评分]的高分，非常值得一读”。
2.  **核心展开（亮点+收获）**
    *   **不要干巴巴地列举知识点**。请把【3. 亮点案例】和【4. 三大收获】融合在一起讲。
    *   采用“讲故事 -> 抛出观点 -> 解释原理”的逻辑。
    *   比如：“书中讲了这样一个故事...（案例），这其实就是作者提到的...（收获）”。
3.  **高潮与结尾（行动+金句）**
    *   在演讲快结束时，严肃且真诚地抛出【6. 金句共鸣】。
    *   最后，给听众布置作业，也就是【5. 行动改变】，邀请大家一起打卡。

# Tone & Style
*   **口语化**：多用短句，多用“对吧”、“各位”、“想象一下”。
*   **互动感**：模拟现场交流的感觉。
*   **第一人称**：自称“我”，称呼听众为“书友们”或“大家”。

请开始撰写逐字稿。
```

### 这个提示词设计的亮点：

1. **强制搜索（Browsing）**：解决了PDF文件里没有“豆瓣评分”和“大众评价”的问题，让拆书稿看起来更客观、更实时。
2. **模版对齐**：完全把你提供的6点要求融入到了提示词中，保证输出结构是你熟悉的“一页纸”风格。
3. **素材分离**：在第一步特意强调提取“亮点案例”，是为了防止第二步写逐字稿时AI只会讲大道理，而没有故事支撑（这是AI写稿最容易枯燥的地方）。
