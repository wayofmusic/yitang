# 🚀 OpenCode 新手实战 SOP：从“码农”进阶为“指挥官”

## 💡 核心认知：为什么要换工具？

- **Cursor 模式** = 你是工头，AI 是小工。你盯着代码细节，累。
- **OpenCode 模式** = 你是产品经理/甲方，AI 是整个外包团队。你只管提需求、看结果，爽。
- **克服恐惧**：不要怕那个黑色的终端窗口（Terminal），它本质上就是一个**聊天框**，你只需要打字跟它聊天。

---

## 第一阶段：搞定“燃料” (配置高性价比模型)

OpenCode 自带的免费模型没了，现在需要自己配置模型。根据你的预算和需求，二选一：

### 🅰️ 方案一：国内高性价比党（推荐⭐️）

**适合人群**：追求稳定、便宜、无需折腾魔法网络的国内用户。

1. **选择一：智谱 (Zhipu AI)**

   - **套餐**：GLM Coding Lite / Coding Plan
   - **价格**：前3个月约 54元（平均18元/月），之后40元/月。
   - **操作**：去智谱开放平台购买 Coding 套餐，获取 API Key，填入 OpenCode 配置。
2. **选择二：MiniMax**

   - **套餐**：Starter (29元/月) 或 Plus (49元/月)。
   - **操作**：同上，去 MiniMax 平台购买。

### 🅱️ 方案二：全球顶配性能党（推荐⭐️⭐️）

**适合人群**：追求最强代码能力，已有魔法环境，预算稍宽裕。

1. **购买 GitHub Copilot 会员**

   - **价格**：Pro版 \$10/月（约72元）。
   - **优势**：可以同时白嫖使用 GPT、Claude、Gemini 等顶级模型。
   - **操作**：

     1. 购买 GitHub Copilot 订阅。
     2. 在 OpenCode 设置中授权连接 GitHub 账号。
     3. **搞定！** 这是目前最省心、也是能用到全球最强模型的方案。

## 第二阶段：实战工作流 (大神同款 4 步法)

在 OpenCode 的聊天框里，不要从头用到尾只用一个模型。**根据任务阶段切换模型（Switch Models）**，效果最好。

### 1️⃣ 第一步：计划与方案讨论

- **当前任务**：搞清楚要做什么，设计架构。
- **推荐模型**：**GPT-5.2** (或同级别高智商模型)
- **为什么**：沟通能力强，像真人专家，能听懂你的“人话”并转化为技术方案。
- **话术示例**：“我要做一个网页版的番茄钟，你帮我规划一下功能模块和技术栈。”

### 2️⃣ 第二步：真正写代码

- **当前任务**：生成具体的代码文件。
- **推荐模型**：**Claude 系列**
- **为什么**：逻辑严谨，代码可靠性最高，不容易瞎编乱造。
- **操作**：确认方案后，让 Claude 执行写入。

### 3️⃣ 第三步：前端与界面调整

- **当前任务**：做网页样式、图片理解、界面布局。
- **推荐模型**：**Gemini 3 Pro** (或同级别视觉模型)
- **为什么**：视觉理解能力最强，懂审美，懂前端布局。

### 4️⃣ 第四步：审查与改 Bug

- **当前任务**：Code Review（代码审查）、修补报错。
- **推荐模型**：**GPT-5.2 Codex**
- **为什么**：长上下文理解能力强，能一次性读懂整个项目的代码，精准定位 Bug。

---

## 第三阶段：避坑指南 (千万别踩的雷)

### ❌ 禁忌一：新手别碰 "CC-Switch"

- **是什么**：一个开源项目，用来强行把 Claude Code 里的模型换成其他的。
- **为什么不推荐**：

  1. **费钱**：必须走 API Key 计费，跑一个复杂任务可能几刀几十刀就没了，不像包月套餐兜底。
  2. **风险**：这属于“违章建筑”，可能会导致你的账号被官方封禁。
  3. **建议**：老老实实买官方套餐或 Copilot 包月。

### ❌ 禁忌二：别再像用 Cursor 那样盯着代码看

- **思维转换**：在 OpenCode 里，你看不到代码文件的细节（除非你特意打开）。
- **你要做的是**：

  - 怎么精准描述需求？
  - 怎么规划执行流程？
  - 怎么验收最终结果？
- **记住**：一旦报错，直接把错误信息丢给 AI，让它自己修，别自己去翻代码行。

---

## 📝 总结：新手起步路线图

1. **下载 OpenCode**（或 Claude Code 等同类终端工具）。
2. **充值**：买个 **GitHub Copilot (\$10)** 或者 **智谱包月 (¥18-40)**。
3. **配置**：把账号连进去。
4. **开跑**：打开终端 -> 输入需求 -> 看着 AI 自动干活 -> 喝咖啡验收。

现在，去跑一个你的小项目试试吧（比如“帮我写一个贪吃蛇游戏”），你会发现新大陆的！
