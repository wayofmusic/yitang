# 2. 背景与灵感

- **背景：** 随着私董会AI化的趋势，如何有效注入“情绪价值”成为关键。
- **灵感来源：** 近期发现 `nano-banana-pro` 能够很好地生成**Q版文字和图片，**非常适合用于提升情绪价值。

# 3. 所需工具与准备

- **核心工具：**

  - **大模型（文案生成）：** `Google-gemini` （或其他类似的大模型，如ChatGPT等）。
  - **多模态生成工具（图片生成）：** `nano-banana-pro`，**其他国内jimeng也可以试试……没测过。**
- **前置条件：** **私董会的文字记录，**从中提取需要转化的“夸夸”内容。
- **付费选项：**

  - `nano-banana-pro` 在AI Studio中的免费使用受限，可能需要通过付费API Key（例如在AI Studio中购买）来获得更好的效果。
  - 如何搞付费API？
  - Gemini API 提供免费层级和付费层级，付费层级提供更高的速率限制和更先进的功能。

# 5. 实践技巧与复盘

- **效果对比：**

  - 使用免费版 `nano-banana` 的效果可能不如付费的 `nano-banana-pro`。
  - 试用Gemini官网里面 `nano-banana-pro`，**效果也不如付费，因为付费可以开4K 用Gemini官网是1k分辨率。 付费API Key（如AI Studio中的付费API Key）可以提供更稳定和高质量的生成效果。**
  - 即梦的效果文字模糊不清。agent状态也不太行。
- **文案与图片联动：** 确保生成的文案简洁有力，图片风格与文案的情绪价值相匹配。
- **迭代优化：**

  - 尝试不同的提示词组合，找到最适合您团队风格的图片。
  - 如果对生成结果不满意，可以微调提示词，或利用 `nano-banana-pro` 的编辑功能（如涂鸦编辑、风格调整）进行二次创作。
- **复盘思考：**

  - **最终成果：** 生成了多少张“图片夸夸”？在私董会或团队沟通中，这些图片带来了怎样的积极反馈？
  - **认知心得：** AI工具在提升团队凝聚力和情绪价值方面有哪些潜力？如何更有效地将AI融入日常团队协作？
