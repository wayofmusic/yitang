# 谷歌云 (GCP) 永久白嫖/低成本 VPS 搭建 SOP

## ⚠️ 核心注意事项 (必读)

1. **几乎免费≠绝对0元**：如果不小心产生了出站到特定CDN（如Cloudflare）的流量，可能会有一年几毛钱人民币的费用。
2. **信用卡要求**：必须拥有一张支持外币支付（Visa/MasterCard）的信用卡（部分国内发行的双币卡也可以）。
3. **按部就班**：请严格按照本教程的配置选择，错选任何一个配置（如地区、磁盘类型、网络层级）都可能导致扣费。

---

## 第一阶段：账号注册与免费试用开启

**目标**：获得3个月\$300美金试用金，并建立结算账号。

1. **访问官网**：打开 [cloud.google.com](https://cloud.google.com)。
2. **登录账号**：点击右上角登录，使用你的 Gmail 邮箱登录。
3. **开启试用**：点击首页的“免费开始使用”或“激活 \$300 赠金”。
4. **填写信息**：

   - **国家/地区**：建议选 **美国** (United States)。
   - **账号类型**：选择 **个人**。
   - **地址信息**：找一个“[美国地址生成器](http://meiguodizhi.com)”网站，生成一个[ ](https://www.meiguodizhi.com/usa-address/oregon)[**俄勒冈州 (Oregon)**](https://www.meiguodizhi.com/usa-address/oregon)[ ](https://www.meiguodizhi.com/usa-address/oregon)的地址（免税州）。将生成的街道、城市、邮编填入。
5. **绑定支付**：

   - 输入你的 Visa 或 MasterCard 信用卡信息。
   - 谷歌会扣除一笔小额资金验证（通常会立刻退还），验证卡片有效性。
6. **完成注册**：提交后，看到“欢迎使用”界面即表示注册成功。

## 第二阶段：创建“永久免费”标准的虚拟机 (关键步骤)

**目标**：创建一个符合 Google 免费政策配置的 VPS 实例。

1. **进入控制台**：在左侧菜单栏找到 **Compute Engine** -> **虚拟机实例** (VM Instances)，点击 **创建实例**。

1. **配置参数 (请严格核对)**：

   - **名称**：随意（例如 `vps-free`）。
   - **区域 (Region)**：**必选以下三个之一**（推荐俄勒冈，离国内近）：

     - `us-west1` (俄勒冈 - Oregon) ✅ 推荐
     - `us-central1` (艾奥瓦 - Iowa)
     - `us-east1` (南卡罗来纳 - South Carolina)

   - **机器配置**：

     - 系列：**E2**
     - 机器类型：**e2-micro** (2 vCPU, 1 GB 内存) —— *选错必扣费* 。

   - **启动磁盘 (Boot Disk)**：点击“更改”

     - 操作系统：**Linux** (推荐 **Ubuntu**，版本选 `22.04 LTS` x86/64)。
     - 磁盘类型：**标准永久性磁盘** (Standard persistent disk) —— \*选SSD必扣费\*。
     - 大小：**30 GB** —— \*必须是30GB，不能多也不能少\*。
     - 点击“选择”。

   - **数据保护 (重点防坑)**：

     - 找到“高级选项”或直接看“数据保护”栏。
     - **取消勾选** “启用备份”或将备份方案改为 **无备份**。 *由默认的快照备份产生费用是新手最常见的扣费原因* 。

   - **网络 (Firewall)**：

     - 勾选 **允许 HTTP 流量**。
     - 勾选 **允许 HTTPS 流量**。

   - **高级网络配置 (省钱核心)**：

     - 展开 **网络 (Networking)** -> **网络接口**。
     - **外部 IPv4 地址**：保持 **临时 (Ephemeral)**。 \*不要选静态IP，静态IP闲置时收费\*。
     - **网络服务层级 (Network Service Tier)**：**改为 标准 (Standard)**。
     - *解释：高级层级没有免费流量；标准层级每月送200GB免费流量。*

2. **确认创建**：检查右侧估算费用（不用管那个显示的金额，那是原价，符合上述配置会自动抵扣），点击 **创建**。**注意 找防火墙的规则！**

## 第三阶段：部署科学上网节点 (一键脚本)

**目标**：在 VPS 上安装代理软件（Sing-box）。

登录软件推荐：
[🚀 告别纯黑白命令行！7 款神级 SSH 终端工具推荐](01-🚀%20告别纯黑白命令行！7%20款神级%20SSH%20终端工具推荐.md)</cite>

1. **连接 VPS**：

   - 在虚拟机实例列表中，找到刚创建的机器。
   - 点击右侧的 **SSH** 按钮，会弹出一个浏览器内的黑底白字命令行窗口。
2. **获取 Root 权限**：

   - 输入命令并回车：`sudo -i`
3. **运行安装脚本** (推荐甬哥 sing-box 脚本)：

   - 复制并粘贴以下命令，然后回车：

     ```Bash
     bash <(wget -qO- https://raw.githubusercontent.com/yonggekkk/sing-box-yg/main/sb.sh)
     ```
4. **脚本交互步骤**：

   - 输入 `1` 选择 **安装**，回车。
   - 后续大部分选项（如端口、内核版本）直接 **回车** 使用默认设置即可。
5. **证书配置 (推荐有域名的做法)**：

   - *如果你没有域名*：选择自签证书（可能会被部分客户端提示不安全）。
   - *如果你有域名 (推荐)*：

     1. 去你的域名服务商（如Cloudflare），添加一个 **A记录**。

        - 名称：任意（如 `test`）。
        - IP地址：填入你 VPS 的 **外部 IP** (在谷歌云后台能看到，35.xxx开头的)。
        - **重要**：如果用 Cloudflare，**必须关闭小黄云 (Proxy status: DNS only)**。
     2. 回到 SSH 窗口，选择 **申请 ACME 域名证书**。
     3. 输入你解析好的域名（如 `test.你的域名.com`）。
6. **安装完成**：

   - 脚本运行结束后，会显示一堆链接和二维码。
   - 重点复制 **Hysteria2** 或 **TUIC** 协议的链接（因为标准层级网络一般，这就两个协议速度最快）。

## 第四阶段：客户端连接与测试

1. **获取链接**：复制脚本输出的节点链接（以 `hy2://` 或 `tuic://` 开头）。
2. **导入软件**：

   - **Windows**: 使用 `v2rayN` 或 `Nekoray`。
   - **Android**: 使用 `Nekobox` 或 `Sing-box` 官方客户端。
   - **iOS**: 使用 `Shadowrocket` (小火箭) 或 `Sing-box`。
3. **测试**：开启代理，访问 YouTube 4K 视频测试速度。

---

## 第五阶段：避坑指南 (如何防止意外扣费)

在使用过程中，为了保住免费流量权益，**严禁**做以下操作：

1. ❌ **不要开启 Cloudflare 的 CDN (小黄云)**：域名解析必须是灰云 (DNS Only)。
2. ❌ **不要使用 Cloudflare Argo 隧道**。
3. ❌ **不要在 VPS 上开启 WARP**：视频中提到，开启 WARP 后流量会经过 Cloudflare 网络，导致谷歌云判定为 CDN 互联流量而收费。

---

## 第六阶段：试用期结束后的操作 (永久使用)

**场景**：3个月试用期结束，或者\$300赠金用完后。

1. **账号状态**：谷歌云会暂停你的虚拟机服务。
2. **激活账号**：

   - 登录控制台，顶部会有提示条。
   - 点击 **激活 (Activate)** 或 **升级 (Upgrade)** 账号。
3. **确认配置**：

   - 只要你的虚拟机配置严格遵守 **第二阶段** 的所有参数（e2-micro, 30GB标准盘, 俄勒冈, 标准网络层级）。
   - 即便升级为付费账号，根据谷歌的 **Always Free 政策**，每月账单也会被抵扣掉（除了极其微小的 CDN 互联费用，**一年约几毛钱）。**
4. **无需重建**：升级账号后，启动原来的虚拟机即可继续使用，IP可能会变，记得去域名解析处更新 IP。

---

### 💡 常见问题排错

- **SSH连不上**：检查防火墙设置**，确保勾选了允许 HTTP/HTTPS，**或者手动添加防火墙规则放行所有端口。
- **速度慢**：确认是否使用了 **Hysteria2 或 TUIC 协议，普通 VLESS 协议在标准网络层级下可能较慢。**
- **IP变了**：因为选的是“临时IP”，每次关机重启 VPS 后 IP 都会变。需要去域名服务商那里修改解析。
