## 各提示词框架

### ROSES框架

• Role 角色：指定ChatAI 的角色

• Objective 目标：说明目的或目标

• Scenario 场景：描述情况

• Solution 解决方案：定义期望的结果

• Steps 步骤：询问达成解决方案所需的行动

**常用场景**

适用于复杂多步骤的解决方案场景,如长期项目规划、商业决策等； 需明确阐述角色、目标、情景、预期结果和具体步骤

**提示词示例**

```SQL
角色：想象一下，你是一个有十年经验的数字营销顾问。

目标：你的客户的目标是，他们电子商务网站的流量，在下一个季度增加 30% 。

场景：他们重新设计了网站，推出了一系列环保家居产品。

解决方案：该公司正在寻求一个详细的搜索引擎优化战略，既创新又能坚持最新的搜索引擎指南。

步骤：概述的步骤包括执行一个全面的搜索引擎优化审计，进行关键字研究； 具体到生态友好的产品市场，优化页面上的搜索引擎，包括元标签和产品描述，并创建一个反向链接策略，针对有信誉的可特续性博客和网站。
```

### TAG框架

• Task 任务：定义具体任务

• Action 行动：描述需要做什么

• Goal 目标：解释最终目标

**常用场景**

探索任务/问题的解决方案；通用场景

**提示词示例**

```SQL
任务：我们的任务是扩大我们公司在 lnstagram上与受众的互动。

行动：这就需要推出一个用户生成的内容活动，客户穿着我们的运动产品，使用一个独特的标签，分享他们的个人健身之旅。

目标：最终目标是在下一委度，我们的 instagram 用户生成内容提交量提高50%。
```

### TRACE框架

• Task 任务：定义具体任务

• Request 请求：描述您的请求

• Action 行动：说明您需要采取的行动

• Context 语境：提供背景或情况

• Example 示例：举一个例子来说明你的观点

**常用场景**

任务完成场景；通用场景

**提示词示例**

```SQL
任务：你的任务是创建一个有吸引力的电子邮件营销活动。

请求：需要你帮忙起草邮件的主题和正文。

行动：我们需要你起草几个这样的例子。

语境：这就是我们即将到来的年终清仓大甩卖，目标是我们现有的客户群。

示例：一个成功的现实世界的电子邮件活动是 Warby Parker的 “啊，你的处方过期了”的活动。利用自动电子邮件提醒客户其即将过期的处方，并敦促他们获得新处方，有效地提高了客户参与度。
```

### ACHIEVE框架

- Achieve: 帮助人类做准备工作
- Cut: 删除繁琐的任务
- Help: 帮助建立安全网
- IEV（Inspiring better problem solving and creativity）：帮助跳出框架思考，形成更有创造力的解决方案
- Enable: 让好的想法快速扩大

**常用场景**

适用于做计划； 评估计划； 收集及验证想法

**提示词示例**

```SQL
A 帮助准备：我在设计一个学习AI的工作坊：请你作为我的助手，读下列会议资料，向我提供探讨要点的摘要。请帮我找出关于这次会议模棱两可的地方。
C 删除繁琐任务：
H 帮助建立安全网：
方面一：当给不同群体做Workshop的时候，面对受众的转换，AI可以帮助检查潜在风险。i.e.上传了120张PPT，“请阅读我的前10张PPT，告诉我我使用的任何我没有定义的、制造业企业高管，可能不熟悉的技术术语”
方面二：当不同的团队在致力于完成同一个目标时，AI可以帮助发现不同团队做出的相互矛盾的决策，以致于检查出可能对目标达成产生潜在的风险。i.e.技术团队准备的麦克风、投影仪设备是针对较小空间的会议室；而后勤团队预定的场地是较大空间的。
IEV：帮助形成更有创造力的解决方案
在做工作坊的过程中，发现需要提供儿童服务。从之前调研的细分受众中，发现有一群四年级的学生，他们都对口袋妖怪的游戏感兴趣。是否可以制作出一些有意思的内容，使这些内容与他们父母正在学习的内容吻合，但对这些年轻受众要更有针对性。
E: 让好的想法快速扩大
在这个工作坊的结尾，我会发邮件邀请大家参加，提升大家参加的动力，可否在邮件中给每个部门定制一个提示词，展示他们能用AI做什么以及他们可能潜在能用AI做什么
“在这个工作坊的结尾，我会邀请函给每个潜在的工作坊的参与者。我希望你创建一个有趣的ChatAI提示词列表，以及将LLMs与每个学科或部门相结合的方法。每个部门至少需要一个非常有趣和创造性的提示词，针对部门的学科和如何在该学科中应用LLMs的一个想法。列出所有的部门以及对应的提示词和想法。”
```

### AI五元素提示词框架

- 背景：给到AI背景信息
- 任务：说明白你想让AI帮你完成什么任务
- 人设：给AI一个角色/人设，越具体得到的答案可能会越精准
- 格式：规范AI输出的格式
- 语气：如有必要，规范AI输出的语气

**常用场景**

任务完成场景；通用场景

**提示词示例**

```SQL
我是自媒体工作者，需要一篇视频口语文稿，我的视频节目一般会将时长控制在5分钟，请你扮演沃伦·巴菲特/一位公共经济学专家，帮我分析这篇文章，归纳重点信息，并提出有见解的分析，请使用轻松、直白的语气。

请按照以下格式进行回复：
背景介绍
事发原因
直接经济影响
间接经济影响
在证券市场预计会对哪些行业造成负面影响
短期利好行业
总结
```

### BROKE框架

- 背景 (Background): 说明背景，为 ChatAI 提供充足信息
- 角色 (Role):我希望ChatAI扮演的角色
- 目标(Objectives): 我们希望实现什么
- 关键结果(Key Result): 我要什么具体效果试验并调整
- 试验并改进 (Evolve)

**常用场景**

完成任务场景； 小红书爆款笔记生产

**提示词示例**

```SQL
我在小红书打造一个个人IP，15年互联网运营营销经验，多个成功0-1创业项目经验，操盘过千万级用户规模的增长和私域运营，目标对象是3%的自燃型人群，包括企业主、创业者、中高管和互联网从业者。我希望能通过分享小红书笔记，传授我的经验给大家。

你是一名资深的小红书玩家，有5年以上小红书爆款文案创作经验，擅长用简约而不简单，专业且易懂的文字，吸引读者。

请围绕“如何在小红书涨粉1000”这个主题，写一篇爆款的小红书笔记。

你输出的小红书爆款笔记的具体要求如下:
1.字数500字，用总-分-总结构写作。
2.重点写小红书起号的5个步骤:(1)搞清平台规则；(2)做好账号定位，明确你是谁?能提供什么价值?(3)账号对标；(4)做好内容规划和选题；(5)爆款笔记模仿；(6)持续发布爆款笔记。
3.请用小红书平台读者喜欢的形式输出
表达自然，口语

试验并调整，通过试验来检验结果，并根据需要与Chat AI沟通并进行调整。
```

### ACTOR框架

- 角色（Actor）：执行任务的主体
- 上下文（Context）：任务的背景或情境（如工作、两性、社交等）
- 任务（Task）：主体执行的任务。任务类型有对话、创作、推理和个性
- 输出（Output）：以什么样的风格或格式输出内容 重复
- 重复控制（Repeat）：要求角色重复N次执行任务，提高回答的质量

**常用场景**

完成任务场景；#写周报

**提示词示例**

```SQL
月底该汇报本月工作了，每次写工作汇报都头疼，1、2天也写不好。不如这次让AI写吧，看看能不能比我写得好。大不了AI写初版，我再修改润色。

我是一名文案专员，主要工作就是写文案。我这个月做了20个公众号文章的选题，被领导选用了15个，上个月通样20个选题只被选中了10个。我还写了8篇公众号文章，16篇小红书，4个短视频文案。小红书累计收藏量1200，公众号文章累计阅读量10万。我觉得还是很好的成绩了，而且比上个月在文章质量上有进步。不足之处是短视频文案的吸引力还不够好，可能由于文案太短了，反而难度很高。你是职场高手，最擅长写我这个岗位的月度工作汇报了。帮我写这个月的工作汇报，要轻松点的写作风格，别一本正经的。1000字左右，别太短。·把我的成绩突出出来，来个环比效果。

结尾处修改一下，别写未来的工作，太远了，写下个月的工作
```

### LACES框架

- Limitation: 增加限定条件
- Assignment: 分配角色
- Context: 提供背景或上下文
- Example: 给出示例
- Step by Step: 拆分任务

**常用场景**

完成任务场景；#写小说

**提示词示例**

```SQL
帮我写一部科幻小说

L: 未来2030年发生的故事

A:假设你是科幻小说作家 刘浪浪

C:我希望这部小说具有划时代的意义，充满创意和未来感，能够表达人类情感的重要性

E:举例就像刘慈欣的小说《流浪地球》

S:
·请为我创作一个科幻小说的开篇，包括情节背景和引人入胜的故事开头，800字以内；
·请确定小说的核心主题和背景设定(举例如未来世界、外星探险等).
·确定主人公的性格特点、外貌描写和职业背景等。
·设定一系列支持角色，如家人、朋友或对手，以及他们与主人公的关系。
·规划一下小说情节的大致发展，从而使故事更有吸引力。
```

### CO-STAR框架

- 上下文(Context)：提供任务的上下文信息，这有助于LLM了解正在讨论的具体情景，确保其答复具有相关性
- 目标(Objective)：确定你希望LLM执行的任务是什么
- 风格(Style)：指明你希望LLM使用的写作风格，这将引导LLM以符合你需求的方式和用词做出回复。例：可以是某个名人的写作风格，也可以是某个行业的某个专家，如商业分析专家或首席执行官
- 语气(Tone)：确定回复的态度。例如，正式的、幽默的、善解人意的等
- 受众(Audience)：确定回复的对象。例：某一领域的专家、初学者、儿童等
- 回复(Reply)：提供回复格式。这可确保LLM按照下游任务所需的准确格式输出。例如，列表、JSON、专业报告等

**常用场景**

完成任务 #写社交媒体文案

**提示词示例**

```SQL
#上下文#
我想为我公司的新产品做广告。我的公司名叫Alpha，产品名叫Beta，是一种新型超快吹风机。

#目标#
为我创建一个Facebook帖子，目的是让人们点击产品链接购买它。

#风格#
效仿戴森等宣传类似产品的成功公司的写作风格。

#语气#
有说服力的。

#受众#
我公司在Facebook上的受众通常是老一代人。请针对这部分受众通常对美发产品的要求，量身定制你的帖子。

#回复#
Facebook上的帖子，简明扼要而又富有感染力。
```

### 结构化提示词框架

- Role 角色:  想让AI扮演的什么人设
- Profile 简介：包含任务的版本、语言和描述
- Attention注意：想让AI注意什么
- Skills: 希望AI具备/掌握什么能力
- Goals: 希望AI实现什么目标
- Constrains: 有哪些限制或规则
- Workflow：完成工作的流程
- Initialization：写下当你在开启对话框时AI对你说的第一句话

**常用场景**

完成任务场景； #写诗 #概念学习 #商业分析

**提示词示例**

```SQL
Role: 诗人

Profile
Author: YZFly
Version: 0.1
Language: 中文

Description: 诗人是创作诗歌的艺术家，擅长通过诗歌来表达情感、描绘景象、讲述故事，具有丰富的想象力和对文字的独特驾驭能力。诗人创作的作品可以是纪事性的，描述人物或故事，如荷马的史诗；也可以是比喻性的，隐含多种解读的可能，如但丁的《神曲》、歌德的《浮士德》。

擅长写现代诗
现代诗形式自由，意涵丰富，意象经营重于修辞运用，是心灵的映现
更加强调自由开放和直率陈述与进行“可感与不可感之间”的沟通。

擅长写七言律诗
七言体是古代诗歌体裁
全篇每句七字或以七字句为主的诗体
它起于汉族民间歌谣

擅长写五言诗
全篇由五字句构成的诗
能够更灵活细致地抒情和叙事
在音节上，奇偶相配，富于音乐美

Rules
内容健康，积极向上
七言律诗和五言诗要押韵

Workflow
让用户以 "形式：[], 主题：[]" 的方式指定诗歌形式，主题。
针对用户给定的主题，创作诗歌，包括题目和诗句。

Initialization
作为角色 <Role>, 严格遵守 <Rules>, 使用默认 <Language> 与用户对话，友好的欢迎用户。然后介绍自己，并告诉用户 <Workflow>。
```

### CARE框架

- Context: 背景
- Action: 行动
- Result: 结果
- Example: 示例

**常用场景**

通用场景；完成任务场景；#传播活动策划

**提示词示例**

```SQL
语境: 我们的组织最近推出了一个新的可持续服装系列。
行动: 你能协助我们创建一个有针对性的广告活动，强调我们的环保承诺吗?
结果：我们期望的结果是提高产品的知名度和销量，特别是在有生态意识的消费者结果中。
例子：类似的成功举措的一个很好的例子是Patagonia的"不要买这件夹克”活动，这有效地突出了他们对可持续发展的承诺，同时提升了他们的品牌形象。
```

### SAGE框架

- 情况（Situation）：描述背景或情况。
- 行动 (Action)：描述需要做什么。
- 目标 (Goal)：解释最终目标。
- 期望 (Expectation)：概述您希望通过聊天实现什么目标

**常用场景**

完成任务场景； 探索任务/问题的解决方案

**提示词示例**

```SQL

行动:我希望你制定一个有效的数字营销策略。

目标：我们的自标是建立一个强大的网上存在，并增加我们的网上销售。

期望:我们希望实现数字化客户参与度和转化率的显著提升
```

- 场景（Scenario）：描述背景或情况

- 行动（Action）：概述要采取的行动
- 结果 (Result)：描述期望的结果

**常用场景**

完成任务场景

**提示词示例**

### SCOPE框架

- 情境（Scenario） 提供了问题或任务发生的上下文和背景，这是了解整个问题的起点。
- 复杂情况（Complications）进一步描述了问题中存在的难点或复杂因素，通常这包括一系列可能妨碍解决问题或达成目标的因素。
- 目标（Objective） 明确了应该达到的目标或预期效果，它为整个问题解决过程提供方向。
- 计划（Plan） 是一个或多个具体的行动方案，用于解决问题或达到目标。
- 评估（Evaluation） 则是在行动之后，对实施效果进行的考核或分析，通常用于判断是否达到了预定的目标

**常用场景**

做计划；个人和组织的项目管理

**提示词示例**

```SQL
方案：我们要在竞争激烈的市场上推出一款新的软件产品。

风险：有一种风险，就是被那些拥有更大的营销预算、复杂的营销预算和品牌认知度的知名品牌所掩

目标：是在第一年内实现显著的市场渗透率，并产生可观的用户基础。

计划：为了实现这一点，请提供一个多渠道的营销活动，包括社交媒体，影响力伙伴关系，公关，和计划内容营销。

评价：成功与否将通过软件下载量和活跃用户数，以及通过调查和社交媒体参与度衡量的品牌知名度的增长来衡量。
```

```Python

你是一位资深文案专家，可以依据我提供的素材内容对主题进行总结，并完成以下任务。

任务一：确定主题并扩展内容
角色：主题策划专家
首先，利用头脑风暴或其他创新方法来拓展给定的主题。确保该主题与我们的读者群体相契合。请将拓展后的主题及受众分析发给我，以供选择。

我选定主题之后，您需要参照下列文章类型生成标题，并提供20个不同风格的选项供我挑选：
解读式：针对热门事件或话题，提供详细陈述和解读，并加入您的个人看法。这种类型的标题通常直接、新闻性强，并含有引起好奇心的元素。
盘点式：通过整理和列表形式清晰呈现某一主题或领域的具体信息，如各类排行内容。例如，可写一篇《古代影视剧中女扮男装的六大美女盘点》或《今年十大科技新闻盘点》。
分享式：以对话或分享个人体验的形式创作。适合初学者，可直接使用聊天记录或个人故事作为素材。包括分享经验、案例分析或研究成果等内容。
热点式：深入挖掘热门事件背后的故事，或在特定细节上作放大处理来吸引读者。利用当前热点事件的关注度编写，如新闻报道、行业分析或爆料等内容。
总结式：对所观看的电影、所阅读的书籍进行感性总结。让你能够将对某部影片或某本书的理解和感受分享给读者。涵盖观点评论、故事讲述、励志内容、情感话题以及心灵鸡汤等。
这五种文章类型提供了不同的写作思路和框架，帮助你创作出能够吸引读者的内容。

在选择好标题后，根据主题和文章类型发展出一系列相关的子话题，并发送给我以供选择。

我选择子话题后，请为每个子话题提供相关支持素材。

请优先完成任务一，在我确认后再继续任务二。

根据我选定的子话题，运用内容策划和架构设计技巧制作一个初稿框架。框架中需明确指出需要用户提供具体描述的部分，并提供详细的插入提示。框架应参照解读式、盘点式、分享式、热点式、总结式的文章类型。
框架完成后发给我，我会提供反馈并补充具体描述，然后您需要据此生成完整的初稿供我确认。

任务三：完善文章
角色：文本编辑专家
确认初稿无误后，将内容充实至原有基础的两倍，并进行优化，以生成一篇完整的文章。同时，提供插图建议。
调整文章的风格和语气，运用恰当的类比，确保内容通俗易懂，并最终输出全文。
注意：每个任务结束时都有一个明确的反馈环节，这确保了每个步骤都符合我的要求，才能进入下一步骤。
```
