# 直播正式开始

欢迎水水\~

**组织行为学对管理学的背叛**

从经验到实证

从艺术到科学

**组织行为学是管理学中的 理工科死直男**

**传统管理学的“范式转移”**

**行为经济学和行为金融学的近亲**

**组织行为学不讲“大道至简”，只有具体问题具体对待。**

**组织行为学很复杂但很简单，不用参悟，管理是数学题集。**

### **四个部分**

一 **组织行为学：**定义、基础、核心、模型

二 **个体：**多元、态度、情境、人格与价值观、知觉、动机

三 **群体：**群体属性、团队、沟通、领导、权力与政治、冲突与谈判

四 **组织系统**：组织文化、人力资源、变革与压力管理

### **一、组织行为学模型**

定义：个体、群体、结构对组织内部行为的影响

目的：**提升组织绩效 -----核心利益者是组织 (**大家记住这个赤裸的动机**）**

核心：**用系统完善直觉，循证管理（大样本实践验证）、无绝对真理----即框架性、实证而非经验、尊重非理性，注重行为而非感觉**

——区别于德鲁克代表的经验学派

关键词：**“权变”**——具体问题对待，具体情境下问题的最优解

面对的问题：高度文明商业环境下的多元的角色、变化的市场、员工幸福感、积极的工作环境

学科基础：心理学、社会心理学、社会学、人类学

**基本模型：**

**纵向：**

**输入**：（个体）员工原始的素质，(群体）结构与角色 、（组织）组织文化和制度——初始值

核心：筛选与判断

**过程**：组织与人在多维度交互博弈——技术性干预。

核心：反馈与激发

**输出**：效率、存续和发展——绩效的结果。

核心：滞后与变革

横向：**个体-群体-组织**

**个体：**多元、态度、情境、人格与价值观、知觉、动机

**群体：**群体属性、团队、沟通、领导、权力与政治、冲突与谈判

**组织系统：**组织文化、人力资源、变革

**再分成2类：（相对的）变量和恒量**

对恒量在起点严格控制，对变量在过程中大尺度改变。

# **二、个体**

**多元**

表层多元：年龄、地域、代际、性别、星座、背景、爱好

深层多元：智商、进取心、人格、价值观、能力

洞见：表层多元，深层一致性的团队效率更高（但过程未必愉快）

          高看一眼女性的职业价值vs平视一下高龄的职业优势

**态度**

由 认知-情感-行为 三部分构成

\*态度是员工纯主观的，评价性的，也是可变性最高的。

**与绩效强相关的工作态度：**

l 工作满意度——爽不爽（工作本身，薪酬，晋升、领导，同事，总体）

l 工作卷入——有没有意义感

l 组织承诺——情感与价值观认同

l 组织支持感——组织对员工的尊重与认同

l 员工敬业度——工作热情 参与与责任

**其中，黄金指标是工作满意度，**带来敬业度和投入的提升，更少离职率，直接影响生产率

——“员工满意，企业获利 ”

背景：08年之后，全球员工工作满意度都在下降趋势中

延伸：

- 忠诚已经过期：对公司的忠诚到对职业忠诚
- 麦肯锡：把离职员工变成资源
- 对于优秀人才，薪酬排第五，成就感第一（关键词是优秀）
- 帮助员工获取家庭支持
- 招人：“你是不是我公司的人“这很重要

**情绪与心境**

情绪：千人千面，不稳定，无共识

心境分类：积极情感和消极情感

心境的应用：决策、创造力、智力、领导力、客户服务、工作态度、安全

 延伸：消极的影响是积极的5倍，五倍表扬搭一次批评

**积极情绪**

不可调节： 人格、基因、情绪智力——只要情绪稳定的成年人

可调节：每（周）日时间、压力、社交环境、睡眠、运动、办公环境

延伸：

- 情绪补偿
- 不关门的茶水间
- 微笑的效应 具身认知
- 大部分的团建都没用
- 睡眠的王冠位置
- 运动和冥想很有用

重要一句：**不要以完全理性的角度去评价别人的行为，你无法把情绪和工作分离开来。**

夸张的一句：**“情绪是第一生产力“**

**人格**

2个标准人格量表：

**MBTI** (外内向、感觉直觉、思维情感、判断感知)量表**，对绩效预测几乎没用。**

**大五模型**（外倾性，随和性，责任心，情绪稳定性，经验开放性）**对绩效有很强预测性。**

\*大五人格中的绩效评价和工作性质有关

**\*其中，责任心是预测绩效的最佳指标**

要极力避免的三个暗黑人格特质：马基雅维利主义、强烈自恋、精神病态

**更具体的，强有力的人格预测指标：**

l 积极的核心自我评价

l 自我监控（自省）

l 主动型人格

**情境强度理论：**性格在一定情境下是可以被改变的

强度定义：明确性，一致性，约束性、严重性（服务业，军队）

延伸：

高情境强度的日常执行：打一场大仗是最好的团建

**价值观**

分类：终极价值观（使命）、工具价值观（手段）

两个方式：人-工作 匹配，人-组织 匹配

代际价值观的差异并没有我们想象中的大，自恋存在于每一代，苛责Z世代是思维上的懒惰

延伸：

价值观的本质是要素的稳定排序

**知觉与个体决策**

知觉：个体感知到的世界（并非以现实世界为基础）

知觉偏差：归因、过度自信、后视偏差、自我偏见、选择性偏见、晕轮效应、对比、刻板印象

对决策的影响：招聘面试、奖励体系、绩效期望（自我实现预言），绩效评估

决策的三种模型：理性（最优），有限理性（最普适），直觉（最糟糕）

延伸：

- 每个人人眼中的世界是不同程度的扭曲
- 尊重人在多数时候是非理性的

**动机概念**

动机：为实现组织目标而付出的强度方向和持续性

延伸：马斯洛理论的过时（生理，安全，社会，尊重，实现，自我）

早期最有力的动机理论：麦克利兰需求理论

l 成就需求（目标，卓越）、

l 权力需求（自主）、

l 归属需求（友好的人际）

当代动机理论

l 自我决定论（自我一致性，组织与自我目标天然一致）

l 目标设置（目标管理，okr）

l 自我效能（完成的信念，反馈）

l 强化理论（行为设计，激励）

l 组织公平（分配、程序、互动）

l 期望理论（努力，绩效，奖励）

**整合以上：个人努力-个人绩效-组织奖励-个人目标**

**\*起点和终点都是个人**

延伸：z世代的极度自我诉求：我要做主

**动机的实践**

5个工作特征模型

**激励潜能分数=（技能多样性+人物完整性+任务重要性）/3 \*工作自主性\*反馈**

延伸：

- 薪酬的边际效应递减
- 3M:每周5%的自主时间

# **三、群体**

类型：正式群体+非正式群体 在组织中同样重要

底层特性：内群体偏爱

群体属性：角色、规范（霍桑实验）、地位、规模、凝聚力、多样性

**群体决策**

优点：全面，支持度

缺点：成本，从众压力，免责

效果和效率的相对性：让最厉害的人单独决策，群体更有创造力

延伸：

集体迷思：精英团队不可避免的愚蠢

**团队**

好团队的外部条件：资源，领导，信任，绩效和奖励

团队的构成：能力，人格、角色、多样、规模、偏好（团队人格）

培养团队选手：甄选、培训、奖励

\*团队并非总是问题的答案

\*有效团队规模不超过10人，有一定的多元背景

**沟通**

沟通的功能：控制，激励，情绪表达、信息传达

沟通的方向：上行，下行，平行

延伸：

- 你以为下属都知道了吗
- 尽可能不要做ppt ，亚马逊

**领导**

定义：影响组织实现愿景和目标的能力

\*领导特质、领导魅力和效能没有正相关

领导行为理论：培养领导者

有效领导的类型（要兼顾）：

结构维度（生产导向），：实现目标的结构性能力

关怀维度（员工导向）：信任，尊重，情感，友善

\*领导力的核心：强大的信任关系，对抗不确定性，反脆弱

**权力**

定义：A可以影响b的行为并且使b按照自己意愿行事的能力（依赖性函数）

分类：

正式权力：强制权，奖赏权、法定权

个人权力：专家权，参照权利（喜欢，尊重，崇拜）

**个人权力最有效：影响满意度，组织承诺，绩效**

强制权有反作用力

奖赏权、法定权无相关性

组织政治的负面：满意度，焦虑，离职，绩效

延伸：

- 桥水：极度透明的公司文化
- 奈飞：只找最优秀的人

**冲突**

冲突：良性和恶性

冲突类型：任务、关系、程序

冲突的解决：

解决冲突（分配，协调，缓和，折衷）

激化冲突（威胁，外援，重组组织，安排杠精）

\*核心在于解决良性冲突，恶性冲突是零和博弈

# **四、组织系统**

组织结构6要素：工作专门化，部门化，智慧链、管理幅度、集权与分权、正规化

组织结构设计类型：

**简单结构：**人少，扁平，2-3个层级，一个人说了算

**官僚结构：**标准化

**矩阵结构：**职能部门化和产品部门化的融合，双重指挥连条

延伸：

- 人越少越好  2 8定律
- 复杂是成熟的代价
- 扁平未必是创业公司的唯一解，官僚机构 不是贬义词

**组织文化**

定义：组织成员共享的一套**区隔性**的意义体系

本质的7个特征：创新与冒险，关注细节、结果导向、员工导向、团队导向、进取心（竞争而非随和）、稳定性（维持现状和成长性）

\***组织文化不是评价性概念而是描述性概念，无关员工是否喜欢（态度）**

\*组织文化是一种资产

**组织文化的创建和维系**

1、甄选：愿景 使命 价值观

2、高层管理者的示范效应

3、社会化：帮助员工适应、持续影响

**创建积极的组织文化**

l 利用优势：用人当用强（发掘员工优势）

l 奖励多于惩罚(5:1)

l 强调活力和成长

延伸：

- 包容建设性错误的组织
- 那些著名的品牌故事
- 强组织文化的性价比
- 创始人的行为准则就是企业价值观：创始人的背影
- **问题出在前三排，根子还在主席台**

**人力资源政策与实践**

组织甄选过程：初步甄选（满足基本需求），实质甄选（最有能力的），条件甄选（背调）

实质甄选是最重要的环节：笔试、**绩效模拟测验（工作抽样检测**）、面试

面试偏差的普遍存在：主观偏差的不可避免，普遍没有结构性

\***面试不是工作绩效的预测手段，而是测试与组织文化的匹配度**

延伸：

- 人人匹配比人岗匹配更容易操作
-  谷歌的招聘改进

**绩效评估**

**类型：**

1任务绩效

2公民行为（对组织的支持行为，氛围，积极）

3反生产行为（伤害组织，挑衅）

**绩效评估内容：**

l 任务结果：具体指标成果

l 行为：过程，不限于生产，还包括其他贡献

l **特质：最弱的标准，可以忽略不计（但很多组织仍然乐于其中）**

360度环评：从上到下，从内部到外部。

优势未有强硬证据，但劣势明显：管理者的扭曲，主观，私利、避免冲突。

**改进评估的建议：**

l 增加评估者数量（去掉最高最低分0）

l 有选择的评价（评估者只评价自己熟悉的领域）

l 培训评估者（统一量化标准，提供更多细节）

l 为员工提供正当公平的程序（信息充分公开，可以辩护，结果依赖于证据）

**绩效反馈的价值**

\*员工很难接受负面反馈（心理偏差）

\*把绩效反馈回忆设计成一种咨询，而不是一种评判。可以更好的驱动员工。

**组织变革与压力管理**

变革的动力：环境的变化，不确定性，社会潮流，政治局势，技术变迁

**变革的阻力：**

l 个体阻力：习惯，安全感，经济，未知恐惧，选择性偏差

l 组织阻力：结构惰性，系统性阻力（局部扰乱系统），群体惰性，对专业的威胁，对权力的威胁

**克服阻力的策略：**

l 教育沟通

l 参与：参与变革策略

l 提供支持和作出承诺

l 发展积极关系：长线

l 公平的实施

l 操纵和收买（两面性，慎用）

l 强制（两面性）

l 选择接受变革的人

组织变革模型：**解冻-移动-重新冻结**

**创建支持变革的文化**

l 形成创新文化

l 建立学习型组织：能持续适应和变革的组织

学习型组织的特征：

1共同愿景

2开放的思维方式，

3系统性看待流程活动职能和环境（有机系统），

4成员的坦诚沟通不怕批评惩罚

5愿意起新实现组织愿景而把个人利益置于次要。

延伸内容

- 招聘：大部分的招聘广告都是错的，ceo的面试清单
- 面对离职：要不要挽留辞职员工，正确的心态和行为

# **彩蛋**

**可能是历史上最牛逼的招聘广告**

1900年，英国著名探险家欧内斯特·沙克尔顿爵士在伦敦日报发布的招聘广告：

**招募男士参加冒险旅行。**

**工资很少，环境严寒，数月不见天日，危险四伏，可能无法全身而退。**

**成功之日，光荣和赞誉纷至沓来。**

利益精准，门槛清晰，预期明确。
