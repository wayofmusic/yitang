## 为什么要学

管理一个业务，我们形成一个基础的、粗糙的收入or转化率公式，不就够了么？需要一路探索参数、形成一个完备的、复杂的公式么？

对于一个不想依赖单纯直觉和手感管理业务的负责人来说，**这个极度重要**。

甚至在磨课时候，我不止一次感慨：**一个业务负责人的参数探索，就是最核心的操盘能力啊。**

如果只有一个基础的、包含5-7个参数的公式，大概率很难支撑持续提高的增长目标。但当你有了更多的参数，你也就有了更多可以提假设的做功点，业务也就有了更多的抓手，有了无限的可能性。

回顾一堂也是，我们创业近6年，我们做的比较出色的一些板块（复盘营/马拉松/教研/推荐模型），一定程度做到了国内相对Top的水准，基本上都迭代出了几十上百个参数。而一些表现平平的模块，往往几年在参数上也进步不大。

第一个案例，还是讲大家最熟悉的复盘体验营吧。

复盘营最早从2019年开始做，最开始的认识就比较简单，就是一个简单的公式：

*流量 = 自媒体流量 +  投放流量 + 推荐流量*

1.*自媒体流量 = 公众号 + 原有私域 + 官网 + 知乎 + 选课中心*

2.*投放ROI = 首单ARPU/CAC*

 ROI：Return On Investment 投入产出比

ARPU：Average Revenue Per User 每用户平均收入

CAC：Customer Acquisition Cost 获客成本

是不是还挺清晰的？大概两三个公式，八九个参数。

是不是挺多公司就是这样的情况？

大家是不是觉得没啥，不就是一周五六节课程，能有什么参数可以挖掘呢。

答案是，至少200个；

我们开始迭代，拆解用户的学习节点：

 每一期收入 = 每一期获客 x 转化率

•每一期获客 = 渠道铺设数量 x 落地页UV  x 落地页购买率（糙）

•转化率 = 进群率-签到率-上课率-作业率-占座率-1v1回复率-完成销售动作率-购买率

比如，后来我们发现【我请客推荐】很重要，我们又拆成了一系列参数：

 **每期推荐人数 = 报名我请客量 x  完成推荐率  x   平均推荐人数**

•**每期推荐人数 = 报名我请客量 x  完成推荐率  x   平均推荐人数**

◦报名我请客量 = 直播在场UV x 直播报名率 +  课后曝光UV x 课后报名率

◦完成推荐率 = 收到海报率 x  转发率 x  扫码率 x  **接受邀请率**

▪接受邀请率 = 加载页面成功率  x   点击按钮率  x  留下联系方式率  x  加五月微信率

比如，后来我们发现【到课率】极其重要，又拆解了系列转化率：

 **到课率 = 预约率 x 到场率 x 讲课90分钟在场率**

按时间，甚至我们还分析过各种切片留存率：

 9点在线率，9:15在线率，9:30在线率 ... 10:00在线率 ... 24:00在线率；

按相关性，我们还剥离了很多影响留存的参数：

 留存率 = f（准时到场率，学习委员率，**PC率**，互动率）

 *PC率和用户留存/后续各种转化率呈现强相关性（2-3倍）*

我们还剥离了一些小的关键参数，比如：3次作业率，当场选课率，TrumanAI电话接通率等等。

哈哈哈，很多同学说，复盘营MBA销售太晚了，会不会数据影响销售，其实我们内部一直有一个监控参数：**已购会员留存率。**

不管是11-12点，这个参数大概都稳定到75-80%以上，我们才在这个阶段不断安排和调整时间的；

复盘营是一堂商业侧最重要的项目，我这几年最大的体感是：

当有了这个各个维度、各个角度的参数公式，我们才有了源源不断的增长假设、优化策略和文案调整思路。

梓丞说，因为自己在代理久雀棋牌室之前，她曾经有过一些营销相关的背景，所以很容易就能拆出一个基本的业务公式：

 门店收入 = 流量 × 转化率 × 客单价 × 复购率

依赖这个基本的公式，其实能够做基本的门店起盘了。

但是思考一个问题：如果你开一个店，就是简单的拆成这个样子，能提假设吗？能提出很多大量假设吗？能精细化管理吗？能不断提升效率么？

 门店收入=抖音曝光量 × 首次购买率 × 客单价 × 预约率 × 到店核销率

凭着以前营销的经验，她判断长期依靠投放流量是不健康的，所以还是要找更多的免费流量，所以这个时候拆出了流量的来源，开始重点关注免费流量这个参数：

 流量 = 免费流量 + 付费流量

免费流量 = 美团免费推荐流量 + 私域流量

为了提升美团的①免费推荐流量，她又去参加重庆总部的培训，跟专家进行了咨询，得到了一个基本的判断：美团的免费推荐流量主要是基于这个店铺的**装修**，**口碑**和**评分**，于是她优化了很多细节和假设。

效果不错，他又把免费流量进行了二次拆解，他们又拆出了：

•美团免费推荐流量= f（点击率，下单率，好评率，复购率）

•私域流量 = 公域订单数 × 到店核销率 × 加微信率

## L3.分层参数

这个类型的参数，通常的挖掘难点是，切片的角度容易缺失。

## L4.转化参数

前面的分层参数通常在业务公式中呈现的是加法关系，而L4转化参数其实是把一个参数按照不同的转化环节拆成一串漏斗式的乘法关系。

这个类型的参数，经常出现的问题是，大家拆解的太粗，有很多很关键的细节转化率被遗漏了。这些细节转化率，虽然可能很细微，但是却是在关键路径上，很有可能挖掘到一个，就会让业务结果大幅提升。

送大家一个一句话心法：

我们来看两个例子，感受一下：

一堂的增长指标中，学习规模一直是非常重要的指标之一，所以我们一直以来很关注的一个子目标就是一堂的作业率。

如果让你们来提升一堂的内测课作业率，你们会怎么拆？

————

是不是大部分人都是这样拆的：

 •作业率=直播作业率+回放作业率+文稿作业率

◦直播作业率= 内测课报名率 × 直播到课率 × 作业打开率 × 作业完成率

很长一段时间，我们自己也是这样拆的，拆成这样已经能够提出非常多的假设了。

但是随着一堂的会员数量越来越大，作业率其实也是一个不进则退的状态，所以我们需要持续保证一堂的作业率，于是我们又继续细拆，又找到了新的参数：

 *到课-Flag率，进入了课程之后，扣“一定作业”口令率。*

*草稿-提交率，我们发现很多人进入了作业，没写完。*

有了这些参数，我们又有了新的分析抓手，又可以继续围绕着这些节点继续提假设、做优化了。

有同学做线下服装店的业务，常规拆解业务公式，可以拆成：

 客流量 \* 进店率 \* 试穿率 \* 购买率 \* 客单价

但是如果拆得足够细，这里面的进店率、试穿率、客单价都还可以进一步去展开：

 •可以把进店率，细化成：停留率 \* 停留进店率；

•可以把试穿率，细化成：拿起衣服率 \* 试衣服率；

•可以把客单价，细化成：连带件数 \* 平均单价；

当有了更细的参数，就有了更多的做功点，可以提更多的假设：

 比如之前有同学就曾经发现，用户会停留但是不进店，发现是担心装修豪华客单价太高，所以不敢进来，于是就提出了明示衣服价签的假设。

再比如，围绕连带件数，在用户决定购买之后，就可以有意识地尝试搭配周边、或者推情侣款、亲子款，尝试提出凑单满减、赠品等策略。

但反过来说，如果拆不出这个参数，这些假设的出现可能就只能靠运气和随机了。

送给大家一句话吧：

我们总是条件反射的找到一个转化率就得了，但是我们要相信一件事：**当我们发现一个转化率的时候，一定还有很多隐藏的没被发现的转化率。**

用户的每一次互动的细节，动作，交互，节点本质上都是转化率。

【疑问❓】磨课时候，有一个常见的困扰：**如果一个转化率不能被统计，我们该留下还是该放弃？**

 *比如：进店率，企业微信-申请好友率，多次试穿率。*

————

我的答案是：建议留下。

有三个原因：

1.*原因1：不管你统不统计，这都是客观发生的转化率。*

2.*原因2：虽然统计不到，但是增长的话，会呈现在更上层的目标里。*

3.*原因3：最最重要的是，有了这个参数，就能涌现非常非常多的新假设了。*

为什么有些人提不出几个业务假设（尤其是动力阻力），而有些人总是能源源不断地大量提假设，往往差别就在这里，当我有比别人细3-5倍的转化率时，我的手段也能多好多倍。

就一个么？**曝光-购买率**么？还有什么？

## L5. 创新参数

有了基础参数，财务参数，分层参数，转化参数，下面进入高阶的阶段：创新参数了。

什么是创新参数呢？就是一些过去没用过的，同行业很少用的，或者自己业务自定义的一些参数。

 *当然，创新是相对的，第一次是创新自定义，以后再做可能就是常识了。*

我给大家举两个例子，大家可以感受一下：

为了优化业务，我们还是提出了很多关键的参数，比如：**PC学习/作业率，已购会员直播留存率，一定作业率，学习委员率，我请客率**等等。

这些比较基础，我们还提出了一些关键的率：线下课的"**带团队学习率**"，**N分钟留存率**等等

再难一点，问大家一个问题：我们投放公众号博主，各个博主的定价、浏览量、ROI都不一样，而且极度**非标**，怎么办呢？有没有一个参数可以辅助我们来决策博主选择呢？

——

我们找到了两个稳定的参数：**单阅价格，单阅价值。**

 *单阅价格 = 博主报价 / 博主近期阅读量均值*

*单阅价值 = 本次总收入 / 本篇阅读量*

新投的博主主要参考历史的【单阅价格】，复投的博主，用两个指标综合衡量。

为什么会提出这些转化率呢？大概率因为过去的经典指标、粗指标已经失效了，或者团队的经验不够，需要自己做数据分析，探索一些关键的节点出来。

一般来说，有两个维度的定义：**某个动作**、或者**某个时间周期**，当然也可能是组合定义。

你可以试着找一找用户的一些特别的动作，或者某一个时间内的动作对于某个上层目标有重大影响。在磨课过程中，我们发现了几个有趣的例子：

这个案例来自刘同学，他做的业务是ToB的销售管理软件（CRM）。

当时为了提升整体的销售业务，列了一个业务公式：

 销售业绩=线索数量×有效线索率×见面率×成交率×客单价

当时他们遇到了一个情况：*在见面环节，销售做了非常详细的准备工作，但多数人面谈根本到不了15分钟，客户就开始找借口草草结束，只能灰头土脸地回来。*

后来他们开始每天放电影式地复盘各自出去见客户的每个动作，意外发现有些成交率高的销售，通常会约见在会议室，而且会坚持**连上投影**再开始给客户讲解。

他们当时复盘的时候推测，大概率是因为在办公室更像是推销和闲聊。而在会议室，尤其是连上投影的时候，整个场合会瞬间变得更**正式**，像是在谈合作，对方出于商务礼仪的尊重，也会耐着性子听对方讲完。

所以，后来“去会议室”，“连投影”，都变成了他们面见客户追求和坚持的动作。

这个案例也很有意思，有同学做的是线下儿童舞蹈培训，他们主要的业务销转模式，就是让孩子先参加试听课，然后再转成正价课。

很多线下儿童培训的业务，其实都是类似的业务公式：

 业绩= 试听课预约率 × 试听课到课率 × 转化率 × 客单价

在做业务的过程中，他们发现，通常被转化的都是那些在试听课上**和老师产生过互动，得到过老师表扬的孩子。**这些孩子会因为被关注，被表扬，被鼓励而喜欢课程，同时会在家长转化的时候，表现出极大的学习兴趣。

所以后来就提出了一个统一的要求，试听课老师需要在试听过程中和转化家长时必须要**1v1夸孩子**。

最开始这些可能都是假设，但一旦发现这些动作很重要，就可以主动干预、重点运营和维护，来实现更大的价值和效率。

## L6. 魔法参数

到最后一层了，冰山的最深层，**魔法数字。**

为什么用这么cool的文案呢，这个来自于增长黑客常用的一个概念："**魔法数字（MagicNumber）**"，而且在各个领域都有所涉及。

在用户增长领域，是去探索和分析数字，找到一个对于留存有巨大影响的一些前置参数。

送大家一个一句话心法：

给大家举一个很典型的案例：

在2017年，我和前公司（某团）同事一起吃饭，就聊起一个很有趣的话题：他正在负责美团外卖某一条业务线的增长，核心目标就是**提升平台订单量**，主要的策略就是补贴，花同样的钱，实现长期最大的收益。

如果是你们，假设一年有一个亿的补贴预算，你会怎么花呢？

这个钱看似很多，但在美团的体量里，如果全平台撒钱，可能瞬间就花完了，所以该如何制定策略呢？

如果是你，你会从哪里开始思考？

————

他看了大量的数据，大概发现了一个类似的曲线：

大概的规律是：这个品类一个新用户，在一**段时间内买够3单**以后，后面的留存就会非常高，但是只买了一单两单的用户，往往流失率就会非常高。

于是他们就定了一个MagicNumber：**30天3单率。**不管是运营，还是投放补贴，还是产品策略，都向这部分用户倾斜，这样可能只需要补贴整个平台5%左右的订单，这样的补贴花钱策略就获得显著的提升。

>  以上数字仅供示意，具体参数脱敏（未知），而且不同业务完全不一样。
>
>

稍微停下来，思考一个问题：从底层思考，为什么3单以后会呈现这么显著的质变的规律呢？WHY？大家可以猜猜背后的认知是什么？

当然MagicNumber最经典的案例，还应该是社交网络类产品：

Facebook早期通过数据分析发现，**新用户在7天内添加至少10个好友**时，其长期留存率、活跃度显著高于未达标用户。

 通过定义关键行为动作（添加好友），看留存曲线，找到量化阀值（7 天 10 个好友）。

稍微停下来，思考一下：背后可能的认知是什么呢？

再比如一堂，我们这些年也试着在思考和探索，有哪些极其重要的指标，可以显著提升收入和复购么？

比如，复盘营，新人完成哪些动作，加入会员率会非常高？

————

答案是：**3次作业率。**

 我们看过很多指标，1次，2次，4，5次，学习委员，推荐，都没有3次作业这么显著。

 大家可以想想，背后是什么？

比如，大会员，完成哪些动作，续费率就会很高？

——————

答案是：**50学分。**

 20/30/40差异不显著，50续费率显著变高，后面70/90/200变缓。

所以运营团队的一个核心指标是：180天50学分率。

 大家可以想想，背后是什么？

所以，**180天内达到50学分**，是一个相对舒适，可以被运营的一个核心指标。

 如果太短，用户可能会被骚扰；如果太长，可能滞后不利于复盘和调整。

其实每一个MagicNumber的背后，都是对于业务价值本质的思考。

1.*3个外卖订单：用户初步建立习惯，认可价值；*

2.*10个好友：遇到了朋友，社交关系开始建立和粘性形成了。*

3.*3次作业率：一堂不错，而不只是259不错，各个课题都不错。*

4.*50学分：用户写了10-20份作业，培养了习惯，留存了数据；*

*....*

每一个数据的出现，可能是自于对于“数据的分析”，用户做了动作A，导致高价值的B，获得了质变级别的显著提升。但是这个背后，其实代表产品价值、服务价值的本质。

必须要承认，多数的业务在多数的时间，是找不到魔法参数的：

但是这种思维方式很重要，你要去不断去思考：对于业务最重要的销售转化率，留存率，复购率，续费率，有没有一个我忽略了的显著动作，一旦提升，整个业务都会显著优化、甚至遥遥领先？

这几年，我们发现了很多类似的有效案例：

1.*某儿童教育会销，发现只要进行了【家长相互感谢成长】，成交率就会大幅提升；*

2.*Slack发现：新客户只要团队【交换2000条消息】，后续留存和复购就会奇高；*

3.*某2B SaaS：【60天内完成系统部署】，第二年续费率就会非常高；*

4.*某手机游戏：新手【获得3次MVP】后，7日留存率显著增高；*

5.*某会议软件：新用户【发起3次会议】后，90天留存率会显著提升；*

6.*facebook：新用户【7天内添加≥10个好友】，次月留存率提升非常高；*

7.*duolingo：用户【连续5天完成课程】，1年的留存率可以大幅提升*

8.*……*

## 新课上架发布

上面内测的这节课，目前已经封装完成，正式上架啦，你现在就可以在选课中心看到\~

《低成本验证实操2：MVP设计篇》，这是精益里面最精彩的部分：**MVP设计**。

很多人即便有了精益思维，即便拆出了关键假设，最后一动手，还是老样子，要么开发了一个大而全的产品，要么实验还不够聪明，不够高效。

这种情况，就是没搞懂怎么设计MVP。

如何设计一个最低成本、最便宜、甚至可以说最聪明的MVP，来验证自己的关键假设呢？这个很考验大家的功力。

那么，什么是学习MVP最好的方法呢？答案其实就是四个字：案例学习。

所以，这节课，我们把最近几年一堂积累的、最精彩的MVP设计案例，都放进来了，并且分门别类找规律，制作了一个MVP设计策略的超级武器库。

MVP的底层逻辑是“**FALSE：借假修真**”，什么是FALSE呢？

送给大家三句话，帮助你理解：

很多时候，我们总是容易憋大招，就是因为太容易陷入"主观幻想"了，有一个美好的期待，有一个宏伟的设想，有一个宏大的架构，一发不可收拾。

我这些年管理业务，有一个非常简单的小技巧：**风险高的业务，话术变成"实验"。**我们把一个业务，一次执行，一次产品，当做一次实验，整个心态都会好很多，就是一次试错拿认知的过程而已。

用户只关心他**得到什么价值**，并不太关心你背后的**实现过程和效率**，

*你做一个课程，和一个轻咨询，背后拿到的反馈是一致的；*

*你做一个AI产品，和用人工凑合顶一顶，背后拿到的反馈是一致的；*

*你做一个完整的产品，和只做第一步观察反馈，背后拿到的反馈是一致的；*

一旦培养了"洞察价值"的用户习惯，你就会发现这张小抄，瞬间变得一目了然了。

最后，一切还得回归对于**项目风险**和**关键假设的验证**上。

MVP的核心就两点：

第一，得足够可以验证你的假设，不然实验也没有意义。

第二，要足够简单，足够低成本，足够快。通过用户反馈来持续迭代，而不是自己憋在家里设计。

所以，再强调一次，有一组堪称灵魂拷问的问题，希望大家在做方案的时候，不断问自己：方案足够简单了吗？

然后不断反思：**真的需要吗？不做又如何？**

1.*真的需要做硬件么？能不能只做软件？*

2.*真的需要做独立APP么？能不能做小程序？*

3.*真的需要做小程序么？能不能不动开发，借用已有工具？*

4.*真的需要这么多功能么？砍掉一半不做又如何？*

5.*真的需要做产品么？能不能先做个调研，排除一些选项？*

如果你的方案，能很坦然的回答这一组灵魂拷问，那么基本也就过关了。

这应该是人类历史上，最全的一个MVP设计策略小抄了。如果你未来再遇到MVP设计的难题，直接从这个武器库里选对应的案例，来匹配测试就好了。

不夸张地讲，如果这节课你未来几年能用其中一招（哪怕再小），至少值回10年的会员费。
