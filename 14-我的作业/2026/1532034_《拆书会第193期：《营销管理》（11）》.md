### 1、分析题

**【我的回答】**

a. 核心定义的转变

i. 从单纯的复购行为升级为深层的情感拥护。 # 认知升级

ii. 检验标准不再是“买了没”，而是“愿不愿意推荐”。 # 关键指标

b. 5A模型与拥护体系

i. 拥护（Advocacy）是5A模型的终极阶段，用户化身为义务宣传员。 # 5A模型

ii. 这一阶段标志着品牌资产从“知名度”转化为“推荐力”。 # 品牌资产

c. 身份认同与社群感

i. 案例借鉴：SoulCycle将健身转化为家族归属感。 # 情感连接

ii. 运营方向：从教授技能转向建立同道社区，增强粘性。 # 社区运营

d. 善意信任（Benevolence Trust）

i. 信任三支柱：能力、诚实、善意；善意最难得且最稳固。 # 信任机制

ii. 实践策略：通过“劝退不适合的高阶课”体现以客户利益为先。 # 长期主义

a. 知识体系的串联

i. 将碎片化认知通过系统阅读整合成结构化思维，如珍珠串成项链。 # 知识内化

b. 增长的策略性（Ansoff Matrix）

i. 增长非偶然，需依安索夫矩阵规划老/新市场与产品的组合。 # 战略规划

ii. 警示：盲目扩张会导致大败局（如乐购、星巴克案例）。 # 风险规避

c. 创新的门径管理

i. 面对95%的新品失败率，必须依赖科学的流程管理。 # 门径管理

ii. 调研原则：拒绝空想，深入现场观察消费者行为。 # 现场主义

d. 全球化思维与本地化行动

i. 核心逻辑：理论/品牌全球化，落地执行必须本地化（Glocalization）。 # 本土化适配

ii. 案例：肯德基老北京鸡肉卷、宜家降价配送服务。 # 场景适配

a. 增长的本质

i. 增长不是目的，而是创造价值后的自然结果。 # 第一性原理

ii. 教育者使命：解决学员真实问题，建立口碑护城河。 # 价值导向

b. 下一步行动计划

i. 聚焦NPS（净推荐值），致力于获取学员的真心好评与推荐。 # 行动指南

ii. 优化咨询流程，坚持“利他”原则，积累品牌信誉。 # 信任资产

**【我的回答】**

书名：《心若菩提》（增订本）

作者：曹德旺（福耀玻璃集团创始人、董事长）

豆瓣评分：8.9分（高分传记，被誉为“中国版《那家伙的真意》”）

一句话推荐：如果不读这本书，你只知道他是“首善”；读了这本书，你才懂为什么他是中国真正的“经营之神”。

本书解决的痛点：

写给谁看：迷茫的创业者、职场管理者，以及每一个想知道“在这个复杂的社会，老实人到底能不能赚大钱”的普通人。

解决什么：打破了“无奸不商”的刻板印象，解决了如何在坚守底线、不行贿、不走捷径的前提下，依然能把生意做到世界第一的内心冲突。

核心论点：“小成靠智，大成靠德。” 商业的终极秘密不是权谋，而是一颗时刻利他的“菩提心”。

案例一（颠覆认知：绝境中的诚信）

背景：曹德旺早年贩卖白木耳，被民兵查扣，不仅血本无归，还欠了乡亲们几千块巨款（当时是天文数字）。

冲突：债主上门逼债，大多数人可能会选择跑路或赖账。

结果：曹德旺一家家登门承诺：“这钱我一定还，如果我死了，我的孩子接着还。”他变卖所有家产，甚至去修水库拉板车苦干。正是这种“把信誉看得比命重”的态度，让他在后来承包工厂时，获得了所有人无条件的信任和支持。

金句：没有了钱，但我还有信。

案例二（实操落地：用数据捍卫尊严）

场景：2001年，美国商务部对福耀玻璃发起反倾销调查，企图将中国企业赶出美国市场。

行动：不同于当时很多中国企业选择“忍气吞声”或“退出市场”，曹德旺选择硬刚。他组建顶级律师团队，花费一亿多美金，用详实的数据证明福耀的成本优势是来自管理和技术，而非倾销。

结果：福耀成为中国第一家状告美国商务部并胜诉的企业。

启示：真正的“硬气”不是嗓门大，而是懂规则、敢于利用规则保护自己。

案例三（慈悲智慧：实习生的白血病）

故事：一名刚入职不久的实习生被查出白血病，巨额医药费让家庭绝望。按理说公司没有义务承担。

行动：曹德旺得知后，直接批示：“不惜代价，公司出钱治。” 哪怕这名员工还没给公司创造过什么价值。

底层逻辑：他说：“他是我的员工，就是我的孩子。”这不仅是慈善，更是把员工当“人”看的菩提心。这件事让福耀的凝聚力达到了顶峰。

收获一：入戏与入角（职业观）

解释：曹德旺提出人生如戏，但要分清“入戏”和“入角”。很多老板只是“入戏”（想当老板的排场），却没有“入角”（承担老板的责任）。无论做什么岗位，都要钻进去，把角色演到极致。

收获二：敬天爱人（财富观）

解释：财富是水，如果你没有足够的“德行”作为容器，钱多了反而是灾难。他认为做生意就是做人，不行贿也能办成事，前提是你的产品和服务要硬到别人无法拒绝。

收获三：终身学习（成长观）

解释：曹德旺小学没毕业，但他自学了会计、MBA、法律。他每天早起坚持阅读两小时。他证明了学历不代表能力，但学习力决定了你的上限。

立刻能做的一件事：

“早起自省”：像曹德旺一样，明早起床后，花10分钟时间，不看手机，反思昨天做的一个决定是否符合“利他”的原则？或者阅读专业书籍10分钟。
