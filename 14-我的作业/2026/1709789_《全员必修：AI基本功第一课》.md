# 《全员必修：AI基本功第一课》

- 日期：2026.08.22

## 我的作业

### 1、第一个作业：学习心得题

**【题目】** 这节课讲了Feature是什么，为什么要用 Feature 思维、以及怎么把不同 Feature 迁移、叠加、组合到真实任务里。学完之后，你有哪些新的收获和启发？

请结合你自己的 AI 使用经历，写一写：你以前用 AI 时最容易忽视的是什么、以及你打算怎么把这种“拆 Feature、加 Feature、组合 Feature”的思路用到自己后续的工作里。

**【我的回答】**

学完这节课 最大的启发就是 帮我治好了工具焦虑症

以前我总觉得AI工具更新太快 今天出个新模型 明天出个新智能体 怎么学都学不完 效果不好就觉得是自己没跟上时代 听完这节课我彻底醒悟了 原来真正的高手不追工具 而是练基本功 也就是去掌握那些长期稳定有效的 Feature

作为一个商业演说教练 平时在同道演说带学员 我发现我以前用AI 最大的问题就是 很容易陷入把大任务直接丢给AI的误区

我以前最容易忽视的就是 最终意图 和 给参考案例 这类关键的 Feature

比如我常常直接跟AI说 帮我写一篇关于个人IP的演讲稿

结果AI给出的东西特别空泛 像是在背课文 根本没法在舞台上感染人 我当时还总抱怨AI没有演说思维

现在我明白了 不是AI不行 是我给的牌太少了 我根本没有给它输入我想要的 最终意图 比如告诉它这篇演讲是为了在招商会上打动创业者 最终让他们产生信任并购买课程 我也没给它同道演说以前那些 转化率极高的优秀演讲稿作为示范

以后在我的演说教练工作里 我打算彻底用上 拆 加 组合 这套心法

首先是 拆 Feature

以后遇到帮学员梳理演讲框架 或者做商业路演辅导 我不再一上来就期待AI一次成型 而是先把需求拆解 找出目前这个任务缺了哪些基础单元 比如是不是缺了 目标受众画像 是不是缺了 清晰的身份设定

然后是 加 Feature

如果AI给出的第一版演讲稿只有40分 我再也不会觉得沮丧或者直接放弃了 我会以学习和测试的心态 慢慢往里加 Feature

比如加一个 渐进式披露 让它不要一次性把道理讲完 而是像真人演讲一样一层层铺垫

或者加一个 负面限制 告诉它绝对不允许用官方说教的词汇

甚至试试调节 温度参数 让它的表达更有激情和创造力 一点点把结果磨到80分

最后是 组合 Feature

我打算把我在教商业演说中 测试出来特别好用的这些 Feature 全部记录下来 变成我自己的 演说AI武器库

以后不管是给学员定制 专属路演教练 还是做 课件自动生成工作流 都可以像搭乐高一样 把这些好用的 Feature 组合起来

真正把一套科学的底层体系 变成我们团队事实上的工作习惯 这样不管工具怎么变 我们的产出质量都能持续稳定 甚至产生复利

### 2、第二个作业：Feature实践复盘题

**【题目】** 请复盘一个你过往做过的 AI 实践案例，不管它最后是成功还是失败。

现在请你尝试用这节课讲的Feature思维，把这个案例重新拆一遍，看当时你用了哪些Feature、缺了哪些Feature、哪些Feature叠加后起了作用，哪些地方其实可以再补一补。也欢迎补充你在这个实践里的其他感受、反馈和反思。

**【我的回答】**

最近我在给同道演说的学员备课 准备一节AI演说实战课

拿大健康赛道的招商开场白做演示案例

一开始我用了基础 Feature

设定角色 明确任务 给定目标受众

AI出了个70分的初稿 逻辑挑不出毛病 但太板正 像在念公司简介 根本抓不住人

以前遇到这种情况 我肯定直接自己上手改了

但这次我用这节课学的 Feature思维 逼自己继续给AI提假设 往90分去死磕

第一步 加最终意图

我告诉AI 别说客套话 你的意图是在前30秒狠狠刺痛台下的老板 让他们立刻放下手机 觉得你就是救命稻草

第二步 加优秀示范

我把同道以前拿过千万融资的三个开场逐字稿喂给它

让它直接照着这种短平快 充满力量感的语感去写

第三步 加负面限制

我下死命令 绝对不准出现 尊敬的各位来宾 行业痛点 这些废话

必须用尖锐提问或者真实的失败案例开场

第四步 加思维链、状态机

别直接出稿子 让它分三步走

先分析实体老板深夜最恐惧什么 再构思经营惨状 最后才去写文案

这四张牌打出去 结果真的绝了

新一版的开场白刀刀见血 情绪饱满 直接干到了90分

我兴奋得当场把它加进课件 准备当标杆案例去讲

这次备课让我对 Feature 彻底有了肌肉记忆

把70分磨到90分 拼的根本不是运气 而是你手里握着多少张牌

AI就像我带的演说小白 给个大方向他能及格

但想让他惊艳全场 就必须像个真正的教练一样

用最终意图去点醒 用优秀示范建审美 用负面限制改毛病

只要 Feature 假设不断 我们就能把AI逼到极致 拿到拿捏人心的好结果
