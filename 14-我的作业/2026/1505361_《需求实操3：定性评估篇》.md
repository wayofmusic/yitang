# 《需求实操3：定性评估篇》

- 日期：2026.02.01

## 我的作业

### 1、第一个作业：学习心得题

**【题目】** 这节课我们讲了需求评估的三个维度，刚性、频次和普遍性，你对于这节课有哪些印象深刻的内容，带来了什么新思考、新启发？可以展开写一写你的学习收获、进步和疑问。

**【我的回答】**

本质： 需求评估不是“算账”（那太贵太慢），而是低成本的“生死判”。

作用： 它是“法官”。在投入开发和设计商业模式前，用定性分析掐死“伪需求”，筛选出“高潜力选手”。

原则：

多选项： 必须有3-10个备选项（不同人群/场景/任务的组合）。

对比： 没有绝对的好坏，只有相对的优劣。

维度： 普遍性 x 频次 x 刚性。

信心： 类似于贝叶斯定理，通过信息修正，将直觉转化为科学的信心。

判断一个需求是否成立，必须且只需考察这三个核心维度：

刚性 (Rigidity)： 多痛？用户愿意付出多少成本（钱/时间/麻烦）？

频次 (Frequency)： 多久发生一次？是自然发生的节奏。

普遍性 (Prevalence)： 多少人有这个痛点？决定了天花板。

⚠️ 不可能三角： 现实中极少有“高刚性x高频次x高普遍性”的需求（那是微信/基础设施）。创业者通常要在三者间做平衡和取舍。

要掌握这套方法，需要经历从“入门”到“高阶”的三个阶段，对应8个自我修养。

拒绝“拍脑袋”和单一维度的直觉判断（如“这太低频了不做”），建立系统分析框架。

自我修养1：坚持全局分析

单一维度的强弱不能定生死，要看三维综合得分。

案例： 非洲中餐厅。

大众快餐：普高、频高、刚弱（利润薄）。

高端宴请：刚极强、普低、频低（圈子小）。

最终解：1+1组合。 大厅做川菜（保流量/普频），包厢做高端（赚利润/刚性）。

自我修养2：尽量合理对比

控制变量法： 只有用户、场景、行业接近的选项对比才有意义。

*误区：*拿“喝奶茶”和“上管理课”比刚需，毫无意义。

自我修养3：追求平衡和匹配

承认“错配”是灾难。

高频打低频： 找死（如上门开锁做补贴大战）。

低频打高频： 瞎干（如手握高频流量却只做黄页赚小钱）。

策略： 初创期寻找 “极高刚性、中高频次、窄普遍性” 的切口（小众且疼）。

拒绝“我觉得/我推测”，建立客观的度量衡。

准备动作：

定性客观化： 虽不测算具体数字，但必须能证伪（如：大食堂比外卖便宜，是客观事实）。

锁定分析层级： 聚焦在 L3/L4 任务层 (JTBD)。不要停留在“我想做个APP”，也不要泛化到“人都要吃饭”。

自我修养4：追求客观的“刚性”

定义： 刚性不是痛，是支付意愿（金钱、时间、认知成本）。

刚性尺子（从弱到强）：

白给也不用 -> 免费才用 -> 收钱也用 -> 加钱抢着用。

痒点（虚拟自我）-> 爽点（及时满足）-> 痛点（恐惧）-> 救命稻草。

调研话术（行为面试法）：

别问：“你想要吗？有这个你会用吗？”（这是愿望，会失真）。

要问：“上次遇到这事你咋办的？花了多少钱/时间？最不满意啥？”（这是事实）。

案例： 跨境手电筒。户外发烧友（极挑剔/红海）vs 商务送礼（刚需是“体面不出错且能印Logo”/蓝海）。

自我修养5：追求客观的“频次”

定义： 是接触节奏，不是使用时长。

误区： 把“人工干预（补贴/提醒）”当成了“自然频次”。

频次尺子：

一生一次 -> 每年 -> 每月 -> 每周 -> 每天。

被动高频（付账单） -> 主动高频（刷抖音）。

可催化（打车） -> 难催化（上门洗车）。

策略： 高频做“习惯/流量入口”，低频做“信任/高客单变现”。

自我修养6：追求客观的“普遍性”

定义： 是真正有痛点的用户总量。

误区： 幸存者偏差（身边朋友都说好 ≠ 市场大）。

普遍性尺子：

特定行业 -> 跨行业 -> 全民。

路边大爷懂 -> 发烧友懂 -> 只有专家懂。

调研策略：

找陌生人随机测试（听懂率、共鸣率）。

走出五环，去下沉市场，去查百度/微信指数。

警句： 小众不可怕，可怕的是把小众需求当成大众生意做。

面对创新难题，像雷达一样多轮扫描，深挖到最Sharp的点。

自我修养7：多轮JTBD循环探索

不要满足于第一轮拆解出的选项。如果是创新/难题，需要一轮轮深挖。

流程： 拆解 -> 评估 -> 不够Sharp -> 再拆解 -> 再评估。

案例： 挂脖空调（Cici的逆袭）

Round 1: 泛人群（年轻男性） -> 太粗，卖不动。

Round 2: 户外场景（徒步/钓鱼/露营） -> 发现徒步登山嫌重、钓鱼有替代方案。

Round 3: 锁定“露营” -> 细分为“精致露营”。

Round 4: 锁定“都市白领的精致露营” -> 场景细化为：生火（装逼）、搬运（不狼狈）、搭帐篷（从容）、拍照（社交货币）。

结果： 价格贵3倍却卖爆，因为刚性在“社交货币”和“体面”上变得极强。

自我修养8：培养最佳实践 Benchmark

建立“判断基准线”。不仅要内部比，还要跟外部的替代品比。

方法： 找外部对标（如做露营空调，对标露营KTV、露营投影仪）。

逻辑： 如果对标物能卖好，且你的需求评估（普/频/刚）得分不低于它，那信心就足了。

不要把“使用时长”当“频次”（看长视频是低频高时长，看日历是高频低时长）。

不要把“用户愿望”当“刚需”（问过去发生了什么，别问未来想不想）。

不要依赖熟人“夸夸群”（去做陌生人访谈，去算共鸣率）。

如果没有信心，请果断熔断（Kill），止损也是成功。

控制变量对比，在相似层级（L3/L4任务层）进行比较。

需求评估就是为了找到那个唯一正确的切口。

通过 拆（场景）- 推（JTBD）- 评（RFP三角） 的循环，把模糊的直觉，打磨成客观的、高信心的商业判断

### 2、第二个作业：案例分析题

**【题目】** 如果你有自己真实在做/想做的业务，可以先描述一下整体的业务背景，然后从刚性、频次和普遍性三个维度来进行一次全面的需求评估；如果你有更多信息，也可以再继续尝试着计算一下大概的业务天花板。

**【我的回答】**

一句话描述业务： 面向一线城市（首选深圳）中产家庭，以“青少年学习力提升（速读/记忆/习惯）”为显性切口，提供解决13-17岁青少年“情绪/目标/亲子关系”根本问题的系统式家庭指导服务（VIP年费制）。

目标用户 (User)：

核心画像： 居住在深圳/广州，家庭年收入50万+的中产家庭。

关键特征： 家中有处于初一至高二（13-17岁）的孩子，正面临青春期叛逆、学习动力不足或亲子冲突严重的问题。

决策者： 通常是35-50岁的母亲，对孩子未来有焦虑感，拥有教育支付决策权。

核心场景 (Situation)：

显性场景（触发点）： 孩子成绩下滑、写作业拖延、沉迷手机、不想上学，家长急需“提分”或“纠正行为”的手段。

隐性场景（根源）： 青春期身心变化导致的剧烈情绪冲突、自我认知迷茫、家庭沟通模式失效。

解决的任务 (JTBD)：

表面任务（Hook）： 让孩子掌握高效学习方法，提升成绩，让家长“省心”。

深层任务（Core）： 修复受损的亲子关系，构建孩子健康的内在驱动系统（全人教育），缓解家长的育儿焦虑。

刚性分层判定： 强刚需（痛点）与弱刚需（理念）的错配。

极强刚性（救命稻草级）： “提分/升学”和“解决严重叛逆（不至于辍学/抑郁）”。这是家长愿意不计成本投入的部分。

中等刚性（止痛药级）： “学习习惯养成”、“时间管理”。家长认为重要，但见效慢，支付意愿略低。

弱刚性（锦上添花级）： “全人教育”、“家长自我成长”。这是项目方想交付的核心，但往往是家长的盲区（家长通常认为“我有钱，你帮我修好孩子就行，不用修我”）。

替代方案：

学科补习（直接竞对，刚性最强）。

心理咨询（针对病理性问题）。

放任自流或暴力管教（免费但无效的替代品）。

评估结论： 刚性取决于包装。如果包装成“全人教育”，刚性不足；如果包装成“提分/学习高手训练”，刚性极强。

痛点频次（高）： 孩子每天都要上学、做作业，亲子冲突和学习挫折几乎是日更的。这为高频服务提供了天然土壤。

交易频次（低）： 该业务属于低频决策、长周期交付。家长通常按年付费或按疗程付费。

交付频次（需调整）：

原模式风险： 单纯教“快速阅读/记忆法”属于“一锤子买卖”，技能学会了，服务就结束了，缺乏粘性。

理想模式： “陪伴式指导”。利用孩子日常学习中的高频痛点（如每次考试后的复盘、每天作业的情绪管理）作为服务触点，将低频交易转化为高频互动，从而维持VIP年费的续费率。

人群筛选漏斗（窄众）：

广谱人群： 所有有13-17岁孩子的家庭（基数大）。

地域筛选： 深圳/广州（家长更务实、更激进、支付能力强）。

意识筛选： 愿意接受“家庭指导”而非单纯“补课”的家长（这一刀切掉了大部分只认分数的家长）。

支付筛选： 能承担约3万/年客单价的家庭。

评估结论： 这是一个垂直细分市场（Niche Market）。它不是一个大众普适性生意，而是一个针对精英/中产家庭的深度服务生意。虽然总人数不多，但单客价值极高。

基于“小而美”的深度咨询工作室模式进行测算。

客单价 (ARPU)：

前端引流品（学习力训练营）：约 2,000 - 5,000元。

后端核心品（VIP年度家庭指导）：29,800元/年。

产能限制  ：

由于是非标准化的深度服务（包含情绪疏导、定制方案），极其依赖资深老师的个人能力。

单师服务上限： 预计 25个 VIP家庭/年（若超过此数量，服务质量和效果将大幅下降）。

资源： 案主本人核心交付 + 少量助理。

满载计算： 25个VIP家庭 × 2.98万 = 74.5万/年。

叠加前端课： 假设每年招收100个前端学员 × 3000元 = 30万/年。

阶段天花板： 约 100万 - 120万/年。

评价：这是一个非常健康的个体户或超级个体生意，利润率高，但规模有限。

资源： 复制出或招募到10位具备同等理念和能力的资深导师（这是最大的难点）。

满载计算： 10位老师 × 25个家庭 × 2.98万 = 745万/年。

阶段天花板： 约 700万 - 1000万/年（考虑流失率和非满载情况）。

评价：这是该类咨询模式的常规天花板。由于“人”的非标准化，很难像SaaS软件那样无限扩张。

瓶颈： 最大的瓶颈不是市场需求（甚至深圳一个区的需求就足够吃饱），而是“合格交付者的供给 。家庭指导师需要懂心理、懂教育、懂沟通，培养周期极长。

突破口： 除非将“服务”转化为“产品”（如出版教材、录制标品网课、开发AI辅助工具），否则业务天花板将始终受限于 （师资人数 × 单师产能） 。
