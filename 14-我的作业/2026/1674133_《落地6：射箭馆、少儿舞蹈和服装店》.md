## 我的作业

### 1、第一个作业：学习心得题

**【题目】** 今天我们的案例课，讲了叶文彬的「我用一堂做射箭馆」、董原的「我用一堂做舞蹈培训」、谢泽丰的「我用一堂做服装店」三个案例。听完课程之后，哪个案例对你最有启发，启发点是什么？可以结合这个案例，说说你的理解，或者也可以写写想对他们说的话。

**【我的回答】**

a. 核心业务公式构建

i. 拆解门店收入：进店量×办卡率×会员ARPU值×(1+裂变率)。 # 结构化拆解

ii. 明确四大经营环节：“一看就进，一进就买，一买再买，带人来买”。 # 客户旅程

b. 进店量（一看就进）优化

i. 认知升级：进店量不是流量问题，而是触点转化率问题，需增加知道、提升吸引、抹平阻力。 # 转化漏斗

ii. 线下触点改造：清理楼道，做大招牌，将爬楼梯重新定义为“射箭热身”。 # 阻力消除

iii. 多渠道引流：线上精装美团点评，线下发质感礼品卡提升回流率。 # 触点管理

c. 办卡率（一进就买）优化

i. 调整流程：变“先付款后体验”为“先体验后付款”，创造自然推销触点。 # 流程重构

ii. 产品重塑：取消单组售卖，改为59元3组，确保新手获得完整体验。 # 产品驱动

iii. 情绪价值：教练夸赞、放大靶心、缩短距离，消除新手没有天赋的挫败感。 # 情绪设计

d. ARPU与裂变率优化

i. 游戏化消耗：引入任务与徽章系统，将会员次数消耗变为可见的成长进度。 # 游戏化思维

ii. 社交裂变：去返利化，改用名、权、情作为会员带新的动力，促使朋友独立办卡。 # 社交货币

e. 科学型组织建设

i. 沉淀经验：将优秀个人的成功案例用动力、阻力、触点拆解，提炼为全员SOP。 # 知识萃取

a. 规模化带来的指标崩盘

i. 问题暴露：从单店扩张至四店，引以为傲的续班率从90%跌破80%。 # 规模化陷阱

ii. 错误归因：初试转化率手段，疯狂送礼、加话术、盯作业，耗费精力但收效甚微。 # 战术勤奋

b. 业务公式重构与分层分析

i. 重新定义：续班率并非单点结果，而是平日积累×窗口期激活的链条产物。 # 链条思维

ii. 参数分层：用业务公式做减法，发现新老师与新生叠加的结构是真正漏水点。 # 结构洞察

c. 针对性策略击穿核心参数

i. 新老师合格：设立成材教练辅导，改师带徒为集中师训与固定助教岗。 # 机制兜底

ii. 新生首期：锁定“喜欢老师”为关键参数，月度盘点新生，推行“安全依恋”SOP。 # 情感量化

iii. 老生留存：面向中高年级推出中考班，解决家长对未来升学规划的意义阻力。 # 需求升级

d. 方法论沉淀

i. 避坑指南：切忌将相关关系（如作业率）误认为因果关系，需找准核心中间变量。 # 本质思考

ii. 系统协同：业务公式负责找准真实战场，转化率负责打透具体节点。 # 战略与战术

a. 红海竞争下的流量困局

i. 背景：靠错位竞争吃红利后，同行模仿导致差异化优势消失，陷入内卷沼泽。 # 红海危机

ii. 痛点：线下门店缺乏基础数据，无法准确计算漏斗，提假设如同无根之水。 # 数字化缺失

b. 搭建数据实验环境

i. 粗暴统计：派专人站门口拿计数器，人工统计客流、进店、触摸、试穿等基础转化率。 # 基础设施

ii. 误区排雷：盲目拉升单一指标（如送水做到100%进店率），服务跟不上则无益于总营收。 # 局部最优

c. 用因果关系寻找创新参数

i. 重审公式：摒弃盲目扩流，将重心转移至优先提升门店转化率，避免流量浪费。 # 优先级管理

ii. 参数挖掘：洞察到二次试穿（试穿两件以上）是大幅拉升成交率的创新参数。 # 关键变量

iii. 聚焦假设：不再泛泛优化面料话术，而是集中精力诱导顾客完成第二次试穿。 # 单点击穿

d. 流量入口与管理迭代

i. 科学引流：测算出音量80的Magic Number，有效吸引过客，进店率提升至30%。 # 变量测试

ii. 范式转移：从凭感觉决策，转向假设驱动的管理范式，用数据证实或证伪。 # 科学决策
