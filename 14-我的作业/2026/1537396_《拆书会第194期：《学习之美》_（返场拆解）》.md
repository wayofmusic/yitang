## 我的作业

### 1、思考题

**【题目】** 用四问学习法，来回顾今晚的读书会...
你听到什么？你想到什么？你变成什么？你用在哪里？

**【我的回答】**

a. 认知核心元能力

i. 确立根本：学习力是一个人最核心的元能力 # 元认知

b. 破除标准答案思维

i. 摒弃旧习：成年人世界没有标准答案，只有参考答案 # 思维破局

ii. 情境依赖：所有重要的管理与学习问题，答案皆是看情况 # 权变思维

c. 践行切己原则

i. 务实导向：永不谈不切己问题，聚焦工作、人际与个人成长 # 知行合一

a. 审视辅导现状

i. 学员执念：常急于索求万能演讲模板与通用标准台词 # 现象剖析

ii. 捷径陷阱：为求见效快给模板，实则强化标准答案思维 # 行为反思

b. 探寻演说本质

i. 场景适配：面对不同投资人、客户与氛围，演说需因地制宜 # 动态适配

ii. 传授核心：摒弃句子碎片，教导商业故事的底层模式与深层逻辑 # 本质思考

a. 升级辅导准则

i. 破立并举：好教练绝不给标准台词，只提供参考模式 # 模式化学习

b. 动词化演说理念

i. 动态连接：演说是与观众产生连接的动作，绝非写死在纸上的稿子 # 具身认知

ii. 过程导向：不盯最终稿件的完美度，更关注思考与表达的演进过程 # 动态评估

c. 转变身份定位

i. 角色重塑：从给答案的权威导师，转变为共探参考答案的对话伙伴 # 助人者定位

a. 设定触发式行动计划

i. 边界管理：下周私房课遇索要模板者，忍住冲动坚决不直给 # 延迟满足

ii. 启发提问：用四问引导学员将客户反馈与产品痛点化为专属商业故事 # 启发式教练

b. 落实场景与复盘机制

i. 场景落地：师生共同推敲该故事在具体路演场合的应用细节 # 刻意练习

ii. 预定复盘：课后三天内复盘，检验是否管住嘴并成功传授演说深层模式 # 持续迭代

iii. 环境提示：将四问清单贴于工作台前，将其固化为长期工作习惯 # 习惯养成

### 2、实践题

**【题目】** 花一点时间，在作业里谈一谈自己从今晚过后到写作业之间有没有发生一些具体的改变？哪怕是很小的一点...
参考四类学习类型的分类，把自己的占比前后变化或者目标展开谈谈...
你之前是如何做的？现在又是如何做的？尝试把这种微小变化记录下来...（这是一个长期功课）

**【我的回答】**

a. 明确四类学习模式概念

i. 消费型学习：追求听课时的即时爽感，缺乏实质能力提升。 # 即时满足

ii. 生产型学习：为输出而拼凑心得或机械传递，未触及核心逻辑。 # 表面输出

iii. 投资型学习：探究底层逻辑，能带来知识与能力的长期复利。 # 长期主义

iv. 浪费型学习：既无知识增量也无情绪愉悦，纯粹消耗精力。 # 沉没成本

b. 评估时间精力分配结构

i. 历史占比：消费型50%，生产型30%，投资型与浪费型各占10%。 # 现状梳理

ii. 未来目标：大幅削减低效学习，将投资型学习占比提升至60%以上。 # 目标管理

a. 阻断无效的肌肉记忆

i. 克制本能冲动：课后拒绝刷手机放松或发朋友圈打卡交差。 # 延迟满足

ii. 拒绝碎片传递：放弃将刚学到的碎片化技巧直接丢给学员练习。 # 认知升级

b. 启动深度内化机制

i. 追问底层逻辑：剖析演说新技巧如何与听众心智产生深度互动。 # 本质思考

ii. 转化参考答案：将外部获取的知识，加工提炼为个人可用的专属模式。 # 知识内化

a. 知识的网络化与结构化

i. 运用四问学习法：将新学方法与自身的演说辅导经验深度结合。 # 跨界整合

ii. 建立专属模式树：把零散知识点挂靠进商业演说教练的底层体系中。 # 体系构建

b. 长期主义的践行路径

i. 调整心理预期：接受不着急对外表现、进度变慢的深度思考状态。 # 节奏控制

ii. 培育核心元能力：坚持用新习惯做加法，让投资型学习长成内在能力。 # 终身成长

**【我的回答】**

书名：《认知天性：让学习轻而易举的心理学规律》

作者：美 彼得·C.布朗 / 亨利·L.罗迪格三世 / 马克·A.麦克丹尼尔

豆瓣评分：7.8分（英文原版 8.4分）

一句话推荐：如果你觉得学习很轻松，那你多半是在浪费时间；真正的深度学习，必须是“反本能”的痛苦过程。

本书解决的痛点：写给那些“努力但没效果”的学习者。解决了：

看了书就忘，合上书脑袋一片空白。

沉迷于画线、重读这种“勤奋的懒惰”。

考试/实战时发挥不出真实水平的“伪勤奋”焦虑。

核心论点：耗费心血的学习才是深层次的，效果也更持久。 只有当大脑被迫工作时，学习才真正发生。

案例一（颠覆认知：棒球手的打击练习）：

大学校队棒球手被分为两组。A组练习“集中模式”，先连打45个快速球，再打45个曲线球。B组练习“随机模式”，快速球、曲线球、滑球随机出现。

冲突：练习中，A组表现更好，感觉更自信；B组打得很烂，挫败感强。

结果：赛季正式比赛时，B组的表现远超A组。结论：随机交叉练习（Interleaving）虽然在当下痛苦，却能培养大脑识别“球种”的底层逻辑，而非肌肉记忆。

案例二（实操落地：模拟飞行器教育）：

比起单纯看飞行手册，飞行员在模拟器中处理突发状况（如单发引擎失效）时，大脑处于高度紧张的“检索”状态。

细节：研究发现，哪怕是错误的尝试，只要在之后得到了及时的反馈纠正，这种“犯错后的检索”对记忆的加深程度，远超直接看正确答案。

收获一：检索练习 (Retrieval Practice)

不要重复阅读！合上书，通过问答、默写、测验等方式强制大脑“提取”信息。“考自己”不是为了检测，考自己就是学习本身。

收获二：间隔与穿插 (Spacing & Interleaving)

不要把一个知识点死磕到底。要在快忘掉时再复习（间隔），并且把不同科目交叉着学（穿插）。这会强迫大脑不断重建知识路径，让记忆从“沙滩刻字”变成“岩石雕刻”。

收获三：生成性学习 (Generative Learning)

在老师给出答案前，先尝试自己解决问题。哪怕猜错，也能在大脑里挖好一个“知识的坑”，等正确答案填进去时，它会扎根得更深。

立刻能做的一件事：从明天起，停止划重点和重读。每读完一章或开完一个会，花5分钟在白纸上写出：“刚才讲了哪3个核心观点？”——这就是最有效的检索练习。

全书金句：“不花力气的学习就像在沙子上写字，今天写上，明天字就消失了。”
