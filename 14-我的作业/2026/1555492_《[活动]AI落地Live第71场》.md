# 《[活动]AI落地Live第71场》

- 日期：2026.03.26

## 我的作业

### 1、体会和变化

**【题目】** 听完今天的分享，你对AI落地真实的业务流程，是否有一些的新的认知或体会？可以说说看。

**【我的回答】**

1 认知重构：从“极客玩具”到“数字员工”

a. 转变定位：不再将AI视为单纯的搜索引擎或陪聊工具。

b. 归因反思：输出效果差多源于岗位职责设定不清，而非AI本身不够聪明。 # 认知升级

2 团队管理：像带领真人团队一样带AI

a. 明确身份：赋予AI明确的角色、工作方法与规矩。

b. 划定边界：避免让其“什么都干”，防范“全能即无能”的陷阱。

c. 技能武装：为AI接入插件与工具，赋予其搜集与处理数据的真实生产力。 # 边界意识

3流程控制：用执行卡片破解复杂任务

a. 痛点洞察：真实业务链条长，作为概率机器的AI极易在长任务中产生偏离。

b. 颗粒度拆解：将大工程拆解为标准化的执行卡片，约束执行动作。

c. 消除不确定：严格规定输入资料、执行步骤与输出格式，构建确定性流水线。 # 流程控制

4业务落地：构建商业演说培训AI流水线

a. 场景映射：将所学模型应用于听众调研、逐字稿打磨、PPT配图排版等环节。

b. 专职分工：按环节分配专职AI Agent，依据执行卡片开展标准化协作。

c. 效能跃升：通过流程重构，实现个人效率与学员交付质量的双重提升。 # 业务闭环

### 2、思考你的数字员工团队

**【题目】** 如果你现在正在设计自己的Agent团队，你希望这个团队应用在哪些场景，你会怎样设计TA们的工作流程？

**【我的回答】**

a. 核心工作场景

i. 聚焦于高频的商业演说辅导与课程研发 # 场景聚焦

b. 现状痛点拆解

i. 查阅大量资料及帮几百位学员改稿，工作量巨大 # 效率瓶颈

ii. 将标准化工作流拆解，交由数字员工自动处理 # 流程重构

a. 案例情报员：小搜

i. 核心任务：不知疲倦地全网巡逻，搜集最新商业案例 # 资源获取

ii. 核心工作流：抓取热点资讯，按背景-冲突-疑问-解答改写故事 # 知识重构

iii. 资源沉淀：为故事打上标签，存入团队本地知识库备用 # 资产沉淀

b. 演说结构师：小理

i. 核心任务：处理逻辑松散的初稿或模糊的课程点子 # 逻辑梳理

ii. 核心工作流：自动调用经典演说框架，提取骨架并砍掉废话 # 模型应用

iii. 最终产出：输出一份条理极其清晰的演讲大纲 # 结构化输出

c. 作业初审助理：小评

i. 核心任务：严格对照打分表，高效初审学员逐字稿作业 # 质量控制

ii. 评价维度：多维评估开场吸引力、金句设置与逻辑过渡 # 评价体系

iii. 团队联动：发现稿件干瘪时，自动调用小搜的案例作为建议 # 跨域协同

a. 参考noah的长程任务串联

i. 启动：学员提交稿件后，小理优先梳理大纲结构 # 流程触发

ii. 诊断：小评随后介入，进行深度诊断并提出优化建议 # 质量把关

iii. 支援：小搜在一旁随时待命，提供案例炮弹支持修改 # 资源补给

b. 最终交付形态

i. 自动产出排版整齐、带有初步修改方案的高质量辅导报告 # 闭环交付

a. 机器的执行边界

i. 承接繁琐的找素材与初级改稿任务，严格守住自身边界 # 机器减负

b. 人类的核心价值

i. 释放精力，发挥创造力与同理心 # 价值聚焦

ii. 重点把握学员的情感状态，具感染力的舞台表现 # 情感共鸣

c. 核心协同理念

i. 将复杂任务拆解为明确步骤，让人工智能做好边界内的事 # 协作哲学
