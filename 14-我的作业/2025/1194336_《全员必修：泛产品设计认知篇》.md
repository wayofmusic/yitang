# 《全员必修：泛产品设计认知篇》

- 日期：2025.06.08

## 我的作业

### 1、基础作业：心得体会题

**【题目】** 今天讲了我这10年一步步探索、困扰和突破自己的故事，讲了什么是泛产品设计，和想要修炼泛产品设计的三大自我修养。听完这节课，你有哪些新的认知、思考？你可以说说你对于泛产品设计的心得体会。

**【我的回答】**

产品设计不仅仅是互联网、硬件、UI/UX这些专业场景里的事情，

“泛产品设计”是一种能跨越生活、工作、学习、表达等各类场景，打磨“美好作品交付能力”的通用能力。

无论是家长课堂、拜年视频、课程地图设计，还是婚礼、装修、写作、旅行规划，都可以用同一套设计理念来拆解。

以前总觉得“Sense”是天生的， “动力阻力模型”、“峰终定律”、“目标-路径-资源” 等底层模型，提醒我：

所谓的Sense，背后是刻意练习。往往是通过反复练习、刻意拆解和建立审美体系练出来的。

尤其是“最佳实践建立审美”这一点，触动特别大，以前做设计很容易凭感觉或套模板，未来要养成刷最佳实践的习惯。

课里提到很多PM做到3年、7年、甚至10年以后跨领域会很痛苦，因为能力迁移性差。我也有类似感受，听完课后认识到如果能系统训练“泛产品设计能力”，未来不论换行业、岗位，很多底层能力都可以复用，形成长期复利。

truman用产品流程做婚礼，效果远超预期。

其实，生活中自己很多事情（写公众号、做家庭相册、搞年会）其实也可以练产品设计思维。

以后要主动把生活项目当成泛产品设计练手机会。

我目前处在 “像做产品一样做XX”的阶段，很多时候靠产品Sense和经验解决问题，

缺乏 固定的工具箱 和 系统的底层模型。也是在一趟学习之后，开始适度思考，尝试为自己的经验做模型，做沉淀，形成工具箱、清单 sop，这样才能从“会用”走向好用，且好复制。

用户视角第一，代入真实用户场景做设计。

目标明确，没有目标就不要谈效率。

最佳实践学习，先建立审美，再下手设计。

峰终定律，关键体验和细节拉满。

长期主义，10年磨一剑而非只求短期成效。

工作中：尝试在公司内训、活动方案中刻意练习、最佳实践学习法，积累更多跨场景产品设计经验。

生活中：今年家里要重新布置儿童房，可以借机做一次像产品一样的“空间设计”练习。

学习上：计划整理自己过往做过的各种项目、用产品设计的思路重新拆一下，包括课程还有其他的项目，复盘提炼出自己的套路。

总的来说，这节《泛产品设计必修课》不仅拓宽了我对“产品设计”的认知边界，也给了我一条 长期可修炼、可迁移的核心能力路径。

### 2、进阶作业：过往作品题

**【题目】** 在你过去的工作、生活中，你都设计过什么作品？在这些作品的设计过程中，你用到过“泛产品设计”的能力吗？
- 如果用到过，可以说说你的哪个项目，用到了泛产品设计的什么思路、方法。
- 如果没用到过，可以说说，再给你一次机会去设计这个产品，你会怎么设计。

**【我的回答】**

坦白说，以前我做这些设计的时候，更多是凭借工作经验 + 项目管理的感觉在推进。

听完这次《泛产品设计必修课》，回过头复盘，我发现自己其实在很多项目里，已经无意中用了泛产品设计的一些思路和方法。最典型的就是今年的 “生命同行”35公里徒步活动。

“生命同行”是我和团队发起的一个线下徒步体验型活动，核心目的是通过 35公里徒步+仪式设计，帮助企业家老板、创业者群体在一年一度的节点上，完成一次身心的 reset，激发对生命、事业、家庭的深度思考和内在承诺。

2025年5月20日在青岛首次举办，30人报名，22人完赛，现场反馈超出预期。

（1）用户场景分析 & 用户分层

活动策划初期，我刻意做了一版 用户分层地图，分成：

核心客户（已报名高价课程的同道VIP）

边缘客户（低价课成交客户，首次参加线下大型活动）

家属（家人陪同参加）

随行志愿者 &合作伙伴

根据每一类用户在活动中会出现的 物理场景+心理场景，我设计了全程体验路径，做到 峰终定律 设计拉满，避免只关注“走路”本身。

（2）目标-路径-资源 三段论设计

目标：不仅完成35公里，更重要是让学员 走出思考、走出承诺、走出关系深化。

路径：设计出 “起点仪式 → 路中分段引导 → 终点仪式 → 个人复盘 → 群体情感共振” 的完整流程。

关键资源：挑选了3位极有带动力的队长，配置摄影师+心理引导师，终点设计了视觉装置+定制徽章+誓言卡片。

（3）最佳实践 &审美建立

调研了 我们自己的活动、徒步活动、心灵成长型活动、跑团文化案例，整理了几十个 优秀峰值设计和仪式设计案例，内化到我们的生命同行设计里。包括活动的物料包，奖牌等纪念品设计参考了马拉松

b 比如“终点仪式”的设计 加入了：

给自己的一封信

情绪释放+共振闭环环节

（4）反复迭代 &风险管理

整个策划过程中，至少做了 6轮全流程复盘，对每个环节的情绪曲线、停留时间、道具物料、指引信息做了细节打磨。

我还提前设计了 Plan B方案 应对天气突变，实际活动当天遇到中午突晒 + 下午轻微降雨，顺利应对。

用户反馈：活动当天95%用户现场打卡/朋友圈分享，完赛率98%

品牌复利：后续带来3批新用户报名后续课程，直接促进课程成交

我个人收获：更深刻体会到“泛产品设计”里 用户视角、峰终定律、最佳实践迁移 的巨大价值。

未来计划将这次经验沉淀成一套模板，供公司其他线下活动团队复用，形成“可规模化复制”的产品设计能力。

泛产品设计不是高大上的概念，而是一种可以迁移、跨领域、持续进步的能力。

未来我希望自己能继续沿着 “最佳实践 → 固定套路 → 大量练习” 这条路走下去，让我们能在更多元的场景里，做出更多“美好作品”交付给用户。

### 3、高阶作业：立即实践题

**【题目】** 你最近有没有特别想挑战的产品？

比如想写一本书、想组织一场年会、想做一个视频、想设计一场旅行……

你可以挑选其中一个，写一写如果你现在要设计这个产品，整体的思路是什么样子的？
可以参考课程中的方法，也可以有你自己的创新。

（默认题目）如果选不出来，可以参考这三个选题：
1. 你想写一本书
2. 你想组织一场年会
3. 你想设计一场旅行
实在没有题目，可以给一堂规划一本书《一堂五步法》，目标是对标欧美经典创业教材《精益创业》，说说完整产品设计思考过程。

**【我的回答】**

最近团队在研究 VIP客户长期关系维护，讨论中提到可以通过AI赋能，探索一些低成本、高情绪价值的定制礼物方案。感谢无敌老崔再AI俱乐部里的分享，崔哥分享了手办这个方向，经过讨论，决定试做一版 VIP客户生日定制手办，预算控制在200-300元之间，作为今年VIP关怀计划的一部分。

这个项目小而美，很适合用 泛产品设计能力 体系化推进。

首先不是直接做手办，而是先分析 用户使用场景，用户视角思考：

用户是谁？ 核心VIP客户（VIP，VVVIP）

他们会在哪用？ 主要会放在办公室桌面、书柜或家庭空间。

他们最期待的价值？ 有辨识度、有情感、有惊喜（不是普通定制公仔）。

用户分层补充

A类：高复购、高粘性会员，追求独特感。

B类：有机会促成下一步高价成交的VIP客户，目标打动TA本人和身边人。

C类：长期潜力客户，增加品牌记忆点。

明确用户场景和分层，才能避免「做完客户其实不会摆、不用」的无效设计。

目标：客户拿到后愿意摆放+愿意晒朋友圈，强化品牌记忆。

路径：AI生成形象→AI生成3D建模 → 定制设计（高精度3d打印） → 生产 → 交付包装 → 后续客户互动。

资源：AI图生图技术、3D技术（GPT\lovart+腾讯混元）、定制手办厂商（崔哥推荐了资源）、精致包装方案（可参考文具圈、文创圈玩法）。

泛产品设计里很核心的一个动作 → 最佳实践审美建立。

这个阶段，主动查阅了以下案例：

小米生态链做的定制手办案例

B站UP主定制手办周边

高端私董会/车主俱乐部赠送过的定制公仔

淘宝/1688 定制手办头部卖家作品Top20

调研结果发现：

脸部精细度很关键，目前模型精度问题不大了，主要是打印精度。

包装要讲仪式感，简单白盒 + 品牌故事卡 + 手写卡片很加分。

有品牌专属元素（比如品牌口号、logo、定制底座文案）更容易晒朋友圈。

具体设计方案拆解：

前期AI生成：根据客户照片、职业特点、兴趣，AI生成 夸张化Q版形象。（GPT就可以）

生成3d模型：lovart 腾讯混元等大模型

生产流程：

就做一个，找靠谱的3d打印

体积建议控制在 8-10cm，高端但可控成本。

定制底座文案：比如“与XXX同行”、“信任是最好的力量”等，品牌内涵结合客户调性。

包装设计：

外包装简约高级

内含手写感谢卡 + 品牌小卡片

额外赠送 “同行勋章”徽章（延伸品牌互动）。

成本控制估算：

AI图生成+设计师时间：Ai稿定基本没啥成本

手办生产 3d打印：约 200-300 元/件

包装+配件：约 50 元

→ 总预算基本符合200-300范围。

关键是 开箱体验 → 客户收到后，开箱过程是否有惊喜？

包装文案刻意设计 3段式节奏（启发自峰终定律）：

1️⃣ “探索”层：开箱提示语

2️⃣ “发现”层：打开后视觉冲击

3️⃣ “情感”层：手写卡片传递品牌情绪价值

目标：客户收到后 忍不住拍照发圈，并且产生「这个品牌真的用心」的感受。

用户场景分析 → 决定了这个产品做不做得出来“有生命力”。

目标-路径-资源 → 保证设计过程不会走偏，始终聚焦目标。

最佳实践学习 → 快速补足领域经验，少走弯路。

峰终定律 → 设计好情绪节奏，提升用户体验。

以前做这类VIP礼物设计，很多时候靠感觉和供应链推进，容易 交付物平庸，客户反馈一般。

这次用泛产品设计的体系方法来拆解，明显感觉设计感更强，后续执行效率也更高，能复用性更强。

下一步计划推进这个方案的小批量试点，后期形成 “VIP手办+文化卡”产品线模板，
