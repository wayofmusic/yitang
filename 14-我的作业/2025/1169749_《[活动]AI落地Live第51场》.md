### 1、第一个题目：学习心得题

**【题目】** 重新回顾了一下Agent的资料，重温了Agent的阶段发展过程，有什么想聊的可以在这里在这里说说。或者思考一下如何在这些信息的基础上，更好完成业务中的AI落地。

**【我的回答】**

高投资回报率 (ROI): 搭建 Agent 需要投入时间和资源，因此预期收益需要足够高才能抵消成本。

高频次重复性任务: Agent 擅长处理重复性高、规律性强的工作，从而解放人力。

标准操作流程 (SOP): 清晰的 SOP 可以帮助 Agent 更准确地理解和执行任务。

必要的知识库 (Know-how): Agent 需要具备完成任务所需的知识和技能。

Coze Agent 适用于那些高频、重复、有标准操作流程，并且可以判断工作质量好坏的任务。

通过学习数据，Coze Agent 可以大概率完成对这些任务的判断和执行。

工作流搭建: 虽然搭建工作流需要一定的时间和精力，但可以有效提升 Agent 的效率。

Token 消耗: 不合理的工作流设计可能会导致大量的 Token 消耗，需要优化流程以降低成本。

大模型能力: 对于一些流程简单的任务，可以直接交给能力强的大模型处理，无需拆分工作流。

利用大模型能力，我是用大模型的知道，帮我快速把原先的提示词 拆成了5个部分的系统提示词
