## 我的作业

### 1、作业1：学习ROI心得

**【题目】** 今天的课上，我们从个人、团队、公司的维度，跟大家分享了同学们真实的ROI评估案例，也给大家交付了冷静清单法、故事推演法、建立体系法、用专业检查的决策基本功方法。
你有哪些心得启发？过往你在决策的「宽度」方面，踩过那些坑？欢迎写一写你的新认知和思考。

**【我的回答】**

在这堂课程中，我深刻理解到广义ROI的重要性。

它不仅适用于投资和营销领域，更是我们日常决策、业务管理和团队领导中的核心。

这节课举了很多例子，思考【宽度】关注于找出关键投入和收益项。

我们从个人，团队，公司三个维度很多决策都可以通过算ROI来达成 偏理性，更务实，不拍脑门的决策

四个估算ROI宽度的方法，看起来还是比较有效的。

在过去，我在决策宽度方面踩过一些坑。（漏掉关键项，导致算错帐）

例如，在评估一个新培训项目时，我未能充分考虑所有相关因素，导致项目后期出现了意料之外的挑战。此外，有时我会过于依赖直觉，而忽视了数据的支持，这导致了一些不精准的决策。这些经历教会了我要更全面地考虑问题，并在决策中融入更多数据和事实。

1.ROI可以用好的话，能够搞定生活的方方面面的决策问题。

2.ROI如果能够把宽度搞定，基本上有60分，只要没有关键成本和关键收益漏了，大账算不错，问题就不大

（当然深度和高度还没说好）

3.有的时候要交差验证，可以考虑把冷静清单法、故事推演法、建立体系法、用专业检查综合

运用一下。

4.ROI属于基本功，需要多练习。

### 2、作业2：作业大贴纸计划

**【题目】** 一堂最近两年，我们做了大量的武器库、小抄、拿来就用的工具，上次线下活动，我们试着把一些"低成本创业小抄"、"情报调研小抄"、"表达火箭小抄"贴在了会场，发现大家讨论问题时很有帮助。
小抄里的各种策略，任何一个能够执行、落地，都是一次价值10w的决策，但是养成使用习惯，还是太难了。
于是有人给我提了个建议：把一些团队共学共用的工具，一堂官方做成商品，放到一个商店里，大家可以自行购买，贴到自己的办公室、会议室、书房，方便日常做决策。
问题来了，这个项目ROI如何？值得做吗？
希望大家可以站在我的角度（一堂全局），来帮我估算一下ROI，进而决定做还是不做。

**【我的回答】**

运用ROI方法进行科学决策，并对一堂开设官方商店销售决策工具的想法进行了分析。以下是我的分析和建议：

一堂近期考虑开设一个官方商店，销售专为团队决策设计的工具，如“低成本创业小抄”、“情报调研小抄”等，以便团队成员在日常工作中便捷使用这些工具，提高决策质量。

直接销售收入：预计通过销售这些工具，一堂能获得稳定的收入流。

品牌影响力提升：通过这些工具的实际应用，能增强团队对一堂品牌的认知和信任。

团队决策效率提升：工具的普及有助于提升团队的决策效率，从而可能带来业务增长。

提升客户的粘性，贴在办公室的海报可以增加粘性，增加用户的迁移成本，长期收益。

宣传和传播，二次扫码引流客户，可以形成与传播和复购。

产品制作成本：包括设计（可以算设计工时费，其实都设计好了基本上，设计忽略了）、打印和包装等费用。

物流成本：将产品送达客户手中的物流费用。

市场营销成本：为了推广这些工具，可能需要进行广告和促销活动。

运营成本：包括商店项目组日常运营和费用。

1.制作了大量的小炒物料如果没人买，会造成浪费。

2.后期更新模型，未及时售出的物料也会浪费。

假定量化计算

产品定价：假设每套工具的售价为200元（购买的人均消费200元）。

销售量：预计第一年的销售量为2000套（1万会员*20%）。

成本构成：

产品制作成本：每套工具的制作成本为20元。

物流成本：每套工具的物流成本为10元。

运营成本：每年的运营成本为2个人的工资，假设每人年薪为120000元。

仓储成本；假设50000元

总收益 = 销售量 * 单价 总收益 = 2000 * 200元 总收益 = 400000元

总成本 = (产品制作成本 + 物流成本) * 销售量 + 运营成本 总成本 = (20元 + 10元) * 2000 + 2 * 120000元 总成本 = 60000元 +50000+ 240000元 总成本 = 350000元

ROI = (总收益 - 总成本) / 总成本 ROI = (400000元 - 350000元) / 300000元 ROI = 50000元 / 300000元 ROI = 0.1666 或者 16.7%

根据新的假设条件的计算，一堂开设官方商店销售决策工具的ROI为16%。这意味着对于每一元的投资，一堂可以期望获得0.16元的净收益。这是一个相对较高的回报率，表明该项目在经济上是可行的。然而，实际的ROI可能会因市场变化、成本控制和执行效率等因素而有所不同。一堂应该在实际操作中持续监控这些变量，并相应调整策略。
