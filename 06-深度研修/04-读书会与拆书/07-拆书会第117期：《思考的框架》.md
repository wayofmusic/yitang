#  模型一：地图不等于疆域本身

- 地图是传递知识的宝贵工具，是对复杂现实的抽象化，作用在于解释性、预测性：可以帮助我们理解世界。世界是动态的，地图必然有缺 陷，它的价值在于帮助我们预测或解释事物，模型也是如此，现实是复杂的，模型是简化的。
- 地图的局限：信息有所减损，还有一片独立于地图之外的疆域，疆域中的具体细节；显示不出疆域的某些风险；是某一特定时刻的疆域状况，但它不一定描述现状或将来，世界是变化的动态的；并非客观产物，至少有一个主观因素，如创作者的价值观、局限性。
-  模型不是现实：对事物的描述并非事物本身，对象抽象出的概念并非对象本身。对事物的认识如果只是简化，而非真正理解，可能做出错误的决定。
-  现实远比模型复杂：只有将模型置于其诞生的背景下，才能发挥最大作用：制图师想达到什么目的？其目的又如何影响地图所描述的内容？可以用地图的思路分析现象或问题，帮助快速分类整理信息，但不能忘记现实本身远比地图复杂——”我的全球定位系统没显示前方是悬崖“

\*公司的财报、制度，绩效评估表，育儿手册，都只是指导

\*公地悲剧的解法

**\*如果模型不符合现实，一定是模型错了**

**\*所有模型都是错的，但是有一些有用**

**\*把一切答案当作参考答案**

# 模型二 ：能力圈

- “万事通”VS“陌生人”：万事通：有详细深入的知识网络；对每个问题有可能不止一个解决方案，可灵活应对挑战，可迅速排除糟糕选项，因为他拥有每一块拼图。陌生人：只有浅尝辄止的所谓知识。
- 如果做事的驱动力是自尊心而不是能力，头脑中就会存在盲点。了解自己的能力圈，可以改善决策和相应的结果。
- 虚心承认自己的知识盲区，了解自己的薄弱之处和进步空间。
-  拥有能力圈的标准：在能力圈边界内，不论遇到什么问题都有多种选择；可以确切知道自己不知道的事，能快速且相对准确的做出决定；知道什么可知什么不可知，并能明确区分两者。能够理解什么可以调整，什么是永恒不变的。
-  **如何打造和维护自己的能力圈：**
-   好奇心和求知欲：必须愿意学习，世界是动态变化，知识日新月异，能力圈必须同步更新。
-    学习=经验+反思
-    监测：建立反馈闭环
-   必须偶尔征求外部诚实的反馈
- 怎样应对能力圈之外的发生：承认自己是陌生人而非万事通；主动与领域的优秀人才交流；了解基本思维模型，弥补对陌生领域知识的匮乏。
- 没有人的能力圈能涵盖一切。
- **呆在你的能力圈里**

 \***理解，是没有捷径可言的**

 **\*能力圈之外，不是你不能做到的事，而是你以为自己能但其实不能的事。**

# .模型三 ：第一性原理

- 定义：第一性原理有时被称为“第一原理推理”，、通过将最基础的理念或事实从由此产生的假设中剥离出来阐明复杂的问题，剥离后剩下的都是精华。如果你知道某件事的第一性原理，你就可以基于这些原理建立其他知识，从而创造新的事物。
- 逆向分析复杂问题，释放创造力的最佳方法之一。
- 建立第一性原理的苏格拉底提问法：

（1）澄清你的想法井解释想法的来源。(为什么我会这么想？我到底是怎么想的？）

（2）对假设提出挑战。（我怎么知道这是真的？如果我的想法正好相反？）

（3）寻找论据。(我该如何支撑自己的论点？论据来源于哪里？)

（4）思考其他可能的视角。(别人可能有什么想法？ 我怎么知道自己是对的？）

（5）探究后果和影响。(如果是我错了，该怎么办？如果我错了，会有什么后果？）

（6）质疑最初的问题。（我为什么会那样想？我的想法对吗？从推理过程中，我能得出什么结论？)

- 减少对直觉的依赖，限制强烈的情绪反应。
- 许多人误以为创造力只是少数人的天赋，从第一性原理推理，可帮我们跳出传统观念，真正理解了发挥作用的原理之后，试探一切可能的边界，摆脱盲目性。

\*提示：第一性原理是很贵的

# 模型四 ：思想实验

- 定义：用来探究事物本质的想象工具。相比物理检验和检测，思想实验的价值在于帮助我们实现现实生活中做不到的事，有助于从更多角度探索问题。
- 想象物理上的不可能；重新想象历史；凭直觉想象并不直观的事物。
- 如果塞尔维亚人普林西普没有刺杀斐迪南大公，第一次世界大战可以避免吗？
- 思想实验的典型应用：罗尔斯无知之幕
- 它的价值不仅在于国家立法，包括公司制定各种政策。
- 思想实验绝不仅仅是白日梦，有效性信赖于同传统实验一样的严谨态度。
- 思想实验的步骤：

1.        提出一个问题；
2.        进行背景研究；
3.        构造假说；
4.        通过思想实验进行测试；
5.        分析结果得出结论；
6.        对比假说进行调整。

# 模型五 ：二阶思维

- 定义：在一阶思维下，我们能预见自己的行动造成的直接后果，二阶思维要求我们考虑结果背后的结果，把长远利益放在短期利益之上。
- 多想一步最好再一步，不仅考虑行为或事件的直接结果，还要考虑更深层次的结果，需要更长远、更具整体性的思考。
- 花一点时间思考前瞻性的问题，回味今后节省更多的时间。
- 加拿大小说家玛格丽特.阿特伍德：如果从结果来判断，那么愚蠢就是邪恶。
- 1963年，加拿大教授哈丁提出生态学第一定律：我们生活在一个错综复杂相互关联的世界，你永远不能只做一件事，如果你不曾考虑过结果背后的结果，就不配说自己真的思考过。
- 吃糖的快乐是一阶，长胖是二阶
- 吵架的爽是一阶，对关系的恶性影响是二阶
- 如果想要了解世界究竟如何运作的，必须考虑二阶乃至更高阶的结果；构建有效论证短期收益是否值得拿长期痛苦来换，是否值得将长远利益置于眼前利益之上。

# 模型六： 概率思维

定义：通过运用数学和逻辑工具，估算特定结果出现的可能性，提高决策准确度。

 概率的三个重要定理

1、贝叶斯定理：在吸收新知识的同时，考虑现有所有的信息，将普通的背景知识与新信息结合起来，从而解决具体问题。数学语言表达：支持某项属性的事件发生得愈多，则该属性成立的可能性就愈大。

**\*观点随行为发生改变**

但行为经济学家发现，人们在决策过程中往往并不遵循贝叶斯规律，而是给予最近发生的事件和最新的经验以更多的权值，在决策和做出判断时过分看重近期的事件。面对复杂而笼统的问题，人们往往走捷径，依据可能性而非根据概率来决策，产生“偏差”。

 2、肥尾曲线：与正态分布曲线相似。钟形曲线两端的极端情况可以预测，但肥尾黄线的极端情况无上限，身高、体重符合正态分布，异常程度有限，在财富是肥尾曲线。

3、非对称：你自己做出的概率估算本身准确的概率，比如股票交易员对“过于乐观“的概率估算相比”不太乐观“的估算，错误率要高得多，大多数投资目标是回报率25%，结果只接近10%。

 **塔勒布的《反脆弱》把事物分三种类型：**

受到波动性和不可预测性负面影响的；

面对波动性和不可预测性不受任何影响的；

受益于波动性和不可预测性的。

 最后一类属于反脆弱。因为这个世界从根本上说是变化多端，不可预测的。

**反脆弱的方法：**不要尝试进行预测，而要尝试做好准备。

对于世界上极具影响力的罕见事件，根本无法预测；做准备反而更有效率。

 构建反脆弱能力：1. 、华尔街交易员的“上行选择权“，寻找认为存在更多机会的情况。比如，鸡尾酒会。2、 学习如何正确的失败。适度冒险，永远不要彻底离场。3、培养韧性，从失败中学习

让随机性和不确定性成为你的朋友，而不是敌人。

不必止步于一点风雨，等所有条件具备再行动，通常不了了之。

# 模型七 ：逆向思维

- 定义：确定最终目标，反向推理。而大多数人从前往后思考，
- 芒格：反过来想，总是反过来想
- 20世纪20年代，如何把香烟卖给女性？伯尼斯不是从前往后想“怎么才能卖给女性呢？”而是反向思考“要让女性吸烟，需要什么条件为真？世界需要怎样改变才能让女性愿意吸烟并为社会接受？自由的火炬，说服酒店餐馆将烟加入菜单，设计含香烟专柜的橱柜……美国烟草公司聘请伯尼斯，想把香烟卖给女性。
- 闭路电视发明：为何在家会有不安全感？正向是加锁，逆向是，什么造成了没有安全感
-  从后往前思考问题，不要只盯着想要的结果，用逆向思维把目标颠倒过来：你想避免什么结果？
- 不要总想着变得富有，而是竭力避免穷困潦倒，不要预测哪些决定可以创造财富，先消除哪些会削减财富的行为。
-  逆向思维步骤

（1）找到问题所在；

（2）描述期望目标;

（3）列出朝期望目标发展的所有驱动力；

（4）列出朝期望目标发展的所有阻力；

（5）制订解决方案，这一步可能包括加强或增加步骤3 中的驱动力，以及减少或消除步骤 4 中的阻力。

# 模型八： 奥卡姆剃刀法则

- 定义：如无必要，勿增实体。相较复杂的解释，简单解释更有可能是正确的。
- 我们总是试图透过自己观察的表象，猜想隐藏在表象之下的重大意义，这是人类共同的倾向。但在多数时候，简单的解释通常更有可能是正确的，避免不必要的复杂处理，不必要的恐慌和压力，有助于节约时间和精力。
- 当所有人都专注于复杂事物时，专注简单就是天才的标志。
- 避免愚蠢比追求智慧容易得多。
- 医学院的学生被告诫：如果听到马蹄声，先想到应该是马，不要猜是斑马。
- 对“奇迹”的更简单解释：有一些自然法则我们还不够了解、无法解释，还需要更新我们对世界的理解，而不是真有奇迹出现了。
- 如何阻挡阳光照射水库：织一块4万平米的防水布，或在水库上方建巨大的可伸缩式穹顶。最终采纳了一位生物学家的简单方案：在水库上投放了300万个可折射紫外线的黑球成每个0.4美元。
- 郭士纳：“IBM现在最不需要的就是愿景，它真正需要做的是服务客户，当下与同行竞争，专注已经盈利的业务。公司需要的是简单而坚定的业务执行。”

\*爱因斯坦：尽量简单，但不总是简单。

# .模型九：汉隆剃刀定律

- 定义：能解释为愚蠢的，不要解释为恶意。
- 有助于我们避免妄想和偏执。不要做最坏的打算，真正的坏人比你想象中的少。
- 卡尼曼和特沃斯基：我们会深受现有证据的影响，甚至愿意做出违背简单判断。我们会基于目前掌握的信息强行得出结论。当我们看到自己不喜欢甚至错误的事情时，会假定这是他人有意为之。只要我们以特定角度呈现证据，大脑就会失灵，无法理性以对。
- 更可能的情况这完全是无意的结果，大多数做错事的人并不是心怀鬼胎的坏人。人非圣贤孰能无过，已发生的事包含主观意图最小的解释，往往是可能性最大的解释；
- 误把愚蠢当恶意会导致妄想症，总是踹度恶意会让你误以为自己处于他人世界的中心，这是一种太过以自我为中心的思维方式。事实上，一个行为背后所有可能的动机中，耗费最少精力的动机（如无知、懒惰）比需要主动恶意的动机，存在的可能性更大。
- 一个拯救了全世界的男人：1962美苏两国古巴导弹危机，旗舰潜艇周围发生爆炸，舰长误以为核战争已经爆发，决定发射核鱼雷，副舰长的阿尔希波夫坚持不同意，拯救全世界。
