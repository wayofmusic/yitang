# 拆书开始

# 一、利益决定信不信

**人没你想的那么好骗**

- 我们常常觉得：“人类是多么容易上当受骗啊！”各种耸人听闻的骗局、层出不穷的谣言，似乎都在印证着这观点。
- 这种看法过于简单化，忽略了人类认知机制的复杂性和适应性。
- “看起来‘吃亏上当了’，也绝不会是由于‘人类易受骗’，个体或许是为了博取社交分，或许是为了讨好权威人士。
- 人的默认状态是保守的，而不是易受骗的。
- 在警觉与开放方面，我们的认知机制兢兢业业，阻止我们吃亏上当的。
- 人类并非天生愚笨，而是在漫长的进化过程中，发展出了一套精密的防御机制，以应对潜在的欺骗和风险。我们的大脑并非一块任人涂抹的白板，而是一部高度发达的怀疑机器，时刻警惕着周围的信息。
- 信与不信，本质上是一种精心计算后的策略，被潜意识后的利己价值所驱动。
- 这实实在在地印证了‘你笑他人太疯癫，他人笑你看不穿’。
- 人类的认知机制不是为了追求真理而设计的，而是为了在社会互动中取得成功而进化的。
- 选择相信不是因为愚昧，而是符合个人最佳利益

**理性是天生的**

- 理性并非人类偶尔才展现出的能力，而是我们认知的普遍特征。
- 尽管我们时常会犯错，做出看似不理智的决定，但这并不意味着人类本质上就是非理性的。
- 理性是一种工具，像其他工具一样，它在某些情况下非常有用，而在另一些情况下则不然。
- 心理学家们设计的各种认知偏差实验，虽然揭示了人类理性的一些局限性，但并不能完全否定理性的普遍性，因为这些实验往往是在高度人为设定的情境下进行的进化标准严苛，不能容忍真正的傻子。，与我们真实生活中的决策环境存在很大的差异。
- 人类的理性并非孤立地存在，而是在社会互动中发展和应用的。我们之所以发展出理性，主要是为了能够更好地与他人交流和合作。
- 我们的理性能力，很大程度上是为了说服他人，为自己的观点辩护，并在社会交往中取得成功。当我们试图解释自己的行为，或者与他人协商解决问题时，我们的理性水平往往会显著提高。
- 陪审团的审议过程：在这个过程中，陪审员们需要听取各方证词，分析证据，并最终达成一致的判决。这个过程充满了理性的辩论和论证，充分体现了人类运用理性解决复杂问题的能力。陪审团制度的设计，正是基于对人类论证性理性的信任。
- 直觉并非总是非理性的，很多时候，直觉是我们长期经验积累的体现，能够帮助我们快速做出判断。
- 一个经验丰富的医生可能仅仅通过观察病人的症状，就能做出初步的诊断，这种快速的判断往往是基于长期的经验和知识积累，并非完全非理性。
- 直觉和理性并非水火不容，而是相互补充的。
- 尽管人类会犯各种各样的错误，但理性仍然是我们认知的重要组成部分。
- 正是凭借着理性，人类才得以创造出如此辉煌的文明，因为理性是人类文明进步的基石。

# 二、清醒不如轻信

**“轻信”背后是交易**

- 看似“轻信”的行为背后隐藏着逻辑：我们并非盲目地接受所有信息，而是在潜意识中进行着复杂的评估，以判断信息的可靠性和可信度。
- 我们的信任机制并非完美无缺，但它在大多数情况下是有效的，并且服务于我们的生存和繁衍。
- 信任是人际关系的黏合剂。然而，信任也意味着风险，因为我们可能会被那些试图利用我们信任的人所欺骗。因此，我们需要发展出一种能够区分可信信息和不可信信息的机制。我认为，我们的信任并非随机的，而是有其内在的逻辑。我们更倾向于信任那些我们熟悉的人，那些与我们有共同利益的人，以及那些看起来值得信任的人。我们信任那些我们认为可靠的人。这种信任往往基于我们对对方的了解，以及我们对他们过去行为的观察。
- 信任的建立往往依赖于一些“信号”。例如，一个人的声誉、他们所处的社会地位、以及他们的肢体语言和面部表情，都可能成为我们判断他们是否值得信任的依据。声誉是信任的重要指标。一个拥有良好声誉的人，更容易获得他人的信任。
- 但仅仅依靠这些表面信号是不够的，因为有些人可能会故意伪装自己，以获取我们的信任。骗子往往善于利用我们的信任倾向。因此，我们需要更加精密的认知机制来评估信息的真实性和可靠性。我会仔细审查那些我们认为重要的信息。当我们接收到一条信息时，我们会对其进行评估，判断其是否合理、是否有证据支持，以及是否符合我们已有的知识和经验。我们不会轻易相信那些缺乏证据支持的说法。这个评估过程很多时候是在潜意识层面进行的。
- 当我们听到一个关于健康的新闻时，我们可能会考虑消息来源的权威性，研究是否有相关的科学证据支持，以及这个说法是否与其他已知的医学知识相符。
- 此外，社会压力会影响我们的判断。社会环境对信任的影响是显著的。在某些情况下，即使我们对某个说法持怀疑态度，但如果周围的人都相信，我们也可能会选择相信，以维持社会关系或避免被孤立。
- 然而，即使在社会压力下，我们的怀疑机制仍然在发挥作用。我们可能不会公开质疑，但我们会在心里保留一些疑问。
- 看似的“轻信”有时也是一种策略性的行为。有时候，为了合群，我们会选择相信一些我们并不完全确信的事情。为了维护社会关系、避免冲突或获取某种利益，我们可能会选择在表面上相信一些我们内心并不完全认同的说法。
- 总而言之，我们的大脑是一部精密的信任评估机器。我们的信任机制是一个复杂而精密的系统，它并非完美无缺，但它在大多数情况下能够有效地保护我们免受欺骗，并促进社会合作。
- 信任是社会合作的基础，没有信任，社会将无法运转。
- 轻信并非愚蠢的体现，而是一种在特定情境下，为了维护社会关系或获取其他利益而采取的策略。
- 轻信的逻辑并非源于认知缺陷，而是基于一套复杂的、适应性的逻辑。

**信仰是主动选择**

- 我们之所以会相信一些看似“怪异”的事情，是因为这些看似不合理的信仰，往往在特定的社会或文化环境中，具有其独特的功能和意义。
- 我们之所以会接受这些信仰，并非因为我们缺乏理性，而是因为这些信仰能够满足我们某些深层次的社会和心理需求。
- 共享的信仰是社会团结的基石。即使这些信仰在科学上是站不住脚的，但只要它们能够帮助群体成员更好地合作，它们就可能得以流传和发展。
- 许多宗教信仰都包含一些看似不合逻辑的元素，例如神迹、超自然力量等等。然而，宗教信仰能够满足人们对意义和归属感的需求。这些信仰往往能够为信徒提供精神上的慰藉，帮助他们应对生活中的困难和挑战。
- 共同的宗教仪式和规范也能够加强信徒之间的联系，形成更强的社会认同感。
- 一些看似荒谬的阴谋论之所以能够流行，也是因为它们能够满足人们对解释和控制的需求。
- 阴谋论能够给人们一种掌控感，即使这种掌控感是虚幻的。当我们感到迷茫和无助时，阴谋论往往能够提供一个简单化的解释，将复杂的社会问题归咎于某个或某些“幕后黑手”。
- 迷信是一种错误的因果推断。迷信行为往往源于我们对因果关系的错误理解，当我们经历了一些不好的事情后，如果恰好之前做过某个特定的行为，我们可能会将这两者联系起来，认为这个行为导致了坏运气。然而，迷信行为有时也能够缓解焦虑，给我们一种控制感。
- 我们对故事的偏爱也是导致我们相信一些“怪异”事情的原因之一。好的故事更容易被我们记住和传播。人类天生喜欢听故事，而一些看似离奇的说法，往往具有很强的叙事性，能够吸引我们的注意力，激发我们的想象力。
- 社会环境对我们信仰的影响是显著的。如果我们周围的人都相信某个说法，即使我们自己有所怀疑，也可能会选择接受它，以避免被孤立或排斥。从众心理在信仰的形成过程中起着重要作用。
- 相信一些“怪异”的事情，有时也是一种社会信号。
- 我们的信仰有时能够反映我们的社会身份，通过表达对某些非主流观点的认同，我们可以向他人展示自己的特定身份或价值观，从而加强群体内部的联系。

**策略性轻信**

- 人类的行为往往是策略性的。
- “轻信”的行为并非源于真正的相信，而是一种经过深思熟虑的策略性选择。
- 人们可能会为了达到特定的社会目的，例如维护良好的人际关系、避免潜在的冲突，或者获取某种实际的利益，而选择在表面上表现出相信某些他们内心并不认同的说法。
- 人类是高度策略性的社会动物，会根据情境调整自己的行为。在与他人互动时，我们会不断地评估周围的情境，并采取最符合自身利益的行动。
- 为了合作，我们有时需要表现出一定的轻信。
- “合作”是人类社会得以存在和发展的基石，而有效的合作往往需要一定程度的信任和妥协。有时，为了维持合作关系，避免破坏共同的利益，我们可能会选择在某些问题上“装糊涂”，或者假装相信对方的说法，即使我们对此有所怀疑。
- 在谈判中，策略性的让步是常见的。例如，在一些商业谈判的场景中，双方可能会在某些问题上持有不同的看法，甚至对对方提出的条件有所保留。然而，为了达成最终的协议，实现双方共同的经济利益，他们可能需要暂时接受对方提出的一些不太合理的条件，或者在某些细节上做出策略性的让步。
- 这种让步在表面上可能看起来像是“轻信”了对方的说法，但实际上是为了达成更重要的目标。
- 为了社会和谐，我们有时需要隐藏自己的真实想法。在许多文化中，维护社会群体的和谐稳定被视为至关重要，为了避免不必要的冲突和不和，维护集体关系，人们可能会选择在公开场合表达与主流观点一致的看法，即使他们私下里持有不同的意见，这种行为在他人看来可能像是相信了主流观点，但实际上可能只是一种为了维护社会和谐而采取的策略。
- 为了获得好处，我们有时需要讨好他人，“讨好”也是一种策略性的“轻信”，为了获得他人的好感、支持、帮助或者其他形式的利益，我们可能会选择赞同他们的观点，迎合他们的喜好，即使我们内心对此并不认同。
- 当我们面对拥有更高权力或更强话语权的权威人物或群体时，为了避免不必要的麻烦、惩罚或者负面后果，我们可能会选择在表面上顺从他们的要求，或者假装相信他们的观点，即使我们内心并不认同。
- 策略性的轻信是一种社会交往的技巧，并不意味着我们真的被骗了，或者我们缺乏辨别能力，而是我们有意识地选择在特定的社会情境下采取的一种行为策略，以最大化自身的利益，看似简单的“轻信”行为背后，可能隐藏着复杂的社会策略和精明的理性考量。

**群体的疯狂**

- 在群体行为中存在着两种截然不同的现象：群体智慧和群体疯狂。
- 集体智慧的力量在于其能够汇集大量分散的信息。在某些条件下，群体能够展现出惊人的智慧，做出比个体更准确的判断；但在另一些条件下，群体行为却可能变得极度 愚蠢，甚至导致灾难性的后果。
- 每个个体都拥有一些独特的信息和视角，当这些信息汇集在一起时，就可以形成一个更全面、更准确的判断。
- 实验中，让一群人猜测罐子里糖豆的数量，结果发现，尽管每个人的猜测都可能存在偏差，但所有猜测的平均值却往往非常接近实际数量。单个人的判断可能出错，但群体的平均判断通常是准确的。
- 然而，群体思维会扼杀独立思考。群体智慧并非总是能够发挥作用。当群体成员之间存在过多的互动和影响时，他们的意见可能会趋于一致，从而导致“群体思维”的出现。在这种情况下，群体可能会做出错误的决策，即使每个个体都可能意识到问题的存在。
- 信息瀑布会导致错误的信念在群体中迅速传播。当群体中的一部分人开始相信某个说法时，其他人可能会因为害怕被孤立或认为多数人是对的而纷纷加入，即使他们自己对此有所怀疑。这就是为什么一些谣言或虚假信息能够在人群中迅速蔓延。
- 群体讨论可能会加剧观点极化。如果成员们最初就持有相似的观点，那么讨论的结果往往会导致他们的观点变得更加极端。为什么在一些社会议题上，不同群体之间的分歧会越来越大，因为群体可能会放大个体的负面情绪和行为。
- 在某些特定的社会情境下，例如在匿名性较高、情绪激动的环境中，个体可能会失去理智，做出一些他们单独一人时绝对不会做的事情，群体行为有时会变得非常暴力和破坏性。
- 在群体中，个体可能会失去自我意识。
- 理解群体行为的关键在于认识到个体在群体中的身份转变，当个体融入群体时，他们可能会更加关注群体的目标和规范，而忽略自己的个人价值观和责任。

# 三、理性没那么容易

**沟通导致偏差**

- 沟通是人类社会存在的基础。我们所拥有的绝大部分知识和信仰并非直接来源于个人的亲身经历，而是通过与他人的沟通交流获得的。
- 理解沟通的机制，对于我们深入理解信仰的传播、演变以及为何某些观念能够深入人心至关重要。
- 我们是积极的信息接收者和处理者，而不是被动地接受他人传递的信息，我们会主动评估信息来源的可靠性、信息的内在逻辑是否合理，以及信息是否与我们已有的知识体系相符。
- 论证是说服的核心工具。当我们试图说服他人相信某个观点时，我们会提供论证，好的论证具有说服力。
- 一个好的论证应该具备清晰的逻辑结构、可靠的事实证据以及合理的推导结论。
- 所以科学研究的结果往往比个人的主观臆断更具影响力，因为科学研究通常会提供严谨的实验设计、充分的数据支持以及清晰的逻辑推理。
- 修辞可以增强信息的感染力，修辞是指使用语言来影响他人情感和态度的技巧，虽然修辞本身并不一定包含严谨的逻辑论证，但它可以通过情感诉求、权威引用、生动的比喻等方式来增强信息的感染力和说服力。
- 我们的认知偏差可能会让我们更容易接受某些信息，而忽略另一些信息。我们并非总是能够清晰地区分好的论证和糟糕的修辞。
- 我们自身的认知偏差，例如确认偏差（倾向于接受与自己已有观点一致的信息）和情感启发式（根据情感反应做出判断），可能会影响我们对信息的客观评估。
- 互联网和社交媒体等平台极大地加速和扩展了信息的传播速度和范围。这也意味着虚假信息和谣言也能够以前所未有的速度和广度传播开来。
- 回声室会加剧观点极化：在回声室中，我们往往只会接触到与我们自身观点相似的信息，这会进一步强化我们已有的信念，并使得我们更加难以接受和理解不同的观点。
- 批判性思维是应对虚假信息的关键。我们需要培养批判性思维的能力，积极主动地寻找不同的观点，并对信息来源的可靠性进行认真的核实。

**聪明不等于理性**

- 为什么那些拥有高智商、受过良好教育的聪明人，有时也会相信一些在常人看来非常愚蠢甚至荒谬的事情？
- 高智商并不等同于完全理性，智力本身并不能完全免疫于错误的信念，即使是聪明人，也可能因为各种复杂的认知偏差、社会因素以及深层的心理需求而接受并坚持一些不合理的观点。
- 聪明人更善于为自己的错误信念辩护，他们往往更擅长运用他们的逻辑能力和知识储备，为自己已有的信念找到看似合理的理由和证据，即使这些信念本身可能是错误的，他们可能会巧妙地运用他们的智力来解释和合理化那些不符合逻辑或缺乏事实依据的观点。
- 即使是受过高等教育的人，也可能受到认知偏差的影响。例如，一些拥有高学历的科学家或学者可能会相信一些伪科学理论，例如占星术、顺势疗法或者某些阴谋论。他们可能会花费大量的时间和精力去研究这些理论，并利用自己的知识和逻辑能力，找到一些看似“科学”的证据来支持它们，而忽略那些与之相悖的证据。
- 专业知识有时会阻碍我们理解大众的认知，知识的诅咒是：当我们对某个领域拥有非常深入的了解和专业的知识时，我们可能会难以理解那些不了解这个领域的人的想法和信念。
- 社会压力会影响聪明人的判断：社会认同感是另一个导致聪明人相信愚蠢事情的重要因素。即使是聪明人，也渴望被自己所属的群体所接受和认可。如果某个不合理的信念在他们的社交圈子、专业领域或者他们所认同的社会群体中非常流行，他们可能会选择相信它，以维持社会关系，避免被孤立或排斥。
- 即使是聪明人，也可能因为强烈的情感需求而接受某些不合理的观点。例如，当人们面临巨大的压力、失去亲人或者感到极度焦虑时，他们可能会更容易相信那些能够提供安慰、希望或者简单解释的说法，即使这些说法缺乏事实依据。
- 过度自信是聪明人的常见陷阱，他们可能会因为高估了自己的知识、能力和判断力，而忽略了潜在的风险和错误，从而更容易接受一些未经仔细审查的观点。
- 我们的愿望会影响我们的信念。
- 动机性推理：即使是聪明人，也可能因为内心深处想要相信某个观点，而选择性地接受支持该观点的信息，并忽略甚至积极反驳与之相悖的信息。

**人是复杂的**

- 我们不是天生的傻瓜，而是精明的社会思考者。
- 人类并非像我们通常认为的那样天生就容易上当受骗。相反，我们的大脑是一部高度发达且精密的怀疑机器，它时刻警惕着周围的信息，并不断地进行评估和筛选。我们之所以会相信某些事情，往往是出于理性的考量，是为了更好地维护社会关系、满足深层的心理需求，或者采取某种策略性的行为。
- '轻信'的标签掩盖了人类认知的复杂性。我们对“轻信”的传统看法往往过于简单化和片面化，它忽略了人类行为背后复杂多样的动机和潜在的理性逻辑。
- 进化赋予了我们怀疑的能力。漫长的进化过程塑造了我们的认知机制，使其能够有效地应对各种社会挑战，包括潜在的欺骗和利用，这种与生俱来的怀疑能力是我们在复杂的社会环境中生存和繁衍的关键。
- 看似荒谬的事物，往往有其存在的理由。我们应该以更加开放和理解的态度重新审视那些看似荒谬的信仰和行为。
- 人类的理性远比我们意识到的要强大。
- 人类的认知能力远比我们通常所认为的要强大和复杂得多。我们并非轻易就会上当受骗，而是在信任与怀疑之间进行着持续的、精密的权衡和选择。深入理解这种权衡的机制，能够帮助我们更深刻地认识人类自身，并更好地应对信息爆炸时代的各种挑战。
- 理性是人类应对信息时代挑战的重要武器。我们应该对人类的理性能力抱有信心，通过理性的思考和沟通，我们可以更好地理解世界。
- 我们应该避免简单地将他人标记为“好骗”，而是尝试理解他们行为背后的原因，理解人类的认知机制有助于我们构建更加理性、健康的社会。
