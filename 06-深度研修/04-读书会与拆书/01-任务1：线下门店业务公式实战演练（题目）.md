# 任务1：线下门店业务公式实战演练（题目）

## 案例背景：一家社区面包店的生死突围

背景描述：

李店长在某大型成熟社区开设了一家名为“醇香手作”的精品面包店，主打日式软欧包。

- **初始投入**：装修及设备投入30万。
- **经营现状**：开业3个月，日均营业额仅2000元，而盈亏平衡点需要达到日均5000元。
- **早期动作**：为了提升业绩，李店长初期主要靠**“发传单”引流，**但这招在封闭式社区效果越来越差，被保安拦截且业主反感。

**店长决定，用一堂建议工作流，进行业务复盘与迭代历程：**

**阶段一：梳理与初版公式**

他首先写下了最通用的公式：营业额 = 进店客流 × 成交率 × 客单价。

通过观察数据（A1.梳理业务），他发现一个奇怪的现象：门口路过的人很多（社区主干道），但大多看一眼就走了。即便进来的客人，买一个面包（15元）就走，很难凑够盈亏平衡点。

**阶段二：寻找重点与参数探索**

李店长意识到，笼统的“进店客流”无法指导工作。他将公式进行了1.0版升级：

营业额 =  进店客流 × 成交率 × 客单价。

进店客流 =(路过流量 × 进店率)

成交率=(试吃转化率 × 成交率)

他发现**“进店率”**是目前最大的漏斗瓶颈

**于是他提出了假设（C3.假设实验）**

- **假设1**：是不是**门头**不够显眼？-> 做了灯箱，效果一般。
- **假设2**：是不是因为**关着门**距离感太强？-> **动作**：天气允许时敞开大门，并在门口摆放刚刚出炉的“试吃台”，用香味吸引路人。
- **结果**：这一动作让进店率从5%提升到了15%。

**阶段三：深入循环与逻辑关系（C阶段）**

解决了进店问题，李店长发现客单价太低。社区多为家庭客，只买一个是早餐，很难高频消费高价面包。

他探索了**逻辑关系**（C2）：家庭客对“次日早餐”有强刚需，但对“下午茶甜点”需求弱。

于是公式升级为2.0版：

营业额 = 进店人数 × (早餐刚需品 × 复购率 + 尝鲜新品 × 连带率) × 会员储值系数

基于此，他推出了**“家庭早餐周卡**”（绑定复购）和“**买三送一”**（提升客单价）。

最终，通过这一系列基于公式的拆解和实验，门店日均营业额突破8000元，实现盈利。

##  实战考核题

### 单项选择题（共5题）

1. 在“A.梳理阶段”向“B.建立阶段”过渡时，李店长最初使用的公式是“营业额 = 进店客流 × 成交率 × 客单价”。根据《一堂建议工作流》，在“B1.初版公式”的要求下，这个公式最大的问题是？（ ）

   - [ ] A. 没有包含成本要素

   - [x] B. 过于宏观，缺乏可执行的顶层（-1层）拆解，无法指导具体动作

   - [ ] C. 没有包含员工的绩效提成

   - [ ] D. 计算起来太复杂

1. 案例中，李店长发现门口路过的人多但进店的人少，因此将重点放在了“进店率”上。这符合工作流中哪一个环节的核心思想？（ ）

   - [ ] A. 制定目标

   - [x] B. 寻找重点（分析关键路径和空间）

   - [ ] C. 跟进复盘

   - [ ] D. 探索参数
2. 在“C3.假设实验”环节，李店长为了验证“香味和开放感能提升进店率”的假设，采取了“敞开大门+门口试吃”的动作。这属于以下哪种类型的具体工作？（ ）

   - [ ] A. 整理业务数据

   - [ ] B. 制定让人兴奋的目标

   - [x] C. 建立一个假设池，系统分析和测试

   - [ ] D. 建立跟进机制
3. 随着业务深入，李店长将公式从1.0升级到了2.0，引入了“早餐刚需品”、“复购率”等参数。这是在执行哪个步骤？（ ）

   - [x] A. C1.探索参数（还有哪些关键节点）

   - [ ] B. A1.梳理业务

   - [ ] C. B1.初版公式

   - [ ] D. A2.制定目标
4. 在整个案例中，李店长没有盲目全场打折，而是先解决“进店率”，再解决“客单价”。这种“按顺序解决问题”的思路，对应了工作流C阶段的什么特征？（ ）

   - [ ] A. 一次性解决所有问题

   - [x] B. 不断循环往复（发现新瓶颈 -> 提假设 -> 实验 -> 复盘）

   - [ ] C. 只关注A阶段的业务梳理

   - [ ] D. 必须在开业第一天就确定终极公式

### 多项选择题（共2题）

1. 在“深入阶段”，李店长针对“客单价低”的问题，探索了业务的逻辑关系。以下哪些思考属于“探索逻辑关系”的范畴？（ ）

   - [x] A. 分析社区客户的属性：是家庭客而非商务客

   - [x] B. 分析购买动机：主要是为了解决“次日早餐”而非“下午茶”

   - [ ] C. 统计昨天的营业额总数

   - [x] D. 分析商品之间的关联：买吐司的人通常需要搭配果酱或牛奶
2. 结合“C4.跟进复盘”，如果李店长要建立长效机制，以下哪些做法是正确的？（ ）

   - [x] A. 每天晚上统计“路过人数”与“进店人数”的比率，监控进店率变化

   - [x] B. 实验成功后，将“门口试吃”固化为门店的标准作业程序（SOP）

   - [ ] C. 只要营业额达标，就不再看具体数据

   - [x] D. 定期记录每次营销活动（如发传单、做灯箱、做试吃）的投入产出比

### 简答题（共1题）

结合本案例背景，简述李店长是如何完成从“B阶段”到“C阶段”的跃迁的？

提示：请用“确定公式 -> 发现瓶颈 -> 提出假设 -> 验证迭代”的逻辑进行描述。

### 1. 确定公式

起初，李店长手里的公式太糙了，就是最通用的“流量 × 成交 × 客单价”。

这玩意儿看着对，但没法指导干活。

为了搞清楚问题出在哪，他搞了个1.0升级版。

他把笼统的“进店客流”，拆解成了**“路过流量 × 进店率”** 。

这就把一个模糊的大概念，变成了可以抓手的小参数。

### 2 发现瓶颈

公式一细化，数据就说话了。

他盯着数据看，发现一个大问题：

门口明明是社区主干道，人来人往，但大多看一眼就走。

原来“进店率”只有可怜的5%。

这就是当时最大的“漏斗瓶颈”，不解决这个，后面面包做得再好吃也白搭。

### 3 提出假设

找到了瓶颈，就得找原因，这就是C阶段的核心——“假设实验”。

李店长没瞎忙活，他提了两个具体的假设：

- **假设一：** 是不是招牌不够亮眼？（于是他做了灯箱，但发现没啥用）
- **假设二：** 是不是关着门显得太高冷，距离感太强？（这才是重点）

### 4 验证迭代

有了假设，立马动手验证。
针对假设二，他做了个动作：天气允许时，把大门敞开。
而且，他利用了面包店的天然优势——嗅觉。
在门口摆上刚刚出炉的“试吃台”，用香味去勾引路人。
**结果验证成功：** 进店率直接从5%干到了15%。

但这还没完，这只是第一轮迭代。

人进来了，他又发现客单价太低，于是继续用这个逻辑，洞察到大家对“次日早餐”是刚需。

他再次迭代公式到2.0版，搞出了“家庭早餐周卡”和“买三送一”。

最后日收8000，店活了。
