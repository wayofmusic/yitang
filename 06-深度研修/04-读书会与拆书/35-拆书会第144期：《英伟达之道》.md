# 拆书开始

# 一、战神的起点

**坚韧的来处**

- 作为移民，他在寄宿学校里遭遇了相当严酷的霸凌与文化冲突，这段经历为他后来的坚韧性格埋下伏笔。
- **我永远不会自找麻烦，但我也绝不会逃避任何麻烦。**
- “那种紧张感，磨炼了我面对挑战的韧性。”
- 从此，养成了“有事就正面应战”的性格，不轻易退缩。
- 在少年时期，他在一家乒乓球俱乐部里边打工边训练，替俱乐部老板打扫地面、擦拭球台。正是在这里，他展现出乒乓球的天赋与对努力的近乎偏执。
- 曾在青少年时参加全美公开赛，“能打扫卫生又能对阵高手”的球员。
- **“我打扫过的厕所，也许比绝大多数CEO都多。”**
- 黄仁勋常常在打工完后继续苦练乒乓到深夜，俱乐部老板甚至几次催他回家：“**努力于我不只是一种手段，而是活下去的方式。**”
- 他早期的指导原则，“为日常辛劳而自豪”，成了英伟达后期企业文化的一条暗线：工作再基础，也要用最高标准去做。
- 乒乓球比赛遭遇意外失利，愈发体会到专注的重要：**“伟大和聪明无关，而是来自品格。”**
- 成功不是基于高智商，而是能否承受挫折并继续战斗
- **“从我能记事起，就知道只有靠自己才能换来任何一点希望。”**
- **“用你全部的力量去做好哪怕最不起眼的事，那些事终将塑造你。”**
- **“最好的教育不是在教室里，而是在汗水蒸腾中。”**
- 为日后面对技术与商业的双重竞争时埋下了“遇到难题就拼到极限”的种子。

**英伟达的诞生：图形革命**

- 黄仁勋早年曾就职于AMD和LSI，从事微处理器和系统工程工作。他在LSI时磨练了商业沟通与项目管理技巧。
- 三人在太阳微系统的内部团队中颇受赏识，却因公司内斗被迫出走。黄仁勋评价那段时光：
- **“我们从来不是甘于平凡的性格，如果一扇门关了，就该自己动手去开另一扇。”**
- 三人真正让他们“一拍即合”的，是对PC图形潜力的共同判断。普里姆弃医从工、马拉科夫斯基痴迷底层编程，而黄仁勋则善于带领团队持续加班冲刺。
- **“他（黄）不只是天赋高，更是永远都比别人多付出几倍时间。”**
- **“当你心里明白没有退路时，你就会掏空所有时间与精力去完成目标。”**
- 1993年，三位创始人拿出各自200美元，凑了600美元成立一家新公司——Nvidia。
- 名称源自拉丁词“invidia”（嫉妒），也暗示他们想在图形界“让人艳羡”的雄心。
- **“我们想要一个足够酷，能让人过目不忘的名字。”**
- **“最初，只有我们三个人的信念，还有对图形处理的狂热。”**
- 公司初建时并没租下像样的办公室，而是在一间临时狭小空间办公。
- **“我们没日没夜地改图纸，几乎24小时倒班，我负责盯进度，谁撑不住了就换人顶上。”**
- 早期员工说：**“在别的创业公司，加班到深夜已经很疯狂，但在英伟达，凌晨四点看到老板在那儿，也不奇怪。”**
- 黄仁勋在LSI的好聚好散，获得前东家CEO的推荐，引入红杉资本等投资。
- **“早期我们的商业计划并不完备，但我的声誉帮我们敲开了门。”**
- **“无论你多聪明，没有好声誉也是白搭；名声就是进入下一关的钥匙。”**

# 二、必须要赢（1993—2003年）

**巨型失败**

- 英伟达花了两年研制出首款显卡NV1，希望以“先进前项纹理映射+波表合成音频”抢占市场。
- **“我们满怀期待，觉得NV1将是石破天惊。”**
- NV1的最大问题在于市场和开发者生态不兼容：领先技术没人配合，音频采用波表合成，对主流声卡不友好，一部分功能与主流游戏标准格格不入结果是零售商大面积退货，现金流迅速枯竭。
- **“当退货产品堆满仓库时，我们离倒闭只剩几个月。”**
- 黄仁勋此时才真正意识到经营公司需要远超于工程之外的综合能力。
- 要迅速吸取教训，“做得少但做得好”，才能避免再次盲目冒进。
- 为让公司活下来，他每天只睡四五个小时，不断去找投资人、客户谈合作。
- **“我回想那段时间，似乎每一天都是48小时，累到极限，但一想到公司撑不下去就无法合眼。”**
- 世嘉的合作款和临时裁员措施让英伟达勉强续命，但远未到安全地带。
- **“最危险的时刻，往往是最能逼出你的潜能。”**
-

**横扫千军**

- “做得少但做得好”的逆袭：RIVA 128
- NV1失败后，团队改走“更贴近市场需求”的策略：以单纯的速度和兼容性打动玩家及OEM厂商。黄仁勋筹集最后的资金，一口气买下仿真器设备（Ikos），让工程师在数字原型阶段就能编写驱动，大幅缩短开发周期。
- **“我们把2年的周期压缩到不到1年，简直在以光速推进。”**
- “光速”工作：长时间工作是必要前提。**用光速去战斗，当竞争对手还在磨刀，我们已经砍下第一刀。**
- RIVA 128背后的高强度加班模式在英伟达已成常态。
- 英特尔当时试图以i740挤占独立显卡市场，放言让OEM厂商等它的产品。黄仁勋震怒：
- **“他们要毁掉我们的渠道，我们只能反击。”**
- 他召开动员会，要求公司“光速”升级研发与销售策略，强调“要么击退英特尔，要么破产”。
-  “我们距离破产只有30天，必须干掉英特尔”
- RIVA 128一举在市场立足，成功抵御英特尔i740对OEM厂商的震慑。
- 英伟达在庆功后，黄仁勋：**或许我们都透支了健康，但我们成功救活了英伟达。”**

**我要赢**

- 3dfx破产：从竞争对手到被收购
- 3dfx当年在3D加速卡上风头无两，但因战略失误（例如收购STB）导致供货渠道崩塌，被英伟达超车。
- 黄仁勋：**“对方不是被我们打败，而是被他们自己的错误打败。”**
- 英伟达最终收购3dfx的核心资产与工程师，巩固了市场地位。3dfx一度称霸游戏市场，但战略失误，最终破产并被英伟达收购。自此，英伟达在游戏显卡领域进一步确立地位。
- 黄仁勋评价：**我们不会等着竞争对手给我们让路，我们只会用实力逼他们离场。**
- **“在竞争面前，第二名就是第一个失败者。”**
- 在与3dfx竞争的过程中，英伟达内部延续高强度加班。
- 有员工：**“在英伟达，如果你不想加班，就得愿意被黄仁勋挑灯夜战的精神吓跑。”**
- **“我们老板是那种把比赛拖到对手体力耗尽也要赢的人。”**
- 对合作伙伴采用“粗糙的公平”原则：**“若我今天拿60，你拿40，下次你拿60，我拿40，长久下来自然是50-50，这才是好合作。”**
- 创新者的窘境
- 1999年，英伟达发布GeForce 256，并将其命名为“GPU”，它不再只是显卡，而是一个新计算品类。市场在接下来几年见证了英伟达快速攀升的营收。
- **“当我们喊出GPU时，很多人以为是噱头，可它最终成了行业标准。”**
- 黄仁勋：**有时候，你先喊出一个名字，未来就得跟着这个名字走。**
- 深受克里斯坦森《创新者的窘境》的启发，既要稳固高端，又不能被低端颠覆。
- 提出“运送一整头牛”策略：为防止低端厂商蚕食市场，英伟达借鉴英特尔做法，把高端芯片中略有缺陷的部件封装成低端版本出售，“不浪费任何资源”。
- **“如果能把整头牛每个部位都用好，就能抵挡底端竞争者。”**
- **员工“我们连下夜班都要先跑去跟黄仁勋报告数据，这公司没有真正的‘下班时间’。”**
- 历史上最糟糕的产品：NV30NV30是英伟达在后来某一代GeForce架构上出现的失利，它暴露了内部沟通与对DirectX 9规范的争议，险些被ATI逆袭。
- **“即便我们在外部呼风唤雨，也不能忽视内部威胁。”**

# 三、巨人崛起（2002—2013年）

**GPU时代**

- 在GeForce横扫游戏市场后，英伟达开始思考：GPU能否做更多？
- 2006年推出CUDA，将GPU从图形加速器变成通用并行计算平台。
- 通用计算的雏形：随着科学研究对并行运算需求增加，英伟达提出“为什么不能用GPU来做通用计算？”
- **“我们发现GPU的并行天赋，远不止渲染画面。”**这在后来演变为CUDA。
- 黄仁勋说：**我们不该把GPU关在图形的小笼子里，它天生该去征服更多战场。**
- 早期投入极高，却无直接收益。许多工程师依然没日没夜地在编写、调试CUDA库。
- **“哪怕只有十分之一机会成功，也要拼尽十分之十的努力。”**
- 让 CUDA对所有人可用“我们的目标不是只卖硬件，要让所有人都能轻松上手GPU并行。”
- 英伟达在2006年前后正式发布CUDA，一开始并不赚钱，但他们耗费巨资维护并行生态，给高校与研究机构提供支持。
-  英伟达的护城河：十年后，随着深度学习井喷，CUDA成了各大AI框架天然支持的接口，这便成了英伟达无可撼动的护城河。
- **“回头看，我们为CUDA投入上百亿美元，才有今天的独占地位。”**

**英伟达工作文化**

- **我不喜欢放弃别人，宁愿磨炼他们**
- 如果团队某个人表现暂时不佳，他更倾向于多给机会、调教，而非立即裁员。他认为这样更能留住人才的潜能。
- 五大事项电子邮件法：英伟达要求每个员工定期发邮件给直属上级和高管，概括本周最重要的五件事情，包括技术动向、进展瓶颈、竞争对手情报等。
- **“我在寻找微弱的信号，强信号很容易捕捉，但微弱信号才是关键。”**
- 黄仁勋每天会浏览大量此类邮件，并在几分钟内回复。黄仁勋每天阅读近百封邮件，并 often凌晨就给下属发指示。
- 员工：**我一度怀疑他是‘不用睡觉的人工智能’。**
- 白板展示胜于PPT：大型会议尤其高级别汇报时，常常把人拉到一块大白板前。
- **“PPT可以掩饰空洞，白板才能暴露思维深度。”**站在白板前的人必须从零开始阐述观点，接受即席质疑与推翻。
-  **机长(PIC)制度**：每个项目都有明确负责人。**“若人人都说‘不是我负责’，那就等于没人负责。”**
- 管理与文化，使英伟达始终能以超强的执行力去完成高难度任务。

**技术型CEO**

- 黄仁勋本人拥有深厚的技术背景，不止一次参与具体的硬件和驱动设计。
- 黄仁勋的“CEO数学”：在极短时间评估决策投入产出。
- 黄仁勋持续保持直接指挥六十余名高管，他会亲自审查项目设计的细节，因为他本身具备工程基底。**“有些CEO只懂财务报表，却不懂技术，这在高科技领域难以成功。”**
- 他反复讲到英伟达过去几次关键产品均在破产边缘“赌一把”，要么深渊，要么天堂。
- **“冒险是家常便饭，但你最好算准最坏的情况。”**
- **“在高科技领域，CEO必须懂技术，否则只能在风暴里茫然失措。如果CEO不能通宵做代码评审，就别说你在搞高科技。”**
- 黄仁勋一天行程常常从早六点开始到次日凌晨两三点都还在处理事务。
- **员工“看他那个劲头，就知道他最看不得别人偷懒。”**
- 黄对团队：**“让自己上瘾于工作，这是你赢过那些三天打鱼、两天晒网之人的唯一方式。”**
- 英伟达在多个关键产品中都差点走到破产边缘，但每回都靠“极度努力”与“关键判断”杀出重围。
- “你必须让自己对工作着迷”，黄仁勋在多次接受采访时强调高强度工作是英伟达文化之根。
- **“如果你做不到全情投入，就会被时代淘汰。”**
- 黄：这是一种“在生死线上跳舞”的日常。

# 四、未来之芯

**点燃人工智能革命**

-  2012年后，深度学习异军突起。
- AlexNet在ImageNet竞赛上使用英伟达GPU大幅缩短训练时间，轰动学术界。
- 黄仁勋兴奋地说：**AI就像遇到干柴的烈火，而我们的GPU正好是那火星。**
- 英伟达针对AI市场推出Tesla数据中心GPU，并且每日加班更新CUDA库以满足研究者需求。
- **“我们不能慢下哪怕一天，否则就是对AI时代的背叛。”**
- 许多工程师连续数周泡在实验室优化底层驱动，周末也不休息。
- **“别人还在想‘周末干啥’，我们已经把下周一要交付的任务干完了。”**
- 在竞购Mellanox的过程中，英伟达法务、财务和技术团队需要查看海量资料。他们常常连续熬夜处理每个协议细节。**“黄仁勋从凌晨两点就开始整理材料，对我们来说已是习以为常。”**
- 通过收购Mellanox，英伟达从“显卡供应商”变成“端-网-云”一体化计算加速公司。“GPU + 高速网络 + 软件生态”成了英伟达的底层底牌。
- 黄仁勋谈及这笔69亿美元收购时说：**“所有伟大的事都源于一场看似疯狂的冒险。”**

**未来无界**

- 英伟达在自动驾驶（Drive PX）、机器人（Jetson）等项目上同样高强度研发。
- 英伟达内部鼓励“无关短期利润”的科研投入，类似Google X的“登月计划”。有时投入巨大，短期看不到回报，但黄仁勋认为：**“要想继续领先，就要敢于培养那些埋在雪地里的种子。”**
- 黄仁勋对这些新方向的团队强调：**“当你只盯着利润，你会错失打开下一个星球的大门。”**
- 工程师们描述，很多项目组为了实现“KPI之外”的登月计划，往往周末加班不休，只为寻求技术突破。
- **“我们冒的险越大，就必须工作得越努力，这是一条铁律。”**
- 黄对团队：**“在英伟达，没有人会因为你不够努力而责怪你，除非你连最基本的加班都不愿付出。”**
- OpenAI推出ChatGPT引爆生成式AI的浪潮，英伟达GPU需求激增，市值突破万亿美元。
- 公司成立多支“突击小组”连夜应对客户定制需求**“我们临时组织了多支突击小组，连续数周拼夜班，每个人都累到极限，但也对AI的未来满怀激动。**
- **黄仁勋说，‘我们是AI的世界引擎’，并非夸大其词。”**
- “AI将渗透各行各业，底层算力需求无穷大”，英伟达要做的就是继续以“光速”迭代产品。
- **“只要我们保持对新应用场景的好奇，就能持续占据领先。”**
- 黄仁勋在内部：**“如果你不是那种能随时为工作而‘牺牲睡眠’的人，可能真的不适合英伟达。”**
- **“我们是AI的世界引擎，我希望让智能像电力一样普及到每个行业。”**

**黄仁勋之道**

- 黄仁勋带领英伟达三十载，从一家险些倒闭的小公司到主宰AI计算的庞然大物；其“极度努力”与“极度冒险”的组合，是英伟达精神的核心。
- **痛苦和磨难才是最好的礼物，你必须全然拥抱它们。**
- 在管理哲学上，他注重“使命至上”
- 在技术路线上，他主张“敢赌、敢冒险”，只要判断方向正确，就不惜用时间和汗水铺出成功之路。
- **黄的成功秘诀：“你可能没法保证比别人聪明，但你能保证比别人更加努力，这就够了。”**
