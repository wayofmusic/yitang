# 拆书开始

# 一、有闲阶级的构成与掠夺起源

- 在维京人的龙头船上，战利品分配遵循着严格的荣誉等级，最勇猛的战士有权优先挑选黄金臂环，这种选择权本身比臂环的实际价值更具象征意义。
- 这种掠夺行为，实质上是将人体暴力转化为物质占有的仪式，矛尖的血迹最终凝结为法律文书上的财产权。
- 当美洲原住民部落将俘虏转化为纺织奴工时，对劳动力的控制完成了从暴力征服到制度占有的关键转化，皮鞭被法律契约取代，但支配的本质从未改变
对女性的占有是所有权的原型
- 有闲阶级由贵族、教士及其附属阶层构成，其核心特征是：在性质上总是属于非生产的。他们的业务范围被严格限定在"政治、战争、宗教信仰和运动比赛"领域。
- 在切罗基部落中，贵族妇女虽被免除粗笨劳动，但仍需监督奴隶纺织；而男性贵族若触碰生产工具将丧失选举权。
- 政治、战争等非生产性职业被神圣化，生产工作则被视为可鄙的、丑恶的。劳动本身成为惹人厌恶的业务。
- 这种污名化机制在工业时代依然延续：19世纪英国贵族将工厂投资视为"肮脏交易"，宁愿通过地租和债券获利。
- **有闲阶级制度的产生需要严格的社会条件：**

1、掠夺性生活模式的确立：部落必须惯于通过武力或策略从事伤害行为，无论是战争还是大规模狩猎。北欧海盗的龙头船劫掠经济是典型——战士依据战功分配黄金臂环，这种暴力分配机制衍生出最早的阶级特权。

2、剩余产品的充足积累：只有当生活资料的获得足够从容，才能让部分成员完全脱离生产劳动。古埃及尼罗河灌溉农业的丰产，使得法老祭司阶层得以专司仪式活动。

- 有闲阶级制度是从和平习惯向好战习惯转变的产物。当部落开始用暴力而非劳动获取资源时，阶级分化就不可避免。
- 早期掠夺行为塑造了所有权观念：用掠夺以外的方式取得任何事物，一个有身份的男子是不屑一顾的。
- 生产活动进一步替代掠夺活动，累积的财产成为优胜的常规证据。财富占有演变为获得敬重的基石，也是自尊心存在的必要条件。
- 后来掠夺活动渐成过去，生产活动进一步代替了掠夺活动，于是累积起来的财产就越来越成为获得成就与优势的象征，而不再是侵占下的战利品。以财富的占有为博得声誉与尊敬的基础，其相对的重要程度和有效程度越来越提高。
- 如果一旦达到了社会的或社会中属于他的那个阶级的所谓正常的金钱标准，他原有的长期不满情绪将为另一种心情所代替，那时他所片刻难安的将是怎样使他自己的金钱标准与这个平均的金钱标准之间的差距能够扩大、再扩大。
- 有闲生活是金钱力量的，因此也就是优势地位的最简捷、最确凿的证明。
- 人类制度与性格特征都是既往淘汰适应过程的产物
- 有闲阶级的存在本身即是对社会效率的系统性破坏

# 二、炫耀的本质：符号

**所有阶层向上看**

- **每个阶层的成员总是把他们上一阶层流行的生活方式作为他们礼仪上的典型，并全力争取达到这个理想的标准。**
- 为了使自己在他们的观察之下能够保持一种自我满足的心情，必须把自己的金钱力量显露得明明白白，使人在顷刻之间就能一览无余。因此很清楚，现在的发展趋向是，人们重视明显消费的作用甚于明显有闲。
- 任何贵重品，要引起我们的美感，就必须能同时适应美感和高价两种要求。
- 高价这一准则还这样地影响着我们的爱好，使我们在对美术品的欣赏中把高价和美感这两个特征完全融合为一。
- 低价无好货”“衣贱人也贱”，这种拥护高价、反对低价的习惯，在我们的思想中已经根深蒂固。
- 消费者评价商品时，对商品所含有的荣誉因素和纯物质的效能因素并不是分别看待的，两者混合起来构成了物品的不经分析的、综合的适用性。
- 生产成本低微，对这类物品进行消费是不含有荣誉成分的，因为它不能适应同别的消费者作有利的歧视性对比的目的。
- 服装是金钱文化的一种表现，在现代社会，有关服装的各种用品的商业价值所含的绝大部分成分是它的时新性和荣誉性，而不是它对穿衣服的人的身体上的机械效用。
- 设计者在每一个细节上的用意是在于要引起一种印象——穿着这类衣服的人并不习惯于从事任何有实用的劳动。

**“有用是可耻的”**

- **有闲的本质是非生产性消耗时间。**
- 这种消耗必须满足两个条件：证明当事人无需劳动，且具备维持闲适生活的金钱能力。
- 法国宫廷的16道晚宴流程：从开胃酒到餐后舞会持续6小时，每道菜的间隔时间精确到分钟，仆人需用沙漏计时。
- 牛津大学的拉丁文必修课：从事非生产性活动学生耗费2000小时学习死亡语言，教授故意采用西塞罗时代的古典语法。这种"知识苦行"的唯一功能是证明：学习者的时间毫无经济压力。
- 波斯贵族的指甲养护制度：蓄留10厘米以上指甲，每日用玫瑰精油浸泡，佩戴纯金指套防止断裂，彻底丧失手部劳动能力
- 绅士不仅要大量消费，还必须懂得得体方式。高雅生活方式需要长期训练，这种训练本身就是金钱壁垒。对勃艮第葡萄酒年份的辨识能力，其价值远超味觉享受本身。
- 任何社会中妇女所处的地位，是社会所达到的文化水平的最明显指标
- 波利尼西亚酋长的巨型独木舟收藏：所有权的心理根源不在于实用需求，而在于对他人产生优越感的欲望，这种欲望在战利品积累中得到最原始的表达
西非部落将铜器熔铸成无法使用的装饰柱，这种行为的经济学本质是用原材料的毁灭来证明：我们富足到可以肆意浪费
哥特复兴建筑是“石砌的阶级宣言”：纽约富豪别墅的尖塔既不挡风也不遮雨，但它们刺破天际的高度恰好等于主人财富的数值，每个飞扶壁都在诉说着'此间容不下实用主义'"。这种空间政治在室内达到顶峰：旋转楼梯的每一级踏步都经过精密计算，确保访客攀登时能充分感受主人的空间支配权
- 银制餐具必须每日擦拭却极少使用，这种精心维护的洁净状态本质上是用时间损耗铸造的阶级勋章.
当普鲁士军官在佩剑镶嵌宝石时，他们故意削弱武器的杀伤力来增强其符号价值——这标志着军事荣誉彻底臣服于金钱竞赛。
巴黎歌剧院的镀金浮雕在煤气灯下闪烁时，每个鸢尾花纹章都在重复着古老的掠夺宣言，只是长矛换成了法郎
天主教会的黄金圣器故意采用无法盛水的夸张尺寸，这种设计将实用价值清零，使器物彻底沦为金钱信仰的圣像
- 股票市场演变为纸上掠夺系统：铁路债券的流转与维京战利品分配具有同构性，区别仅在于血腥掠夺被抽象为数字游戏。

**代理消费：真有钱，是有人替我花钱**

- 代理有闲的需要，或对劳役的明显消耗的需要，是畜养奴仆的主要动机。
- 占有并畜养一批奴隶，叫他们从事生产财物，其所证明的是财富与威力；但是畜养一批仆役，不让他们从事任何生产工作，其所证明的却是更多的财富和更高的地位。在这样的原则下，就兴起了一个仆役阶级。
- 仆役阶级的一个部分，主要是以执行代理有闲为职务的那些人，渐渐地负担起了一类新的、附属的任务——进行对财物的代理性消费。这种消费的最显著方式是他们穿特制号衣，住宽敞的仆役宿舍。
英国管家的条纹背心保留着18世纪裁缝的针脚，这些过时的针法如同活化石，证明雇主家族的财富积累早于工业革命高级仆役的无用性是其存在价值的核心，一个能准确区分12种葡萄酒杯却不会拧螺丝的管家，才是完美的阶级显示器。
- 仆役必须展现训练有素的卑屈态度，任何疏漏都会暴露主人财力缺陷。他们的存在本质是'移动的支付能力证书
- 主妇的职责远超家务管理，更是家庭财力的活体广告：贵妇们的有闲表现为侍奉主人的不辞劳瘁，她们在饮食、衣着、住宅布置上的消费，实质是代理性的炫耀消费。
- 束腰服饰的流行是“呼吸权的阶级让渡”：当金属骨架将肺活量压缩到生存极限，这种痛苦本身就成为丈夫财力的活体广告——她连氧气都由他人供给，何况衣食住行
- 育儿：雇佣瑞士奶妈的传统绝非为了乳汁质量，而是要用阿尔卑斯口音证明婴儿从第一声啼哭就超越市井

**符号支配人心**

- 一旦私有制确立，人与人之间的竞争就从武力较量转向财富攀比。拥有财产成为获得敬重的必要条件，自尊心开始与账户数字深度绑定。
- 这种异化在威尼斯商业法中达到制度顶峰：商人必须公开账本证明财力，才能获得政治选举权。破产者被强制佩戴黄色帽子，社会地位等同于麻风病人
- 消费品的核心价值在于非实用性：奢侈品的消费在其真正意义上，是为使消费者感到舒适的一种主人标志。物品的非生产性消费之所以光荣，在于其是实力与特权的证明。
- 礼貌的经济学本质：礼貌的养成需要长期应用，唯有脱离生产的人才能掌握。高雅举止的价值在于它们是有闲生活的确凿证明。
- 礼仪的本质是制造非必要困难，当程序复杂到唯有闲适阶层能掌握时，它就自然成为阶级过滤器。
- 法国宫廷的屈膝礼训练需耗费200小时。
- 知识垄断在艺术品收藏中达到顶峰：美第奇家族赞助的文艺复兴画家，是将金融资本转化为文化资本。
- 高级学识是金钱文化的一种表现
- **任何阶级都不会放弃炫耀性消费。**
- 城市贫民宁可饿肚子也要购买二手丝绸，表面体面’的需求压倒生存本能。
- 19世纪纽约：与农村工匠相比，城市劳工家庭收入更高却更拮据——他们必须将更大比例资金投入服饰与礼仪，以维持符合都市标准的‘金钱体面’。

 **阶级符号的迭代**

- 原始阶段：物理暴力（战利品）
- 中级阶段：物质积累（贵金属）
- 高级阶段：抽象符号（角色/学历）

# **三、阶层闭环**

**有闲阶层特征**

- 富裕阶级生来是保守的。富裕阶级之所以反对革新，是由于它拥有那种不值得称道的既得利益，是由于要保持现状，保持那种既得利益。他们没有受到非屈服不可的压制。
- 保守主义是上流社会的特点，对一切社会革新会本能地抱着反感并加以排斥。富裕有闲阶级的习尚、举动和见解，是社会中其他成员一贯奉行的行为准则，这一事实使这个阶级的保守主义的影响格外增加力量，扩大势力范围。
- 今天有闲阶级成员的供源是在金钱标准上成功的那些人。要进入有闲阶级就得从金钱工作人手，而这类工作，通过淘汰和适应，只有在掠夺的考验下、在金钱的立场上适于生存的那些后裔，才能胜任愉快。要在有闲阶级中保持地位，就得保持金钱的气质。
- 在早期未开化阶段或纯掠夺阶段，必须具有粗豪凶暴、蛮横霸道、意志顽强、党同伐异等等天赋的品质。要想累积并继续享有财富，这类禀赋是不可少的。
- 到了未开化文化的后期，直率的进攻和肆无忌惮的凶暴，已经在很大程度上被精明、狡狯和诈伪的作风所代替；后者已成为累积财富的最有效方式。到了今天，现在要取得加入有闲阶级的资格，所必需的品质只是金钱的品质。
- 有闲阶级向来处于荣誉的示范者的地位，其以下各阶级接受了它的生活理论的许多特征，以致整个社会对于这类贵族特征，相当坚定地不断地加以培养。
- 战争狂热是掠夺气质的指标。民族在掠夺文化与准和平文化下经受长期锻炼而养成的尚武精神已经遗留给现代的人们，这种精神与凶暴和狡猞一类表现是一拍即合的。

**阶层捍卫的壁垒**

- 黄金囤积现象：英格兰银行地窖里的金块永远不会流通，它们的存在意义就是证明'我们富足到可以让财富休眠'"
常春藤盟校的拉丁文校训，既不需要师生理解，也不能翻译成白话，这些僵死的字母组合如同学术城堡的护城河，将实用知识隔绝在吊桥之外
- 当英国行会要求学徒制作毫无用处的榫卯构件时，他们实质上是在用木材的浪费来维护技艺的神秘性。
- 拉丁语在医学教育中的存续是“学术巫术”：当医生用'Q3H'缩写开具处方时，这种伪古典语法既不能治病，却能有效区分知识阶级与普通民众。
- 学生耗费五年论证过时命题，实质是重复中世纪修道院抄经仪式。
- 法学院：布莱克斯通的《英国法释义》之所以保持中世纪英语，是因为晦涩本身就是法律阶级的准入壁垒
- 巴黎美术学院：不许用水泥
直到1900年，哈佛医学院仍要求用拉丁文书写处方，尽管90%患者无法理解。
- 英国律师故意保留《大宪章》时期的术语，将法律文本变成"阶级密码本"。

**任何技术创新必须经历三代人才能消除制度敌意。**
