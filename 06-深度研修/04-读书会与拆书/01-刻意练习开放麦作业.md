# 刻意练习开放麦作业

|-|-|

3. **当前工作** ：在一堂主导训战营课程设计与训练体系搭建，通过**刻意练习** 实现从财务到教育创新的跨界。 |
| 陈建弛背景 | 他是一位**连续创业者** 与**科学方法的笃定实践者**
1. **教育背景** ：中山大学本科，香港科技大学硕士。
2. **创业经历** ：10年斜杠创业者，全域可降解材料产研公司创始人，“圳品”石斑鱼养殖基地技术合伙人。
3. **一堂经历** ：决策案例课案主，Y30创业者，坚信**刻意练习** 和**清单体笔记** 是核心基本功。 |
| 起因与初步调查 | 1. 信息来源       a. 许多学员反馈：“**道理都懂，但一上手就懵** ”。
2. 盈盈的疑问与目标       a. 疑问：为何学员无法将理论转化为实践？       b. 目标：通过实操和反馈，带领学员真正掌握清单体笔记，形成**肌肉记忆** 。
3. 验证教学效果的真实性
       a. 初步验证：收集了 **280多份** 学员作业，发现大家有很强的**刻意练习** 决心。
       b. 进一步验证：对比分析学员的两轮作业迭代，拆解其进步点。
           i. 观察学员笔记从“流水账”到“**结构化** ” 的转变。
           ii. 分析其如何应用**模块化** 、**标签化** 和**结论前置** 等技巧。
           iii. 总结出学员笔记迭代的**共性优势** 和**核心规律** 。 |
| 心理活动 | 盈盈曾经有**3**  个阶段的“踩坑”经历：
1. **第一阶段（纸质笔记）** ：因频繁搬家导致笔记**全部丢失** ，感到心疼不已，意识到其**无法迁移** 、难以复用的弊端。
2. **第二阶段（录音整理）** ：采访时用录音笔+iPad，结果整理一份稿件耗时**2-3天** ，充斥着错别字和冗余信息，几乎**崩溃到想放弃** 。
3. **第三阶段（加入一堂）** ：看到Truman的“最佳实践”，感觉“**天灵盖打开** ”，意识到自己之前一直**用错了方法** 。 |
| 深入验证清单体笔记有效性 | 1. 结构逻辑清晰性验证 #[框架感]
       a.**付豪作业** ：从流水账式罗列，进化为用「模块+干货点」的**结构化梳理** 。
       b. **铃悦作业** ：从被动记录，进化为以「访谈目标」为导向，将流程拆分为「**起因→判断→提炼** 」的流程清单。
2. 信息提炼精准度验证 #[干货密度]
       a. **刘鑫作业** ：通过添加**#转机** 、**#细节拉满** 等标签，实现关键信息**标签化** 。
       b. **虞同学作业** ：严格按照 **OSCAR模型** 重构内容，将个人经验**工具化** ，形成可复用的调研模板。
3. 学员反馈总结：
       a. 普遍进步规律：**分层论述** 、**框架复用** 、**关键信息显性化** 、**经验工具化** 是“从记录到知识资产”的关键路径。 |
| 课程要点 | 1.  学员常见卡点
      a.**打字慢/吸收慢** ，笔记记不全怎么办？ -> 接受“记不全是常态”，核心是“**抓关键** ”。
       b. **想不到延伸点** ，笔记太“干”怎么办？ -> 用“**倒逼法** ”和“**延伸法** ”训练关联思维。
       c. **平时没机会练** 怎么办？ -> 将练习融入**日常生活** ，如看新闻、开会、购物。
2. (个人实践)
      a. **考察对象** ：盈盈自己所有的工作场景（每节课、每次磨课、每个方案）。
      b. **了解信息** ：逼着自己用清单体，从慢和乱开始，最终练顺，**效率高了不止一倍** 。
3. 线上学习 #[陈建弛的迭代之旅]
       a. **学习方式** ：经历了不记笔记 -> 思维导图 -> 分散文档 -> 拆分整理 -> **Y模型** 的迭代。
       b. **梳理的关键点** ：笔记的认知从“形式” -> “工具” -> “信息处理过程” -> “**问题导向** ” -> “**解题和秘籍** ”。
4. 面试交叉验证 #[获取反馈]
       a. **采取的行动** ：将作业发到大群，请同学提意见。
       b. **获得的结果** ：获得**及时反馈** ，加速迭代。
       c. **其他方法** ：拿自己的笔记与**最佳实践** 对比；让 **AI** 结合原则进行评分和点评。
5. 了解信息 (笔记到底是什么):
      a. 是**信息** 、是**理解** 、是**联系** 、是**轨迹** ，最终是“**我** ”之所以为“我”的框架。
6. 发现 (练习的附加价值):
      a. 刻意练习清单体笔记，同时也在练习**深度学习** 、**知识管理** 、**时间管理** 等一系列能力。
       b. 组织层面，能提升**高效协作** 、**深度复盘** 和**知识萃取** 的能力。
7. 评估：
       a. 这是一项**高杠杆** 活动，花一份时间，能提升一个系列的能力，**非常香** 。 |
| 金句自己总结/迭代 | • 道理都懂，但一上手就懵。
• **实操比什么都重要** 。
• **见过好的，才知道怎么变好** 。
• **记 = 解题，笔记 = 秘籍** ，这是10倍成长的杠杆。
• **不要陷入形式主义，记住自己最初的目标** 。 |
| 结论 | 最终决策是**全面采纳并持续刻意练习清单体笔记法** ，因为它不仅是高效记录的工具，更是**训练思维、沉淀个人知识资产、实现能力跃迁** 的核心载体。 |
| 总结与思考 | 1. 实践心得
       a.**普通人也能做到** ：盈盈和建弛都从“磕磕绊绊”开始，关键是“**先做起来** ”，不怕丑和慢。
       b. **好东西是长出来的** ：笔记的迭代是渐进的，无需一次性重构所有旧笔记，应在需要时再优化。
       c. **聚焦目标而非形式** ：不要为工具的炫酷功能所困，回归到“**让记和笔记都价值连城** ”的最终目标。
2. 价值总结：清单体笔记的真正价值在于，它是一个**可以无限成长的技能** ，能让你的思考更清晰，并让笔记本身随着认知提升而**螺旋上升** ，持续质变。 |
