# 拆书开始

我们正进入一个全新的、以知识为核心、以学习为增长引擎、以时间为货币标尺的“后资本主义”时代。

一个新经济理论的诞生，一个革命性的经济理论框架：这并不意味着资本主义的终结，而是对资本主义本质的重新理解和定义。

四个核心命题：

1. **财富即知识**
2. **增长即学习**
3. **信息即意外**
4. **金钱即时间**

# 一、超越稀缺性——从物质到知识的范式转变

### 物质主义迷信的终结

- 当前的经济学理论，无论是古典的、新古典的还是凯恩斯主义的，都深陷于物质主义和决定论的泥潭。它们将经济视为一部可以精确计算和控制的“伟大机器”，强调资源的稀缺性和分配的重要性，却忽视了经济活动中最核心的要素——人类的创造力、知识的增长和信息的“意外性”。
- 传统经济学，从亚当·斯密到卡尔·马克思，都建立在物质稀缺性的基础上。正如1935年英国经济学家莱昂内尔·罗宾斯所总结的："经济学……研究人类行为作为目的与具有替代用途的稀缺手段之间的关系。"
- 我们熟悉的那个由亚当·斯密开启、卡尔·马克思命名的“资本主义”时代，其理论基础和实践模式，在信息技术和全球化浪潮的冲击下，已显露出深刻的不适应性。斯密的“伟大机器”比喻从根本上就是错的，它忽略了经济的有机性和创造性。在任何意义上，经济都不是斯密所称的‘伟大机器’。
- 物质资源像宇宙中的原子和分子一样丰富。
- 真正稀缺的不是物质，而是时间。时间是唯一不能被回收、储存、复制或恢复的资源。
- 托马斯·索威尔："尼安德特人在洞穴中拥有的自然资源与我们今天拥有的完全相同。"
- 它揭示了一个事实：财富的差异主要在于知识的差异。
- 经济财富的分配远不如其生产重要，尽管许多经济学家和政治家似乎相信如此。
- 由于资本主义市场……已经让位于新一代的政府规则，最好定义为‘紧急社会主义’，我们已经超越了资本主义。我们正在以确保确定未来、保证稀缺资源分配和保障回报的名义，压制资本主义创新的‘意外’。
- 我们的财富在增长，但我们的理论却在倒退。
- 从应对金融危机到新冠疫情，再到气候变化，政府不断以“紧急状态”为名，实施大规模的财政刺激和货币宽松，以及无孔不入的管制。这种“紧急社会主义”看似在解决问题，实则是在扼杀市场的自发秩序和企业家的创新精神。
- 政府政策几乎普遍地违背和禁用了资本主义的经典信条。
- 现代货币理论（MMT）是一种神奇的货币思维，它相信政府可以无限制地印钞而不会产生负面后果。精英们试图通过控制货币和投资来维持他们的权力，但这只会导致停滞。
- 我们生活在一个由官僚和专家统治的时代，他们相信自己能够比市场更好地分配资源。

### 财富即知识

- MIT的塞萨尔·伊达尔戈描述了一辆价值250万美元的布加迪威龙：想象一下，你刚刚在彩票中赢得了一辆布加迪威龙。兴奋之余，你决定开着你的新车兜风。在兴奋中，你把布加迪撞到了墙上……现在，那公斤布加迪值多少钱？"汽车的价值在几秒钟内蒸发了，但它的重量没有变化。"汽车的价值蒸发了……不是因为撞击破坏了组成布加迪的原子，而是因为撞击改变了这些原子的排列方式。
- 伦纳德·里德的经典文章《我，铅笔》：”地球上没有人知道足够多的知识来制造一支木铅笔。“——现代经济中知识是分布式式的。
- **财富即知识。经济的核心是人类心智的创造力，是新思想、新技术的涌现。**
- 财富不是货物的存量，而是思想的流动。经济增长的源泉不是物质，而是思想。
- 人类心智是地球上最重要的经济资源，我们交易的最终不是物质，而是差异化的知识。
- 资本主义的真正力量在于其解放人类创造力的能力。
- 硅谷的财富并非来自地下的黄金，而是来自工程师头脑中的思想。
- 信息时代的核心是知识的指数级增长。衡量经济健康状况的最佳指标是其产生新知识的速度。
- 知识一旦产生，就可以以极低的成本复制和传播，从而产生巨大的经济效益。真正的资本不是机器或建筑，而是嵌入在人和系统中的知识。
- 将财富等同于物质会导致错误的经济政策，比如过分强调资源的稀缺性，或者试图通过简单的再分配来实现繁荣。我们应该关注如何创造一个有利于知识生产和传播的环境。
- 稀缺性是经济学的一个迷信，人类的创造力是无限的。专注于再分配就像是在重新摆放泰坦尼克号上的躺椅。
- 繁荣来自生产，而非消费或分配。经济学应该关注创造财富的过程，而不是计算现有的财富。
- 自由市场是产生和检验知识的最佳机制。

### 增长即学习

- 经济不是一个均衡系统，而是一个不断演化的学习系统。
- 经济人’是一个危险的虚构，它忽略了人类行为中最关键的要素：创造力、信仰和对未知的探索。
- 现实世界中的企业家不是计算者，而是实验者。他们（企业家）在不确定性的迷雾中航行，他们的成功源于他们的洞察力和冒险精神。
- 市场经济本质上是一个巨大的“测试-测量”系统。企业家提出假设（新的产品、服务或商业模式），然后通过市场进行检验。成功带来利润和增长，失败则提供宝贵的反馈和学习机会。
- 利润是对成功学习的奖励，亏损是对错误假设的惩罚。
- 市场是一个发现过程，它不断揭示关于世界的新知识。
- 失败在学习过程中与成功同样重要，一个健康的经济体允许并鼓励实验和失败。试图消除失败的经济政策，最终也会消除增长。
- 风险投资家投资于那些高风险、高回报的项目，他们知道大多数项目会失败，但少数成功的项目将带来巨大的回报，并推动整个经济向前发展。这就是学习过程的体现。
- 政府无法像市场那样进行有效的学习，因为它缺乏价格信号和盈亏机制。官僚主义倾向于规避风险，而学习需要承担风险。
- 学习不是线性的，而是充满曲折和意外的。我们必须拥抱不确定性，因为它是学习和增长的前提。”
- 波士顿咨询集团的布鲁斯·亨德森："学习曲线理论预测，在市场经济中，任何商品或服务的成本都会随着总销售单位的每次翻倍而下降20%到30%。"
- 最著名的学习曲线是摩尔定律。戈登·摩尔在1965年预测，集成电路上的晶体管数量每两年翻一番。
- 摩尔定律是学习现象，与所谓的学习曲线以复杂的方式相关。

# 二、信息、创造力与企业家精神

### 信息即意外

- 香农：信息量取决于克服了（减少）多少不确定性。克劳德·香农揭示了信息论的悖论：信息是‘意外’。
- 一条消息包含的信息量，取决于它让你惊讶的程度。如果一条消息是完全可以预测的，那么它就不包含任何信息。
- 熵在香农的理论中，不是混乱，而是自由度或意外的可能性。
- 如果有人告诉你“太阳明天会升起”，这条消息几乎不含信息，因为它完全在预料之中。但如果有人告诉你一个你从未听过的秘密，或者一个颠覆你认知的科学发现，那么这条消息就包含了巨大的信息量。
- 通信的目标不是传输数据，而是传输‘意外’。
- 信息论的核心思想是：只有新的、不可预测的东西才构成信息。
- 信息不是秩序或决定论或均衡，甚至不是模式，而是它们的对立面。信息是打破模式的东西。信息是意外的比特，熵。
- 传统经济学寻求均衡和可预测性，但实际的经济增长是意外的现象，是信息熵的现象。
- 普林斯顿大学阿尔伯特·赫希曼："创造力总是给我们带来惊喜。如果不是这样，我们就不需要它，政府计划就会奏效。"
- 这解释了为什么中央计划经济总是失败。正如哈耶克所说："中央计划之所以失败，正是因为它声称知道它不能知道的东西，因此掩盖了意外并取消了知识。

### 企业家精神的本质在于创造力

- 企业家的本质是创造者和学习者。
- 信息是“意外”，“意外”来自人类的创造力，这是信息经济学理论的基石。
- 经济学本质上是信息论的一个分支，经济增长是由企业家创造的‘香农信息’（即意外）驱动的。
- 与机器只能执行预定程序不同，人类心智拥有产生全新思想和“意外”的能力。
- 创造力是经济增长的终极源泉。人类心智是宇宙中已知的唯一能够持续产生‘香农信息’（意外）的源头。
- **人工智能可以处理信息，但它无法像人类那样创造真正的‘意外’。**
- 任何试图将人类行为简化为算法或模型的经济理论，都注定会失败。
- 创造力不是凭空产生的，它需要自由、信仰和冒险精神。一个压制自由、扼杀异见的社会，不可能有持续的创新和经济增长。
- 企业家精神本质上是一种信仰行为——相信未来可以通过创造性的努力来塑造。
- 每一次成功的创新都是一个‘意外，它打破了现有的模式，创造了新的价值。企业家是经济中的‘意外’制造者。
- 他们（企业家）的工作是挑战现状，引入不可预测的新事物。企业家通过他们的实验，向市场释放“意外”，市场则通过价格信号和盈亏机制来反馈这些“意外”的价值。
- 利润是对成功创造‘意外’（即满足未被满足的需求或创造新需求）的奖励。
- 亏损表明一个‘意外’没有被市场接受，或者说它是一个错误的‘意外’。一个充满活力的经济体，是一个不断产生和检验‘意外’的系统。
- 试图消除经济中的‘意外’（例如通过过度监管或计划经济）就是扼杀经济增长。经济学家们常常试图建立预测模型，但经济的本质恰恰是不可预测的，因为它充满了‘意外’。
- 一个社会对待其企业家的态度，决定了它的经济命运。我们必须庆祝那些敢于梦想、敢于创造‘意外’的人。
- 谷歌的成功不是来自对现有市场的优化，而是来自创造一个全新的、出人意料的市场。创新不是渐进的，而是颠覆性的；它不是可预测的，而是‘意外’的。
- 我们无法预测下一个伟大的创新将来自何方，我们只能创造一个让‘意外’得以发生的环境。。政府不应该试图挑选赢家，而应该为所有可能的‘意外’创造公平的竞争环境。
- 经济学必须从研究稀缺资源的管理，转向研究‘意外’的创造。
- 德州仪器的一个小团队在公司石油工业设备的持续销售资助下锻造了第一个硅晶体管
- 仙童半导体由罗伯特·诺伊斯等人创立，得到了工程师谢尔曼·仙童的资助，而不是银行家
- 从一开始，硅谷就是由具有矛盾组合的内部人士资助的：巨大的先前专业知识和愿意被惊讶的意愿，追求不可能和难以置信的。
- 彼得·蒂尔："所有企业都寻求垄断，并在达到垄断的程度上取得成功。创新是从零到一。
- 这挑战了传统经济学对垄断的负面看法，垄断主要在政府在紧急社会主义制度下捍卫它们时才具有破坏性。
- 将经济比作生态系统是误导性的，因为它忽略了人类的目的性和创造性。
- 经济学必须以人为本，以人类心智为中心。物质世界是有限的，但人类心智的潜力是无限的。
- **后资本主义时代，将是一个心智战胜物质的时代。**

# 三、货币、时间与区块链的未来

### 时间价格

- 盖尔·普利和马里安·图皮开创"时间价格"概念，这是一种革命性的衡量财富和进步的方法："我们用金钱买东西，但我们用时间支付。
- 这意味着有两种价格：货币价格和时间价格。
- 时间价格的计算很简单：将产品或服务的货币价格除以小时收入。
- 感恩节晚餐，1986年到2021年，虽然名义价格上涨了70.1%，但对于非熟练工人来说，时间价格下降了29.7%。
- 1850年，一个工厂工人需要工作2小时50分钟才能买一磅糖。今天只需要35秒。"自1850年以来，生活变甜了28,700%。
- 1910年，买一辆自行车需要66.4小时的工作。2021年只需要3小时。"你在1910年买一辆自行车所需的时间，今天可以买22.62辆。

**从1980年到2020年：**

- 50种基本商品的平均时间价格下降了75.2%
- 个人商品资源丰富度上升了303%
- 全球资源丰富度增加了608%
- 从1980年到2020年，基本50商品指数表明，人口每增加1%，时间价格就会下降1%。"这完全颠覆了马尔萨斯的人口悲观论。
- **人口不会消耗资源；他们创造资源。**

### **货币即时间：重新定义金钱的本质**

- 现代经济学对货币的理解是根本性错误的。无论是将其视为交换媒介、价值储存还是记账单位，都未能触及货币的本质。
- **货币的真正本质是时间**。
- 金钱是时间。或者更确切地说，金钱是对时间的衡量。
- 金钱是‘冻结’的时间，你可以保存它并在以后使用。
- 所有经济价值最终都源于人类的时间——我们投入工作、学习和创造的时间。
- 利率不是货币的价格，而是时间的价格。储蓄不是推迟消费，而是购买未来的时间。
- 一个稳健的货币体系，就像一把可靠的尺子，能够准确地衡量和交换时间价值。当央行操纵利率时，它们实际上是在操纵时间的价格，这是对经济最严重的扭曲。
- 零利率意味着时间没有价值，这在逻辑上是荒谬的，在经济上是毁灭性的。
- 印钞并不能创造财富，它只能稀释现有货币的时间价值。法定货币的价值最终取决于人们对其未来购买力的信心，而这种信心正在被侵蚀。
- 我们正在用‘坏’钱（不断贬值的法定货币）取代‘好’钱（能够稳定衡量时间的货币）。这种对货币和时间的扭曲，导致了金融体系的失控和实体经济的空心化。金融体系已经从服务实体经济的工具，变成了自我膨胀的赌场。
- 当时间被扭曲时，长期的投资和创新就会受到抑制，而短期的投机和寻租行为则会盛行。我们生活在一个‘金融猖獗’的时代，金融的回报远远超过了实体经济的回报。这导致了财富的集中和机会的不平等。
- 每天近8万亿美元的货币交易"比所有商品和服务贸易大约73倍，比世界国内生产总值大约25倍。货币上下波动的频率和剧烈程度远远超过它们背后的经济。
- 浮动货币创造了一个固有的嘈杂渠道。填充噪音的渠道——总是令人惊讶因为随机——信号变得无法区分。

### **可靠的货币**

- 我们必须恢复货币作为可靠时间尺度的功能。
- 黄金在历史上长期扮演着时间锚的角色。黄金之所以成功作为货币，不是因为它是一种商品，而是因为它具有独特的时间特性。
- "值得注意的是，开采增量金锭所需的时间变化很缓慢。"朱德·万尼斯基在1979年指出，"黄金抵消了资本和技术的进步，因为在任何给定时间，地球上仍然存在的黄金比过去几千年、几百年或几十年开采的黄金更难找到，更难提取。"
- 这意味着黄金供应的增长率（每年约1.5%）远低于全球GDP增长率，使其成为稳定的价值衡量标准。
- 比特币是第一个真正意义上的数字黄金，它是一种以时间为基础的货币。
- 区块链技术的核心是创造一个不可篡改的时间戳记录。”
- 一个以时间为基础的货币体系，将更有利于长期的储蓄、投资和创新。未来的货币政策应该致力于稳定货币的时间价值，而不是操纵利率。
- 中本聪的区块链发明是"一个'统一体'，解决了世界经济双重失败范式的两个方面：互联网安全的崩溃和货币的丑闻。
- 区块链的关键创新：每个全球网络上的节点——你的电脑、你邻居的、杰夫·贝佐斯的和比尔·盖茨的——都可以保存整个网络上发布的每笔交易的完整历史记录，按时间排序。
- 因为每笔新交易都带有所有先前交易的不可磨灭的数学印记，它不能与记录中的它们分离，也不能被伪造。
- 比特币的致命缺陷：通过在2141年设定2100万单位的上限，这个上限对比特币作为货币是致命的货币供应必须能够随着生产经济的扩张而扩张。比特币极其波动——在紧张的日子里上下波动高达20%。

# 四、资本主义未来之路

###  **走出稀缺迷思，拥抱丰裕未来**

- ‘增长极限’理论是20世纪最有害的迷信之一。它低估了人类的创造力，高估了物质资源的限制。
- 历史一再证明，当一种资源变得稀缺时，人类会通过创新找到替代品或提高效率。
- 我们不是生活在一个原子稀缺的世界，而是生活在一个知识丰裕的世界。
- 经济学不应该是关于计算原子，而应该是关于激发思想。
- 将二氧化碳视为污染物是错误的，它是地球生命的基础。我们不需要回到‘新石器时代’，我们需要进入一个‘新碳时代’——一个我们更聪明地利用碳资源的时代。
- 对化石燃料的妖魔化，正在剥夺数十亿人获得廉价可靠能源的机会。 可再生能源（如风能和太阳能）是不可靠且昂贵的，无法支撑现代经济。我们应该投资于核能等更清洁、更高效的能源技术。
- 技术进步，特别是信息技术和生物技术的发展，将为我们带来一个“丰裕的时代”，人工智能、基因编辑、纳米技术等将彻底改变我们的生活。”
- 挑战不再是生产，而是如何利用这种丰裕来创造有意义的生活。
- 我们必须警惕那些试图通过制造稀缺（例如通过过度监管或知识产权滥用）来获取权力的人。
- **未**来属于那些拥抱丰裕、拥抱变革的人。

### **后资本主义繁荣之路**

- 我们必须放弃将经济视为机器的观念，并将其视为一个学习系统。
- 我们必须认识到，财富的源泉是知识，增长的动力是学习。
- 教育体系需要改革，以培养创造力、批判性思维和终身学习的能力。
- 我们必须拥抱‘意外’，并为企业家创造一个能够自由实验和冒险的环境。
- 我们需要一个稳健的货币体系，一个能够准确衡量时间的体系。这意味着要限制央行的权力，允许货币竞争。
- 自由市场、有限政府和法治是实现繁荣不可或缺的基础。
- 自由是经济增长的第一要素。政府的角色应该是保护产权、执行合同和维护秩序，而不是试图管理经济。税收应该低廉、简单和公平，以鼓励工作、储蓄和投资。监管应该被最小化，以避免扼杀创新。
- 保持政府规律和可预测，作为低熵载体，而不是不可预测的高熵操纵者。
- 保持货币像时间一样可预测、不可逆转、无欺诈和可替代。
- 允许破产和失败。它为新创造开辟了未来。
- 促进实验（加密货币、碳基发明、新商业模式），但不要预先确定或补贴结果。
- 支持贸易和交换，通过知识和权力的分散扩大机会和创造力。
- 不要控制价格。它们是分散信息和知识的宝贵来源。"
- 不要给予保证。熵和惊喜是定义信息、知识和学习的东西。
- 不要补贴现有的经济权力结构。存在的东西是过时的。
- 不要对抗不确定性——未来是不可预测的；如果你让它发生，它会比你想象的更好。
- **记住你不在控制之中。**

### **经济学的信仰**

真正的资本主义应该是：

1. 基于知识和学习，而不是物质和稀缺
2. 由企业家的创造力驱动，而不是政府的计划
3. 用时间来衡量价值，而不是用操纵的货币
4. 拥抱惊喜和不确定性，而不是寻求虚假的稳定

- 经济不仅仅是物质或信息的交换，它还建立在信任、道德和对未来的信念之上。
- 资本主义不仅仅是一个经济体系，它也是一个道德体系，它建立在信任、诚实和对他人的服务之上。
- 企业家精神需要一种近乎宗教的信仰——相信未来会更好，相信他们的努力是有价值的。
- 一个没有信仰的社会，不可能有长期的繁荣。
- 吉尔德的核心信息是：**人类的心智是终极资源**。
- **在一个知识成为财富、学习成为增长、信息成为“意外”、时间成为货币的时代，我们必须将焦点从物质转向思想，从控制转向创造，从稀缺转向丰裕。**
- **后资本主义生活，最终是关于重新发现我们作为创造者的角色，并以信仰和勇气去拥抱未来。**
