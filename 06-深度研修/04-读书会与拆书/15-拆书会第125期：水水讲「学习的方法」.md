# 正式开始

#  AI时代的学习：人要比AI凶残

- 20个实习生很有用，但有限
- 通才式ceo比专才收入高出19%
- 通才的前提是专才：一个90分的专+N个70分才是通才
- 人要更像人：复杂决策能力
- 决策能力的学习，实践之外源自多学科的学习

# 学习从来都是碎片式的

- 大脑的摄入过程就是碎片的
- 真正的结构存在于你的大脑里，而不是书本上
- 不要迷恋思维导图
- 大脑里的知识树，独家所有，无可取代
- 抓住所有机会学习，你不需要完整的时间和完整的精力

# 刻意练习的本质：只在非舒适区练习

- 一万小时定律是错的
- 只在学习区学习
- 舒适区，学习区，恐慌区——流畅的自动化不是学习，艰难的输出才是
- 学习就是找到从把学习区练成舒适区，再让恐慌区变成学习区，循环往复的过程。
- 最优学习效率数值：15.87% （新知的比率）
- 只在痛苦区反复练习，通盘练习很开心但是无意义
- 艺术的基本功毫无艺术感，创业的基本功毫无快感
- 业余球员每天能踢8个小时，职业球员最多2小时
- 随机轮番折磨比同一个动作猛练效果好
- ABC三组实验——现实世界的挑战是非连续的
- 即时反馈：没有测验，学习只是幻觉
- 最好的体育教练都是“无趣的数学家”，像素级的挑毛病
- 不追求乐趣，想要赢的才是刻意练习

# 记不住怎么办

- 多记几遍，没任何别的办法。
- 中年记不住了，是因为记得次数太少了
- 不要用年龄当借口：中年人大脑60岁之前都是巅峰状态
- 神经元反复激活就会连在一起，髓鞘反复“摩擦”就会越来越厚越来越高速

# 方法论代替不了练习，术比道重要100倍

- 中国作家最缺少的就是工匠气 ：李娟
- 学围棋不会提高数学水平，做数学题才会。看剧不会提高写作水平，不停的写才会。
- 只有高手才真的懂高手：老虎伍兹厉害在哪里？埃隆马斯克的实诚

# 寓教于乐是错误的学习方式，兴趣不是最好的老师

- 娱乐/游戏化，愉悦的方法都是学习的敌人
- 纪录片，TED演讲，都只是娱乐不是学习
- 思维导图不是好的记忆路径
- 兴趣不是原生的
- 兴趣只在起点和塔尖的两端有用
- 你学的越多，有兴趣的东西越多
- 用灵魂去热爱小提琴的爱因斯坦是8流演奏家

# 学习者不配提天赋和灵感

- 越业余越爱说灵感，越懒惰越推推崇天赋
- 三流的艺术家才说灵感，一流的艺术家靠练习
- 决断力也是练习的结果
- 专业直觉是长期思考的沉淀
- 赞美牛人的天赋，大概率是侮辱
- 我们忽略了天才的稀有程度
- 普通人的天赋在努力面前不值一提（人人都有）

# 中年危机是伪命题

- 自证预言，懈怠者的遮羞布
- 中年大脑下降的能力：计算速度（计算机）和注意力（想的更全面）
- 提升的能力：模式识别、空间想象、逻辑推理、幸福能力（情绪控制）
- 流体智力：快速运算的能力童子功，儿童和少年最强，成年后逐渐下降——围棋、数学
- 晶体智力：成熟的决策能力，复杂的智慧——随年纪增长，中年后受学习能力影响巨大
- 日本美国飞行员退休年龄从60到67岁
- 到老年才是大脑的全面衰弱
- 延缓大脑衰老的最重要因素：文化程度和认知能力
- 人类的衰老正在变慢：2000年的58岁等于1970年的51岁

# 最好的学习方法只有一种

- 最好的足球打法只有一种风格
- 欧洲大陆足球破译足球的秘密：多传球，快速推进，避免粘球。传球总数，传球距离，射门次数的精算《足球经济学》
- 欧洲的日益强悍和巴西阿根廷原始足球的没落
- 中国足球为什么不行：距离现代足球体系太远，没有现代足球的青训营
- \*围棋的最优解：人工智能教会所有棋手点三三（从占完星位就拆边到所有人都点三三）
- 被证伪的VARK学习风格模型：听，说，读，行
- 喜欢的风格和实际的效率，没有关联。

# 科学的学习方法

1、非线性时间间隔，重复训练/测试

day1,day3,day10,day30,year1.

多场景配合/交替练习同一个内容

2、知识之间建立连接：新知识连接在自己的旧系统上

重点是“自己的系统”而不只是系统性思维

一本书，作者的体系并不重要，你自己的体系才重要

\*漂亮的思维导图是糟糕的记忆工具，优秀的思考工具

3、混合练习：交替练习，千万不要让自己舒服

网球训练：a固定练习（每次重复1个动作）b顺序练习（固定顺序不同动作）c随机练习

a进步最快，训练成绩最好，c进步最慢，比赛成绩最好

数学：交替组比组合组正确率高出2倍

钢琴（跨15个琴键\*200次，还是分别跨8个，10个，15个加起来200次）

海豹突击队和运动员

# 记忆力模型

- （随时间减弱的）记忆力遗忘曲线的过时
- 我们如此恐惧遗忘
- 巴拉德的证伪：诗歌默写实验（学完5分钟和两天之后的测试成绩差距10%)
- 原因：遗忘曲线基于无关联的信息，并不符合主流学习场景（有关联）
-  记忆力模型：存储强度+提取强度
- 存储强度：存储的牢固程度
- 存储强度不会随时间减弱，只会越用越强
- 大脑的储存空间：1000亿神经元网络，上千tb300万套电视节目同时播放，够存一生中每一秒的所有信息
- 神经元网络的核心部位：内嗅皮层（过滤信息）、海马体（筛选 连接组合信息）、新皮层（打标签 储存信息）
- 每个神经元最多与其他神经元产生一万个连接，一粒沙子大小的大脑组织包含十亿个连接
- 你的脑子其实相当够用：大脑的信息容量等于华尔街日报600万年的信息总和
- 额叶皮质：大脑决策者，理性的源头，20多岁才能长完整（青春期的冲动和暴躁是生物学决定）
- 感性和理性：额叶皮质的强与弱，不能自控可能是是硬件问题
- 提取强度：提取使用的难易程度
- 时间越久越低，提取频率越高越强。
- 记忆力下降，记不住东西，是提取强度出了问题
- \* 记不起的小学同学
-  遗忘的重要功能：先忘记，再想起，提取的时候越痛苦，对两个强度的增加值久越大
- 忘记不是记忆力不好，忘记是学习的必要环节
- 不要每天重复，要有时间间隔
-  考试的功能：强行提取的优质练习，让知识更牢固——费曼学习法的本质
- 先测验后复习：汲取重要信息，聚焦
-  考试100分 ，考完就作废（存储强度低）
- 几本书同时看的好处：激活提取强度

# 学习的凋零效应：慢比快好

- 快速灌短期优势，后劲不足逐渐凋零
- 美国空军学院：什么样的老师最好？成绩不是最好，但规定内容以外的，知识的连接
- 慢慢学会比快速掌握要好 ：文字远远好于视频，有障碍才记的牢
- 记忆力宫殿、速读都是邪门武功
- 速度从来就不是学习的目的 没有和知识体系的连结
- 大脑30%的区域用于视觉，所以我们更喜欢图像信息——但喜欢不代表最有用

# 流利比理解更重要

- 你以为你懂了，其实并没有
- 流利是理解的前提
- 用学俄语的方法学数学：数学恐惧症奥克利从俄语翻译高龄转型数学家（大学工程学教授）‘
- 公式反复练习不断试错，
- 我们对教育过分注重理解而忽略了流利——到真用的时候就菜了
- 要给大脑充分时间和摩擦拉扯，知识才能长在大脑里
- 流利才可能快速调用、准确调用，无意识的使用才是知识
- 你必须记住一些东西，而不只是“重点框架”
- 你的大多数使用场景是没有谷歌的
- 框架很重要，但缺的砖瓦（知识点）太多了，大厦就垮了
- 搜索引擎有用的一个前提是：你得能想的起搜什么
- 要舍得重复看书，但不用一看到底
- 书里的故事也值得被记住，那是记忆的引子

# 重新理解专注

- 高倍速听不是为了学的快，而是为了获得更高专注力。
- 每个人都是单线程工作动物
-  被低频打断让学习更高效
- 蔡加尼克效应：极度投入注意力时被打断切换新任务，任务的完成效率高出一倍
- 做数学题不断切换，成功率比挨个做，成功率高出30%
- 底层：对完成目标的强烈的渴望、打断之后思考并不会停止，大脑感知力的极限调动，自动捕捉关联
- 打断切换的频率：主流认为50分钟左右
- 番茄钟总体不靠谱（周期太短），适合多动症
- 一篇文章写到高峰时停止，明早再写

# 分心利于提出创造力

- 蒂姆哈福德：任意的震动 偶然分心利于发挥创造力
-  弊端：没谱儿，低效、浪费
-  默认模式网络：注意力松弛，创造力的来源，建立连接，走神的好处
- 看电视打游戏不算默认网络——注意力仍然需要集中
- 环境：散步，睡觉，发呆，冥想，白日梦，洗澡（阿基米德）
- 多数时候集中思维比发散思维更重要——大多数脑力工作不需要创造，而需要苦逼的稳定输出
- 砖头的50种用法，小孩比大人更厉害，因为小孩集中思维比较差
-  用发散思维提出问题，用集中思维解决问题

# 学习：以我为主

- 以“我”为主才是真学习
- 任何学习的本质都是自学：老师是启蒙监督和反馈，学校是激活的环境
- 塔勒布——每周阅读50个小时/大学买下所有“概率，风险，随机”的书
- 自我管理：时间、计划、收集资料、自我判断、执行力
- 学习：学习是塔尖的行为
- 不要跪任何“书”：精神上迷恋大师，智力上他是你的“服务者”
- 不要仰视作者，平视他，甚至批判他
- 无敌浪费书的土豪 泰勒科文
