# 年度分享开始

# 值钱的人类：做一个永远在场的人

- 每天都惊呆的ai时代，不要对抗焦虑，与焦虑共生。焦虑是推动力。
- 是否被ai取代不是真问题，以“我”为主体去构建自己的秩序。世界怎么样是世界的事，我怎么活是我的事。
- **情绪不是现实，现实才是现实**。放弃确定性，强化主动性。
- 要接受，从此之后，‘稳定’会成为我们普通人消受不起的奢侈品。
- 不相信任何预测，只相信“我可以变化”
- 乐观就是理性，理性就是乐观。
- 安全感的本质：站树上的鸟，从不会害怕树枝断裂，因为它相信的不是树枝，而是自己的翅膀。
- “ai更强了”和“我更强了”，是两件毫无关系的事。85分就是ai时代的60分。
- 工作不等于任务。任务会被ai替代，价值不会，解决问题不会。
- “若一去不回就一去不回”只有人类会有这样的胆识和雄心。
- ai会收拢于目标函数。但人类的不算计，成就了伟大。
- 理性会让你在80%的时候避坑，20%的时候错过机会
- AI能让产能可以扩大十倍，能让需求扩大十倍吗？
- 企业降本增效只是基础，就像会打字一样，不值钱。
- ai真正的价值，是提供新的生产力——去做到原来人类自己做不到的事情，满足原来无法被满足的需求。这才是唯一需要长期关注的。
- AI时代，谁说的比说了什么更重要。不完备的、充满偏见的洞察和思考，永远稀缺。
- 人味儿是财富。刻意练习去做一个增强版的人类。
- 好人才的标准“今天面试了一个活的”。
- LinkedIn 职位总数下降，但 storyteller（叙事者）职位出现的频率翻了一倍。
- ai垃圾遍地，活人味儿的品牌比以往更重要了。品牌降低信任成本，高价值投名状。

# 值钱的自己：我是我注意力的总和

- “成功就是，当我在任何时刻从所做的任何事情中抽身出来，我可以说，我极其专注并且倾尽全力。至于结果，并不由我决定，我从来没有说一定要赢。我说的是，我专注了、我学习了、我尽了最大努力”
- 放下低级趣味，乱我注意力秩序的一切，不可保留。人无法在有蟑螂房间里还能保持清新的呼吸
- 项飙：严肃性和深度，才是解压的最好方式。
- 谷爱凌：“上学就是训练的休息，做时尚就是上学的休息，轮流来！一件事是另一件事的休息。”
- 存量的世界，没有任何仁慈可言。放弃一切幻想。
- 存量和存量思维是两件事。腾讯是最大的存量，互联网世界的一切增量都会变成腾讯的存量。
- 不要对存量认命。保住存量，向外部世界拓展自己的增量，而不只是探索内心世界。
- 外部世界扩大10倍，内心世界自会扩大10倍。内心是世界的投影，坚定的唯物主义。
- 对抗爹味最好的方式，是每天主动去创造失败的机会，失败使人谦卑，干活使人不屑对他人指手画脚。
- 工作不是工具，工作本身就是目的。在一次次的挑战里，磨难里，危机的解决里，持续获得力量和快乐。
- 不要希望,直接行动。不要希望变得更好，而是采取行动让一切变得更好。
- 用行动代替语言，用行动代替解释。
- 你不是由你掌握的模型和方法论定义，你由你的行动和结果定义。

# 值钱的状态：活色生香是核心竞争力

- 信念系统和利益系统是一件事——你愿意为了什么去效力去持续付出，不惜成本。利益共同体和信念共同体是一件事，利益不是我想要什么，而是我愿意付出什么。
- “把一切都怪到自己头上,这样才能保住主动权。”
- 乐观的本质，是理解变化，并包容那些意想不到的可能性。
- 马丁·海德格尔：告别“常人”。“常人”不是指某个具体的人，而是指一种匿名、平均化的存在状态——我们放弃了自我，活成了社会期待、舆论潮流和既定规范的奴隶。
- 做一个有“上行心态”的人。不畏缩，不要怂，不理会别人的叹息。要发展，要繁荣，要“活过”。
- 保持莽撞，保持鲁棒，保持野心勃勃。攻击力就是生命力。
- 欲望永不满足，贪嗔痴是碳基生物最后的特征。
- 人从出生就被判了死刑，我们要兴高采烈的老去。
- 彼得·圣吉：在所有的修行传统中，不仅仅是佛家、道家，而是在东西方几乎所有的修行传统中，最基本的思想是:你不是生而为人，你花费你的一生来成为人。
- 成人不是成品，是成长中的人。
- 痛苦不是来自欲望太多，而是欲望太全面了
- 把‘过去如何’改变成‘我将如何’。不执着于发现“我是谁”，专注于“决定我想成为谁”。我们不是在发现自己，而是在重新创造自己。
- 我，是动词。我在营造我。
- 真正的觉悟，不是平衡，而是勇敢的进入一次又一次的失衡。智慧是对无常的不恐惧。
- 快速正反馈是毒药。在无人理解的角落里，日复一日地坚持做正确的事。
- 时间就是实践。你过去做了什么，才是属于你的永恒。永恒取决于我现在在做什么。
- 不要跟着社会时钟走，不跟着别人的节奏走，跟着自己的时钟走。人可以定义自己的时间
- 聪明是靠不住的。
- 你是一个什么样的人，比你想要成为什么样的人重要。你的能力和你坚守的原则，决定了你能在商业上拿到多大结果。至于你想赚到十个亿，这件事并不重要。
- 你的行动，就是你唯一的解释。
- 坚持出现。成功的99%就是坚持出现。做一个永远在场的人。
- 在“坏”选项远多于“好”选项的世界里，拒绝“坏”比寻找“好”更重要。不要在沙子里淘金子，而去找到金子。

# 值钱的学习：保持凶猛，保持机警

- 杨振宁：真正的进步，不是你记住了多少知识，而是你直觉发生的变化。
- 知识为直觉服务，想法为行动服务。
- ai无法取代读书，读比以前更多的书，像喂养ai一样喂养自己的神经网络。
- 亚当斯：“你学习到的所有东西都会成为你理解其他事物的捷径。”
- ai有一万种方式机会帮大脑偷懒，保持大脑锋利是我的责任。运动无能机器可以代劳，脑力腐化不可逆转。
- Karpathy ：“Software 2.0 自动化了创造，却把验证留给了我们。”
- 理科生负责制造，文科生负责为它标价
- 硅谷：品位是唯一的壁垒。珍惜 taste，练习taste。
- 当“制造”变得极其廉价，“鉴赏”就成了最昂贵的能力——当拥有无限选择，人们需要有人告诉他应该选哪一个。
- 品位不是来自输入，而是输出。美食家不是因为会吃，而是会写。
- “文科就像短剧里的雪，你要是逼问学文科有什么用，获得的答案仿佛就是没有用，毫无必要。但人总是需要雪的。”
- 无法被解构的，不代表没用。无法被量化的，不代表没有价值。
- 有了AI，正确变的不重要，探索本身才重要。当你拥有的知识越少，越匮乏，你越容易正确。有用的都会错，不会错的都没用。
- 目标是为失败者准备的，系统是为成功者准备的。
- 方法：1、用碎片时间输出，用整块时间输入（张zara）

                  2、主动记忆（卡尔·纽波特）

                  3、先实践后学习（奥特曼）

# 值钱的生意：主动创造稀缺性

- 只做特赚钱的事和完全不赚钱的事
- 高客单=对的人+对的钱
- 故事会越来越值钱。摆事实讲道理无法形成共识，故事可以。花钱即用户与你达成共识。
- 情绪价值不如情感价值值钱。iphone17参数被吊打，4个月卖出1500万台，超过后面9名之和——情绪随时可以被撩拨，被控制，会降温会转移，而情感是稳定而持久的。
- 爱你，还是爱你便宜。这个要想清楚。
- 用户要的是尊重而不是讨好，人性慕强，他们渴望被摧枯拉朽地征服。
- 平庸是原罪。You have to be out to be in  你必须非主流才能入流
- 人心永恒向上，泥巴里仰望星空是本能。“我从中看到我自己”，是不值钱的故事；“我看到我想要成为的样子”是值钱的故事。不值钱的故事让人流泪，值钱的故事让人花钱。
- 每一步都很难，但卖的贵一点，让难，变得比较值得。
- 贵，是逼着自己持续做正确的事。贵让人坚定和忠诚。
- 导演塔西姆·辛：“你花钱买到的不只是我做导演的这段时间，还有我喝过的每一口酒，品过的每一杯咖啡，吃过的每一餐美食，读过的每一本书，坐过的每一把椅子，谈过的每一次恋爱，去过的每一个地方。你买的是我全部生命的精华转化成的30秒，怎么会不贵。

     ——所谓第五消费时代，就是以上变现的时代。

- 年度案例：Edwin Chen未拿一分投资，构建12亿美金的Surge AI

Chen使用少数几个对大多数SaaS公司来说会很陌生的指标来运营Surge：

● 人均收入：目标：1000万美元+ (当前：990万美元)

● 客户终身价值：目标：1亿美元+ (当前：9200万美元)

● 标注员时薪：目标：150美元+ 平均值 (当前：172美元)

● 一次通过准确率：目标：99%+ (当前：99.2%)

● 客户员工比例：目标：10:1 (当前：10.1:1)

● 决策速度：目标：<24小时 (当前：平均18小时)

注意缺少了什么：用户增长、营销指标、销售漏斗。

Surge不追踪虚荣指标，因为它们对其商业模式无关紧要。
