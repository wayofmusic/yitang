# 第一部分：看懂词元——财富的新计算单位

## 第一章：词元是AI时代的货币

### 从 Token 到“词元”

- 2026年3月23日，国家数据局局长刘烈宏正式将Token的中文标准译名定为“词元”，明确了它的定义和产业意义。
- 刘烈宏局长： **词元不仅是智能时代的价值锚点，更是连接技术供给与商业需求的结算单位，为商业模式的落地提供了可量化的可能 。**

### 可计量、可定价、可交易：词元的货币属性

#### 第一，可计量

无论是文本生成、代码编写，还是多模态任务，模型处理的信息都可以转换为一定数量的输入词元和输出词元，并据此统计资源消耗。

通常，AI 服务会分别统计：

- 输入词元（Input Tokens）：模型需要理解的信息
- 输出词元（Output Tokens）：模型生成的信息

词元的意义在于：AI 的使用成本开始可以被精确核算

#### 第二，可定价

- 大模型服务商可以按照输入和输出词元数量收费：用了多少，支付多少。
- 从过去的：“一套软件多少钱”转变为：“完成这项智能任务消耗多少词元、成本多少钱”，它背后是一种非常重要的商业模式变化。

#### 第三，可交易

词元可以在产业链的各个环节之间自由地流转、分配和结算。上游的算力提供商，把算力卖给模型厂商，模型厂商用算力生产词元；中游的平台服务商把词元打包，卖给下游的应用开发商；下游的应用开发商再把词元封装成服务，卖给最终的用户。

## 第二章：词元经济的三层格局：你在哪一层，决定你赚多少钱

- 在GTC 2026的主题演讲上，英伟达CEO黄仁勋向全场十万名观众描绘了一个全新的图景： **数据中心相当于全天候运转的词元工厂，原材料是数据和电力，产品是词元 。**
- 黄仁勋提出了一个全新的指标： **每瓦词元数（Tokens per Watt）** 。这个指标衡量的是每消耗一瓦电力，能够生产多少词元。 **它将成为词元经济的核心KPI，决定着谁能在竞争中获胜 。**

### 词元经济的三层产业结构 - 财富机会在上游

| **层级** | **角色** | **商业模式** | **核心能力** | **赚钱方式** | **主要问题 / 优势** |
|-|-|-|-|-|-|
| 下游 | **词元消费者** | **调用大模型 → 消耗词元 → 提供服务** | AI 工具应用、服务交付 | 接单、做文案、PPT、图片、视频等 | 门槛低、容易复制、价格竞争激烈
收入与时间高度绑定，缺乏长期积累 |
| 中游 | **词元服务商** | **采购词元 → 打包服务 → 转售用户** | 资源整合、渠道、流量、客户关系 | 赚取词元差价、软件服务费、代理返点 | 利润空间有限，容易陷入价格战
上游厂商可能直接服务客户 |
| 上游 | **词元生产者** | **算力 + 模型 + 数据 → 生产词元 → 供给市场** | 算力、模型、成本控制、规模化生产 | **向开发者、企业和平台提供模型与 API 服务** | 进入门槛最高，但更接近核心生产资料，规模效应和议价能力更强 |

再精炼如下

| **层级** | **一句话理解** | **财富逻辑** |
|-|-|-|
| 下游 | 用词元干活 | 用时间换钱 |
| 中游 | 买卖和包装词元 | 赚服务费与差价 |
| 上游 | 生产并供应词元 | 靠规模、效率与技术赚钱 |

### 财富增长的核心逻辑

- **上游的词元生产者** ： **不需要拼时间，不需要拼价格，只要把生产线建好，就能实现持续盈利，能够实现财富的自动增长 。**
- **中游的词元服务商** ： 做着中间商的生意 随时会被上游巨头侵占利润，需要时刻警惕被替代的风险。
- 下游的词元消费者： 在消费环节内卷 市场越来越内卷，空间越来越小，难以实现真正的财富自由。

## 第三章：词元不等于代币：合规、安全、国家支持的财富赛道

### 词元≠代币

词元和虚拟货币、代币是两码事，有着本质的区别。

### 国家的明确态度：一禁一倡

- **一禁：** 严厉打击虚拟货币：虚拟货币、代币是国家严厉打击的对象 过去几年见过太多打着"区块链""代币"名义的骗局 很多人被割韭菜割怕了。
- **一倡：** 大力支持词元经济： **词元是国家大力支持的，是合规的，是安全的 是真正服务于实体经济的财富赛道 。**

# 第二部分：词元经济铁三角：电力—算力—词元

## 第四章：电力：词元的第一成本，也是第一壁垒

### 电力成本占比高达 60%-70%

行业运营数据显示， 在一个AI数据中心的运营成本中，电力成本的占比高达60%到70% 。也就是说，你每花10块钱运营一个词元工厂，就有6-7元钱是用来买电的。剩下的3-4元钱，才是硬件折旧、运维、带宽等其他成本。

### "一度电的逆袭"的故事

**在新疆的戈壁滩上，一度光伏电的上网价格只有0.15元人民币** 。这度电，如果只是卖给当地的居民，它就只值0.15元。如果把它通过特高压电网输送到上海，卖给东部的工厂，加上传输损耗，加上过网费，它能卖到0.6元左右，价值翻了3倍多。但是，如果我们把这一度电留在当地，流过GPU， 转化为词元，然后通过光纤网络卖到全球市场，它的价值会变成多少？答案是：几美元，甚至几十美元！

这就是为什么所有人都在疯狂地建词元工厂。这就是为什么我们说，搭建词元生产线就等于拥有了一台"印钞机"。因为一旦你搭好了，它就能自己运转，自己生产词元，自己赚钱，不需要你再投入太多的精力

### 电力决定定价权

电力不是可有可无的后勤保障，它是词元生产的第一成本，是决定你定价权的核心要素。 **谁掌握了更低的电价，谁就能在全球词元市场上，拥有无可匹敌的成本优势，谁就能掌握定价权**

### 西部绿电：巨大的竞争优势

- **甘肃庆阳** ：作为"东数西算"的国家枢纽节点之一，当地的绿电不仅清洁环保，而且极其便宜。

- **字节跳动在乌兰察布** ：建了一个超大规模的AI数据中心，这个数据中心全部用当地的风电、光伏供电，绿电占比超过90%。当地的电价只有0.28元/千瓦时。这意味着， **字节跳动的算力生产成本天生就比那些建在东部的公司低了30%以上。这就是为什么字节跳动能以极具竞争力的价格，向外提供算力服务 。**

- **阿里巴巴在宁夏** ：全部采用当地的风电、光伏供电，配套了大规模的储能系统，还做了弹性的算力调度。最终，绿电占比超过了90%，供电稳定，完全能满足AI数据中心24小时运转的需求。 **这就是绿电的优势，它不仅便宜，而且稳定，完全能支撑词元工厂的持续运转**

### 中国的核心竞争力：词元成本只有美国的 1/10～1/6

100万词元需要多少电？

根据国内电力机构的测算， **当前主流大模型在高强度推理任务下，生成100万个词元平均耗电量为15-20度电**

如果是 **在美国** ，按照最高电价来算，这20度电的成本就是20×1.1= **22元人民币**

而在 **中国西部** ， **一度电只要0.15元，20度电只要3元** 。这就是中国词元成本只有美国1/10～1/6的原因

## 第五章：算力：词元的生产机器

### 算力不是显卡，是词元工厂

- 普遍的误区：算力是显卡
- 实际上，算力是一个完整的工厂，是一个把电力转化为词元的精密系统。这个工厂的核心早就已经发生了翻天覆地的变化。 **过去大家都在抢着训练算力，抢着训练大模型，但现在战场已经彻底转移了。推理算力才是词元财富的真正主战场**

在过去两年，大家一提到AI算力，想到的都是训练算力，就是那种用来训练大模型的、超大的算力集群。比如训练GPT-4，训练 Llama，需要几万张GPU，跑几个月

但现在，战场已经彻底转移了。推理算力才是词元财富的真正主战场。为什么？ **因为训练是一次性的，而推理是持续的、海量的、永无止境的 。**

2026年，全球AI芯片的市场规模，预计突破2800亿美元。其中， **推理芯片的市场** 规模达到了1450亿美元，占 **比约52%** 。 **训练芯片** 呢？只有950亿美元， **占比约34%。** 在中国，这个趋势更明显。IDC的数据显示， **2026年，中国的GPU服务器市场，推理算力的占比已经达到了70%，训练算力只占30% 。**

### 每瓦词元数（Tokens per Watt）：核心 KPI

黄仁勋说，这将是未来衡量数据中心收入能力的核心指标。为什么？ **因为"在固定功率限制下，谁的每瓦词元数吞吐量最高，谁就拥有最低的生产成本"**

## 第六章：词元生产公式：决定你能否赚大钱

### 词元成本 = 电力成本 + 算力折旧 + 模型效率

- **电力成本** ：这是最大的成本项，占比 60%-70%。谁掌握了更低的电价，谁就掌握了定价权
- **算力折旧** ：硬件的折旧成本。规模化运营能把硬件利用率拉到90%以上，24小时不停转，大幅摊薄成本
- **模型效率** ：这是最有技术含量的一部分，也是最能拉开差距的一部分。同样的硬件、同样的电力，不同的模型，能生产出来的词元数量，可能差了好几倍

### 词元收入 = 专业价值 + 稀缺性 + 规模效应

- **专业价值** ：这是最大的溢价来源。词元越能解决具体行业问题、创造实际业务价值，价格就越高。通用词元只能完成聊天、写作等基础任务， **而工业、医疗、法律、金融等垂直领域的专业词元，因为融合了专业知识和业务经验，往往能获得更高溢价**
- **稀缺性** ：这是决定高价的重要因素。 **独家数据、独家模型、稀缺算力、低延迟能力，以及难以复制的行业知识，都会形成稀缺性** 。别人越难生产出同样的词元，你就越有定价能力
- **规模效应** ：这是放大利润的关键。随着词元生产规模扩大，算力、硬件、研发等固定成本被持续摊薄，模型利用率和生产效率不断提升，单位词元成本越来越低，从而形成更高的利润空间和更强的价格竞争力

### 利润 = （收入 - 成本）× 规模 = 低成本生产 × 高价值定价 × 规模化供给

### 两种核心财富路径

1. 低成本规模优势：把成本做到极致，靠规模赚钱，适合普通人、中小团队
2. 高价值专业优势：深耕垂直行业，靠专业壁垒赚钱，适合有行业资源的专业人士

| **对比维度** | **第一条路径：低成本规模优势** | **第二条路径：高价值专业优势** |
|-|-|-|
| 核心逻辑 | 把电力、算力、模型效率做到极致，持续压低通用词元成本，再以极具竞争力的价格规模化供给市场 | 避开通用词元市场的价格战，深耕垂直行业，提供高价值的专业词元服务 |
| 赚钱方式 | 低成本 × 大规模，靠薄利多销赚钱 | 高价值 × 高溢价，靠专业能力和长期客户赚钱 |
| 定价策略 | **成本路线定价，例如按成本的 3 倍定价** | **按专业价值定价，价格可达到通用词元的 10–100 倍** |
| 适合人群 | 普通人、中小团队、创业公司 | 有行业资源、行业数据和专业能力的人 |
| 核心优势 | 单位成本低，可以依靠大量中小用户快速扩大规模 | 专业壁垒高、替代性低，利润空间更大 |
| 典型案例 / 领域 | **MiniMax：通过低价格和大规模调用形成规模优势** | **医疗、法律、工业、金融等高价值垂直领域** |
| 关键竞争力 | 电力成本、算力效率、模型优化、规模化供给能力 | 行业知识、专业数据、业务理解、专业模型能力 |
| 财富逻辑 | 每个词元利润较低，但靠海量调用放大总利润 | 单个词元价值更高，即使规模较小，也能获得较高利润 |
| 共同方向 | **规模效应：规模越大，固定成本摊得越薄，单位成本越低，最终利润越高** | **规模效应：客户和调用规模扩大后，专业能力可以被持续复制，边际成本下降，利润进一步放大** |

# 第三部分：搭建你的第一条词元生产线

## 第七章：入门：用最小可行产品验证你的模式

### MVP 验证的核心步骤

1. 选择一个开源模型（如Llama 3、Qwen等）
2. 选择一个算力平台（如云服务器、算力租赁平台）
3. 使用一键部署工具（如VLLM）部署模型
4. 设计一个简单的应用场景
5. 找到几个种子用户进行验证

### 数据版权：容易被忽略的合规风险

| **重点** | **说明** |
|-|-|
| 数据来源要可追溯 | 网络公开数据、GitHub 项目、文档资料等，都要确认原始来源与授权情况 |
| 开源协议要筛选 | 不同开源协议对修改、分发和商用的要求不同，不能把“开源”简单理解为“随便用” |
| **MIT、Apache 2.0** | 相对宽松，通常允许使用、修改和商业化，但仍需要遵守许可证中的版权声明、NOTICE 等具体要求 |
| **GPL 等 Copyleft 协议** | 对修改、分发及衍生作品可能附带 **更强的开源义务，闭源商业项目需要特别谨慎** |
| 公开数据也可能侵权 | 文章、书籍、报告、图片、代码等即使能在网上获取，也可能仍受版权保护 |
| 训练前需要数据清洗 | 过滤来源不明、未经授权、可能侵权或许可证不符合项目要求的数据 |
| 建立合规记录 | 保存数据来源、许可证、授权方式和清洗记录，便于后续审计和风险追踪 |

## 第八章：算力：如何用最低的成本拿到最高的算力

### 算力的来源不只是云服务器，还包括：

1. **云服务器：** AWS、Azure、Google Cloud、阿里云、腾讯云等
2. **二手GPU市场：** 从矿场、倒闭的AI公司购买二手GPU
3. **算力租赁平台：** CoreWeave、Lambda Labs、Vast.ai 等
4. **边缘计算：** 利用闲置的算力资源

### 典型案例：CoreWeave 的崛起

CoreWeave是一家专门提供GPU云服务的公司，他们用低价算力搭建词元生产线，2025年营业收入超过50亿美元。他们的成功秘诀：

- 从矿场收购大量二手GPU
- 用极低的价格提供算力服务
- 专注于推理算力市场
