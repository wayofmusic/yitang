## **极简商业闭环：价值，共识，模式**

# **一、价值**

**价值公式**

- **产品价值 = 功能价值 +情绪价值 + 资产价值**
- 功能价值的四个模型
- 原材料（或劳动力）模型。
-  专利（或IP）模型。
-  平台（或供应链）模型。
- 基础设施模型。
- **情绪价值 = 生理唤起 + 认知标记 + 心理账户。**
- **情绪价值的三个付费要素：保障感、愉悦感、彰显性**
- **资产价值 = 专门交易市场（及服务）× 对手共识（价值与价格依赖）**
- 包租婆，梵高
- 对于功能需求，人们天然会去比较，然后寻求更高效、更便捷、更低成本的方案，没有忠诚可言。
- 如果我们需要一个家庭提供的是功能价值和情绪价值，你就会发现家庭很脆弱。因为商业社会里，会有无限多的专业提供者，来提供功能价值和情绪价值。家庭里一个人的供给能力，无论如何都没有办法和一个商业社会花样繁多的无限可能、无限供给相比。
- 所以，今天家庭的价值，就没有农耕时代那么“刚”了。一个家庭最有价值的部分，其实是家庭成员大家所共创的资产价值。是属于我们这个家庭共同生活，基于共同的回忆、共同的经历所构建的情绪价值和资产价值。
- 唯有在此地，你才能够拥有的共同回忆，才能够激发的情绪体验，共同的社交资产、社会资产、社会财富，这些东西是一个家庭最厚实的部分。
- **创新的逻辑：通过新功能、新情绪、新资产的组合或叠加产生创新。**
- **功能创新，情绪创新，资产创新   非同质化代币（NFT）**
- **品类进化：功能价值商品整合，情绪价值商品分化。**

**品牌的价值**

- **网红=产品价值+新鲜感+话题度。**
- **大牌=产品价值+辨识度+情感唤起。**
- 品牌是信息在人心中沉淀的结果。
- 品牌与记忆和情感关联。
- 品牌拥有定价权，白牌产品则需随市场波动。
- 网红品牌关注新鲜感与话题度。
- 大品牌关注辨识度与情感唤起。
- 可口可乐。
- 基亚与塞班。山寨机华强北时代。
- 小米与OPPO。
- 乔布斯与iPhone。
- **一个网红品牌依赖的话题度，来自外部的声量；而大牌能做到的情感唤起，来自一个人内心的低语。**
- 大家都说生意不好做。但如果从另外一个视角看，很多最基础的东西，今天的中国用户其实已经不缺了。
- 单机游戏《黑神话：悟空》发布。开售10个小时，超过400万人付费，交易额超过15亿元人民币。这件事犹如一声号角，用市场的声音在告诉大家，人们会为什么付钱？就是今天的自己没有，但是想拥有的东西。人们为《黑神话》付费，是因为那个向往自由、战天斗地的猴子，就是我们自己；人们为新荣记付钱，是因为那个事事讲究、怕丢面子的荣叔，就是我们自己；
- **这是一种超越了物质，超越了原材料的价值认同。中国人已经开始为了审美体验、精神共鸣而付费了。这就是市场的变化，而每当市场变化，总有人应运而出。**

# **二、共识**

**共识从分歧开始**

-  **感知的分歧：特性与属性**
- 产品特性的5种认知结果：魅力属性、期望属性、必备属性、无差异属性、反向属性
-  **想象的分歧：用户人设**
- **改变公式：不满情绪 × 愿景 × 第一步 ＞ 改变的阻力** 。
- 用户画像是刚需时代的工具，假设“用户需要什么，是因为他缺什么。”
- 用户人设是丰饶时代的工具，一个人的强项就是他的需求，越强的点越会引发他加倍需要和加倍投入。
- **人设 = 固定人物分类 +外在形象特点 + 性格 + 特长 +记忆锤**
- 立人设，就是在社交空间里把自己简单化、清晰化，从而让自己更容易被他人记住、被想起。
- 当对方想起你时，就知道你在他的“哪个固定人物分类里”并且立刻唤醒你的几个特征“形象、性格、特长”。
- 人设既包含了功能性描述、也包含感性认知，缺一不可。
- 合理的部分是理性，不合理的部分是人性。
-  **场景的分歧：产品场景匹配**
- 产品需要找到一个能让自己活下去的具体“场景”。
- 小产品靠口碑、大产品靠国民习惯，周期性出现的场景就是习惯产生的地方。
- 同一个产品在不同的场景里，用户的感受是不同的。场景更具体、产品更有力。
-  **利益的分歧：利益驱动**
- **任何一件事能成，一定是受益者驱动。一件事情能做的很大，一定是受益者很多。**
- 公关危机：弱者聚集讨伐强者、因为强者傲慢；强者可以调动市场资源、而弱者天然占据道德高地。
- 可口可乐。

 **认知战和关系**

- 如何构建新共识？需要一场认知战。
- **认知战5个点：信息操纵、情绪操纵、认知引导、舆论导向、心理操作**。
- 农夫山泉
- 脑白金
-  **关系：共识的结果**
- **关系的4个层次：需要、喜欢、认同、归属。**

# **三、模式**

**模式是“自己活下去的秘密”**

- 模式是一个企业构建自己的竞争力，从而活下去的秘密。
- 模式设计三大板块：
- 能力系统——企业构建自己的能力系统：认知是顶、安全是底，认知是因、创新是果。
- 认知决定了能力的顶，那什么决定认知呢？是用心、是爱，根本性的情愿，胜过一切天赋。
- 变现逻辑——赚钱能力的差别首先来自认知差，有稳定认知的人，可以用自己的价值框架来判断所有产品的价值，而交易的达成，除了价值判断，还要有控制能力。
- 分配机制——最初的天赋只能支撑一个人崭露头角，在之后长期的生存竞争里，要靠自己主动投入，配置更多地资源，我们才能拥有那些可以成为生存优势的特性。

**求真**

- 行动力是一个人的自我模式，每个人、每个企业，都是由自己的行动力塑造的。
- 所谓的打磨产品，其实是磨心：去伪存真，去掉那些妄念和矫情，让这颗心越来越诚实，越来越坦然，能够越来越如实地关照自己，关照世界。让这颗心，在我们服务的行动里，不断地更趋明净，然后在无限的明净里，看到更遥远的真、更广博的善、更生动的美。向这个世界交付自己所能抵达的真善美，是一代代造物者一生又一生的修行。
- **生生不息的就是真的**
- 什么是人世间真正的奢侈？是时间，是自由，是理想，是爱，这些是真正的奢侈，因为它们是这个世间最稀缺之物。自由、理想、爱，是我们在求生道路上往往最早抛弃的，它们成了人类社会最稀缺的东西，也成了最珍贵之物，而它们才是真正的内核。
