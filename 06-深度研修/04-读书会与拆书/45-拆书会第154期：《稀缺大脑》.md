# 拆书开始

# 一、稀缺大脑的形成与伤害

### 我们的稀缺大脑

- 稀缺大脑：在文明发展的长河中，人类大脑进化形成了一种特殊的机制：我们总是渴望更多，从不满足。
- 作为科学记者和教授，我对人类行为感兴趣。每个人都喜欢关注如何培养好的新习惯。但我想知道的是我们如何解决那些对我们伤害最大的行为。对我们危害最大的行为往往有一个共同特点：它们可以被快速重复。这些行为在短期内往往令人愉悦和有益，但从长远来看却适得其反。
- 我们都会做这样的事情。即使我们意识到这些行为已经变得适得其反，我们也很难停止。每个人都知道任何行为适度都没问题。但为什么我们如此不擅长节制呢？为什么我们吃饱了还要继续吃？为什么我们拥有太多东西却还要继续购物？为什么我们已经醉了还要继续喝酒？为什么我们刷社交媒体明知道它让我们感到痛苦？
- 这些行为通常是对"稀缺"感觉的反应。一个小小的"稀缺提示"就能触发研究人员所称的稀缺心态。这导致我们相信自己没有足够的东西，并本能地专注于获取或做我们认为能解决问题并让我们感到完整的事物。
- 稀缺提示就像空气：无处不在，在我们身边，也在我们体内。它们可以通过广告、社交媒体、新闻、与同事的聊天、在街坊散步等多种方式触发我们。它们可能是直接而全面的，比如经济衰退或全球大流行病。也可能是微妙和轻微的，比如邻居买了一辆闪亮的新车。
- 对稀缺的反应并不是什么新鲜事物。这是人类思维中自然进化出的古老行为系统，帮助我们的祖先生存。
- 今天，人们普遍接受这样一个观点：在人类历史的大部分时间里，服从下一个稀缺提示并不断渴望和消费更多使我们保持活力。我们在恶劣环境中进化，这些环境有一个共同点：它们是缺乏的世界，是稀缺的世界。
- 那些生存下来并传递基因的人追求更多。他们默认过度进食，积累物品和信息，寻求对他人和环境的影响力，以及过度追求快乐和生存本能。
- 服从这些进化的渴望让我们保持活力，对所有物种来说仍然是有意义的。。
- 随着人类在工业革命期间学会了如何更快、更便宜地制造东西，我们的稀缺环境迅速转变为丰富环境。
- 到20世纪70年代，这场革命的成果已经扩散到发达国家的大多数人群。从那时起，这些成果一直在向全球各地扩散。我们现在拥有我们进化来渴望的事物的丰富——一些人可能会说过载——的东西。像食物（尤其是咸的、脂肪的、甜的品种）、财产（装满网购商品的家）、信息（互联网）、情绪调节剂（药物和娱乐），以及影响力（社交媒体）。
- 然而，我们仍然被编程认为我们没有足够的东西，就好像我们仍处于那些古老的稀缺时代。三磅重的神经束在我们头骨中不断扫描背景，拾取并优先处理稀缺提示，推动我们消费更多。
- 我们仍然被迫吃下比我们身体需要的更多的食物。冲动地搜索更多信息。购买更多不必要的东西。为了对他人的影响力而争夺。做一切可能的事情来获得另一次短暂的快乐。关注获取我们没有的东西，而不是使用和享受我们已经拥有的东西。
- 我们有一个稀缺大脑。它是我们无法摆脱的适得其反行为的根源。阻碍我们改善身心健康、幸福感和充分发挥潜力的习惯。成瘾、肥胖、焦虑、慢性疾病、债务、环境破坏、政治争端、战争等。

### 稀缺循环：欲望陷阱

- 家乡拉斯维加——这个城市对稀缺大脑的影响，就像梵蒂冈对天主教的影响一样。
- 在这个城市提供的一切中，似乎没有什么比老虎机更能触发稀缺大脑的了。拉斯维加斯不是建立在赢家身上。它是建立在那些人们一遍又一遍玩的、发出叮当声、闪烁着光芒的机柜中的旋转轮上，最终对他们有害。
- 老虎机无处不在——不仅在拉斯维加斯赌场内，还在加油站、杂货店、酒吧、餐厅和机场航站楼。人们在一天中的各个时段玩这些老虎机，一玩就是几个小时。它们在美国每年创造超过300亿美元的收入，相当于每个美国人每年大约100美元。这比我们在电影、书籍和音乐上的消费总和还要多。并且这个数字每年增长约10%。
- 探索老虎机成瘾机制时，发现了一个被他称为"稀缺循环"的关键行为模式：
- 这就好像有一些更大的行为模式在起作用...几乎像一个稀缺循环。我甚至开始称呼我注意到的这种模式为'稀缺循环'。它是节制的连环杀手。
- 稀缺循环由三个部分组成：

1. **机会**：首先是机会，获得可以改善我们生活的有价值事物的机会。但这个机会伴随着风险。我们可能会得到有价值的东西，如金钱、财产、食物，甚至地位。但我们也可能不会，甚至可能会失去它。
2. **不可预测的奖励**：稀缺循环的第二阶段是不可预测的奖励。日常行动的奖励是可预测的。十年的研究表明，这些可预测的奖励可能是乏味的。另一方面，不可预测的奖励则不是。如果我们知道我们会收到奖励，但不确定何时，我们会被吸引进去。我们等待看此刻是否会带来好东西时，会经历一种令人兴奋的、充满悬念的焦虑。我们的大脑聚焦于不可预测性。
3. **快速可重复性**：稀缺循环的第三阶段是快速可重复性。大多数日常行为都有明确的开始和结束，我们不会立即重复它们。我们有痒处，我们抓痒，痒处消失了。或者我们的手很脏，我们洗手，手变干净了。我们没有理由几秒钟后再次抓痒或洗手。稀缺循环则可以立即重复。我们看到机会，有时获得奖励，然后再做一遍。随心所欲。

- 这些是行为落入稀缺循环的三个条件：机会、不可预测的奖励和快速可重复性。
- 托马斯·曾塔尔："有一个叫做最优刺激模型的模型。它说动物和我们人类有一个我们喜欢的刺激水平。当它低于那个水平时，我们寻找刺激。我们发现，如果鸽子有更像野外生活的替代形式的刺激，它们选择赌博游戏的可能性似乎会减少很长一段时间。"
- 鸽子在某种程度上认识到它们拥有足够的东西。它们得到了所拥有的满足，渴望更少，不想逃入稀缺循环。这种对满足的认识，在人类文明中却越来越稀缺。

# 二、稀缺循环无所不在无处可逃

### **稀缺循环遍地都是**

- **社交媒体**：循环明显使社交媒体"运作"。发帖给我们提供了提升社会地位的机会，每个通知都感觉像旋转轮子的不可预测性。我们得到了赞或评论或私信吗？有多少？
- **电子邮件**：循环存在于我们的电子邮件中，创造一个不可预测的悬念时刻，我们可能会收到好消息、坏消息或只是一般的消息。
- **购物**：亚马逊Prime提供的快速、强迫性重复性是一回事。但与新应用如Temu相比，这算不了什么，Temu是一个类似赌场的在线商店，直接从中国工厂向消费者销售商品。
- **个人理财**：像Robinhood这样的流行新股票交易应用正在利用更多的不可预测奖励和更快的可重复性。
- **移动赌博**：我们不再需要去赌场玩老虎机或赌体育的障碍和停顿。赌场就在我们口袋里。
- **电视**：Netflix的自动播放功能大幅增加了观看时长。而YouTube的自动播放算法则会将我们引入越来越极端和极化的视频。
- **健康**：稀缺循环正在改变我们的健康习惯。WHOOP活动追踪器等设备通过给用户不同的每日"恢复分数"和"压力分数"，利用不可预测奖励的悬念。
- **约会**：约会应用是利用循环驱动行为和利润的绝佳案例。以Tinder为例，它使向左或向右滑动变得流行，并彻底改变了不仅仅是约会应用，还有所有领域的应用。
- **视频游戏**：研究人员现在有一个术语来描述赌场技巧被视频游戏世界窃取的现象。他们称之为"赌博转向"。
- **零工工作**：优步等零工经济公司正在"参与行为科学的非凡幕后实验，以操纵司机为其公司增长服务"。
- **新闻**：稀缺循环的元素存在于我们24/7的全方位新闻环境中。媒体学者表示，2016年之前的政治新闻有点像无聊的老式老虎机，而之后的政治新闻则更像雷德的老虎机。
- 平均每个人现在花费11到13小时使用数字媒体——在手机、电视、电脑等上。
- 但这些只是稀缺循环存在的最新场所，技术专家正在编程它来操纵我们的行为。
- 记住，稀缺循环是古老的。研究人员在一些最具影响力的机构中发现了循环，如我们现代的食品、医疗和教育系统。

### 为什么我们渴望更多

- 在我们渴望的一切中，人类大脑倾向于不断添加而非减少。麻烦总是找到足够的食物。为了提高我们的生存几率，我们的大脑开发了优雅的机制，比如稀缺循环，帮助我们在搜索中坚持。
- 莱迪·克洛茨是弗吉尼亚大学的科学家和工程学教授，他研究设计的大问题以及设计如何改善世界和我们在其中的体验。克洛茨通过一个简单的乐高积木实验来展示了人类的"添加偏见"。
- ——当物品丰富时，我们倾向于用更多物品来解决任何问题。添加和购买。我们更有可能按照广告所说的那样使用物品，因为一定有一些其他小工具我们可以购买来解决我们的问题。
- 人类是社会动物，我们进化来警惕地争夺地位，担心别人对我们的看法，并经常作为对他人的反应来思考和行动。直到最近，影响力还是一门软科学。衡量我们的社会地位，或者与他人相比我们的表现如何，或者我们的行动是好是坏，都很难。然后，每个人都通过互联网连接起来，我们可以量化影响力。
- 研究表明，当我们开始感到有机会获得地位和影响力时，我们开始更加重视它，并做更多事情来获得它。无论是在社交媒体上发帖还是在他人周围以某种方式行为，我们都会看到机会，采取行动，等待不可预测的奖励，然后重复。稀缺循环。
- 哈佛计算认知神经科学实验室的研究员汤米·布兰查德将人类称为"信息食客：寻找和消化信息的生物，就像食肉动物狩猎和吃肉一样。
- 传统媒体于1833年开始转变信息格局，当时本杰明·戴创办了一份报纸并意识到他的"产品"不是他的报纸或新闻，而是他的读者和他们的注意力，这可以出售给广告商。为了获取更多读者，他将报纸价格降至其他报纸的六分之一，并开始刊登更多负面故事：混乱、谋杀、欺骗、盗窃、愤怒、伤亡、丑闻等。
- 这开始了我们现在生活的注意力捕获和信息经济。从那时起，就一直有一场军备竞赛，利用我们对信息的渴望来捕获我们的注意力。今天，仍有大约90%的新闻是负面的。
- 随着广播、电视和最终互联网的到来，信息洪流大幅增加。媒体程序员学会媒体可以"拥有"人们的日子，不断给他们提供信息。
- 一些学者估计，在一天内，我们现在接触到的信息比十五世纪的人在一生中遇到的更多。其中大部分利用稀缺循环使我们感到自我正义、愤怒、快乐、悲伤或正确——所有这些都是为了让我们看广告。
- 这种信息过载影响我们的生活质量。研究人员在英国发现，网络大脑已经以三种方式改变了我们的思维：它伤害了我们集中注意力的能力，我们已经将一些记忆卸载到云端，它正在改变社交互动。

# 三、应对稀缺的策略：人类要保留主动权

### 摆脱循环：找回平衡

面对稀缺大脑的挑战，有方法可以帮助我们找回生活的平衡。

- **食物**：研究表明，像Tsimane人的饮食般简单而多样的饮食可以带来显著的健康益处。Tsimane人的饮食基础是白米饭、土豆、芭蕉等富含碳水化合物的朴素食物。这种饮食与流行的低碳水或高脂饮食不同，但他们拥有科学有史以来记录的最健康的心脏。
- 如果你给人类一块饼干——或者芝士汉堡或皇家蓝酸奶或注入了黄油和奶油并在上面涂有厚厚咸味肉汁的土豆泥——我们会吃更多更多的那些食物，直到我们变胖并死于心脏病。如果你给人类配有一些浆果的普通酸奶——或者普通土豆、瘦肉或米饭——我们会吃恰好足够的那些食物。我们不太可能陷入食物稀缺循环。
- **物品**：从泽拉那里学到了一种思考消费的新方式："装备，而不是物品"。物品是为了拥有而拥有的财产，经常用来填补情感冲动或向社会宣传我们是某种类型的人。而装备有明确的目的，帮助我们实现更高的目的。
- 装备，另一方面，有明确的目的，帮助我们实现更高的目的。
- 这种方法击中了我们可以摆脱稀缺循环的所有三种方式。它带走了无意识购买的机会、不可预测的奖励和快速重复性。一个项目提供的机会转变为更有意义的东西。而泽拉的装备是她保存在背包中的物品——不是太多，也不是太少，而是实用的物品，使她陷入有益循环，锻炼她的身体和思想，并导致深度满足。
- 对于我们其他人，'装备，而不是物品'可以帮助我们稍微接近拥有我们自己的隐喻背包，装满引导我们生活得更投入和有意义的物品。即使我们的背包是一座房子。
- **创新从限制中来**：研究表明稀缺环境实际上可以促进创造力和问题解决能力。伊利诺伊大学和约翰霍普金斯大学的科学家发现，面临资源稀缺的人往往能提出更多更好的解决方案。
- 在所有六项研究中——所有六项！——面临稀缺资源的参与者表现更好。他们想出了更多的砖块用途。他们的玩具最有趣。他们变成了像麦克盖弗一样的人。总的来说，稀缺组不仅提出了更多的解决方案，而且他们的解决方案也更高效和创造性。
- **信息消费**：汉克是谷歌地图和谷歌地球的开发领导者，后来创立了Niantic公司，开发了Pokémon Go等将人们引导到户外的应用程序。
- 这些应用程序促使人们更多地活动身体和探索他们的环境。伦敦经济学院的科学家研究了Pokémon Go的崛起如何影响抑郁率，他们写道："我们认为Pokémon Go的推出，一个鼓励户外身体活动、面对面社交和接触自然的移动游戏，可能会减轻玩游戏的用户的非临床形式的轻度抑郁。"
- **幸福的新定义**：马修神父解释，真正的幸福来自于接受生活的戏剧性，尝试做对的事，关注更大的事物而不是自己的即时满足。
- 如果你专注于你和你的幸福，你首先会压垮他人，你会摧毁你自己的幸福。我们变得幸福的方式是忘记自己并爱上帝。
- 虽然这种宗教观点并不适合所有人，但核心思想是将注意力从自己转向更大的目标和服务他人。研究一致表明，金钱、权力、声望等"世俗"快乐通常不会导致持久的幸福。例如，美国人从1975年到1999年并没有变得更快乐，尽管他们根据人均GDP变得更富裕了43%。
- 我们对一切我们进化来渴望的东西的涌入与我们的工业幸福综合体——关于幸福的痴迷和推动幸福——使我们感觉好像任何不是纯粹幸福的日子都是有问题的，并引导我们追求错误的东西。

### 从稀缺到丰富：重新设计生活

从稀缺思维转向丰富思维的框架：

1. **意识到稀缺循环的存在**：识别你生活中稀缺循环的领域是第一步。无论是食物、购物、社交媒体还是信息消费，了解这些模式如何运作可以帮助你有意识地改变行为。
2. **接受限制的价值**：克洛茨的研究表明，限制实际上可以促进创造力和效率。我们不需要总是添加更多物品、食物或信息；有时减法解决方案更有效。 "人类系统地忽视减法，如果人们考虑加法或减法，然后选择加法，那是一回事。但如果人们甚至没有考虑这个减法的基本选择，那就是一个大问题。这可以说是关于我们如何改变和使事情变得更好的最基本问题。我是添加，做更多，还是删除，做更少？我们发现人们系统地忽视减法和做更少的选择。"
3. **重新定义消费**："装备，而不是物品"的思维方式可以应用于多个领域。问问自己每次购买是否真正有目的，是否支持更大的目标。
4. **培养深度参与**：不管是通过自然活动、创造性工作还是精神实践，寻找能将你带入有益循环而不是稀缺循环的活动。 "虽然稀缺循环的负面影响似乎很明显，但也有积极的循环，像泽拉用她的寻找鹿角做的那样或者汉克用Pokémon Go做的那样。许多自然活动将我们推入循环。例如，钓鱼、观鸟、收集岩石等都模仿稀缺循环。"
5. **追求意义而非短暂幸福**：真正的满足感来自于服务于比自己更大的事物，建立持久的关系，以及寻求使生活有意义的经历，而不仅仅是短暂的愉悦。 也许幸福是一场漫长而艰难的没有明显目的地的戏剧性努力。地形崎岖，天气并不总是完美的。这是一次踏入深渊的漫步。但在某个时刻，通过试图使每一步都不那么关于我们的即时欲望，我们意识到我们是快乐的，尽管旅程还没有结束。

- 摆脱稀缺循环的三种方式之一是机会消失，二是奖励停止流入，三是重复减慢。当我们做出重大改变时，新的更吸引人的机会可能会打开，而这些机会带有自己的一系列不可预测的奖励。这些新奖励超过了药物使用带来的短期舒适。
- 通过学习识别和管理稀缺循环，我们可以开始重新设计我们的生活，使其更加平衡、有意义和可持续。这不是关于完全消除我们的欲望或回到原始生活方式，而是关于在丰富的现代世界中更加有意识地选择我们的行为和习惯。
- 在这个前所未有的丰富时代，我们有幸能够超越纯粹的生存需求，探索更深层次的满足和意义。通过认识到我们不是我们欲望的奴隶，而是可以选择如何回应稀缺提示的智慧存在，我们可以找到一种新的方式来驾驭我们天生的稀缺大脑，使其为我们的长期福祉服务，而不是被它控制。
- 稀缺大脑不会消失。但我们可以学会与它相处，就像我们学会与其他进化遗留下来的特征相处一样。通过意识、选择和有意识的实践，我们可以创造一种更加平衡的生活方式，既享受现代丰富的好处，又不陷入它可能设置的陷阱。
