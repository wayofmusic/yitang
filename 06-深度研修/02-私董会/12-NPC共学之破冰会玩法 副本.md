# 活动一、暖场小设计    5min

请用天气来形容最近的心情

# 活动二：画布寄情    10min

所有伙伴在画布上画出能代表自己的图案

双击下面的画布，左侧可以选择图形，也可以选择自由画笔。

# 活动三、正式介绍    10min

- 你的昵称：希望别人如何称呼你？可以但不限于网名/小名/代号……
- 你的画作: 你画的什么？为什么用这个来代表自己？
- 你的趣历: 独一无二的经历（一句话介绍）
- 你的助力: 遇到什么问题可以来找我\~（可以提供的认知和资源）
- 你的期待：对本次破冰会体验的期待\~

# 活动四、用卡牌做自我介绍    10min

玩法：请从下面的卡牌中选择一种动物来代表你自己，为什么选择这张？

场景：想象你本打算去马尔代夫的一个小岛度假，结果遇到暴风雨，最后自己飘到了一个海岛上，荒无人烟，你可以选择一种动物和你一起，你会选择什么动物？

# 活动五、深度连接工具：我眼中的我vs他人眼中的我    15min

玩法：从下面的卡牌中选一张代表自己，为什么选择这张卡牌？

从下面选择一张卡，心里记住这个卡牌下面的字母，然后看着卡牌，如果这个代表他人眼中的你，那是什么样？

# 活动六、深度连接工具：生命风暴与黄金时刻     15min

生命风暴玩法：从卡牌中选择一张卡牌，代表你生命中曾经经历的风暴，那时候发生了什么，是什么支持你走出那个风暴？你从哪个风暴中学习到的是什么？

黄金时刻玩法：从卡牌中选择一张卡牌，代表你生命中曾经经历的黄金时刻，那时候发生了什么，你做对了什么让这个时刻可以到来？你发现了自己怎样的优点？
