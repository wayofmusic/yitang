# 一堂S级**私董会价值**

## **一堂私董会缘起**

一堂同学，相互梳理创业问题，落地一堂核心认知和方法论，少走弯路，少踩坑。是国内少有的，从当事人出发，自下而上，根据早期创业者需求迭代而成的私董会。

### **一堂私董会特点**

不同于市场上很多私董会，不是团体心理咨询，不是心灵培训，不是专家问诊，不是企业教练流量转化课，不是高端人士才能参加的会所，不下挖原生家庭，不涉及夫妻关系，不涉及玄学哲学

#### **三个坚持：**坚持商业、坚持问题导向、坚持建设性激发。

同学一起解题：一些有经验的人提问、分析，一起找到真问题，探究建设性解法

消除业务盲区：快速被推向绝望之谷，找到问题，然后重新出发

真实案例学习：私董会是一个相互学习，彼此激发，增进关系的活动

#### **原则：**真实、开放、互助、进步、求同、存异、专业、探究

#### **目的：借真修真、借假修真、借缘修缘、借缘修果**

#### **核心任务：出口式咨询**（找出口、换视角、探解法）

#### **关键词：平等对话**（真诚倾听、代入用户、一堂接口、尊重公理、有敬畏心、克制答案、主动提问、引导思考、避免对抗、友好探讨）

# 私董会SOP

接下来三个月，请大家把群设置置顶，并修改群昵称哦

私董会流程：

1. 会前（CEO主要负责）

   1. 提前一周确定下期案主/主持人/笔记官
   2. 至少提前3天确定私董会主题，案主提交五步法画布等，其他成员确认是否可以按时参会，统计人数
   3. 提前1天确认所有参会人员有认真阅读案主提供的项目信息，保证认知对齐
   4. 笔记官负责建私董会文档，并帮助案主将前期项目背景资料整理进文档
2. 会中（私董官主要负责）

   1. 班规（只是建议，需要大家一起共建）

      1. 全员幕僚，没有特殊情况不设旁听
      2. 参会成员最好打开摄像头，保证全程参与
      3. 如已接龙参会但临时不能参与的需提前1天请假，临时无法到场需要发鸽子红包
   2. 活动流程

      1. 主体流程参考私董会模板（在附件里）
      2. 每次都是飞书会议，官方会统一建立直播间
      3. 建议大家更换背景

      1. 每次活动开始时可以有个简单破冰
      2. 每次结束安排全员总结
      3. 每次活动结束时案主需制定To Do List，并选择需不需要监督小组的支持，设定Check Point
   3. 私董官的自我修养

      1. 带领破冰
      2. 控制时间
      3. 控制话题方向
      4. 控制现场情绪
      5. 确保活动有产出
3. 会后（笔记官主要负责）

   1. 当期班委和案主一起复盘
   2. 笔记官整理文档，发回放
   3. (监督案主完成TD)
   4. Check Point 跟进案主问题解决情况，如需进一步解决可申请专家库外援
