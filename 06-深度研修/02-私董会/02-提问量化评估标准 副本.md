# 提问量化评估标准 副本

### 表格一：幕僚提问质量量化评估标准 (0-5分)

**使用说明：** 私董官可针对幕僚提出的**每一个关键问题或一系列问题** 进行打分，也可以在一轮提问结束后进行综合评分。该表格的核心目的是诊断提问的质量，并为改进提供依据。

| **测评维度** | **评分** | **详细描述与判断标准** |
|-|-|-|
| **开放性 (Openness)** | **0** | **命令/建议式：** 完全不是问题，而是伪装成问题的建议或评判。 (例：“你难道不应该去…？”) |
|  | **1** | **封闭/诱导式：** 只能用“是/否”回答，或问题本身已强烈暗示了“正确”答案。 (例：“你是不是因为A才导致B的？”) |
|  | **2** | **基础开放式：** 典型开放式问题，能获取基本信息，但深度有限。 (例：“你接下来打算做什么？”) |
|  | **3** | **高度延展式：** 能打开一个全新的、广阔的思考空间，激发无限可能性。 (例：“如果这个问题是你人生给你的一个礼物，那份礼物会是什么？”) |
| **启发性 (Inspiration)** | **0** | **产生困惑：** 问题让案主更加混乱，或完全偏离主题。 |
|  | **1** | **重复确认：** 只是让案主重复已知信息，未带来任何新视角。 (例：“所以你的意思是…对吗？”) |
|  | **2** | **引发联想：** 促使案主将已知信息进行新的组合或思考。 (例：“你刚才提到的A和B之间，是否存在某种被忽略的联系？”) |
|  | **3** | **颠覆认知 (Aha! Moment)：** 彻底挑战了案主的底层假设或心智模式，使其看到问题的全新维度，常常引发案主的长时间沉默或惊叹。 |
| **目标相关 (Goal Relevance)** | **0** | **完全无关：** 问题服务于幕僚自己的好奇心或议程，与案主目标毫无关系。 |
|  | **1** | **擦边球式：** 与主题有微弱关联，但并未触及核心，对达成目标帮助甚微。 |
|  | **2** | **直接相关：** 问题紧密围绕案主提出的议题和期望目标。 |
|  | **3** | **精准聚焦：** 不仅相关，而且直指达成目标的最关键障碍或最重要的驱动力，每句话都像在剥洋葱的核心。 |
| **未来导向 (Future Orientation)** | **0** | **沉溺过去/指责：** 问题不断纠结于过去的错误和责任，让案主陷入负面情绪。 (例：“当初为什么会犯这种错？”) |
|  | **1** | **分析过去：** 以中立的态度了解过去，为未来做铺垫，但停留时间过长。 |
|  | **2** | **连接未来：** 从过去的经验中提取智慧，并明确地将其与未来的行动联系起来。 (例：“从那次失败中，你学到了什么可以用在未来？”) |
|  | **3** | **创造未来：** 完全聚焦于未来的可能性、愿景和解决方案，激发案主的创造力和能动性。 (例：“假设你已经成功了，请描述一下那是一个怎样的画面？”) |
| **方法论相关 (Methodology)** | **0** | **无章法：** 提问逻辑混乱，不成体系。 |
|  | **1** | **套用表面：** 生硬地使用某个模型或术语，但未理解其精髓。 |
|  | **2** | **有效应用：** 能够清晰地运用某个方法论（如GROW、冰山）的框架进行提问，逻辑清晰。 |
|  | **3** | **内化于心：** 已将方法论内化，提问时自然流露，不着痕迹，但逻辑严谨、层层递进，展现出深厚的专业功底。 |
| **私董会价值观 (Values)** | **0** | **违背价值观：** 提问方式带有炫耀、评判、不真诚或破坏性的意图。 |
|  | **1** | **基本遵循：** 态度基本中立，但缺乏深度关怀和推动成长的力量。 |
|  | **2** | **良好体现：** 提问展现了**真实** （敢于提问）、**互助** （利他）和**开放** （好奇）的态度。 |
|  | **3** | **完美践行：** 提问是**真实、开放、互助、成长** 四大价值观的完美结合体。既有直指核心的勇气，又有激发成长的智慧和温度。 |

### 表格二：案主回答质量量化评估标准 (衡量提问效果)

**使用说明：** 此表格用于评估案主的回答，其分数高低\*\*直接反映了幕僚提问的有效性\*\*。一个5分的回答，通常是由一个5分的提问所激发的。

| **测评维度** | **评分** | **详细描述与判断标准** |
|-|-|-|
| **目标出口相关度 (Outcome Relevance)** | **0** | **回答导致偏离：** 案主的回答将话题引向了与目标完全相反或无关的方向。 |
|  | **1** | **原地踏步：** 回答是重复信息或表达困惑，没有向目标迈进。 |
|  | **2** | **有所进展：** 回答提供了新的信息、澄清了事实或形成了一个初步的想法，离目标更近了一步。 |
|  | **3** | **实现突破：** 回答本身就是一个关键的里程碑，案主明确了下一步的关键行动、做出了一个重要决策或找到了问题的根本解法。 |
| **是否拓展盲区 (Blind Spot Expansion)** | **0** | **强化固有认知：** 回答在不断地为自己已有的观点找理由，认知更加固化。 |
|  | **1** | **触及但回避：** 案主似乎意识到了什么，但很快又退回到自己的舒适区。 |
|  | **2** | **承认新视角：** 案主明确表示“我之前没这么想过”，或开始用新的角度复述自己的问题。 |
|  | **3** | **产生新认知：** 案主清晰地表达出一个对自己过去思维、行为或信念的全新洞察。这是一个“看山不是山”到“看山还是山”的认知飞跃。 |
| **情绪是否正向 (Emotional Shift)** | **0** | **负向固化：** 回答后，案主的情绪变得更加负面（如愤怒、防备、沮丧、抗拒）。 |
|  | **1** | **迷茫/无力：** 案主表现出更多的困惑和无力感，能量水平下降。 |
|  | **2** | **平静/中立：** 案主的情绪从焦虑或激动变得平静，进入理性思考状态。这是一个必要的过程。 |
|  | **3** | **正向转化：** 案主的情绪能量有显著提升，从“卡点”（Stuck State）转向“资源状态”（Resourceful State），表现为更开阔、更有希望、更坚定、更有力量。 |

【分数0】：完全封闭问题，仅需“是/否”或固定选项回答，无法引导案主拓展表达；示例：“您遇到的问题是资金不足吗？”“您接下来会选择A方案吗？”
【分数1】：封闭问题，但附带1个简单拓展方向，仍以固定回应为主，拓展性极弱；示例：“您的问题是资金不足吗？还是有其他小问题？”
【分数2】：半开放问题，可引导案主表达，但局限于单一维度，无法覆盖多视角；示例：“您当前遇到的资金问题具体体现在哪些环节？”（仅聚焦“资金”单一维度）
【分数3】：开放问题，可引导案主多维度表达，但深度不足，未触及细节；示例：“您推进项目时遇到的核心障碍有哪些？”
【分数4】：高开放问题，引导案主多维度表达，且包含“细节追问”倾向，能推动案主具体说明；示例：“您推进项目时，内部团队配合和外部资源对接方面，分别遇到了哪些核心障碍？能举1个例子吗？”
【分数5】：极致开放问题，引导案主多维度、深度表达，且关联“自身感受/认知”，激发案主主动思考；示例：“您推进项目时，从‘问题现象’到‘背后根源’，觉得内部团队、外部资源、自身决策三个层面分别有哪些关键障碍？这些障碍让您最困扰的点是什么？”<h3>2. 启发性维度</h3>
【分数0】：无任何启发，提问预设标准答案，限制案主思考（本质是“灌输式提问”）；示例：“您应该按照行业通用方法解决，对吧？您觉得这个方法没问题吧？”
【分数1】：轻微启发，提问有“非标准答案”倾向，但未引导案主突破固有认知（仅浅层次拓展）；示例：“除了行业通用方法，您还想过其他简单办法吗？”
【分数2】：基础启发，提问引导案主“换1个视角”思考，但未关联案主实际场景（视角单一）；示例：“如果从‘用户需求’而非‘自身成本’角度看，您觉得这个问题有不同解法吗？”
【分数3】：中度启发，提问引导案主“多视角结合实际场景”思考，能触动案主初步反思；示例：“您之前从‘成本’角度考虑，若结合‘团队能力’和‘用户反馈’这两个您企业的实际情况，会发现哪些新的解题思路？”
【分数4】：高度启发，提问引导案主“关联过往经验/他人案例”思考，推动案主认知升级；示例：“您过往解决类似问题时，有哪些经验可以复用？若参考XX同行（与案主业务相关）的做法，会调整您当前的思路吗？”
【分数5】：极致启发，提问引导案主“从‘问题本身’到‘自身成长’”思考，激发案主主动探索本质；示例：“这个问题反复出现，您觉得背后反映了您在‘决策逻辑’或‘团队管理’上需要提升的地方是什么？找到这个点，对您未来应对同类问题有什么帮助？”<h3>3. 目标相关维度</h3>
【分数0】：完全偏离私董会议题目标，提问与案主核心诉求/会议主题无关；示例：会议目标是“解决案主团队流失问题”，提问“您企业的产品研发进度如何？”
【分数1】：严重偏离目标，仅与目标有“极弱关联”，需案主强行关联才能回应，无实际价值；示例：会议目标是“解决团队流失”，提问“您团队成员的学历结构如何？”
【分数2】：部分偏离目标，与目标有“间接关联”，能关联到目标，但无法直接推动问题解决；示例：会议目标是“解决团队流失”，提问“您团队的绩效考核周期是多久？”
【分数3】：基本贴合目标，与目标有“直接关联”，能推动问题分析，但未聚焦核心痛点；示例：会议目标是“解决团队流失”，提问“您团队成员离职时，反馈的主要原因有哪些？”
【分数4】：高度贴合目标，聚焦“目标核心痛点”，能直接推动问题拆解，且覆盖关键分析方向；示例：会议目标是“解决团队流失”，提问“您团队中‘核心员工’和‘新员工’的离职原因有差异吗？分别聚焦在‘薪资’‘发展空间’‘工作氛围’哪块？”
【分数5】：完全贴合目标，聚焦“核心痛点+解决方案导向”，不仅拆解问题，还关联目标落地；示例：会议目标是“解决团队流失”，提问“您团队核心员工离职的核心原因是发展空间不足，那结合您企业未来1年的业务规划，如何调整晋升机制来针对性解决这个问题？”<h3>4. 未来导向维度</h3>
【分数0】：完全聚焦“过去/当下”，无任何未来视角，仅回顾历史或描述现状，不涉及未来规划；示例：“您团队过去半年流失了多少人？”“您现在的薪资体系是什么样的？”
【分数1】：提及“未来”，但仅为“简单时间提及”，无具体方向，无法引导案主规划；示例：“您未来会考虑调整薪资吗？”“以后您打算怎么管团队？”
【分数2】：聚焦“未来单一维度”，有基础规划倾向，仅覆盖1个未来方向，深度不足；示例：“您未来3个月，打算如何优化团队的薪资结构？”
【分数3】：聚焦“未来多维度”，有明确规划方向，覆盖2-3个未来方向，能引导案主初步梳理；示例：“您未来3个月，在‘薪资调整’和‘晋升通道’两方面，打算分别采取哪些行动来减少流失？”
【分数4】：聚焦“未来中长期+风险预判”，规划有落地性，覆盖多维度，且考虑未来可能的障碍；示例：“您未来半年，从‘薪资’‘发展’‘氛围’三方面优化团队，过程中可能遇到‘成本超支’或‘员工不认可’的问题，您会提前做哪些准备？”
【分数5】：聚焦“未来中长期+成长关联”，规划与案主/企业成长绑定，不仅解决问题，还关联长期能力提升；示例：“您未来半年优化团队的行动，如何与‘您自身的管理能力提升’‘企业的人才梯队建设’结合？这些行动能为企业未来2年的扩张打下什么基础？”<h3>5. 一堂方法论相关维度</h3>
【分数0】：完全无方法论支撑，提问无任何逻辑框架，仅随意发散，无法引导案主结构化思考；示例：“您觉得这个问题该怎么弄？”“您还有什么想说的？”
【分数1】：提及“单一方法论关键词”，但无实际应用，仅提方法名称，不引导案主结合场景使用；示例：“您用过‘SWOT分析’吗？这个问题能用吗？”
【分数2】：结合“单一方法论”引导，但未拆解步骤，引导案主用方法，但不明确如何落地分析；示例：“您可以用‘SWOT分析’看这个问题，您觉得有哪些优势和劣势？”
【分数3】：结合“单一方法论+步骤拆解”引导，能推动案主结构化分析；示例：“您用‘SWOT分析’拆解这个问题：第一步先列‘自身优势’（比如团队经验），第二步列‘外部机会’（比如行业政策），您先说说优势有哪些？”
【分数4】：结合“多个方法论联动”引导，覆盖问题分析全流程，用2个以上方法，形成分析闭环；示例：“您先通过‘SWOT’明确自身优劣势和外部机会，再用‘5W1H’（who/what/when/where/why/how）拆解具体行动，比如‘who负责推进机会落地’？”
【分数5】：结合“方法论+案主适配性”引导，推动案主内化方法，不仅用方法分析，还帮案主调整方法适配自身场景；示例：“您之前没怎么用‘SWOT’，我们可以简化：先列‘对您来说最关键的1个优势’和‘最紧急的1个威胁’，再结合您企业‘小而灵活’的特点，调整分析重点，您觉得哪个优势最关键？”<h3>6. 私董会价值观（真实/开放/互助/成长）维度</h3>
【分数0】：完全违背价值观，打断案主、否定案主感受、预设负面结论，封闭且无互助倾向；示例：“您这思路肯定不对，别浪费时间了”“我早就说过您的问题在管理，您还不承认？”
【分数1】：轻微违背价值观，表面开放，实则有预设，不关注案主真实痛点；示例：“您应该是管理上有问题吧？说说您怎么管错的？”
【分数2】：基本符合价值观，不违背，但仅浅层次体现，无主动互助/成长引导；示例：“您真实的痛点是什么？说说看，我们听听”
【分数3】：符合价值观，主动关注真实痛点、保持开放，有基础互助引导；示例：“您刚才提到‘不敢说真实问题’，没关系，我们这里很开放，您说说最困扰的点，大家可以帮您出出主意”
【分数4】：高度符合价值观，深度挖掘真实痛点、完全开放无预设，有明确互助行动；示例：“您说‘担心成本问题被笑话’，其实很多案主都遇到过，您具体说说成本压力在哪，XX案主（同行业）之前有类似经验，稍后可以帮您对接”
【分数5】：极致符合价值观，挖掘痛点本质、开放包容，互助+成长双导向；示例：“您表面说成本问题，其实背后是‘怕决策失误’的担忧吧？没关系，我们一起拆解：先帮您对接有经验的案主，再一起梳理‘如何降低决策风险’，慢慢提升您的决策信心”<h2>二、案主回答测评维度评分标准</h2><h3>1. 目标出口相关度维度</h3>
【分数0】：完全偏离目标，回答与私董会议题目标/幕僚提问方向无关，无任何关联点；示例：会议目标是“解决团队流失”，幕僚问“离职原因”，案主回答“我们产品卖得很好”
【分数1】：严重偏离目标，仅1个极弱关联点，核心内容与目标无关；示例：会议目标是“解决团队流失”，幕僚问“离职原因”，案主回答“离职的人里有个销售，他之前卖产品很厉害”
