# 为什么视频号今年热度飙升？

微信早在抖音崛起之前就是流量平台顶流。为什么今年大家又开始关注微信？

判断标准是竞争是否充分。

1. **当年的公众号就是抖音的现在：**

公众号流量卷到最后ROI 降低；短视频平台对用户粘性更高，创作者都转移到了短视频平台。

1. **现在的视频号就是当年的抖音：**

现在视频号的客单更高、ROI更高、退货更低；创作者数量远小于抖音。

1. 还有一个原因是微信的天然优势，**社交属性**。我们继续往下看。

# 为什么在视频号上要做成交型IP？

## 什么是视频号成交型达人 IP？

1. 获取用户信任
2. 给用户提供需求价值
3. 影响粉丝购买决策
4. 给路径引导成交

## 视频号的优势是什么？

我们先回溯互联网上三大成交路径。

1. **搜索：需求-触点-信任**

eg：饿了，去楼下便利店买方便面，选了一款牌子，完成购买。

**代表平台：**淘宝（大而全）、京东（3C）、拼多多（极致性价比）

> 先有需求，再去触点搜索，然后选择信任的购买。

1. **内容：触点-需求-信任**

eg：刷抖音刷到一个卖衣服短视频，小姐姐试穿很好看，用户评论很好，下单。

**代表平台：**抖音（兴趣）、小红书（精致生活）

> 先逛触点，被激发出需求，然后选择信任的购买。

1. **社交：信任-需求-触点**

eg：你跟闺蜜喝下午茶，闺蜜聊到刚去过泰国旅游，住的酒店特别舒服，你年底要跟老公出去玩，就要来了酒店名字，去酒店官网预定了一个海景房。

**代表平台：**微信（熟人）

> 先有信任，突然有了需求，被引导到触点去成交。

在微信上做流量生意，信任是原点，是成交型 IP 天然的活跃场。微商、大健康、培训一直就没停过。

当微信生态条件适宜的时候，创作者回归微信，利用视频号做成交型 IP 是必然的。

## 抖音和视频号做号有什么区别？

1. 视频号不像抖音、快手、 B 站、小红书，显示粉丝量。

   1. IP 账号不会因为关注的多，形成大 IP 。
   2. but！在微信生态：IP+微信私域=超级 IP
2. 抖音是公域逻辑，雷军、罗永浩、董宇辉是超级 IP ，不论是为企业发声，还是直播带货，越大越好做。
3. 微信是天然的私域场，维护好私域的用户，就可以深度服务，做到公域比不了的 ROI 。

   1. 你可以把视频号、公众号、微信群的触点打通，直播效率要比公域流量平台高太多了。

> 张小龙：视频号的目的不是造神，而是让中小商家吃上饭。

## IP 必备五项基本能力

**金字塔IP模型：**

1. 需求：底面积，拆推平算。扎不扎实？够不够吃？
2. 知识力、形象力、标签力、背书力是骨架、支柱。

   1. 形象力：

      1. 符合身份：

      1. 好识别：

      <sheet sheet-id="d4ehqh" token="FIi1siL7UhxoLMtE1qncag3mnxP"></sheet>

      1. 独特：差异化是快速脱颖而出的法宝，but！不要让用户对你失去信任。你是行业 IP 达人，不是网红。
   2. 知识力：

      1. 理论：实事求是
      2. 模型：五步法
   3. 标签力：

      1. 封杀一个领域：从 top one 到 only one
      2. 观众印象：罗永浩（较真、段子手、脾气爆）、董宇辉（有文化、被打压）、雷军（实干、北京现金王、谦卑）
      3. 风险点：人设就是标签，人设塌方塌的就是标签。
   4. 背书力：讲自己的故事、客户的故事、行业的故事

      1. 案例：最硬的背书
      2. 荣誉：比赛名次、事件（中国渔船撞日本军舰保卫钓鱼岛）
      3. 资源：人脉、实体资源、资金
      4. 资质：生产资质、文化资质（非遗、老字号）
      5. 口碑：点评
   5. 传播力：如何获取流量
